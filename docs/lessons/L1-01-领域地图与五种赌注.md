## 1. 直觉：为什么需要一张地图

L0-00 和 L0-01 回答的是「**怎么做**」：官方给了什么数据，什么才算一次合法提交。但「怎么做」有一类问题它永远答不了：

- 有人贴出一篇新论文，说他们在跨细胞背景预测上刷新了指标。**你该不该花两周去复现？**
- 你手上有一个能跑到 −0.04 的控制基线和一个声称能到 +0.3 的方法。**这个差距是真的还是评分噪声？**
- 官方六项指标里，有一项你一直在丢分。**是该换模型，还是该换验证方式？**

这些问题的答案不在任何单篇论文里，而在**这个领域同时存在的几套互相竞争的思想**里。它们是对同一个经验事实的不同回应。知道它们各自在赌什么，你才能判断一篇新论文是「在已经封顶的地方又刷了 0.01」还是「打开了一条新路」。

这类知识通常被称为「领域地图」或者「研究品味」。它的成本极低——不需要 GPU，只需要把已经评估过的材料读成一张图——但对判断力的回报最高，而且它会**反过来告诉你该选哪条 L2 深潜路线**。

### 1.1 先说那个经验事实

五种赌注不是凭空的分类，它们都是对下面这一个事实的回应。这个事实是整个任务最硬的一块地板：

> **扰动效应几乎不跨细胞背景迁移。**
>
> 参赛者 Ilyes Baali 报告：同一细胞类型、不同状态之间（例如 CD4 静息 vs 刺激）的效应一致性在 **0.25–0.33** 量级；而**不同细胞类型之间塌到 0.016–0.037**。该作者认为这是理解整个任务最重要的一个数字。

`[P1]`，**参赛者自报，尚未复核**。这个数字来自他对若干公开 CRISPRi screen 的二次分析，本仓库没有复现；在把它当作量化依据之前，必须回到他引用的原始 screen 重算。`[S?]`

但它指出的**定性**结论与多条独立证据方向一致，所以下面按「工作假设」使用：

1. 同一扰动在不同细胞里造成的响应，只有很小一部分是共享的；
2. 剩下的绝大部分是**背景特异**的，且这部分目前没有任何方法能可靠地从对照细胞推出（见 §3.2）；
3. 而官方评分恰恰奖励特异分量——只预测共享效应，等于在评分表上主动放弃大头。

### 1.2 关键区分：这个任务要的到底是什么

把三种不同的目标混在一起，是读这领域论文时最常见的误判来源：

| 目标 | 问题 | 谁在做 |
|---|---|---|
| **目标发现** | 这个基因被压低后，哪些基因显著变了？ | 差异表达分析、生物学家的日常工作 |
| **幅度预测** | 这个扰动会把表达拉低多少？ | 幅度建模、效应表路线 |
| **分布生成** | 给出这个背景 + 这个靶点，400 个细胞的**计数矩阵**长什么样？ | 本赛要求的那一种 |

本赛要的是第三种。它包含了前两种，但**额外要求细胞间的变异结构**——这正是「把 400 个细胞预测成完全相同的一行」会拿到约 −0.81 的原因。任何只服务前两种目标的方法，在本赛上都只能算半成品。

## 2. 五种赌注

*图：五种赌注都是对同一个经验事实的回应。本图由 `.agents/skills/archify` 生成（light 模式 / 简体中文）；交互版见 `output/figures/L1-01-five-bets.html`，图源规格见 `docs/style/sources/L1-01-five-bets.architecture.json`。*

下面逐个展开。每个赌注都按同样的六项说明：**核心假设 / 代表工作 / 输入输出形态 / 成本 / 天花板判据 / 在本赛合同下的缺口**。

---

### 2.1 赌注一：效应迁移

**核心假设。** 扰动效应本身（而不是背景）是可迁移的。只要把多个公开 screen 的效应取加权平均得到一张「效应表」，再把它乘到目标背景的对照细胞上，就能预测新背景的响应。

**代表工作。**
- 参赛者两步流水线：先跨 screen 构造加权效应表，再乘到目标背景对照细胞上重采样。作者自己明确说明这**「不是细胞模型」**，它只是绕开了「建模目标状态」这一步。`[P1]`（参赛者自报）
- 响应幅度路线的独立证据：Shoeibi 与 Yousefi 报告四个确定性响应幅度特征的线性/树模型优于他们测试的 MLP 编码器，并主张幅度与方向应分开建模。

**输入输出形态。** 输入是一张 `扰动 × 基因` 的效应矩阵 + 目标背景的对照细胞；输出是一个伪批量 delta 或直接采样出的细胞。**不显式建模目标背景**。

**成本。** 五种赌注里最低的一档。全部可在 CPU 上完成，训练过程基本上就是加权求平均。

**天花板判据。** 这个赌注的上限由 §1.1 那个数字直接封顶：如果效应只有 0.016–0.037 能跨类型迁移，那么无论效应表做得多精细，可迁移的那部分就只有这么多。**它的失败模式不是「拟合不足」，而是「信息不存在」**——再多的算力也换不来。

**在本赛合同下的缺口。** 它能满足原始计数合同（通过重采样），但必然在「生物效应线」上受限。它的正确位置是**基线**，不是主模型：它便宜、稳定、可解释，用来给复杂方法划一条「如果打不过它就别做了」的线。

**证据等级。** 参赛者自报 `[P1]`；幅度结论为 arXiv 预印本 `[P]`，终点是 log Anderson-Darling 距离，不是本赛六指标。

### 2.2 赌注二：条件化生成

**核心假设。** 不需要假设效应可迁移。直接把问题写成学一个条件分布 `p(细胞表达 | 背景, 扰动)`，让模型自己从大规模数据里找出哪些信息该共享、哪些该特异。

**代表工作。**
- **State**：结合状态嵌入与集合层面（cell set）的状态转移模型，从大规模观察性与扰动单细胞数据中学习跨情境扰动效应。**本项目的实施主线**，也是官方推荐背景模型。
- X-Cell：在大规模 CRISPRi Perturb-seq 汇编上训练扩散语言模型，融合文本、蛋白、网络、依赖性和形态学先验。
- 同类还有 MORPH（DepMap 共必需性向量作为连续扰动描述的条件生成模型）。

**输入输出形态。** 输入是目标背景的对照细胞集合 + 靶点（可以是基因名、序列或先验向量）；输出是**一族**细胞的表达分布，而不是一个均值向量。

**成本。** 高。这是本赛三种主流路线里最贵的一档，训练需要真正的多卡/大显存资源。

**天花板判据。** 这个赌注的真正难点不是容量，是**它必须区分三种「零」**：

| 情形 | 含义 | 模型该怎么处理 |
|---|---|---|
| 未测 | 这个细胞的这个基因没被测到 | 应该被模型当作缺失 |
| 测得零 | 测到了，计数就是 0 | 应该被当作真实的低表达 |
| 生物学关闭 | 基因真的不表达 | 应该被当作信息 |

把前两者混为一谈，模型就会学到「零就是零」的平凡规律，在稀疏矩阵上看起来指标不错，实际什么都没学到。**这是判断一个条件化生成模型是否真的学到东西的第一道检查。**

**在本赛合同下的缺口。** 需要做的不多：State 本身就在这套任务形式上设计。真正的缺口在输出端——官方合同要的是 18,533 基因的**原始整数计数**，而多数条件生成模型在 `log1p` 或 HVG 子空间上训练。

**证据等级。** State 已正式发表于 Cell（Adduri, Gautam, Bevilacqua et al., 2026），并已发布多个预训练检查点 `[P]`；X-Cell 为 bioRxiv 预印本，且**当前没有可下载的权重或数据**（只有占位页），因此不能作为可运行路线。

### 2.3 赌注三：分解式

**核心假设。** 响应可以被**拆开**：`响应 = 共享分量 + 扰动特异分量 + 背景特异分量 + 交互分量`。如果每一块都有自己的结构和可预测性，那就应该分别建模、分别验证，而不是端到端堆容量。

**代表工作。**
- **perturbation-decomposition**（Molina 与 Zhang）：把 CRISPRi 伪批量响应分解为全局、扰动特异、细胞系特异和 `扰动 × 细胞系` 交互四个分量，并分析各分量的可预测性。
- **AdaPert**：从 STRING 蛋白互作图为每个靶基因选择稀疏、扰动特异的子图，用三个损失（全局重建、非 DEG 稳健惩罚、DEG 响应对齐）减少「均值塌缩」。
- **C3TL**：把同一扰动在多背景的伪批量效应聚合成扰动表示、把同一背景中多种已测扰动聚合成背景表示，再用轻量解码器组合——报告与 State 相近或更好，训练 epoch 约快 30 倍、显存约 2.1 GB。

**输入输出形态。** 通常工作在**伪批量**上，输出一组分解后的分量或 delta，而不是单细胞计数。

**成本。** 中等。分解后的分量往往可以用 Ridge / MLP 这类轻量模型拟合。C3TL 报告的 2.1 GB 显存意味着本地 GPU 在原理上是够的。

**天花板判据。** 三个问题，按顺序问：

1. **分解可识别吗？** 如果把四个分量加起来能还原原矩阵，但每个分量单独看都没有生物学含义，那这个分解只是换了种写法，没有增加信息。
2. **分解可验证吗？** 能不能设计一个实验，让某个分量单独变化？如果不能证伪，就不是科学主张。
3. **目标背景的交互分量从哪来？** 这是最要命的一环。

**在本赛合同下的缺口。** 第 3 点是决定性的。Molina 与 Zhang 自己发现：**纯零样本方法无法恢复 `细胞系 × 扰动` 交互分量**，只有把目标背景约 30% 的真实扰动加进训练后才改善。而本赛的 D/E/F **没有任何扰动真值**，只有 NTC。

`[P]` 原文实证，不是本项目的推断。

这意味着分解式路线在本赛上只能拿到「共享分量 + 部分背景模板」这一半，交互那一半**在合同层面就不可得**。要改用这条路线，必须找到不依赖目标背景扰动数据的交互估计方式——这本身就是一个开放问题。

**证据等级。** 三篇均为预印本或未同行评议版本 `[P]`，且 C3TL 的作者仓库只有 README 与 LICENSE、没有实现代码。

### 2.4 赌注四：表征预训练

**核心假设。** 先在海量单细胞数据上学一个**通用细胞表征**（embedding），再把它迁移到扰动预测上。表征里应该已经编码了「细胞状态」和「基因功能」，下游任务只需要一个轻量头。

**代表工作。**
- scGPT：3,300 万细胞上生成式 Transformer 预训练，联合学基因与细胞表征。
- Stack：在 1.49 亿个人类单细胞上用表格注意力学上下文相关表征，让无标签上下文细胞在**推理时充当示例**。
- scBaseCount：用 AI Agent 工作流统一处理公开 10x 原始读取，构造跨物种、跨组织的标准化计数资源（提供**数据**，不直接提供扰动标签）。
- AIDO Cell：具备持久细胞状态、连续扰动、分支轨迹、多尺度多模态读出的通用模拟器，v1.0 提供 K-562 与 Hep-G2 原型。

**输入输出形态。** 表征本身是细胞的稠密向量；下游可以是任意任务。Stack 的形态特殊——它把「示例细胞」也当作输入的一部分。

**成本。** 高。这些模型的预训练规模从数千万到上亿细胞。

**天花板判据。** 这一条最反直觉，也是本课最该记住的一条：

> **在本任务上，大规模预训练表征的收益经常是负的。**
>
> - Ahlmann-Eltze、Huber 与 Anders 在 Norman 双扰动与 Adamson、Replogle K562/RPE1 上，将 5 个单细胞基础模型与 GEARS、CPA，以及无变化、均值、加性、低秩线性基线比较：**没有一个深度模型稳定优于相应的简单基线。** 他们的进一步发现是关键——使用**另一细胞系 Perturb-seq 学得的扰动表示**可以提高线性模型，而**观察性单细胞预训练表示的收益则有限**。
> - Csendes 等在 Adamson、Norman、Replogle K562/RPE1 上比较 scGPT、scFoundation 与均值、Elastic Net、kNN、Random Forest：**训练集均值优于两个基础模型**；带 GO 或文本基因特征的 Random Forest 进一步提高。他们还指出常用数据的扰动间方差偏低会放大 benchmark 误读。
> - PerturBench 在六个扰动数据集上统一比较匹配式、解耦式与简单基线模型，报告**没有一种架构在所有数据上占优**；数据规模增大时，简单 Latent Additive 或 Decoder-Only 模型往往比复杂 VAE 更稳。

三组独立工作，同一方向。这不是「基础模型没用」，而是：**扰动任务需要的不是「细胞长什么样」的表征，而是「扰动会改变什么」的表征。** 观察性图谱里没有扰动信息，学得再好也不补上这一块。

**在本赛合同下的缺口。** Stack 与 State 并列被官方 FAQ 允许用于比赛（参赛使用代码视为 Non-Commercial Purpose，仍须遵守适用代码许可；商业参赛者使用预训练权重需相应商业许可）`[S2]`。但本项目首投**暂不依赖 Stack**，这是实施优先级决定，不是法律判断。

**证据等级。** 三条基准结论来自同行评议原文（Nature Methods、BMC Genomics）与 arXiv v4 `[P]`。

### 2.5 赌注五：世界模型 / 动力学

**核心假设。** 与其预测「某个时刻的表达」，不如学**状态转移**本身：给定当前细胞状态和一次干预，预测下一个状态。这样模型原则上可以迭代、可以处理连续干预、可以推广到训练中没见过的组合。

**代表工作。**
- AlphaCell：以全基因组潜在空间、知识丰富的解码器和条件流匹配统一建模连续细胞状态转移。
- Lingshu-Cell：以掩码离散扩散直接学约 18,000 个基因的转录组状态分布，在身份和扰动条件下生成细胞；公开 MIT 代码与 85M 检查点。
- 概念框架：VCWM roadmap 把虚拟细胞世界模型定义为「维护细胞状态、结合生物与观测上下文、按干预执行状态转移」的系统，并用三个实验区分「表征 ≠ 动力学、预测 ≠ 干预、多模态 ≠ 多尺度」。

**输入输出形态。** 状态空间 + 转移算子；输出是下一个状态分布。

**成本。** 最高，且成熟度最低。

**天花板判据。** **目前在本任务上没有可复核的正收益证据。** 具体来说：

- AlphaCell 使用离散的、已学习的 perturbation ID，**不能预测训练中未见的靶点**——而本赛 D/E/F 的靶点正是未见的；
- Lingshu-Cell 的 H1 实验使用**同一背景**的 150 个监督扰动，词表为 18,080 基因，不能证明匿名新背景；
- VCWM roadmap 的三个实验是**动机性诊断，不是完整领域 benchmark**。

**在本赛合同下的缺口。** 缺口太大，不足以在限期内跨越。本项目的处理方式是把这条路线留在**视野内但不投入**：理解它的判据，在 L2 附录里保留一页纸模型卡，等赛后或明年的任务形式变化时再回来看。

**证据等级。** 均为预印本或技术报告 `[P]`；AlphaCell 无公开代码或权重。

### 2.6 五种赌注速查

| 赌注 | 一句话假设 | 成本 | 天花板判据 | 本赛可用性 |
|---|---|---|---|---|
| 效应迁移 | 效应比背景更可迁移 | 极低（CPU） | 跨类型一致性 ≈0.02，信息本身不足 | 可作基线，不可作主模型 |
| 条件化生成 | 直接学 `p(表达 \| 背景, 扰动)` | 高 | 能否区分「未测」与「测得零」 | **主线**，输出端需适配 |
| 分解式 | 响应可拆成可分别建模的分量 | 中 | 交互分量在 NTC-only 合同下不可得 | 部分可用，交互那一半封死 |
| 表征预训练 | 通用细胞表征可迁移到扰动任务 | 高 | 基准显示常不敌线性基线 | 需要专门消融才能证明价值 |
| 世界模型 | 学状态转移而非某时刻表达 | 最高 | 本任务上尚无任何可复核证据 | 观察，不投入 |

## 3. 失败与噪声：三条比「选哪条路线」更要紧的判断

地图告诉你有哪些路。下面三条告诉你走路时会撞到什么——它们都是**坑**，不是路线：口径不一致会让你比较不可比的数字，零样本条件比看起来更严会让你把泄漏当成能力，平凡基线的胜利会让你的消融顺序从第一步就走错。

### 3.1 三个控制基线的负分口径不同，不可互换

「控制基线」听起来是个客观参照物，但公开材料里有三个被反复引用的数字，它们的**定义完全不同**：

| 报告者 | 基线定义 | 分数 |
|---|---|---|
| Ilyes Baali `[P1]` | 输出 400 个**完全相同**的细胞，均值正确 | 约 **−0.81** |
| Forrest Sheldon `[P4]` | 直接采样对照细胞 | 总分 **−0.304**，其中 DE 方向保真度 **−1.721** |
| 本项目文档 | 作者 H1 benchmark control baseline | 约 **−0.04523**（待本机复现） |

三者任务、背景、评分版本都不同。**把它们并列在一张表里比较是错的。**

但它们共同指向同一件事，而且这件事比任何单个数字都重要：

> **本地必须先建立自己的噪声地板，否则无法判断任何改进是真实提升还是评分噪声。**

−0.81 和 −0.045 之间的差距不是「谁的方法好」，而是「在问不同的问题」。你要用它来判断自己的模型，就必须**自己测一遍**——那是 [`L1-02`](L1-02-证据基线与噪声地板.md)的核心任务。

### 3.2 「零样本」这个条件比看起来更严

本赛的设定是：D/E/F 只给你对照细胞（NTC）和目标列表，**没有任何扰动真值**。

注意这不只是「没有标签」这么简单。把两条证据放在一起看：

- Molina 与 Zhang 发现纯零样本方法**无法**恢复 `细胞系 × 扰动` 交互；给目标背景 30% 真实扰动后才有改善 `[P]`。
- AdaPert 的跨细胞系实验（三个细胞系训练、整个 K562 留出）中，直接跨细胞系 Perturb Mean 在 Pearson-delta 上仍强于该模型 `[P]`。

也就是说：**交互分量是背景特异的、可被测量的、但目前没有免费的估计方式。** 任何声称「零样本解决了交互」的方法，都值得你去问一句「你的目标背景扰动数据是从哪来的」。

反过来，这条也界定了**合理的期望**：在 NTC-only 条件下，能可靠拿到的只有「共享分量 + 由 NTC 推得的背景模板」。如果某个方案声称的分数远超这个范围，先怀疑泄漏，再怀疑评分口径。

### 3.3 平凡基线为什么常常赢：本项目该按什么顺序做实验

把 §2.4 的三条基准结论抽象一下，会得到一个可迁移的判据：

**当信号的方差主要来自「共享分量」时，能把共享分量估计准的简单模型就会赢。**

均值基线之所以强，是因为在「未见扰动」的设定下，扰动间方差本身偏低（Csendes 等专门指出了这一点）——此时预测均值已经吃掉了大部分可解释方差，复杂模型额外拟合的多半是噪声。**PerturBench 的 rank 指标**就是用来诊断这件事的：如果多个不同扰动被预测成几乎相同的响应（mode collapse），平均误差可能还行，rank 指标会立刻暴露。

这条判据直接决定了本项目的消融顺序（[`L2-05`](L2-05-实验方法-消融与证伪设计.md)）：

```
无变化 → 均值 → 加性 / 低秩线性 → 跨背景 target-effect → 复杂模型
        ↑                                        ↑
   必须先跑到这里                      每一步都要证明自己超过了前一步
```

**每一步都要证明自己超过了前一步**——不是「超过了无变化」，而是超过了**紧邻的**那一步。

## 5. 对模型的影响

本课不改变任何接口或损失，但它改变**你评估一个方案时的顺序**：

1. **先问它属于哪种赌注**，再看它的数字。同一张表里比较「条件化生成」和「效应迁移」的成绩是没有意义的——它们解决的问题不同。
2. **先问它的天花板判据在哪**，再看它在哪个数据集上跑得好。效应迁移路线在 K562 上跑到 0.9 也不能改变 0.02 的跨类型上限。
3. **先问它的目标背景信息从哪来**，再看它是不是「零样本」。这一条能过滤掉绝大多数在本赛上不可用的方案。
4. **先测噪声地板**，再判断改进。这一条在 `L1-02` 落地。

## 7. 诊断题

**题。** 你读到一篇新论文，摘要如下（本节内容为构造的教学情景，不是某篇具体论文）：

> 我们提出 PertX，一个基于（此处省略架构细节）的模型。我们在 Replogle K562 上训练，在 RPE1 上评估跨细胞系泛化，取得了比 State 更好的 Pearson-delta。为模拟真实零样本场景，我们在评估时**用目标细胞系的 5% 扰动数据做了 few-shot 适配**。此外我们在 HepG2 和 Jurkat 上也报告了一致的改进。

请回答三个问题：

1. **它属于哪一种赌注？** 依据是哪一句？
2. **它能不能直接用到本赛？** 如果不能，缺的是什么？
3. **即使它能用，你还需要额外知道哪两件事**，才能判断它是否真的超过了本项目的现有方案？

<details>
<summary>参考答案（先自己写，再展开）</summary>

**1. 赌注归属。** 它**自称**是条件化生成（因为要与 State 比，且谈的是跨细胞系泛化），但它的**实际做法**混合了分解式的成分：用目标细胞系的扰动数据做 few-shot 适配，本质上是在估计「背景特异 + 交互」那一部分。**注意这两者的区别很重要**——论文的定位是它的营销，它的目标背景信息来源才是它的实质。

**2. 能否用到本赛。** 不能直接用。关键的判据句是「**用目标细胞系的 5% 扰动数据做了 few-shot 适配**」。本赛 D/E/F 只提供 NTC，**没有任何目标背景的扰动真值**，因此这个适配步骤在合同层面无法执行。这也正好是 §3.2 那条判据的实例化。可以保留的是它不含该步骤的部分（主干架构、损失设计），但那时它报告的改进幅度已经不适用了。

**3. 额外需要知道的两件事。**（任答两点即可，关键是意识到「比 State 好」这个表述本身不构成证据）

- **协议是否干净**：它的「跨细胞系评估」有没有把 RPE1 的扰动数据泄漏进训练（例如预训练语料就包含 RPE1，或超参是在 RPE1 上选的）。跨背景验证最容易被这一步污染，见 [L3-02](L3-02-公开扰动数据与跨背景验证.md)。
- **指标口径**：Pearson-delta 是**一个**指标，而本赛有六项，其中三项依赖差异表达集合。历史上有模型在均方误差上赢、在 DE 方向保真度上输。
- **噪声地板**：改进幅度如果只有 0.01 量级，在没测过噪声地板之前无法判断是否真实。见 [`L1-02`](L1-02-证据基线与噪声地板.md)。
- **输出空间**：它在什么空间上评估（HVG？`log1p`？2000 基因？）。本赛要 18,533 基因原始计数，3,352/5,000 HVG 上的结果不能外推。

</details>
