## 1. 它赌什么

**它属于 [L1-01](L1-01-领域地图与五种赌注.md) §2.2 的「条件化生成」赌注**，并且额外押了一注「表征预训练」（SE 分支）。核心假设是一句话：

> 不需要假设「效应可迁移」。把问题写成学一个条件分布 `p(细胞表达 | 背景, 扰动)`，让模型自己从大规模数据里找出哪些信息该共享、哪些该特异。

State 把这个假设拆成了三个更具体的赌：

| 赌 | 具体内容 | 如果赌错了会怎样 |
|---|---|---|
| **赌集合比均值信息多** | 扰动响应不是一个均值向量能描述的；同一批细胞里有细胞周期、状态比例、扰动效率造成的**残余异质性**，必须让细胞之间互相看见才能建模 | 直接对伪批量均值建模就够了，8 层自注意力白花钱 |
| **赌规模与多样性** | 1.67 亿观察性细胞 + 超过 1 亿扰动细胞的规模，足以让「跨背景」这件事从数据里涌现，而不需要显式的背景特征工程 | 跨背景迁移的上限由数据的背景多样性封顶，加数据无效 |
| **赌不必配对** | 可以用集合级的分布距离当训练目标，从而绕开「同一个细胞扰动前后各测一次」这个生物学上做不到的事 | 训练信号被离散度项主导，单细胞精度学不到 |

论文为第一和第三个赌给了消融证据：在 Tahoe-100M 上，**增大集合规模会显著改善验证损失，直到一个最优点**（256 个细胞最优）；把自注意力换成平均池化（伪批量版）或把集合大小设为 1（单细胞版）都明显更差；移除自注意力性能下降。[P1]

### 1.1 什么时候它一定会输

三条，都是结构性的，不是调参能救的：

1. **目标背景里唯一可用的信息是 NTC。** 本赛给 A/B/C 的只有非靶向对照和靶基因名字。如果某靶点从未出现在预训练的 one-hot 词表里，它的靶点嵌入就是「没学过的位置」——模型能接收它，不代表模型知道它在该背景里的作用。
2. **真实效应小于噪声地板。** 集合自注意力是一个高容量模块，当待学信号小于抽样噪声时，它会非常乐意去拟合噪声。[L1-02](L1-02-证据基线与噪声地板.md) 测出的本机地板是判定这件事的唯一阈值：改动前后分数差不超过地板，就不算改进。
3. **它必须区分三种「零」**（[L1-01](L1-01-领域地图与五种赌注.md) §2.2 的天花板判据）：未测、测得零、生物学关闭。State 在 `log1p` 空间上训练、末端走 `ReLU`，这条链路上「零」的语义是被压过的，本赛的稀疏计数合同要求你在输出端重新处理它（见 [L3-03](L3-03-单细胞原始计数生成.md)）。

## 2. 输入输出契约

### 2.1 张量形状

论文把输入写成四个张量（[P1] 式 12），源码里对应 `state_transition.py` 的 `forward()` 取 `batch["pert_emb"]`、`batch["ctrl_cell_emb"]`、`batch["batch"]`，目标取 `batch["pert_cell_emb"]`（[S1]）：

| 张量 | 形状 | 含义 |
|---|---|---|
| `X_ctrl` | `B × S × G` | 对照（NTC）细胞集合，每个细胞一个 `G` 维表达向量 |
| `Z_pert` | `B × S × D_pert` | 扰动嵌入；**同一集合内所有细胞共享同一个** |
| `Z_batch` | `B × S × D_batch` | 可选的批次嵌入（本赛无此列） |
| `X_target` | `B × S × G` | 监督目标：同背景同靶点的真实扰动细胞集合 |

其中 `B` 是集合的个数（不是细胞数），`S` 是每个集合的细胞数（`cell_set_len`），`G` 是基因数。**一个细胞是一个 token**——这是理解整个模型的钥匙。

### 2.2 三套维度，别合并成一句话

| 量 | 已发布权重 `ST-HVG-Replogle/zeroshot/jurkat` | 当前源码默认 `model=state` | 本赛 2026 合同 |
|---|---|---|---|
| 输入基因 `G_in` | 2,000（`X_hvg`） | 全基因（18,533） | 18,533 |
| 输出基因 `G_out` | 2,000 | 18,533（`output_space=all`） | **18,533 原始整数计数** |
| 集合大小 `S` | 64 | 512 | 每靶点 400 个细胞 |
| `hidden_dim` `d_h` | 328 | 768 | — |
| 层数 | 8 | 8 | — |
| heads / `head_dim` | 12 / 64 | 12 / 64 | — |
| FFN `intermediate_size` | 3,072 | 3,072 | — |
| 靶点维 `D_pert` | 2,024（one-hot） | 由数据词表决定 | 300 个本次靶点，且**未见** |
| 批次维 `D_batch` | 56（`gem_group`） | `batch_encoder=false` | 官方未给批次列 |
| 输出空间 | `log1p` 浮点（HVG） | `log1p` 浮点（全基因） | **非负整数 counts** |

左两列都是官方事实（[S1][S2]），但它们**不是同一个模型**。下面这些话是错的：「State 是 328 宽的」「State 每个集合 64 个细胞」「State 输出 2,000 个基因」。每次引用都要说明用的是哪一套。

### 2.3 一个反直觉的细节：注意力宽度 ≠ hidden

`hidden_dim=328` 的配置里，`num_attention_heads=12`、`head_dim=64`，于是 `q/k/v` 把 328 投影到 `12 × 64 = 768`，`o_proj` 再降回 328。**注意力内部宽度是 768，主干残差流是 328。**

这直接给出一条操作规则：**不要为了「能整除」擅自把 head 数改成能整除 328 的值。** 投影后的宽度由配置决定，不是由 `hidden_dim / heads` 推出来的。复制父配置的真实结构，比套用一般 Transformer 的经验规则可靠（[S2]，与架构图事实边界文件一致）。

### 2.4 与比赛的四个接口差

1. **基因轴**：2,000 或 6,546 都不足 18,533，两端线性层必须换（§7）。
2. **集合长度**：训练时 `S=64`，比赛每靶点要 400 个细胞。推理可以多次分组、处理尾组后精确保留 400 行；**权重张量的形状与 `S` 无关**（模型无位置编码），所以这不是「能不能加载」的问题，而是「行为会不会变」的问题——论文报告集合大小会影响验证损失。
3. **输出类型**：模型输出的是 `log1p` 空间的浮点，经 `ReLU` 后非负；合同要原始整数计数。这是另加模块，不是改损失函数（[L3-03](L3-03-单细胞原始计数生成.md)）。
4. **靶点表示**：one-hot 2,024 覆盖预训练见过的扰动；本赛未见靶点需要连续表示（ESM2 等），这时 `pert_encoder` 的输入层要换。

## 3. 架构：逐层说清每个模块在解决什么问题

`forward()` 的完整路径（[S1]，行号对应 commit `9bbfe78` 的 `state_transition.py`）：

```text
pert  ── pert_encoder (MLP) ──────┐
ctrl  ── basal_encoder (Linear) ──┼─→ 逐元素相加 ─→ 8 层双向集合 Transformer ─→ 残差加回 ─→ project_out ─→ [ReLU]
batch ── batch_encoder (Emb.) ────┘
```

### 3.1 三个编码器：把三种信息压到同一个向量空间

- **对照细胞编码器** `basal_encoder`：`G → d_h`。**默认配置下它是一个单层 `Linear`，不是 MLP**——因为 `n_encoder_layers=1` 时 `build_mlp` 只返回 `nn.Linear`（[S1] `utils.py`）。论文写的是「采用 GELU 激活的四层 MLP」[P1]，**这是论文与已发布配置的一处真实差异**：预训练用的那组权重里，细胞编码器是一次线性投影。
- **靶点编码器** `pert_encoder`：`D_pert → d_h` 的 MLP。注意 `2,024 → 328` 是一次 6 倍压缩：one-hot 只有一位是 1，第一层实际上是在给每个靶点学一个 328 维的「查表」。
- **批次编码器** `batch_encoder`：`nn.Embedding(D_batch, d_h)`，仅在 `batch_encoder=true` 时创建（已发布权重是 true，源码默认是 false）。

**为什么是相加而不是拼接？** 论文式 (16) 给出 `H = H_cell + H_pert + H_batch`[P1]。相加把三个信息源放进同一向量空间等权叠加，模型必须自己学会把「我是哪个批次」「我被怎么扰动」「我现在什么状态」分开编码。代价是三者共享 `d_h` 个坐标：当 `D_pert = 2,024` 而 `d_h = 328` 时，靶点信息的容量被这个共享预算直接限制。

### 3.2 8 层双向集合 Transformer：整个模型的核心

三个决定，每一个都是为了「这是一个集合，不是一个序列」：

| 决定 | 源码实现 | 不这么做会怎样 |
|---|---|---|
| **双向注意力** | `LlamaBidirectionalModel` 覆写 `_update_causal_mask` 返回 `None`，并把 `config.is_causal` 和每层 `self_attn.is_causal` 都置 `False` | 用因果掩码的话，第 `i` 个细胞只能看见前 `i-1` 个，输出会依赖一个人为排列的细胞顺序 |
| **无位置编码** | `rotary_dim=0` / `use_rotary_embeddings=false`，并由 `NoRoPE` 把 `cos` 全置 1、`sin` 全置 0 | 位置编码会给「第 3 个细胞」一个固定身份，而集合里这个身份没有意义 |
| **没有 token 词表** | `get_transformer_backbone` 把 llama 的 `embed_tokens`（GPT2 的 `wte`/`wpe`）**权重置零并冻结**，模型只通过 `inputs_embeds` 接收输入 | 说明它真的只是拿 Transformer 当集合处理器用，不是语言模型 |

这三条合起来的结果是：**整个主干对细胞顺序置换等变**。打乱一个集合里细胞的顺序，输出会以完全相同的方式被打乱，集合整体的内容不变。这是「不配对」这个赌注在架构层的落地。

**自注意力在这里到底在学什么？** 不是「基因和基因的关系」（基因已经被压进 token 特征里了），而是**细胞与细胞之间的关系**：哪些细胞处在相似的状态、这个集合的状态组成是什么、扰动应该把哪些细胞推得更远。论文的消融显示移除自注意力会显著掉点 [P1]。

### 3.3 FFN：Llama 的 SwiGLU

`intermediate_size=3,072`，即每个 Transformer 层里是 `gate_proj / up_proj`（各 `d_h → 3,072`）加 `down_proj`（`3,072 → d_h`）三个矩阵。这是标准 Llama 前馈，State 没有改它。

### 3.4 残差加回：让模型只学「变化量」

`predict_residual=true`，但**两条路径的实现不同**，这是最容易读错的地方（[S1] `forward()` 502–511 行）：

```python
if self.predict_residual and self.output_space == "all":
    out_pred = self.project_out(res_pred) + basal      # 在基因空间加回原始对照表达
    out_pred = self.final_down_then_up(out_pred)        # G → G//8 → GELU → G
elif self.predict_residual:
    out_pred = self.project_out(res_pred + control_cells)  # 在隐空间加回对照嵌入
else:
    out_pred = self.project_out(res_pred)
```

- **HVG / 基因空间路径**：先把对照细胞的**隐空间嵌入**加回 Transformer 输出，再一起投影回基因空间。
- **全基因路径**：先投影回基因空间，再加回**原始对照表达** `basal`，然后过 `final_down_then_up`（`Linear(G→G//8) → GELU → Linear(G//8→G)`）。这个瓶颈结构用 `G/8` 的宽度强制压缩一次，参数量却因为两头的 `G` 而非常可观（见 §3.6）。

**为什么要残差？** 一个细胞有近两万个基因的值，扰动通常只改变其中一小部分。让 Transformer 直接预测完整的扰动后表达谱，等于让它先学会「重建一个表达谱」再学会「改变它」。改成预测残差，学习目标从「重建 18,533 个数」变成「预测其中变化的那部分」。

> **类比的边界。** 软件里这很像 diff/patch：只传变化量。但生物上并没有同一个细胞的「扰动前后两次快照」——这个 delta 是统计意义上的，不是对象意义上的。

**一个必须按源码而不是按配置读的点：** 末端实际调用的是 `ReLU`，不是配置里写的 `softplus`（`softplus: true` 在该路径未生效，[S1] 514–516 行）。判断条件是 `embed_key == "X_hvg"` 或 `embed_key is None`。所以：**按 YAML 读代码会读错激活函数**。

### 3.5 两套配置不能混用（重申）

`README` §8 的权威归属表和架构图事实边界文件都要求这一点。把两套数字写进同一句话，是本项目最容易犯的引用错误。

### 3.6 参数量：手算量级，不是实测

以下为**工程假设**（按矩阵形状手算，未在初始化时打印确认）：

| 配置 | 主干 8 层 | `final_down_then_up` | 三个编码器 | `project_out` | 合计可训练 |
|---|---|---|---|---|---|
| 328 / `G=2,000`（已发布） | ≈ 3,232 万 | 不存在 | ≈ 134 万 | ≈ 66 万 | **≈ 3,432 万** |
| 768 / `G=18,533`（源码默认） | ≈ 7,559 万 | ≈ 8,587 万 | ≈ 1,579 万 | ≈ 1,425 万 | **≈ 1.92 亿** |

1. **容易看走眼的一项：** 768 那一套里 `final_down_then_up`（8,587 万）比整个主干（7,559 万）还大。它只是 `G → G/8 → G` 两个矩阵，但因为两头都是 `G=18,533`，参数量随 `G²` 走。**这就是「换基因轴」的真正成本所在**，也是 §7 第 1 项为什么必须重训。

3. Llama 主干的 `embed_tokens`（词表 × `d_h`，默认 vocab 32,000 ⇒ 328 档约 1,050 万、768 档约 2,458 万）**会被分配但被置零并冻结**，不参与训练也不贡献梯度。上表未计入它。

## 4. 训练目标：为什么不能换成 MSE

### 4.1 它用的到底是什么

论文写的是 MMD（最大均值差异），核函数是 **energy kernel** `k(u, v) = −‖u − v‖₂`，通过 `geomloss` 实现 [P1]；源码对应 `SamplesLoss(loss="energy", blur=0.05)`（[S1]）。

两者是同一个东西：带 energy kernel 的 MMD 就是 **Energy 距离**，闭式形式为

```text
MMD²_energy(P, Q) = 2·E‖p − q‖ − E‖p − p′‖ − E‖q − q′‖
```

其中 `p, p′` 独立来自预测集合 `P`，`q, q′` 独立来自真实集合 `Q`。三项依次是：跨集合平均距离（要小）、预测集合内部离散度（要大）、真实集合内部离散度（要大）。

关键在**后两项是负号**：它们奖励两个集合各自「散得开」。这是它不会塌缩成均值的直接原因。

源码里 `loss` 可选 `energy`（默认）/ `mse` / `sinkhorn` / `se`，其中 `se` 是 `CombinedLoss = 0.001 × sinkhorn + 1.0 × energy`（[S1]）。**默认路径是纯 energy，不是组合损失。**

### 4.2 换成 MSE 会发生什么：四个后果

1. **MSE 要求配对。** `‖x̂_i − x_i‖²` 预设「第 i 个预测对应第 i 个真实细胞」。Perturb-seq 里这个对应不存在——测量会破坏细胞，无法先测一个细胞、扰动它、再测同一个细胞。这是 [L3-04](L3-04-State微调实战与算力预算.md) §1.3 讲的那件事，也是整个设计的起点。
2. **若强行按行配对，最优解是条件均值。** MSE 的最小值在预测等于条件期望 `E[x | 背景, 扰动]` 处取到。它会系统性地抹掉方差，把 400 个细胞压成「均值 + 零方差」。而 [README](README.md) §5 的三条成绩线里，**群体分布线**（总 UMI、检测基因数、方差、零比例、状态组成、基因间协同）直接看的就是这个。
3. **energy 距离不惩罚「哪个细胞对应哪个」。** 这是它的优点也是它的代价：它保证两群像，但不保证单细胞层面的协变结构对。所以计数生成必须作为独立模块来做，并单独审计（[L3-03](L3-03-单细胞原始计数生成.md)）。
4. **计算代价是 `O(S²)`。** 每个集合要算 `S × S` 对距离。`S=64` 是 4,096 对，`S=512` 是 262,144 对。源码的 `mmd_num_chunks` 是沿**特征维**切块（[S1] `_compute_distribution_loss`），不改变这个二次代价。这也是集合大小不能无限加大的原因之一（**工程假设**：二次代价的具体常数未实测）。

### 4.3 一个可手算的对照

取一维 toy（真实的 `G` 是 2,000 或 18,533，这里只为了让手算可见）。真实集合 `Q = {0, 2}`，两个候选预测：

- `P₁ = {0, 2}`（分布正确）
- `P₂ = {1, 1}`（塌缩到均值）

**情形 A：行序恰好对齐。** `MSE(P₁) = 0`，`MSE(P₂) = ((1−0)² + (1−2)²)/2 = 1`。MSE 选 `P₁`，看起来没问题。

**情形 B：行序被打乱。** 这正是 Perturb-seq 的实际情况——你拿到的 `Q` 与你的 `P` 之间没有对应关系，行序是任意的。此时 `P₁` 可能被配成 `(0↔2, 2↔0)`，`MSE(P₁) = ((0−2)² + (2−0)²)/2 = 4`，而 `P₂` 与行序无关，仍是 1。**MSE 转而偏好塌缩解**，并且偏好程度随真实方差增大而增大。

**Energy 距离不受行序影响**，因为三项都是对集合内所有配对取期望：

| 量 | `P₁` vs `Q` | `P₂` vs `Q` |
|---|---|---|
| `E‖p − q‖`（跨集合） | `(0+2+2+0)/4 = 1` | `(1+1+1+1)/4 = 1` |
| `E‖p − p′‖`（预测内部离散度） | `(0+2+2+0)/4 = 1` | `0` |
| `E‖q − q′‖`（真实内部离散度） | `1` | `1` |
| `D² = 2·E‖p−q‖ − E‖p−p′‖ − E‖q−q′‖` | `2 − 1 − 1 = **0**` | `2 − 0 − 1 = **1**` |

两种情形都得到 `0 < 1`，即 **energy 距离稳定地选 `P₁`**。差别来自中间那一行：`P₂` 把预测集合的内部离散度做成 0，丢掉了本该得到的奖励，于是被罚。

注意 MSE 在情形 A 与情形 B 之间会**翻转结论**，这不是「MSE 算错了」，而是它依赖了一个数据里不存在的前提（行对应）。同一份预测、同一个真值，换一个排列就换一个答案——这在 Perturb-seq 上是无意义的。

### 4.4 本赛口径下的含义

官方 `cell-eval2` 的 vcc2026 指标是**伪批量层面 + DEG 层面**的（[L3-01](L3-01-评分指标与离线评估.md)），也就是说官方评分本身不要求逐细胞配对。**在这一条上，State 的训练目标与比赛口径是对齐的。** 真正的分歧在两处：官方要原始计数（State 输出浮点 `log1p`），以及官方的 DEG 指标会检查个体基因的方向与幅度（energy 距离作为集合损失不会直接优化它）。

## 9. 诊断题

### 9.1 题一：换损失之后

你把 ST 的损失从 `energy` 换成逐细胞 MSE（`loss=mse`，其他不变）。训练后观察到：训练损失比之前更低，但生成的 400 个细胞彼此几乎相同。

1. 为什么 MSE 会更低？
2. 为什么这在本赛六项指标上会更差？
3. 这说明 energy 距离里的哪一项在起作用？

<details>
<summary>参考答案</summary>

1. **MSE 的最小值在预测等于条件期望处取到。** 真实细胞围绕均值分散，预测均值会同时减小所有行的平方误差；只要真实方差大于「模型能解释的方差」，塌缩解就是 MSE 的最优解。训练损失更低是**预期的，不是 bug**。
2. 本赛的 [README](README.md) §5 三条成绩线里，**群体分布线**直接检查总 UMI、检测基因数、方差、零比例、状态组成和基因间协同。塌缩解把方差做成 0，分布线全灭；DEG 线也会因为「没有细胞间变异就没有可检验的差异」而受损。另外六项官方指标里有分布层面的项（[L3-01](L3-01-评分指标与离线评估.md)）。
3. **energy 距离的后两项**——`− E‖p − p′‖ − E‖q − q′‖`。它们是负号，奖励两个集合各自散得开。塌缩解会把这两项变成 0（失去奖励），因此被惩罚。这正是「不能换 MSE」的机制层面原因，不只是「论文这么写」。

**额外一层**：即便你想「既用 MSE 又保留方差」，也解决不了配对这个前提问题——Perturb-seq 不存在逐细胞对应关系，行配对本身是无意义的。
</details>

### 9.2 题二：一句话里的两个错

有人说：「State 是 hidden 328、每个集合 64 个细胞、输出 2,000 个基因的模型。」给出**两个**这句话会出错的具体场景。

<details>
<summary>参考答案</summary>

场景一：**你用的是当前源码默认配置**（`model=state`）。它是 `hidden_dim=768`、`cell_set_len=512`、`output_space=all`，输出全基因 18,533。三个数字全错。

场景二：你用的是 `st-x-replogle-full/k562_0.99` 那组权重。它 hidden 是 328、set 是 64，但**输入/输出是 6,546 而不是 2,000**。「2,000」只属于 `ST-HVG-Replogle` 的 HVG 版本。

还有第三个更隐蔽的错：**「每个集合 64 个细胞」描述的是训练配置，不是推理时的硬约束。** 推理可以用不同的分组方式凑出 400 行，权重形状根本不依赖 `S`（没有位置编码）。把它当成硬约束，会让你误以为必须重训才能输出 400 个细胞。

**根因**：这三件事分属「模型结构 / 训练超参 / 数据轴」三个不同层面，被压进一句话就一定会丢主语。
</details>

### 9.3 题三：残差学习与噪声地板

`predict_residual=true` 让模型只学 delta。假设某靶点在某背景里的真实效应幅度**小于** [L1-02](L1-02-证据基线与噪声地板.md) 测出的本机噪声地板。这时残差学习会怎样？这对「要不要微调」意味着什么？

<details>
<summary>参考答案</summary>

模型会把噪声当成信号去拟合。因为残差分支是一个高容量模块，而监督目标（真实 delta）里信号部分小于噪声部分时，**拟合噪声是训练损失下降最快的方向**。表现通常是：训练/验证损失稳定下降，但指标不动甚至变差；不同随机种子给出方向不一致的 delta。

对微调的含义：**先量效应幅度，再决定要不要微调。** 判据用 L1-02 的地板——改动前后分数差不超过地板就不算改进。这也给出一条更便宜的顺序：先用 [L2-04](README.md) 那类平凡基线估计「这个靶点在这个背景里到底有没有可测效应」，只对幅度显著超过地板的子集做微调。把全部 300 个靶点一起丢进微调，等于用大规模算力去买一个无法判定的结论。
</details>
