# VC2026 课程索引与学习路线

> 本目录是 VC2026 的系统学习材料，**本文件是唯一入口**。课程是一条**线性路线**：8 门连续编号主线课（`00`–`07`）按课号顺序读，外加一份不占课时的附录。每个课位说清「读什么、跑什么、留下什么产物」，不绑定日期和每周投入。
>
> **课号规则：** 主线课用连续编号 `00`–`07`（State 主线）；附录课保留 `L<层>-<序号>` 层前缀（现为 `L2-06`）。2026-09-17 曾裁决全部用层前缀以避免插课改名；2026-09-18 第二轮合并把 15 门层前缀课收敛为 8 门主线课，层前缀只留在附录与历史指称里（对照表见[归档节](#归档课号对照表与附录说明)）。
>
> **证据分级必须显式。** 全教程统一三级标注：`[S#]` 官方事实（来自 `docs/Official-website/`）、`[P#]` 论文章节或原文（**未在本项目复现**）、**工程假设**（本项目设计，无外部证据）。三者不混写，也不把 `[P#]` 当作已验证结论。参赛者博客属于额外一级：**参赛者自报，待复核**。

## 3. 两种课，两套固定结构

### 3.1 因果单元 8 步

不把很多概念压进一篇超长说明。每课只讲透一个主要因果单元，按下面顺序展开：

1. **直觉解释**：先回答「为什么需要它」，不先抛公式；
2. **生物机制或数学对象**：解释量从哪里来、代表什么、不能代表什么；
3. **实验与数据流程**：逐步说明输入、实际操作、输出，以及每一步解决的问题；
4. **失败与噪声**：指出批次、测量、抽样、映射和实现会怎样制造假象；
5. **与 VC2026 的关系**：把知识落到 A–F、300 个目标、400 个细胞和六项指标；
6. **对模型的影响**：明确这个知识会改变哪个接口、特征、损失或验证方法；
7. **可复现实践**：产出脚本、表格或图，而不是只读概念；
8. **一道诊断题**：检查是否真的理解当前因果链。

软件类比只用于建立直觉（例如把数据合同类比为 API contract），但细胞状态不是固定配置，生物测量也不是确定性日志。每次类比都必须紧邻写出边界。

### 3.2 模型深潜 8 步

每课一个模型或一族模型，逐层拆到能复述其每个设计决策：

1. **它赌什么**：这个模型对「什么让扰动响应可预测」的核心假设是什么？对应 [第 06 课](06-其余路线全景.md) §1.3 的哪一种赌注？
2. **输入输出契约**：喂什么、吐什么、维度是什么、和本赛合同差在哪；
3. **架构**：逐层说明每个模块解决哪个问题，不用术语替换机制；
4. **训练目标**：损失函数为什么是它，它把什么当成噪声、什么当成信号；
5. **数据**：训练语料是什么、暴露了哪些背景和靶点（直接决定能不能用于干净验证）；
6. **官方代码怎么跑**：`references/` 下本地副本的入口、最小可运行命令、实测显存与耗时；
7. **在 VC2026 上的适配缺口**：要改哪几层、哪些权重可以迁移、哪些必须重训；
8. **诊断题**：给一个具体现象，问这是该模型的哪个假设失效。

第 6 步按算力裁决（见 §5）写到「本地可执行」为止；第 7 步是本项目真正的工作量所在。

## 4. 三条贯穿全程的成绩线

以后不再只保存一个总分。每次实验至少同时记录三条线：

### 4.1 生物效应线

目标基因是否下降？下游基因变化的方向和幅度是否合理？显著响应集合是否恢复？这一条主要连接差异表达和 delta 指标。官方六项指标会排除当前被扰动目标基因，因此「目标自身是否下降」只作内部生物 QC，不能直接抬高六项分数。

### 4.2 群体分布线

400 个细胞的总 UMI、检测基因数、方差、零比例、状态组成和基因间协同是否像真实群体？这一条防止把一个漂亮的伪批量向量冒充完整单细胞预测。

### 4.3 工程合同线

基因顺序、目标集合、context、计数类型、行数、稀疏项、内存、运行时间和随机种子是否正确？这一条不证明生物预测好，但任何一项失败都可能让好模型无法被正确评分。

## 5. 算力边界：哪些能实操，哪些只能读

本机 GPU 是 **RTX 3070 Ti Laptop，8 GiB 显存**。`docs/research/first-submission-plan.md` §1.1 已记录：「本机可用于编码和小型检查，**不承担正式训练**」。

按 2026-09-17 的算力裁决（**C 打底 + A 按需**）：

| 类别 | 内容 | 对应课 |
|---|---|---|
| **本地可实操**（教程必须给出能跑的命令） | 数据审计、评估回路、噪声地板测量、计数生成器、小批推理、CPU 侧消融、公开基准复现、论文里的小规模统计主张复核 | 第 03 课（评估与计数）、第 04 课（指标、地板与消融）、第 06 课（基线评分路径与分档判据） |
| **必须云端**（教程只给命令与预期资源，不要求产物） | 任何真正的 State 微调、全基因训练、多 seed 消融 | 第 03 课（微调部分）、第 07 课 |
| **纯阅读**（零算力） | 模型架构解剖、方法论、路线全景 | 02、05、06 |

这条边界必须在课里显式写出。**云端才能跑的内容不应强制要求产物**，否则教程会停在「跑不了」的地方。

## 6. 交付形态与写作约定

按 2026-09-17 的裁决：

| 项 | 要求 |
|---|---|
| **可运行 notebook** | **必选。** 每课至少一份，放在 `notebook/`，与课文互相引用 |
| **诊断题** | **必选。** 每课至少一道「读完能回答」的题，用来检验因果链是否真的建立 |
| **可复核产物**（表 / 图 / 脚本） | **条件性。** 只在本机可实操的课上强制要求；云端课不强制 |

其他约定：

- **配图。** 科研数据图用 `.agents/skills/nature-figure`；结构图与流程图（模型架构、系统架构、数据流、时序）统一用 `.agents/skills/drawio-skill`（light 配色、简体中文标签）。两者的产出按 [docs/style/README.md](../style/README.md) 的流程转 WebP 后放入本目录的 `assets/`，图源与 prompt 存 `docs/style/`。需要概念插画时可派子代理经浏览器用 ChatGPT 生成，prompt 取自 `docs/style/prompts/gallery-research-paper-figures.md`；**生成式图片只作解释性插画，不作机制或数据证据**。（archify 已于 2026-09-17 卸载，不再使用。）
- **不重复研究文档。** 模型课不复制 `docs/research/` 的内容。研究文档记录的是「本项目的决定和证据」，教材讲的是「这个领域的选择空间」。引用关系单向：**教材 → 研究文档**。
- **术语。** 首次出现给出中文、英文或缩写及一句话定义；权威定义在 [CONTEXT.md](../../CONTEXT.md)，别处只回指。
