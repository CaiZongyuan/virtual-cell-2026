## 1. 它赌什么

三条路线都属于 [L1-01](L1-01-领域地图与五种赌注.md) §2.4 的**「表征预训练」赌注**：先在海量观察性单细胞数据上自学一套细胞与基因的表征，再把这套表征迁移到包括扰动预测在内的下游任务。这一注的核心假设是：

> 细胞状态与基因功能的结构可以从**观察性**数据里学到，并且这种结构对**干预性**问题仍然有效。

这条假设有一个不显眼但致命的跳跃：观察性数据里只有「谁和谁一起变化」（相关），而本任务问的是「我动这个基因，其他基因会怎样」（干预）。表征预训练赌的是——共同表达结构足以支撑干预外推。三条路线的差别，主要在于它们各自**怎么处理这个跳跃**：

| 路线 | 它实际上是「什么」 | 它怎么处理观察 → 干预的跳跃 | 在本任务上的位置 |
|---|---|---|---|
| **scGPT** | 一个**模型**：生成式预训练的 Transformer，附一套多任务微调目标 | 靠一个 **二元逐基因条件 token** 显式告诉模型「这个基因被敲了」，再用对照细胞当作输入、扰动细胞当作目标做微调 `[P2]` | 备选基线。它的扰动接口是**逐基因**的，不是「靶点身份」的（§3.4） |
| **scBaseCount** | **不是一个模型**，是一个持续更新的**数据库/语料**：2.3 亿细胞、21 物种、72 组织 | 自己不做干预外推；它赌的是「只要语料足够大且流程统一，下游模型就能学到可迁移结构」 | 观察性数据候选源。**不提供扰动标签**，因此不能单独构成一条预测路线 `[R1]` |
| **AIDO Cell** | 一个**平台/世界模型**：以「持久细胞状态 + 连续扰动」为卖点，v1.0 只发布 K-562 与 Hep-G2 两个原型 | 靠把三种留出机制写进评测：见细胞系未见药、未见细胞系见药、未见细胞系未见药 `[R2]` | 路线参考。它已经把本任务的外推结构写进了自己的 benchmark，但输出形态与合同不匹配（§3.4、§7） |

**为什么这三条要放在一节课里比较而不是三条平行课。** 因为它们的「天花板判据」是**同一条**，来自 [L1-01](L1-01-领域地图与五种赌注.md) §2.4 列出的独立基准工作：在本任务的同构设置下，大规模预训练表征的收益经常是负的。把三条路线分开讲，会让读者以为它们各自有不同的失败原因；放在一起才看得见——**它们共享同一个失败模式**。

### 1.1 三条必输条件

1. **语料覆盖不到留出背景。** 本赛的 A–F 背景是匿名的，只在比赛期给 NTC。三条路线在预训练时看到的都是**公开命名的细胞系与组织**。如果留出背景不在任何公开图谱里（这正是匿名设定的目的），模型对它的先验就是「几个相似背景的平均」。这不是调参问题，是语料问题。
2. **扰动真值在合同上不存在。** 本赛给每个靶点 400 个预测细胞，但**不给该靶点在该背景里的任何已测细胞**。任何「用同背景真实扰动细胞去校准」的做法（包括 scGPT 的配对微调、AIDO Cell 的 held-out cell line 评测、Stack 的上下文示例）都必须先回答：这些细胞从哪来。见 §6.1。
3. **输出形态不匹配。** scGPT 的扰动预测头输出的是 **`log1p` 归一化表达值的单点估计**（`pred = coeff × values + bias`，无 softmax；`[S1]` 源码确认），不是「400 个细胞的原始非负整数计数」。AIDO Cell 的状态读出给的是 **TPM 聚合谱** `[R2]`。两者都需要在末端接一个计数生成器（权威位置：[L3-03 单细胞原始计数生成](L3-03-单细胞原始计数生成.md)）。

## 2. 输入输出契约

### 2.1 scGPT：一个细胞是一个「基因句子」

scGPT 把每个细胞当成一句由基因 token 组成的句子。输入嵌入是三项**相加**：

$$
\mathbf{h}^{(i)} = \underbrace{\text{emb}_g(\mathbf{t}^{(g_i)})}_{\text{基因身份}} + \underbrace{\text{value\_encoder}(\mathbf{x}^{(i)})}_{\text{表达值}} + \underbrace{\text{emb}_p(\mathbf{p}^{(i)})}_{\text{扰动标记}}
$$

| 张量 | 形状 | 含义 | 源码位置（`references/scGPT` 固定 commit `cebd6fae65`） |
|---|---|---|---|
| `src` | `(batch, seq_len)` | 基因 token id | `generation_model.py:134` |
| `values` | `(batch, seq_len)` | `log1p` 后的表达值（非分箱） | `generation_model.py:136` |
| `input_pert_flags` | `(batch, seq_len)` | 每个基因一个 **0/1/2 的整型标量** | `generation_model.py:137` |
| `total_embs` | `(batch, seq_len, embsize)` | 三者逐元素相加 | `generation_model.py:138` |
| 输出 | `(batch, seq_len)` | 每基因**一个标量**预测值 | `model.py:851-857`、`generation_model.py:438` |

三件事值得停一下。

**第一，扰动信息是一个 3 元词表。** `self.pert_encoder = nn.Embedding(3, d_model, padding_idx=pert_pad_id)`（`generation_model.py:80`），默认 `pert_pad_id=2`，扰动教程里设为 `pert_pad_id=0`（`tutorials/Tutorial_Perturbation.ipynb` 打印确认 `Embedding(3, 512, padding_idx=0)`）。也就是说，模型对「这个基因被扰动了吗」的全部知识，来自一个 **3 个取值**的离散标记。`[S1]`

**第二，scGPT 的位置编码是定义出来但没有被用上的。** `model.py:736` 定义了 `PositionalEncoding`，但在 `TransformerModel`（`model.py:21`）与 `TransformerGenerator`（`generation_model.py:27`）里**都查不到任何 `self.pos_encoder` 的实例化**。逐基因相加的 `total_embs` 直接进 `TransformerEncoder`。论文自己解释了这个设计的意图：引入特殊设计的注意力掩码，让基因表达的非序列特性适应序列预测框架 `[P2]`。**这意味着 scGPT 对基因顺序在结构上是不变的**——这与 [L2-02](L2-02-Stack与上下文学习.md) §3 的 Stack 形成对照，Stack 用的是**显式的可学习 `gene_pos_embedding`**。两条路线对「基因有没有顺序」给出了相反的答案。`[S1]`＋`[P2]`

**第三，scGPT 的扰动预测微调是「对照 → 扰动」的配对监督。** 论文原句：把未受扰动的对照细胞与每个受扰动细胞随机配对，输入用对照细胞的全部基因表达值，目标用扰动后的值，采用 perturb-GEP 目标 `[P2]`。**这个监督信号在本赛里不存在**——我们没有该背景该靶点的扰动细胞。见 §6.1。

### 2.2 scBaseCount：它的「契约」是数据格式，不是张量

scBaseCount 没有模型接口。它的可消费产物是**统一流程重建的 h5ad 计数矩阵**，规模与来源见 §5.1。读者要注意的是：它的「接口」问题变成了**字段与可比性问题**，而不是维度问题。

### 2.3 AIDO Cell：接口是「细胞状态 + 扰动」，读出是 TPM

AIDO Cell v1.0 的接口以「持久细胞状态」为中心：查询分子、转录、形态等多尺度读出，输入扰动后返回新的状态。表达读出的单位是 **TPM**（transcripts-per-million），不是原始计数 `[R2]`。它另有一类生成能力（小分子、抗体、纳米抗体的 in-context 设计），与表达预测是两条不同的通路 `[R2]`。

### 2.4 两个维度对照，与 L2-01 / L2-02 放在一起看

| | State（L2-01） | Stack（L2-02） | scGPT（本课） |
|---|---|---|---|
| 建模单位 | 集合 → 集合 | 集合 + 上下文 → 集合 | **单细胞** → 单细胞 |
| 扰动条件的形式 | 靶点 one-hot 词表 | 上下文里的示例细胞 | **逐基因 3 元标记** |
| 基因顺序 | 无序集合 | 可学习位置嵌入 | **无序（位置编码已定义但未接线）** |
| 输出 | 分布（能量距离） | 负二项参数 | **单点标量（无 softmax）** |
| 训练时是否需要配对真值 | 否 | 否（自蒸馏） | **是（对照↔扰动配对）** |

这张表右下角那一格——**「是」**——就是 scGPT 在本赛上最硬的阻塞点。

## 3. 架构

### 3.1 scGPT：标准 Encoder + 三个头

`[S1]` 逐层读下来的结构，没有意外设计：

| 模块 | 形状/参数 | 位置 | 它解决什么问题 |
|---|---|---|---|
| `GeneEncoder` | `Embedding(ntoken, d_model)` + `LayerNorm` | `model.py:717-733` | 把基因 id 变成向量；LayerNorm 让不同词表的尺度可比 |
| `ContinuousValueEncoder` | `Linear(1,d) → ReLU → Linear(d,d) → LayerNorm` | `model.py:759-787` | 把一个标量表达值提升到 `d` 维；`clamp(max=512)` 截断极端值 |
| `pert_encoder` | `Embedding(3, d_model)` | `generation_model.py:80` | 逐基因的扰动开关 |
| `TransformerEncoder` | `nlayers` 层，`batch_first=True` | `generation_model.py:100-104` | 基因之间的自注意力（**全对全，无掩码**） |
| `AffineExprDecoder` | 两个 `ExprDecoder`，各是 `Linear(d,d)→LeakyReLU→Linear(d,d)→LeakyReLU→Linear(d,1)` | `generation_model.py:373-438`、`model.py:842-857` | 输出系数 `A` 与偏置 `b`，最终 `pred = coeff × values + bias` |
| `ClsDecoder` | `nlayers_cls` 层 MLP | `model.py:884-912` | 细胞级分类（本任务不用） |
| `MVCDecoder` | 内积式 | `model.py:915` | 掩码值预测（本任务不用） |

**那个仿射解码器要单独说。** `pred = coeff × values + bias`（`generation_model.py:434`）意味着：模型预测的每个基因的表达值，是**它自己的输入表达值**乘一个系数再加一个偏置。这不是打印错误——它是让模型学「相对自己调整多少」而不是「绝对值是多少」。对本任务的意义：**输入的 NTC 表达值会直接乘进预测里**。如果输入是原始 UMI 计数（量级 0–10⁴），输出就是它的仿射变换，不天然落在整数上。

**论文的实现细节 `[P2]`（不是源码）：** 嵌入 512、12 个堆叠块、8 个注意力头、前馈隐藏 512、最大输入长度 1,200、预训练只输入非零表达基因、掩码比例从 {0.25, 0.50, 0.75} 均匀采样、Adam、batch 32、lr 1e-4。这些与扰动教程里写的 `embsize=512 / d_hid=512 / nlayers=12 / nhead=8` 一致 `[S1]`。**注意区分：源码里 `TransformerModel.__init__` 的 `d_model / nhead / d_hid / nlayers` 全是必填无默认参数，唯一有默认值的是 `dropout=0.5`**（`model.py:25-32`）；所谓「默认超参」只存在于各个脚本与教程里。这正是 [L2-02](L2-02-Stack与上下文学习.md) 同款教训：**配置和结构要分开看**。

### 3.2 scGPT 的参数量：仓库没给

`[S1]` 在 `references/scGPT` 下**没有找到任何写明的参数量**，README 的 Model Zoo 只给预训练细胞数。按论文超参手算一次（本课给出的数字都是手算，标为**工程假设**）：

| 项 | 计算 | 参数量 |
|---|---|---|
| 基因嵌入 | `ntokens × 512` | 见下 |
| 值编码器 | `1×512 + 512 + 512×512 + 512` | 263,168 |
| 每层注意力 | `4 × 512² + 4×512` | 1,050,624 |
| 每层前馈 | `2 × 512 × 512 + 512 + 512` | 525,312 |
| 每层合计 × 12 | 1,575,936 × 12 | 18,911,232 |
| 解码器（两个 ExprDecoder） | `2 × 3 × (512×512 + 512)` | 1,575,936 |

**基因嵌入项取决于词表，不能拍脑袋。** 本仓库实际检出了词表文件：`scgpt/tokenizer/default_gene_vocab.json`，**48,292 条基因条目**（本地解析，`[S1]`）。用该词表代入：`48,292 × 512 = 24,725,504`。**这里有意不给出一个「总数」**——因为工程实现里还会叠加 `<pad>/<cls>/<eoc>` 特殊 token、`cls_decoder`、以及是否启用 `do_mvc`/`explicit_zero_prob`，一个合并的总数会让「这数字从哪来」变成查不到的事。要引用 scGPT 的规模时，**引用它的层数与嵌入维度（12 层 / 512），不要引用一个来源不明的总参数**。

### 3.3 scBaseCount 的「架构」是流程

它没有神经网络架构。它的技术内容是一条**重建流程**：SRAgent（检索原始 SRA 条目并抽取元数据）→ scRecounter（Nextflow 流程，`fasterq-dump` 下载后**用 STARsolo 重新比对**，不用作者提供的矩阵）→ 输出 h5ad `[R1]`。这条流程的架构意义在于：**它把「不同研究之间的处理差异」显式当成要消除的变量**。而它的作者也承认这个目标没有完全达到（§5.2）。

### 3.4 三条路线的接口差异（本任务视角）

| 维度 | scGPT | scBaseCount | AIDO Cell |
|---|---|---|---|
| 能给本赛什么 | 预训练权重 + 微调头 | 观察性语料 | 评测设计参考（**未发布可下载权重**） |
| 靶点如何进入 | 逐基因 3 元标记 | 不适用 | 扰动接口（技术报告未展开张量形状）`[R2]` |
| 能否表达「未见靶点」 | **只表达「被标记/未标记」**，靶点身份靠该基因的表达值 | 不适用 | 报告称支持连续扰动与未见条件 `[R2]` |
| 输出单位 | `log1p` 归一化值 | h5ad 原始计数 | **TPM** |
| 与本赛合同的差距 | 需要配对扰动真值 + 计数生成器 | 无扰动标签 | 无权重 + 输出非计数 + 未覆盖 18,533 基因轴 |

**第二行是本课最容易被忽略的一条。** scGPT 的 `Embedding(3, d)` 只能表达「某基因是否被扰动」；「被扰动的是哪个基因」是由**该基因自身的位置**携带的。所以当你要预测一个**在词表里存在、但在该细胞系里表达为零**的靶点时，模型看到一个全零值 + 标记 1 ——它无法从表达值里读出这个基因是什么。这是「逐基因开关接口」的固有边界，不是训练不足。

## 4. 训练目标

### 4.1 scGPT：生成式掩码 + 多任务微调

预训练是**生成式掩码**：把一个细胞的输入基因分成「已知」与「未知」，未知基因的表达值被省略；先在**基因提示**步用 `<cls>` 嵌入 + 已知基因 + 未知基因算一次损失，再在**细胞提示**步把上一步输出的细胞嵌入回填到 `<cls>` 位置再算一次，两步损失相加 `[P2]`。论文说该掩码设计是为了**解决基因表达的非序列特性** `[P2]`——与 §2.1 第二点呼应。

微调期有五个目标，`[P2]` 列出全部名称以便检索：GEP（基因表达预测，掩码位 MSE）、GEPC（基于细胞表征的 GEP）、perturb-GEP（扰动版 GEP，目标是扰动后表达）、ECS（弹性细胞相似性）、DAR（梯度反转的域适应，针对批次）。源码侧确认 `model.py` 里有 `explicit_zero_prob` 的零概率分支（`model.py:859-876`，`sigmoid`），但**默认关闭**。

**训练目标把什么当噪声：** GEP/perturb-GEP 用的是**逐基因 MSE**。这意味着模型把「同一条件下不同细胞之间的表达差异」全部当成噪声来平均掉——这与 [L2-01](L2-01-State模型深潜.md) 的 State 恰好相反（State 用分布距离，把细胞间离散度当成要建模的信号）。后果见 §6.2。

### 4.2 scBaseCount：没有损失，只有流程

不适用。它把「损失」换成了**流程一致性**：同一条 Nextflow 流程处理全部条目，使不同研究之间的技术差异至少是**同一种**差异。

### 4.3 AIDO Cell：多尺度读出的联合目标

`[R2]` 技术报告描述的是多尺度、多模态读出的联合建模（分子 / 转录 / 形态），以及连续扰动和分支轨迹。**本课不展开其损失形式**——报告没有给出可供逐项核验的目标分解，且本机没有权重与代码，展开等于复述营销语言。这一栏的诚实写法是：**已知它把外推写进了评测设计，未知它用什么损失做到**。

### 4.4 三个训练目标与六项指标的错位

本赛的六项指标关注**单细胞分布**（相关结构、DE 集合、目标区分），不是逐基因 MSE。三条路线的训练目标与指标口径的错位程度不同：

| 路线 | 训练目标 | 与六项指标的错位 | 后果 |
|---|---|---|---|
| State | 集合间分布距离 | 小（同为分布视角） | 输出仍需转计数 |
| Stack | 负二项似然 + 自蒸馏 | 小（显式建模计数离散） | 目标自身被官方指标排除 |
| **scGPT** | **逐基因 MSE** | **大** | **MSE 最优解是条件均值，天然抹平单细胞离散度** |

这一行是「为什么基础模型常打不过线性基线」的**第二个**解释（第一个在 §6.2）。评分指标的权威位置是 [L3-01](L3-01-评分指标与离线评估.md)，本课只讨论训练目标与它的对齐关系。

### 5.2 scBaseCount 自己报告的批次效应证据

这是它作为数据源最值得记住的一段，因为它直接关系到本赛的跨背景验证（权威位置：[L3-02](L3-02-公开扰动数据与跨背景验证.md)）：

- 样本 ID 在 CELLxGENE 中的轮廓评分明显高于 scBaseCount，作者解释为「针对特定研究的处理引入了更强的批次效应」`[R1]`。
- 单细胞 vs 单核在 PC1 上的解释方差从 CELLxGENE 的 **15% 降到 scBaseCount 的 11%**；作者据此表示「超过 **4%** 的基因表达变异可归因于数据分析处理的差异，而不是生物学差异」`[R1]`。

**这段的因果方向要小心读。** 它是作者对自己流程的**自我评价**（我的统一处理减少了假变异），不是独立的第三方核验。用它当证据时只能说「作者报告其统一流程降低了处理差异」，不能说「scBaseCount 比 CELLxGENE 更接近生物学真值」。

### 5.3 AIDO Cell 的评测设计（本课真正想借的那部分）

`[R2]` 报告里写明了三种留出机制：**(i) 见细胞系、未见药；(ii) 未见细胞系、见药；(iii) 未见细胞系、未见药。** 本赛的最终轮要求的是第 (iii) 类再加「未见靶点」。

**但必须同时读出它没做的事：** 报告中的 Tahoe-100M 实验是 **42 个训练细胞系 + 3 个留出细胞系**、**301 个训练化合物 + 75 个结构不相似化合物留出** `[R2]`——这是**化学**扰动。本赛是 **CRISPRi 遗传**扰动。化学扰动有分子结构先验（Morgan 指纹、Chemical Checker），靶点扰动没有等价的可计算先验。**把 AIDO Cell 的化学外推结论迁移到 CRISPRi 上是未经检验的**。

### 6.4 为什么基准论文里基础模型打不过线性基线

这是本课的核心问题，答案有三个层次，必须分开说，混在一起就会得出错误结论。

**第一层：协议问题——「打不过」有时是评估方式的产物。**

`[P3]` Csendes 等在 Adamson、Norman、Replogle K562/RPE1 上比较 scGPT、scFoundation 与均值、Elastic Net、kNN、Random Forest 基线，在其未见扰动 + Pearson-delta 协议下**训练集均值优于两个基础模型**。同一批作者还指出：常用数据的**扰动间方差偏低**会放大 benchmark 误读。`[P4]` Ahlmann-Eltze 等独立得到相近结论。

**关键限定**：这些实验留出的是**同一细胞系内的扰动**，用的指标是 Pearson-delta，**不是本赛的跨背景六指标**。所以正确的表述是「在这些协议下均值基线很难被打败」，而不是「基础模型在本赛上没用」。这个区分必须写清楚，否则会用一个未经检验的结论去否定一条没被检验的路线。

**第二层：口径问题——「效应」被拆错了分量。**

「基础模型 vs 线性基线」的对比里，双方预测的其实是同一个东西：$\Delta_{c,t,g}$，即背景 $c$、靶点 $t$、基因 $g$ 上的响应。按 [L2-04](L2-04-简单基线与效应迁移族.md)将要建立的分解口径，$\Delta$ 至少可以拆成：

$$
\Delta_{c,t,g} = \underbrace{\overline{\Delta}_{t,g}}_{\text{共享分量（跨背景可迁移）}} + \underbrace{\Gamma_{c,t,g}}_{\text{背景特异分量（交互）}} + \varepsilon
$$

**均值基线（B1）在几乎所有数据集上已经吃掉了共享分量的大头**，因为共享分量是「跨背景平均后剩下的东西」，它天然被均值估计得很好。一个基础模型要赢，必须证明它的额外收益来自**背景特异分量 $\Gamma$**——而 $\Gamma$ 恰恰是最稀疏、最难学、也最容易被噪声淹没的那一项（[L1-02](L1-02-证据基线与噪声地板.md) 的地板就是判它真假的阈值）。

**当一个高容量模型没有被要求显式地区分这两项、也没有在留出背景上验证 $\Gamma$ 的收益时，它在验证集上要么学不到 $\Gamma$，要么去拟合噪声。前者让它等价于 B1，后者让它在留出上比 B1 更差。** 这就是「打不过」最机械的解释。

`[R3]` 提供了一条独立佐证：`perturbation-decomposition` 仓库用四分量 ANOVA 把这个句子变成了可计算的东西——`delta = mu + alpha_c + beta_p + gamma_{c,p}`（`decomposition/anova.py:3`），并对每个扰动单独算一个 **transferable fraction**：

$$
\text{beta\_frac}(t) = \frac{\operatorname{Var}(\beta_t)}{\operatorname{Var}(\beta_t) + \operatorname{mean}_c \operatorname{Var}(\gamma_{c,t})}
$$

（`anova.py:68-72`，公式为**本项目对该源码的转写**，不是论文结论）。这个比值高的靶点，B1 就能做得很好；比值低的靶点，才有 $\Gamma$ 的空间。**本赛 300 个靶点应当先按这个比值分档，再决定把算力投到哪里**——这是 §8 单元 5 的训练目标。

**第三层：接口问题——本课的 scGPT 特有发现。**

即使抛开前两层，scGPT 的扰动接口在本赛也很难发挥作用：它的 `pert_encoder` 是 3 元词表（§2.1），而「哪个基因被扰动」完全由该基因在序列中的位置与表达值携带（§3.4）。当靶点在该背景中表达为零时，模型看到的是一个**零值 + 标记 1** 的输入，无法从值里读出靶点身份。本赛留出的是**匿名背景**，靶点在这些背景里的表达水平未知且可能为零。**这是一个接口级阻塞，不是容量级问题——加大模型不会修好它。**

### 6.5 「那基础模型是不是就不该用」

不是。正确的结论比「用/不用」细：

1. **作为端到端预测器**：本课没有找到任何在「未见背景 × 未见靶点 × 原始计数 × 六指标」下验证过的基础模型。三条路线都不进入首投主线。
2. **作为表征层**：scGPT 的基因嵌入仍可作为**靶点编码**的输入特征（替代 one-hot），这是 [L2-04](L2-04-简单基线与效应迁移族.md)B3 低秩交互项的一个候选先验。**但要先做它 vs 随机初始化靶点嵌入的对照**——否则无法区分收益来自预训练还是来自「多了一个可训练参数」。
3. **作为语料**：scBaseCount 的观察性细胞可以扩充背景表示的训练数据，前提是先解决它自己承认的细胞级扰动标注缺失（§5.1）。
4. **作为评测参考**：AIDO Cell 的第 (iii) 类留出机制应当被抄进本项目的内部验证协议——**这一点是免费的，且不依赖能否跑它的模型**。

## 9. 诊断题

### 9.1 题一：一行代码的后果

你打算用 scGPT 的预训练权重初始化一个微调模型，期望「3,300 万细胞学到的知识能提升扰动预测」。你在 `tutorials/Tutorial_Perturbation.ipynb` 里看到：

```python
load_param_prefixs = ["encoder", "value_encoder", "transformer_encoder"]
```

**问：从上表这三个前缀能推出什么结论？如果你只加载这三个前缀，`pert_encoder` 会是什么状态？这对「预训练给了扰动能力」这个说法意味着什么？**

<details>
<summary>参考答案</summary>

`pert_encoder` 不在前缀列表里，因此**不会被预训练权重覆盖，保持随机初始化**，在微调阶段从零开始学（`[S1]`，§6.2）。

结论：**预训练权重里根本不包含任何扰动信息。** scGPT 的「扰动预测能力」全部来自下游微调用的那三套 Perturb-seq（Adamson 87 / Replogle 1,823 / Norman 236）`[P2]`，与 3,300 万观察性细胞的预训练无关。

这直接推翻了「用基础模型做扰动预测 = 直接受益于大规模预训练」的通俗叙事。正确的说法是：预训练提供的是**基因与细胞状态的表征**；扰动是下游注入的、用一个 3 元标记 + 少量标注数据学出来的。所以本赛的问题——「没有该背景的扰动真值」——**恰恰打在这个模型唯一有扰动知识的地方**。

（补一句边界：这不等于 scGPT 的预训练没用。它的编码器提供了基因共表达结构，对「下游小样本微调」是有帮助的。但「有帮助」不等于「提供扰动知识」，两者是不同来源。）
</details>

### 9.2 题二：两个实验，哪个结论更强

两组实验都想回答「基础模型在本任务上值多少」：

- **实验 A**：在 Adamson 数据集内留出 20% 的扰动（同一细胞系），指标 Pearson-delta，比较 scGPT 微调 vs 训练集均值。
- **实验 B**：用公开细胞系做训练集、留出整个细胞系，指标本赛六项，比较 State 零样本 vs B1 全局 target delta。

**问：如果 A 的结论是「均值赢了」，B 的结论是「State 赢了」，这两个结论冲突吗？你会用哪个来指导本赛的模型选择？**

<details>
<summary>参考答案</summary>

**不冲突，因为它们比的不是同一件事。** 差别在两条轴上：

| | 留出轴 | 指标 |
|---|---|---|
| 实验 A | 同背景内留出**靶点** | Pearson-delta（论文自定） |
| 实验 B | 留出**整个背景**（+ 靶点） | 本赛六项（分布级） |

A 检验的是「目标效应能不能在已见背景间推广」；B 检验的是「背景变换后还能不能预测」。本赛最终轮要求的是 **B 那类，且要加上未见靶点**——即 A 与 B 的**交集**，两者都没单独覆盖。

指导价值：**用 B 的结构设计实验，用 A 的警示设计基线。** 具体说——按 [L3-02](L3-02-公开扰动数据与跨背景验证.md) 的 leave-one-context-out 划分，指标用六项，但**必须把 B1 全局 target delta 当作主要对照**（而不是把均值当作一个可以忽略的弱基线）。A 的真正价值在于提醒你：**共享分量足够大的时候，一个不学任何交互项的方法就已经很强了**。这与 §6.4 第二层是同一件事。

**错误做法**：拿 A 的结论（「基础模型打不过均值」）去否定整条跨背景神经路线，或拿 B 的结论去宣称基础模型在留出靶点上一定更强。两者都是把结论搬到了它没被检验的轴上。
</details>

### 9.3 题三：该把算力投给哪个靶点

你手上有一个已评估的扰动面板，可以算出每个靶点的 $\text{beta\_frac}$（共享分量占比，`anova.py:68-72` 口径）。三个候选靶点：

| 靶点 | $\text{Var}(\beta_t)$ | $\operatorname{mean}_c\operatorname{Var}(\gamma_{c,t})$ | 在训练背景中被测过的次数 |
|---|---|---|---|
| T1 | 0.90 | 0.02 | 5 |
| T2 | 0.10 | 0.40 | 5 |
| T3 | 0.60 | 0.05 | **0** |

**问：按「投入产出比」排序，你会在哪个靶点上投入微调/建模算力？T3 的「0 次」会带来什么特别注意？**

<details>
<summary>参考答案</summary>

先算比例——T1 = 0.90/0.92 ≈ **0.98**；T2 = 0.10/0.50 = **0.20**；T3 = 0.60/0.65 ≈ **0.92**（但见下）。

**T2 最值得投入。** 它的共享分量只占 20%，意味着 B1（全局 target delta）本身就只能解释小部分——**剩下的 80% 是背景特异的结构，只有能建模 $\Gamma$ 的方法才可能吃到**。高容量模型的价值正来自于这种靶点。

**T1 不值得投入。** 共享分量占 98%，B1 就能做得很好，任何 T1 上的「改进」都极可能是噪声（用 [L1-02](L1-02-证据基线与噪声地板.md) 的地板判）。在 T1 上跑微调等于花算力去买一个无法判定的结论。

**T3 的坑在最后一列。** 「训练背景中被测过 0 次」意味着**没有 $\Delta_{d,t}$ 可供估计**——上表的 $\text{Var}(\beta_t)$ 是**训练侧**的量，而 T3 在训练侧根本没数据，它那个 0.92 **不成立**。按 [L2-04](L2-04-简单基线与效应迁移族.md)B1 的规则，正确动作是**回退到 B0**（不加任何扰动量），而不是拿名字相似的基因当已知靶点。

**推广到本赛**：300 个靶点应当先做两件事再谈建模——(1) 剔除在可用训练数据上**零覆盖**的靶点（它们只能走 B0 或猜）；(2) 在剩余靶点上按 $\text{beta\_frac}$ 分档，**把算力集中在中低档**。这一段是本课给 [L2-04](L2-04-简单基线与效应迁移族.md)的直接接口。
</details>
