# VC2026 教程重构：从任务导向到模型导向

> **状态：已裁决，已转为执行决定（2026-09-17）。** 第 8 节的五个问题已由用户裁决，结论见第 9 节。本文作为**决策记录**保留，记录当时的论证与取舍；此后课程表以 [课程索引 README.md](README.md) 为准，不再回改本文正文。
>
> 决策视角：把教程从「为了完成一次合法提交所需的最小知识」扩展成「能自己判断一个方法值不值得做」的领域知识。**不怕重构**，因此这里不迁就现有文件边界。

## 1. 为什么现有 00–06 不够

现有 00–06 是按**比赛阶段**组织的任务导向材料，回答的是「怎么做」。它没有回答「为什么这样做」和「还有别的什么做法」。四个缺口，按影响排序：

1. **没有领域地图。** 扰动响应预测这个领域有几套互相竞争的思想，各自在赌什么、在什么条件下会赢——教材里完全没有。结果是能跑通一条流水线，但无法判断一个改进值不值得做，也无法读完一篇新论文后决定要不要试。
2. **没有模型深潜。** 第 5 课 §2 用一段区分 State 的 SE/ST，第 3 课讲权重选择，但 State 的核心设计——集合式 Transformer、Energy distance 集合分布损失、残差预测——没有一节完整解释过。而 `docs/references/INDEX.md` 里已评估的 Stack、X-Cell、Lingshu-Cell、AlphaCell、MORPH、perturbation-decomposition、scGPT，一个都没进教材。附录《非 State 路线》里的 T0–T4 阶梯讲的是「怎么自己搭」，不是「别人是怎么搭的」。
3. **没有实验方法课。** 怎么做消融、怎么读基准论文、怎么在噪声地板上判断一个差异是否真实、怎么设计一个能证伪自己假设的实验——这些是最可迁移的部分，目前散落在附录 §8 和 `docs/research/` 里，没有形成课时。
4. **数据和评估课是合同导向的。** 第 1 课教你怎样通过校验，第 2 课教六项指标在看什么，但都没回答「这个指标为什么这样设计」「它会奖励什么样的错误」。

## 2. 两个必须尊重的现实

### 2.1 日历：D/E/F 发布到截止只有 14 天

| 日期 | 事件 | 来源 |
|---|---|---|

D/E/F 发布到截止只有 **14 天**。教程按**阶段**组织而不是按学时：每个阶段给出「读什么、跑什么、留下什么产物」，不绑定日期和每周投入，由读者按自己的节奏推进。

### 2.2 算力：本地 8 GiB 训不了

本机 GPU 为 RTX 3070 Ti Laptop，**8 GiB** 显存。`docs/research/first-submission-plan.md` §1.1 已记录：「本机可用于编码和小型检查，不承担正式训练」，完整训练分支按 A100 80 GB × 150 小时的**上限**规划。

这条约束把「实操」切成了两类，教程必须显式区分，否则会出现「课讲了但跑不了」的落差：

| 类别 | 内容 |
|---|---|
| **本地可实操** | 数据审计、评估回路、计数生成器、小批推理、CPU 侧消融、公开基准复现、论文里的小规模统计主张复核 |
| **必须云端** | 任何真正的 State 微调、全基因训练、多 seed 消融 |

## 3. 提议结构：三层

```text
L1 领域地图        ——  这个领域在赌什么，证据说了什么
   L1-a 虚拟细胞建模的五种赌注
   L1-b 基准文献到底给出了什么结论（含噪声地板）

L2 模型深潜        ——  别人具体是怎么搭的，我能不能用
   L2-1 State（主线）
   L2-2 Stack（in-context learning）
   L2-3 基础模型路线：scGPT / scBaseCount / AIDO Cell
   L2-4 分解式路线：perturbation-decomposition / AdaPert / CCCTL
   L2-5 生成式与世界模型路线：X-Cell / Lingshu-Cell / AlphaCell
   L2-6 简单基线与效应迁移族（基准论文的结论来源）

L3 比赛实施        ——  落到本赛合同、本机算力、本日历
   现有 01–06 的主体归入这一层，改写成「原理 + runbook + notebook」
```

**L1 是当前完全缺失的一层**，也是最便宜、对「知识面」贡献最大的一层：它不需要 GPU，只需要把 `docs/references/INDEX.md` 里已评估的 50 余篇材料读成一张图。

### 3.1 L1-a 的内容：五种赌注

这是我认为最值得教的一张图。这五种赌注不是分类学摆设，它们是对**同一个经验事实**的五种不同回应——[P1] 报告的不同细胞类型之间效应一致性只有 **0.016–0.037**，而同一类型不同状态之间是 0.25–0.33。效应几乎不跨背景迁移，而评分恰恰奖励特异分量。

| 赌注 | 核心假设 | 代表工作 | 便宜/昂贵 | 天花板判据 |
|---|---|---|---|---|
| 效应迁移 | 扰动效应比背景更可迁移 | 两步效应表流水线、response magnitude 路线 | 极便宜、CPU 可跑 | 跨类型一致性 0.02 是硬墙 |
| 条件化生成 | 学 `p(表达 \| 背景, 扰动)` 就够 | State、UniPert、CellHermes | 昂贵 | 需要能区分「未测」「测得零」 |
| 分解式 | 响应 = 共享分量 + 背景特异分量 | perturbation-decomposition、AdaPert、CCCTL | 中等 | 分解是否可识别、可验证 |
| 表征预训练 | 先学通用细胞表征再迁移 | scGPT、Stack、scBaseCount、AIDO Cell | 昂贵 | 基准显示常不敌线性基线 |
| 世界模型/动力学 | 学状态转移而非某时刻表达 | AlphaCell、Stack in-context、VCWM roadmap | 昂贵、最不成熟 | 尚无本任务上的可复核证据 |

[P2][P3] 的基准结论是这一层必须讲清的张力：大模型常打不过平凡基线。这不是「不要用大模型」，而是「必须知道自己在为哪一部分付钱」。

### 3.2 L1-b 的内容：证据与噪声地板

- 基准的方法论缺陷（划分、指标、可比性）。
- [P1] 引用的双 guide 一致性数据：部分「误差」不可约，**在追精度之前必须先测噪声地板**。
- 本项目已有的两个独立控制基线的负分（见 §6.3）口径不同，必须自己复现一份。

## 4. 模型深潜课的统一样板

沿用 `docs/lessons/README.md` 第 2 节的 8 步结构，但替换为模型导向的 8 步。每课一个模型（或一族），每课必须能回答：

1. **它赌什么**：这个模型对「什么让扰动响应可预测」的核心假设是什么？
2. **输入输出契约**：喂什么、吐什么、维度是什么、和本赛合同差在哪。
3. **架构**：逐层说明每个模块解决哪个问题，不用术语替换机制。
4. **训练目标**：损失函数为什么是它，它把什么当成噪声、什么当成信号。
5. **数据**：训练语料是什么、暴露了哪些背景和靶点（直接决定能不能用于干净验证）。
6. **官方代码怎么跑**：`references/` 下本地副本的入口、最小可运行命令、实测显存与耗时。
7. **在 VC2026 上的适配缺口**：要改哪几层、哪些权重可以迁移、哪些必须重训。
8. **诊断题**：给一个具体现象，问这是该模型的哪个假设失效。

第 6 步依赖算力裁决（见 §8-Q3）；第 7 步是本项目真正的工作量所在，也是现有第 5 课最该加强的部分。

## 6. 本次检索暴露的三项新发现

这三项来自新下载的两篇参赛者博客，都会影响现有执行计划，属于必须在教材里讲清、也必须回填到研究文档的内容。

### 6.1 A/B/C 的身份可能已被两个独立参赛者推断出来

[P1] 和 [P4] 用两种不同方法得到同一组结论：

- Ilyes Baali：单细胞伪批量与 DepMap 24Q4 bulk 参考谱做中心化余弦相关 → A = Jurkat（0.87）、B = HeLa（0.70）、C = CAL-33（0.76）。
- Forrest Sheldon：独立给出相同猜测（Jurkat E6.1 / HeLa / CAL-33）。

**这是参赛者推断，官方从未确认，不能作为已核实事实。** 但如果成立，它会改变两件事：

1. 第 3 课「跨背景验证」可以用真实的细胞系身份来选择匹配的公开 screen，而不是只按组织来源猜。
2. `docs/research/first-submission-plan.md` §2 目前明确排除 CD4 T cell screen（Zhu 2026）——「Orion、CD4 screen、Jiang 等暂不扩大首投数据范围」。**若 A 确实是 Jurkat（T 淋巴母细胞系），这个排除决定值得重新评估**：这是在谱系上唯一与 A 匹配的公开 CRISPRi screen。

### 6.2 效应迁移的一致性数字可以当作难度上界锚点

[P1]：同细胞类型不同状态（CD4 静息 vs 刺激）一致性 0.25–0.33；**不同细胞类型 0.016–0.037**。作者认为这是理解整个任务最重要的一个数字。

用途：L1-a 的判据来源，也是「为什么必须建模背景而不只是迁移效应」的定量理由。**该数字为参赛者自报，需要回到其引用的原始 screen 复核后才能作为本项目的量化依据。**

### 6.3 三个控制基线负分，口径不同，都不能直接采用

| 报告者 | 基线定义 | 分数 |
|---|---|---|
| Ilyes Baali [P1] | 400 个完全相同的细胞，均值正确 | 约 **−0.81** |
| Forrest Sheldon [P4] | 直接采样对照细胞 | 总分 **−0.304**，DE 方向保真度 **−1.721** |
| 本项目文档 | 作者 H1 benchmark control baseline | 约 **−0.04523**（待本机复现） |

三者任务、背景、评分版本都不同，**不可互换**。共同指向一件事：本地必须先建立自己的噪声地板，否则无法判断任何改进是真实提升还是评分噪声。这条应写入 L1-b。

## 7. 执行顺序（已按阶段落地）

不建议先写 L2——那是最大的一块，但方向未定就动工会返工。实际执行顺序：

1. **裁决第 8 节的五个问题**（已完成，结论见第 9 节）。
2. **建 L1-01 领域地图**（1 课，待写）。成本低、不需要 GPU、立刻提升判断力，且它的产物会反过来校正 L2 的选材。
3. **建立噪声地板**（L1-02，1 课 + 1 个 notebook）。本地可做，直接服务比赛，同时是评估课的最佳教学案例。
4. **写 L2-01 State 深潜**。它是主线模型，也是 L2 样板，写完就能看出这个格式是否合口味。
5. **按样板推进其余 L2**，与比赛实施并行。
6. 结构冻结后再回飞书同步；现在同步会在结构变更后留下多个版本。

「每阶段读什么、跑什么、留下什么产物」的完整表在 [README.md](README.md) 第 2 节。

## 8. 待裁决的五个问题（2026-09-17 提出）

以下问题已全部裁决，**结论见第 9 节**。本节保留当时的选项与推荐，用于回看取舍依据。

**Q1 模型深潜覆盖到哪一层？**
A 只做 State + 简单基线族（最省，约 2 周）；B 做 State + Stack + 基础模型路线 + 简单基线族（覆盖主流三类）；C 六条路线全做（约 7 课）。
➡️ 推荐 **B**，把 C 中剩余的做成「一页纸模型卡」放在附录，不占课时——覆盖面保住，时间可控。

**Q2 算力路线怎么定？** 这决定 L2 第 6 步能写到什么程度。
A 租云 A100（沿用研究文档的 150 小时上限预算）；B 用 Colab Pro / Kaggle 免费额度，只跑小规模；C 本轮不训练，全部做已发布权重的推理 + CPU 侧离线评估。
➡️ 推荐 **C 打底 + A 按需**：先用纯本地把数据、评估、计数、推理闭环全部打通（这些本来就必须做），再只为「真正需要训练的消融」租卡。避免在没有本地闭环时就开始烧 GPU 小时。

**Q3 你每周能投入多少小时？** 这决定时间盒和 L2 的取舍，我无法从环境里查到。
➡️ 建议按 **10–15 小时/周** 设计，即截止前约 70–100 小时：够走完 L1 + L2-1 + 噪声地板 + 现有 02–06 的实操，不够走完六条模型路线。

**Q4 现有 02–06 的内容是否授权重写？** 包括改编号、拆分、合并、把实操段落移入 notebook。
➡️ 推荐 **授权重写**。02–06 从未同步到飞书，重排成本只有仓库内部引用；而保留现有边界会让 L2 无处安放。

**Q5 交付形态？**
a 每课一个可运行 notebook；b 每课至少一个「读完能回答的诊断题」；c 每课一个可复核的产物（表/图/脚本）。
➡️ 推荐 **a + b 必选，c 只在能本地实操的课上要求**。云端才能跑的内容不应强制要求产物，否则教程会停在「跑不了」的地方。
