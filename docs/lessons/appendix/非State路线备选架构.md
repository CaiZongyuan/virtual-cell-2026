## 1. 可检验的工程分解

先不写公式。把一次预测想成一张四层「调试地图」：

| 层 | 直觉 | 在数据中怎样看 |
|---|---|---|
| `NTC(context)` | 这个背景原本处于什么状态 | 该背景一群 NTC 细胞的表达分布 |
| `transferable delta(target)` | 某目标在多个背景中重复出现的变化 | 其他背景中「目标扰动伪批量 − 对照伪批量」的共同部分 |
| `interaction(context,target)` | 同一目标在这个背景中特别强、特别弱或改变方向的部分 | 某背景下的 `delta` 减去该目标全局 `delta` 后的剩余结构 |
| `count noise` | 从 RNA 分子到最终 UMI 计数的抽样与测量波动 | 同一条件下单细胞总 UMI、零值和基因计数的分散 |

$$
y(\text{context},\text{target})
= \operatorname{NTC}(\text{context})
+ \Delta_{\text{transfer}}(\text{target})
+ \Gamma(\text{context},\text{target})
+ \varepsilon_{\text{count}}.
$$

**这不是细胞真实运作方式。**真实的调控网络有非线性、阈值、反馈、时间延迟和细胞状态转换。四层地图只是让我们能逐层问：「不预测扰动时有多好？」「加上跨背景共性后提升多少？」「再加背景交互是否真的有用？」

这个加法也不能不加说明地直接用在原始计数上。原始 UMI 计数受每个细胞测序深度影响，且不能小于零。实践中通常先在固定归一化空间（例如 `log1p(CPM)`）学 `delta`，再单独转回原始计数分布——这个转换不会自动保真，必须另行验收。

![从背景 NTC、可迁移扰动 delta、背景交互到单细胞计数的四层工程分解](../assets/vc2026-course/05-transferable-delta.webp)

### 1.1 为什么四层在生物上说得通

- **NTC 告诉我们「系统现在在哪」。** **NTC（non-targeting control，非靶向对照）**是携带完整 CRISPRi 流程、但 guide 不被设计去命中人类目标基因的细胞。它不是「什么都没发生」，而是保留 guide 导入、培养、固定、检测和测序等共同流程，用来估计没有特定目标敲低时的群体分布。同一目标的效应不能脱离这个起点解释。
- **「可迁移 delta」是重复出现的群体差异。** 对背景 $c$、目标 $t$、基因 $g$：$\Delta_{c,t,g}=\overline{x}^{\,\text{pert}}_{c,t,g}-\overline{x}^{\,\text{NTC}}_{c,g}$。「在已见背景中平均一致」不等于「在任何背景中必然一致」，它是需要在留出背景上检验的统计规律。
- **交互项表示「这个背景改变了效应」。** 它不宣称背景向量与目标向量真的做了乘法，而是：仅知道背景平均状态和目标全局平均效应，仍无法解释的系统性剩余。来源可能是目标基础表达不同、互作通路活性不同、细胞周期/应激/分化组成不同，也可能是 guide 效率与实验平台差异——**最后一项是技术差异，不是生物调控**。
- **不存在「这个细胞扰动前」的真值行。** scRNA-seq 检测会消耗被测细胞，一行 NTC 和一行扰动细胞不是同一个细胞的前后两张照片。不能按行号、最近邻或随机顺序相减，再把结果当成真实单细胞反应。可直接估计的是**群体分布之差**，不是个体配对因果效应。

## 2. 四级统计基线：每加一层都要证明值得

| 级别 | 形式 | 新增能力 | 通过条件 |
|---|---|---|---|
| B0 | $\widehat{\mu}^{B0}_{c,t,g}=\mu^{\mathrm{NTC}}_{c,g}$ | 无；定义最低验收线 | 不适用——它是别人的门槛 |
| B1 | $\widehat{\mu}^{B1}_{c,t,g}=\mu^{\mathrm{NTC}}_{c,g}+\overline{\Delta}_{t,g}$ | 跨背景全局目标 delta | 在多数 fold 的扰动相关指标上超过 B0 |
| B2 | $\widehat{\Delta}^{B2}_{c,t}=\sum_d w_{c,d}\Delta_{d,t}$ | 相似背景加权 | 稳定超过 B1，否则回退 B1 |
| B3 | $\Delta_{c,t,g}\approx\overline{\Delta}_{t,g}+\sum_{r=1}^{R}a_{c,r}b_{t,r}q_{g,r}$ | 低秩 context × target × gene 交互 | 在外层 fold 改进，而非只降低训练误差 |

**B0 与官方 scaled=0 的 mean-response baseline 不同。** 后者从真实扰动面板计算一个跨目标平均响应；B0 完全不加入扰动效应。B0 保留留出背景的基础表达、状态混合和计数分布，只是故意预测零扰动效应——它不是「随便猜」。

**B1**：先在每个捐献背景 $d$ 内部计算 $\Delta_{d,t}$，再跨背景取稳健中位数 $\overline{\Delta}_{t,g}=\operatorname{median}_{d\in\mathcal D_t}\Delta_{d,t,g}$。**绝不先把所有细胞混在一起求差。** 若目标在所有训练背景都没出现，B1 没有该目标的干预证据，合理回退是 B0，而不是把名字相似的基因当成已知目标。

**B2**：仅用 NTC 比较留出背景与各捐献背景的基础状态，让更相似的背景贡献更大权重：$w_{c,d}=\exp(s(z_c,z_d)/\tau)\big/\sum_{d'}\exp(s(z_c,z_{d'})/\tau)$，其中 $z_c$ 是 NTC 得到的背景摘要。必须反复提醒的边界：

> NTC 表达相似只是观察性相似，不保证两个背景对某一干预的因果响应也相似。

VC2025 第三名 `TransPert` 的 Arc 官方摘要中包含按相似性聚合多细胞系扰动效应的做法，这说明它值得作为基线，**不证明它在 VC2026 的新背景中必然有效**。[S3]

**B3**：**低秩（low rank）**假设「背景 × 目标 × 输出基因」三维张量主要由少数几种重复模式组成。$a_{c,r}$ 表示背景含有多少第 $r$ 种模式，$b_{t,r}$ 表示目标激活多少，$q_{g,r}$ 说明该模式对各基因的影响。好处是数据稀疏时可共享信息，风险是把真实但稀有的背景特异响应抚平；$R$ 越大越容易记住批次。$R$ 与正则强度只能由训练背景内部的嵌套 LOCO 选择。**关键限制**：若 $a_c$ 只是每个训练背景的自由 ID 向量，它不会自动适用新背景——必须由 NTC 摘要经可外推函数得到；同理，若 $b_t$ 只是目标 ID，也不能外推到全局未见目标。

## 3. 两条必须独立处理的输出约束

### 3.1 目标基因自身敲低：是软约束，不是把一列归零

CRISPRi 的直接目标是降低目标基因的转录，所以目标在 NTC 中可检测时，预测的群体平均通常应有下降倾向：$\widehat{\mu}_{c,t,t}=(1-\kappa_{c,t})\mu^{\mathrm{NTC}}_{c,t}$，$0\le\kappa_{c,t}\le 1$。

但**不能默认 $\kappa=1$，也不能强迫每个预测细胞的目标计数为零**：CRISPRi 是敲低不是 DNA 删除；guide 效率和作用时间会变化；低表达基因在 NTC 中已有大量零，零计数不能证明强敲低；RNA 下降的大小不能直接推出所有下游效应。实践中应把「自身敲低修正」当作独立消融：不加、加固定收缩、根据公开训练数据估计收缩，然后在 LOCO 上比较。

### 3.2 非负与测序深度：负数截断不等于计数生成

VC2026 提交要求原始、有限、非负整数计数，每个细胞总计数不得超过 1,000,000。[S1][S2] 在归一化空间得到 $\hat x$ 后直接 `round(clip(expm1(x), 0, inf))` 有三个问题：`expm1` 后的数是深度归一化的相对量，不是已有真实 library size 的 UMI；把所有负值截成零会系统改变基因均值和总量；确定性四舍五入会让 400 个细胞过于相同。

最小可审计方案是：从该背景 NTC 的经验分布抽取 400 个 library size，把预测的非负相对表达归一化成概率，再用多项分布或更合适的过度分散计数模型生成整数。这仍是工程生成器，不等于真实分子机制；完整方案见 [第 03 课 单细胞原始计数生成](../03-State上手.md)。

## 4. 背景端表示：为什么要读一群 NTC

对一个软件服务，只知道「环境 A」这个名字并不会告诉你当前 CPU 负载、内存和请求组成，你需要一组运行时观测。VC2026 的字母 A–F 同理只是分组标签。**这个类比只用于建立直觉**：细胞不是可完全观测的机器，RNA 只是当前状态的一类读出，与染色质、蛋白、代谢、形态和历史状态之间没有一一对应。

VC2026 每个公开背景包含 46 个 NTC guide、每 guide 400 个细胞，合计 18,400 个 NTC 细胞。[S1] 这个集合足以估计均值和部分分布结构，但**不能自动区分生物背景与技术批次**，也不含该背景的目标扰动真值。

| 级别 | 表示 | 解决的问题 | 主要代价 |
|---|---|---|---|
| C0 | 伪批量均值 $z_c^{\mathrm{mean}}=\frac{1}{n_c}\sum_i x_{c,i}$ | 提供稳定的表达起点，易解释易复现 | 把两个完全不同的群体压成同一行：「所有细胞都中等表达基因 G」与「一半高一半不表达」均值相同，响应可能不同 |
| C1 | 方差、零比例、分位数、细胞级 QC | 区分「中等同质」和「高低混合」 | 仍不知道多个基因是否在同一细胞中共同变化；直接拼接所有统计维度极高，须用预注册基因集、PCA 或带正则的线性层压缩 |
| C2 | 状态组成（state composition） | 同一个扰动可能对增殖中和静息细胞作用不同，均值不能说明两者比例 | 最大风险是把批次聚类当成生物状态，须检查状态是否几乎由一个数据集/guide/深度区间独占 |
| C3 | DeepSets / set encoder $z_c=\rho(\operatorname{pool}_i\phi(x_i))$ | 学习压缩方式而非人工指定；可表达稀有状态、群体比例、同均值下的多峰 | 显存与计算随集合大小快速增长；「可以表达」不等于「实际使用了」 |

**DeepSets 的关键性质是置换不变**：交换任意两个 NTC 细胞的输入顺序，$z_c$ 应保持不变；否则模型在学没有生物含义的行顺序。实践中应固定每个训练 set 的细胞数，从 18,400 个 NTC 中重复抽样多个 set，并用 guide 分层防止一个 guide 独占。

C2 的一条实用流程：用训练数据拟合共享低维空间和 $K$ 个状态原型 → 把新背景 NTC 分配到这些原型（保留软概率而非硬标签）→ 输出 $K$ 维状态比例。

STATE 的作者把对照细胞作为集合输入，用集合层面的状态转移预测扰动群体；Stack 的索引摘要把推理时的无标签上下文细胞视为适配背景的样例。[P1][P2] 它们支持「集合是合理的模型输入单位」这个方法方向，**但不保证某个预训练权重不经适配就能输出 VC2026 要求的原始计数**。

## 5. 目标端表示：一个基因能用什么表示

### 5.1 先补齐生物信息链

**Gene（基因）**是 DNA 上能产生功能性 RNA 或编码蛋白质产物的遗传区域。简化链路是：`DNA 上的基因 →(转录)→ RNA 转录本 →(翻译)→ 蛋白质`。CRISPRi 通常通过 guide 把 dCas9-KRAB 带到转录起始位点附近，使目标更难被转录。**比赛 scRNA-seq 主要观测 RNA 计数，不直接测量蛋白数量或活性。** 因此：目标 RNA 下降不意味着蛋白立刻同比例下降；蛋白半衰期、翻译效率和修饰会改变时间延迟；某些基因产生功能性非编码 RNA，根本没有对应蛋白序列；同一基因可能有多个转录本和蛋白异构体，一个固定蛋白嵌入会丢失这种差异。

| 级别 | 表示 | 解决的问题 | 边界 |
|---|---|---|---|
| T0 | gene symbol one-hot | 强的身份基线，能说明外部先验是否真的超过了「记住这个名字」 | 两个基因的 one-hot 距离都一样，不含通路、功能或表达相似性；未见目标没有可外推的专属向量 |
| T1 | 目标在当前 NTC 中的基础表达（均值、检测率、方差、分位数） | 显式 `context × target` 特征 | 与自身敲低上限相关，**不是目标生物重要性**：高表达不意味着强下游效应；低计数可能是真低表达也可能是检测效率低 |
| T2 | 蛋白序列嵌入 | 序列/结构/功能相关的蛋白在表示空间更近；VC2025 前两名的官方摘要都提到蛋白嵌入 [S3] | 从 symbol 到嵌入必须带可审计映射表，见下 |
| T3 | 通路 / 基因网络先验（multi-hot、邻居、度、社区、图嵌入） | 对未见目标可从邻近基因传播信息 | 图混合多种证据和细胞背景，通用关系不代表在当前匿名背景中活跃 |
| T4 | 预训练基因表示 | 从大规模数据学到的高维基因特征 | 维度更高不代表证据等级更高；必须与 T3 分开消融 |

T2 的映射表必须显式处理：标准蛋白编码基因记录数据库版本、canonical isoform 与序列校验和；多异构体预先固定 canonical 规则或带 mask 聚合，**不按验证分数挑异构体**；非编码 RNA 基因蛋白特征设为缺失并保留独立缺失 mask，不伪造序列；符号无法映射或为过期别名时先查版本化别名表，仍失败则记为未映射并回退其他特征。**对缺失特征全填零却不给 mask，会让模型无法区分「没有蛋白」「映射失败」和「真实嵌入恰好接近零」。**

最重要的边界：

> 共表达、语义相似、通路共现和蛋白互作用都是因果效应的候选线索，但不能单独确定「用 CRISPRi 降低基因 T 后，基因 G 会上升多少」。

因为观察性数据中 T 和 G 可能同时被第三个过程驱动；网络边也可能没有方向、没有时间和背景信息。真正的扰动响应仍需干预数据训练或验证。

## 6. 两编码器融合与消融矩阵

第一版架构应先预测群体 `delta`，而不是一步直接生成 18,533 维的 400 个整数细胞：

$$
z_c=E_c(X_c^{\mathrm{NTC}}),\qquad z_t=E_t(f_t),
$$
$$
\widehat{\Delta}_{c,t}=D\!\left[z_c,\ z_t,\ z_c\odot z_t,\ e_{c,t}^{\mathrm{basal}}\right],\qquad
\widehat{\mu}_{c,t}=\mu_c^{\mathrm{NTC}}+\widehat{\Delta}_{c,t}.
$$

$e_{c,t}^{\mathrm{basal}}$ 是目标在当前 NTC 中的基础表达特征；$\odot$ 是工程交互特征，不宣称对应某个分子反应。**为什么先预测 `delta`**：NTC 已经告诉我们新背景的大部分基础表达，模型只需学扰动带来的变化，误差更容易按「背景估计错」「目标效应错」「交互错」定位。

消融原则是：**每次只改一类信息，训练数据、分割、decoder 容量、随机种子数、损失和调参预算保持一致。**

| 背景表示 | T0 symbol | T1 + 基础表达 | T2 + 蛋白 | T3 + 通路/网络 | T4 + 预训练 |
|---|---:|---:|---:|---:|---:|
| C0 伪批量均值 | 必做 | 必做 | 必做 | 必做 | 必做 |
| C1 + 方差/分位数 | 必做 | 建议 | 建议 | 候选 | 候选 |
| C2 + 状态组成 | 必做 | 建议 | 建议 | 候选 | 候选 |
| C3 DeepSets | 必做 | 必做 | 必做 | 建议 | 建议 |

不必一开始跑满 20 个实验。先做两条路径：固定 T0 比较 C0→C1→C2→C3；固定 C0 比较 T0→T1/T2/T3/T4。只有某一轴出现稳定改进后才跑交叉组合。

### 6.1 分割必须同时检查两种外推

| 外层测试 | 隐藏什么 | 提供什么 | 回答的问题 |
|---|---|---|---|
| LOCO | 一个 context 的全部扰动真值 | 留出 context 的 NTC、已见 target 特征 | 背景 encoder 能否从 NTC 外推 |
| LOTO | 一组 target 在所有训练 context 的扰动真值 | 留出 target 的预先特征 | target encoder 能否超越 ID 记忆 |
| LOCO × LOTO | 新 context 中的新 target 组合，且 target 全局未见 | 新 context NTC + 目标先验 | 两个 encoder 是否能联合零样本外推 |

随机留出单细胞无法回答上述任何一个问题，因为同 context、同 target、同批次的其他细胞已经出现在训练中。**也不要在 LOCO 中把留出 context 的一小部分扰动当调参集**——这与 VC2026「该背景只提供 NTC」的信息合同不符。

## 7. 模型阶梯与能力升级门

先分清三种对象：

- **表示**把高维输入压成便于比较或下游学习的向量。好表示可能包含细胞类型或状态信息，**不代表它已学会「敲低这个基因后会怎样」**。
- **终点预测器**学习 $\hat X_{c,p}^{post}=f(X_c^{NTC},p)$，即给定 NTC 群体和目标直接输出扰动后表达。统计 delta、residual MLP、多数比赛模型都属于这一类，**它们可以是很好的 VC2026 解法**。但输出不等于可以当作新状态再施加第二个扰动。
- **细胞世界模型（VCWM）**至少要维护可重用状态 $S_t$ 并显式提供带干预的转移 $S_{t+\Delta t}=T_{\Delta t}(S_t,a_t,c)$。[P8] 对本比赛的实际意义是：**VC2026 只评估一次 CRISPRi 后的单时点转录组终点**，专用终点预测器可能比完整世界模型更简单、更容易验证且分数更高。

| 等级 | 候选模型 | 新增能力 | 必须通过的门 | 达不到时的处置 |
|---|---|---|---|---|
| L0 | NTC/no-effect、全局 delta、低秩 delta | 无，定义起点 | 数据合同、六指标、留出 context 流水线都可复现 | 不训神经网络，先修评估 |
| L1 | Residual MLP $\hat\Delta_{c,p}=W_{out}\,\mathrm{MLP}([z_c;e_p;q_c])$ | context-target 非线性交互 | 在多个留出 context 上超过 L0，参数和种子稳定 | 回到特征、损失和数据对齐 |
| L2 | DeepSets / set encoder | 利用 NTC 群体异质性 | 超过同维手工摘要；通过置换、子采样和结构打乱检查 | 保留 L1，不以更大 set model 硬凑 |
| L3 | 潜变量（autoencoder / CPA 式）或图先验（GEARS 式） | 可解码低维状态，或未见 target 知识传播 | 无先验/打乱先验消融；未见 target × context 交集提升 | 删除没有证据的先验 |
| L4 | STATE 式集合转移 / diffusion / flow | 直接学习扰动后单细胞分布 | 在冻结相同伪批量下改善方差、零、协变和状态，且不伤害六指标 | 使用 L1/L2 + 简单计数生成器 |
| L5 | 候选 VCWM | 可重用状态、干预条件转移和 rollout | 多步转移、改变干预的分叉未来、不确定性报告 | 称为终点预测器，不做过度声称 |

**每个门都应预先写下「什么结果会推翻升级」。** 例如 set encoder 若在细胞结构打乱后仍有全部增益，说明增益不能归因于细胞异质性；若只在随机细胞分割上有增益，则不支持跨背景泛化。

**关于基础模型**：**单细胞基础模型（scFM）**先在大量观察性或扰动细胞上预训练再迁移。「在更多细胞上预训练」和「学会了未见背景中的 CRISPRi 因果效应」不是同一命题。[P7] 正确消融位置是：在相同 residual MLP 和训练协议下比较 A（伪批量/PCA 背景 + 可训练 target embedding）、B（冻结预训练细胞表示 + 相同 target embedding）、C（相同背景表示 + 冻结预训练 target 表示）、D（B + C）。**只有 B/C/D 在多个留出 context 上稳定超过 A，且改善来自多个扰动而不是一小群训练集近邻，才有理由付出大模型的推理和对齐成本。**

L1 的最小网络应该有多小：双层 MLP、层归一化、GELU、dropout 和线性输出层就足以当基线。先扫描 2–3 个隐层宽度，**不要先扫描深度、注意力头、不同预训练模型和十几个损失权重**。如果 residual MLP 无法在留出 context 上稳定超过低秩/相似背景 delta，问题更可能在数据对齐、目标表示或评估设计，而不是缺一个更大 Transformer。

## 8. 消融顺序：一次只问一个问题

每一行继承上一行的数据、划分、种子和计数生成器：

1. `B0`：当前背景 NTC/no-effect，不预测扰动；
2. `B1`：训练背景全局 target delta；
3. `B2`：相似背景加权或低秩 target-context delta；
4. `N1`：伪批量 context + 可训练 target embedding 的 residual MLP；
5. `N2`：冻结 MLP，只将 target embedding 换成蛋白/知识表示；
6. `N3`：冻结 target 路径，只将伪批量 context 换成 DeepSets；
7. `N4`：在 N3 上加入图先验，并同时跑打乱图对照；
8. `N5`：保留相同 context/target 表示，换成潜变量解码器；
9. `G1`：保留相同伪批量终点，比较模板/NB/DM 生成；
10. `G2`：只在 G1 证明分布指标尚有稳定缺口时，再评估 STATE 式 set transition、diffusion 或 flow。

**不应在 `N1 -> N2` 时同时更换数据集、context encoder、损失、学习率和生成器**——那会产生一个也许分数更高、却不知道为什么的系统。

一个可直接复用的判据例子：要判断 DeepSets 是否真的用了单细胞联合结构，需要两个边界清楚的负对照——`M3a` 在每个基因内独立置换细胞（保留逐基因边缘分布，破坏细胞内协方差）；`M3b` 按原始每行 library size 从同一伪批量 composition 独立做 multinomial 采样（精确保留行和分布，移除状态和基因协方差）。**如果实验模型对这两种对照都没有稳定优势，就不能声称它利用了单细胞联合结构。**

## 9. 失败模式汇总

| 失败模式 | 看起来像什么 | 实际可能发生了什么 | 最小对策 |
|---|---|---|---|
| 随机拆细胞 | 验证分数很高 | 同一背景和批次同时进入训练/验证，模型识别了实验指纹 | 整背景 LOCO，必要时整数据集外部验证 |
| 对 NTC/扰动细胞强行配对 | 得到大量「单细胞 delta」 | 把两群独立细胞的自然差异写成个体反应 | 在群体/分布层面建模，明确无配对设计 |
| 公开数据混杂 | 某个捐献背景权重最高 | 模型追随测序协议、批次或实验时间 | 批次内做差；记录协议；做 dataset-holdout |
| 目标敲低失败 | 目标下游没效应 | guide 未命中、基础表达低或检测漏失 | 按 guide 审计自身敲低，不把所有标签当同质真值 |
| 低秩过度平滑 | 平均指标尚可，强特异效应消失 | 小秩只保留常见变化模式 | 按效应强度分层报告，检查最大 `delta` 与稀有通路 |
| 深度处理错误 | 表达方向大致对，原始计数指标差 | 归一化空间预测被直接当成 UMI | 分开均值预测与 count decoder，审计总 UMI/零比例/方差 |
| 相似性幻觉 | NTC 很近，但扰动方向不一致 | 共表达相似不能确定干预响应 | 对比 B1/B2；只在 LOCO 稳定改进时接受 B2 |
| 测序深度指纹 | encoder 仅凭总 UMI 识别来源 | 数据集间深度不同形成技术捷径 | 将深度作为显式 QC，做深度匹配对照 |
| guide 指纹 | 训练 set 总由某一 NTC guide 组成 | 模型记住 guide 的微弱技术差异 | 跨 guide 分层抽样，比较 leave-one-NTC-guide-out |
| 细胞数指纹 | 求和 pooling 把 set 大小编码进向量 | 集合大小成为可识别信号 | 固定大小或用均值 pooling，单独提供已审计细胞数 |
| 状态组成偏差 | 群体比例在过滤前后改变 | 质控对某种状态更严 | 按过滤前后审计状态组成 |
| 目标泄漏 | 先验特征异常有效 | DEG 频率、效应均值或网络包含留出真值 | 在外层分割前固定映射规则与版本 |
| 名字错配 | 目标指向了另一个基因 | 过期 symbol、别名、大小写或物种映射错误 | 用版本化别名表核对，失败记为未映射 |
| 蛋白缺失非随机 | 模型学会「缺失 = 弱效应」 | 非编码和研究较少的基因更易缺特征 | 按缺失类型分层报告 |
| 网络知识偏差 | 高度节点被当作生物中心性 | 研究多的基因有更多边，反映文献热度 | 与随机度保持图、打乱图对照 |
| 观察性快捷方式 | 共表达猜中相关基因但方向错 | 观察性数据中两者同被第三过程驱动 | 用干预真值的 LOTO 验证 |
| 保守塌缩 | 预测接近 NTC，扰动特异 delta 被压小 | 高维输出中降低不变基因误差更「划算」 | 用 delta 范数、方向、DEG 数、PDS 和表达误差一起诊断 [P4] |
| 伪重复和错误置信 | 数百细胞被当作数百次独立实验 | 同条件细胞共享 target、context 和实验过程 | 训练损失可在单细胞算，但分割、显著性和不确定性不能假设行独立 |
| Context ID 记忆伪装成理解 | 只在已见背景有效 | 细胞系名/study/batch 几乎唯一标识 context | 外层 LOCO 是最低要求；推理路径只使用比赛时可见的 NTC 特征 |

**注意最后一条的对称性**：把 study 一键「去批次」也不安全，它可能删除真实 context 信号。要分开报告同 study 跨 context、跨 study 同类 context 和完全外部数据的结果，不用一个总平均掩盖域转移失败。

## 10. 诊断题

在多个公开背景的 LOCO 中，B2「相似背景加权 delta」比 B1「全局 target delta」的平均分数更高，但改进几乎全来自一个与某训练数据集同平台、同实验室的留出背景；换到另一个数据集时 B2 还更差。能否宣布「NTC 相似性能预测跨背景因果响应」？下一步最值得做的对照是什么？

<details>
<summary>答案：先自行作答，再展开</summary>

不能宣布。现有结果与「NTC 距离主要捕捉了平台或实验室指纹，而不是会改变扰动响应的生物状态」完全相容。一个 fold 的改进也不能证明稳定泛化。

优先做两个对照：第一，将外层拆分升级为整数据集/平台留出，不让同实验指纹同时出现在捐献与留出端；第二，将真实 NTC 距离与只使用批次/平台标签的负对照比较。如果 B2 仅在共享技术条件时有效，就应回退 B1，并把这一结果记录为「相似性假设未通过跨数据集验证」。

## 11. 与主教材的接口

这条路线在当前项目中承担三个具体作用：

1. **基线对照。** B0/B1 是判断 [第 03 课](../03-State上手.md) State 微调是否真的学到东西的最低门槛。若 State 的 H1 开发评分打不过 B1，问题在模型或数据对齐，不在缺少容量。
2. **验证协议的来源。** LOCO / LOTO 的划分规则、泄漏检查清单和「目标自身敲低只作内部 QC」的边界，与 [第 03 课](../03-State上手.md) 和 [第 04 课](../04-你怎么知道改进是真的.md) 一致，主教材沿用。
3. **计数生成的独立验收。** 本节 §3.2 的约束和 [第 03 课](../03-State上手.md) 是同一套要求：**均值预测与 count decoder 必须分开验收**，伪批量上的提升不能替代 400 个单细胞计数的分布验收。
