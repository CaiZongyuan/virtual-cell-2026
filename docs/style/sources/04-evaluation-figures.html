A/B/C 无扰动真值。「噪声 / 扰动效应」这个决定性的比值要等公开面板（本课 §3 的硬边界）。
口径 A · 半集重复 + jackknife
抽 2n 个细胞分两组 → 记录 ‖b₁−b₂‖²；同时删一重算得 2·VarTrace。直接观测量 vs 无偏估计量，实测相差 0.0%–0.3% —— 这本身就是实现自检。
口径 B · 置换零分布 → 判据
同一细胞池随机分两组，「两组有系统差异」在构造上不成立 → 分布就是纯噪声。取 95% / 99% 分位当判定阈值。口径 A 答「噪声多大」，口径 B 答「多大才算超出噪声」，不能互相替代。
陷阱 · 朴素 Pearson = 0.999 的假安心
相关系数被高表达基因主导：三个背景的地板明明差 14%，Pearson 只在小数点后第五位动。必须在差值空间里看平方距离。
1/n 律 · 压地板很慢
细胞数 100 → 400 → 1600，平方距离 4.00× → 1.00× → 0.249×，实测与 1/n 吻合到小数点后两位。翻倍细胞数只降 1/√2；官方 1 分参考是半深度（200 细胞档），地板约是完整深度的 2 倍（实测 1.996）。
地板是测量仪器的属性它属于「400 细胞抽样 + 这把评分尺」，换个模型它不变。任何「改进 0.003」在与换算后的阈值比较之前，既可能是真实增益，也可能只是又一次抽样波动。

假设：这一步在验证什么 ／ 证伪条件：如果它没用我会看到什么（动手前写） ／ 结果：Δ 与阈值 T 的比较（动手后写）。写不出可观测的证伪条件，就不要开始。
两条硬规则
① 每步只改一件事；② 只报总分的消融不算完成 —— 至少同时报逐指标成绩单与逐留出背景成绩。换损失、相似加权、缩方差这三类改动在总分上看不出来。
为什么顺序不能换昂贵实验通常也是「看起来最有希望」的那个，而便宜实验往往能提前把它否掉 —— 输出合同的基因顺序错了，微调一周也得不到可解释的结果。
