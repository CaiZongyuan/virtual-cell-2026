L0 · 可计算的起点
统计 delta
对照均值 + 可迁移扰动效应
能力稳定、可解释的伪批量终点
验证门数据合同 + leave-one-context-out + 六指标
成本：低
L1 · 最小神经基线
Residual MLP
背景摘要 × target 表示的非线性交互
新增学习非线性 context-target delta
验证门在多个未见 context 上稳定超过 L0
成本：中低
L2 · 群体表示
DeepSets / set model
直接读取无顺序 NTC 细胞集合与异质性
新增稀有状态、多峰分布和群体交互
验证门过置换/子采样/结构打乱检查
成本：中高
L3 · 结构先验
Latent state / graph prior
压缩可解码状态，或沿预登记基因关系传播目标信息
新增低维状态与未见 target 关系先验
验证门无先验 / 打乱先验消融与 LOTO
成本：中高
L4 · 分布终点
Set transition / diffusion / flow
在扰动条件下生成多个不同的单细胞
新增方差、零、协变和多状态分布
验证门固定同一 mean，分布改善且六指标不退化
成本：高
