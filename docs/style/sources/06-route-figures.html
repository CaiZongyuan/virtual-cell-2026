靶点算力分档：从 beta_frac 到「该往哪儿投」

拿到 300 个靶点，先剔零覆盖，再分档。
阈值 0.70 / 0.50 是工程假设，不是物理常数；
判据永远是第 04 课的噪声地板。
分量口径：β 共享、Γ 特异，B1 只建模 β
anova.py:68-72 转写
Δ(c,t,g) = β̄(t,g) + Γ(c,t,g) + ε └共享·可迁移┘ └背景特异·交互┘ beta_frac(t) = Var(β_t) / [ Var(β_t) + mean_c Var(Γ_(c,t)) ]
β 是跨背景共享分量——B1 一个纯查找表就能估准；Γ 稀疏、难学、易被噪声淹没。一个高容量模型要赢，必须证明它的额外收益来自 Γ。
情形该用哪一级理由
目标在所有训练背景零覆盖B0无干预证据；名字相似 ≠ 效应相似
beta_frac ≥ 0.70（β 主导）B1 就够查找表已吃到共享分量大头
0.50–0.70（中间档）先 B1 再试 B2/B3必须有外层 fold 证据才升级
< 0.50（Γ 主导）B2/B3 或 State高容量唯一可能回本的档
匿名背景强加的三条边界
A–F 只有字母标签
① B2 的相似性只能盲猜。无法预先知道哪个公开细胞系与目标背景相似；B2 反例：跨实验室/跨平台留出上比 B1 差 0.054，是它同平台赢到 0.003 的十倍以上。
② 覆盖未知。300 个靶点里零覆盖的比例直接决定 B0 回退比例，而这个比例在 A–F 上无法预先测量。
③ B3 的 a_c 必须可外推。只能是 NTC 摘要的函数，不能是背景 ID 的 embedding——否则在测试背景上没有定义（scGPT / AlphaCell 同栽在这类「不可外推的靶点身份」上）。
阈值要自己找拐点。在公开真值面板上同时记录 beta_frac 与 B1 的实测分数，按分数曲线定分档线；0.70 / 0.50 只是本课的占位假设。
