【**摘要**】细胞对扰动的响应是理解生物学机制和筛选潜在药物靶点的基石。与实验方法相比，计算模型在预测扰动效应方面潜力巨大，但目前仍难以将实验已观测细胞情境中的效应泛化到未观测情境。本文提出 STATE，一种在预测扰动效应时兼顾扰动实验内部及实验之间细胞异质性的机器学习架构。STATE 跨越多个物理尺度运行：它包含一个状态转移模型，利用来自** 70 种细胞情境、超过 1 亿个受扰动细胞的数据**，学习细胞集合层面的扰动效应；还包含一个**状态嵌入模型，该模型基于 1.67 亿个人类细胞的观察性单细胞数据训练而成。**在多个大型数据集上，STATE 将扰动效应的区分能力提高了 50% 以上；与现有模型相比，它在遗传、信号和化学扰动中识别真实差异表达基因的准确度提高至 2 倍以上。利用其嵌入模型，STATE 还可以在训练期间从未观测过扰动的新型细胞情境中识别强扰动。我们进一步提出 CELL-EVAL，这是一个采用生物学相关指标的综合评估框架，突显了 STATE 如何实现对细胞类型特异性扰动响应（例如与细胞存活相关的响应）更精确的发现。总体而言，STATE 的性能与灵活性为虚拟细胞模型的规模化开发奠定了基础。

# 引言
---

治疗发现依赖于对细胞扰动影响的准确预测。从 CRISPR 或 RNAi 等遗传干预，到采用小分子或生物制剂的化学处理，这些扰动不仅用于诱导目标表型，也是建立基因、通路和细胞结局之间因果关系的核心手段，从而帮助我们更深入地理解细胞功能。通过选择性破坏细胞系统的特定组成部分，科学家可以识别表型的因果驱动因素，这是靶点识别和药物开发中的关键步骤。**实验扰动技术使研究人员能够沿两个主要维度探查干预效应：所施加的扰动类型，以及细胞或生物学情境。**这两个因素都会深刻影响系统响应。功能基因组学的进展如今使在特定细胞情境中开展大规模测试成为可能，常用方法包括将汇集式 CRISPR 扰动与全转录组读出相结合的单细胞筛选（Dixit et al., 2016; Datlinger et al., 2017; Przybyla and Gilbert, 2022; Replogle et al., 2022; Norman et al., 2019）。然而，要将这些测定扩展到许多情境，其成本和人力投入仍高得难以承受。提升我们在不同生物学情境之间泛化扰动响应预测的能力，将极大加快因果靶点发现，加深对细胞功能与疾病的理解，并进一步促进情境特异性干预方案的设计，从而为个体化治疗预测奠定基础。



目前已有多种计算方法用于解决这一问题（Lotfollahi et al., 2019, 2023; Bunne et al., 2023; Roohani et al., 2024a; Cui et al., 2024; Hao et al., 2024）。然而，尽管扰动数据集的规模与覆盖范围迅速增长，预测能力却未得到与之成比例的提升（Wu et al., 2024; Chevalley et al., 2022; Li et al., 2024b,a; Wenteler et al., 2024）。当前深度学习方法在跨细胞情境泛化扰动效应时，并不能稳定优于线性模型（Wu et al., 2024; Li et al., 2024b）。我们认为，**这主要源于两类噪声，它们掩盖了单细胞扰动数据集中的真实扰动效应：一是研究群体内部无法由实验协变量解释的生物学异质性，二是不同扰动数据集之间的技术或实验差异**（图 1A 和公式 1）。

> **细胞异质性**是指同一组织或细胞群体中的各个细胞在基因表达、形态结构、生理功能、代谢状态等方面存在差异的现象。**主要特点：**
>
> 1. **基本概念**：这种差异使得看似相同的细胞群体实际上由多种"亚群"组成。
> 2. **存在范围**：细胞异质性不仅存在于肿瘤细胞中，也广泛存在于正常组织、干细胞等各类细胞群体。
> 3. **表现形式**：
>     - 基因表达水平不同，导致蛋白质合成有差异
>     - 形态结构不同，如细胞大小、形状各异
>     - 功能状态不同，如增殖能力、分化潜能不同
>     - 代谢状态不同，如能量利用方式不同
> 4. **与遗传异质性的关系**：遗传异质性指表型相同的个体可能由不同基因型导致，分为基因座异质性（不同基因突变引发相同表型）和等位基因异质性（同一基因不同突变引发疾病）。
>



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786087349276-fb7c3673-fe3b-438c-b8f4-c13b5d3aacd2.png)

> 图 1：STATE：一种用于预测细胞集合层面扰动效应的基于 Transformer 的模型。（A）在单细胞分辨率下对扰动效应建模，需要将生物学信号与噪声、批次效应以及接受相似处理的细胞间异质性所引入的混杂变异解耦。
>



**对生物学异质性建模的挑战，源自单细胞 RNA 测序的一项内在局限：测量过程会破坏细胞，因而无法观察细胞的扰动前状态，也无法准确推断每个细胞特有的扰动响应。**为解决这一问题，**研究者通过比较受扰动和未受扰动细胞群来推断扰动效应，同时尝试在细胞类型、批次或其他群体层面协变量的尺度上解析异质性。一些方法假定，相较于扰动效应，群体内异质性可以忽略，于是只将受扰动细胞映射到具有共同协变量、随机选择的未受扰动细胞**（Roohani et al., 2024a）；这种映射方法也已在表达能力强的基于 Transformer 的模型中得到检验（Cui et al., 2024; Hao et al., 2024）。在扰动效应较强的数据集中，这类方法虽有效（Norman et al., 2019），但当扰动效应较为细微、未受扰动群体的异质性甚至可能超过扰动信号时，往往难以泛化。细胞周期状态变化、谱系偏向或预先存在的表观遗传程序都会令这一问题尤为明显；当基础群体本身就来自多种细胞类型时，例如体内研究中，问题更加突出（Lara-Astiaso et al., 2023; Saunders et al., 2024）。另一些模型将细胞群体视为分布，采用变分自编码器等生成式方法来学习数据生成分布，或显式解耦有标签和无标签的变异来源（Lotfollahi et al., 2023; Piran et al., 2024; Bereket and Karaletsos, 2024; Weinberger et al., 2023; Lopez et al., 2023; Papalexi et al., 2021; Weinberger et al., 2024; Song et al., 2025）。然而在实践中，当应用于扰动效应预测时，这些模型往往无法显著优于不显式建模分布结构的方法（Wu et al., 2024; Chevalley et al., 2022）。也有人提出基于最优传输的方法，将未受扰动群体映射到受扰动群体，但其适用性受到强假设和较差可扩展性的限制（Bunne et al., 2023, 2024b）。



第二类主要噪声属于技术噪声，源于数据本身而非模型的局限。在遗传扰动实验中，基因敲除或敲低等预期效应不一定会在每个目标细胞中发生，导致一些细胞被错误标记为受扰动。实验条件带来的额外变异，包括转导效率、RNA 测序深度、试剂化学性质和采集时间，也进一步增加了跨研究整合数据的难度（Bock et al., 2022）。这些技术混杂因素共同稀释了数据中真正由扰动引发的信号，从而限制了能够在不同数据集之间稳健泛化的模型开发。尽管单细胞基础模型已成为学习跨数据集稳健细胞表征的一种策略（Theodoris et al., 2023; Rosen et al., 2023; Cui et al., 2024; Hao et al., 2024; Ho et al., 2024; Pearce et al., 2025），但它们目前仍无法有意义地区分由遗传扰动等因素驱动的较细微变异，因为这些模型通常被优化用于区分细胞类型等更宽泛的类别（Luecken et al., 2022）。



> **单细胞扰动实验中的异质性建模**
>
> 可以基于每个细胞的未受扰动状态，对其观测到的对数归一化扰动后表达状态 $ (X_{p}) $ 进行建模。然而，由于细胞的未受扰动状态不可观测，我们将 $ X_{p} $ 近似为：
>
> 
>
> $ \hat {X} _ {p} \sim \hat {T} _ {p} (\mathcal {D} _ {\mathrm{basal}}) + H (\mathcal {D} _ {\mathrm{basal}}) + \varepsilon , \qquad \varepsilon \sim P _ {\varepsilon}\tag{1} $
>
> 其中：
>
> + $ \mathcal{D}_{\mathrm{basal}} $：未受扰动基线细胞群体的分布。
> + $ \hat{T}_p(\mathcal{D}_{\mathrm{basal}}) $：扰动 $ p $ 对该群体造成的真实效应。
> + $ H(\mathcal{D}_{\mathrm{basal}}) $：基线群体的生物学异质性。
> + $ \varepsilon $：实验特异性技术噪声，假定其独立于未受扰动细胞状态及 $ \mathcal{D}_{\mathrm{basal}} $。
>
> 该 $ \hat{X}_{p} $ 是 $ X_{p} $ 的分布类比，即 $ X_{p} \stackrel{d}{\approx} \hat{X}_{p} $，从而可以基于可观测的群体特征进行建模。
>



为克服这些挑战并推动有效虚拟细胞模型的发展，我们提出 STATE，这是一种灵活且表达能力强的架构，用于对多样化数据集内部及数据集之间的细胞异质性和扰动效应进行建模。**STATE 是一个包含两个互补模块的多尺度模型：状态转移模型（State Transition model，ST）和状态嵌入模型（State Embedding model，SE）**。**ST 是一种 Transformer，它利用自注意力对细胞集合中由扰动诱导的转变进行建模，其中每个细胞由其原始基因表达谱或学习得到的嵌入表示。SE 通过学习多样化数据集中细胞之间的基因表达变异进行预训练，以生成表达能力强的细胞嵌入**（Zhang et al., 2025; Program et al., 2025; Youngblut et al., 2025）；由此获得的表征对技术变异具有稳健性，并针对扰动效应检测进行了优化。通过在细胞集合上利用自注意力，ST 无需依赖显式的分布假设，便能灵活捕捉生物学异质性。SE 和 ST 共同使 STATE 能够在数据集与扰动之间实现泛化，提高扰动—响应建模的可迁移性。



STATE 的多尺度架构既能利用 1.67 亿个细胞的观察性数据来训练嵌入模型，也能利用超过 1 亿个细胞的扰动数据来训练转移模型。我们在多个大型数据集上评估 STATE，包括基于**药物的扰动**（Tahoe-100M（Zhang et al., 2025; Srivatsan et al., 2020））、**细胞因子信号扰动**（Parse Biosciences, 2023），以及**全基因组尺度的遗传扰动**（Replogle et al., 2022; Nadig et al., 2025; Jiang et al., 2025; McFalone-Figueroa et al., 2024; Feng et al., 2024）。为了全面评估 STATE 和其他模型模拟细胞扰动的能力，我们提出 CELL-EVAL，一个综合评估框架。该框架超越了基于表达计数的传统指标，纳入了一组具有生物学相关性和可解释性的指标，重点考察差异表达预测和扰动强度估计。



在跨越多个数量级的所有指标和数据规模上，STATE 始终优于朴素模型和最先进模型。据我们所知，它是首个在跨细胞情境泛化扰动效应时能够稳定超越简单线性基线的模型。此外，我们表明，在低数据量条件下利用 STATE 嵌入对扰动建模，即使训练期间未使用这些细胞类型的任何扰动数据，也能够在新型细胞类型中检测到强响应。例如，我们证明，在 Arc Virtual Cell Atlas（Youngblut et al., 2025）中基于 Tahoe-100M 数据集（Zhang et al., 2025）预训练 STATE，可以改善扰动效应向未见细胞情境的泛化。因此，STATE 为学习可在数据集与实验设置之间迁移的扰动效应提供了一种可扩展方法。



除实证性能外，我们还给出了将 STATE 与最优传输（Optimal Transport，OT）理论相联系的新理论结果；最优传输是一种常用于建模细胞对扰动响应异质性的方法（Bunne et al., 2023; Chen et al., 2024; Demir et al., 2024; Dong et al., 2023; Bunne et al., 2024b; Ryu et al., 2024）。具体而言，我们证明，在温和的正则性条件和渐近极限下，未受扰动与受扰动细胞群体之间唯一的连续 OT 映射属于 STATE 的解族。这一结果将 STATE 定位为对基于 OT 方法的推广：它既可以恢复经典 OT 解，也允许对可能不符合标准 OT 公式所施加假设与约束的扰动效应进行更灵活的建模。

# 结果
---

## 构建用于预测细胞集合扰动效应的状态转移模型


STATE 是一种多尺度机器学习架构，用于预测细胞扰动后的下游转录组响应，包括基因表达变化、差异表达基因和总体扰动效应量（图 1B）。它利用：

1. **在分子层面，表示不同实验和物种中单个基因的嵌入；**
2. **在细胞层面，捕捉每个细胞转录组状态的嵌入，既可以由细胞的对数归一化转录组表示，也可以由状态嵌入模型（SE）生成的嵌入表示；**
3. **在群体层面，状态转移模型（ST）学习细胞集合上的扰动效应。**

STATE 在训练期间既可以利用观察性数据，也可以利用干预性数据：**SE 在来自多个大型观察性单细胞资源库的 1.67 亿个人类细胞上训练**（Youngblut et al., 2025; Zhang et al., 2025; Program et al., 2025），**ST 则在来自大规模单细胞筛选的超过 1 亿个经化学或遗传扰动的细胞上训练**（Zhang et al., 2025; Parse Biosciences, 2023; Replogle et al., 2022）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786088212845-2ff20628-15dd-4a73-91d9-42a3ce25d86d.png)

> **图 1：STATE：一种用于预测细胞集合层面扰动效应的基于 Transformer 的模型。**（B）STATE 是一种跨基因、单个细胞和细胞群体运行的多尺度机器学习架构。核心状态转移模型（ST）通过对按共同协变量（例如扰动类型、细胞情境和批次）分组的受扰动和未受扰动细胞群体集合进行训练，来学习扰动效应。ST 可直接作用于基因表达谱，也可作用于状态嵌入模型（SE）生成的紧凑细胞表征；SE 从大规模观察性数据中学习信息丰富的嵌入。这种多尺度架构使 ST 能够有效地在计算机中模拟扰动实验，并支持表达量化、差异基因表达分析和扰动效应量估计等下游分析。
>



**ST 的核心动机是对已知协变量（例如细胞类型和扰动标签）之外的细胞异质性进行建模，从而改善扰动响应预测。**为此，首先根据已知协变量对细胞进行分层（图 S1）。对于每个协变量匹配的受扰动组，ST 构建固定大小、彼此不互斥的细胞集合；这些集合在训练期间作为输入，并与大小相等且协变量匹配的未受扰动对照细胞集合配对。



![](https://cdn.nlark.com/yuque/0/2026/jpeg/1739170/1786085569868-3a45de6a-12ee-4cba-9427-43e329737aa4.jpeg)

> **图 S1：ST 扰动模型的细胞集合设计。**根据共有特征（如组织、谱系或批次）对细胞进行分组，使模型能够学习以集合大小及匹配协变量为条件的扰动效应。
>



ST 使用 Transformer 主干网络，在对照细胞集合上反复执行双向自注意力和前馈运算（第 4.3 节，图 S2A）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786704037350-235a6701-eaf9-4203-a1f2-3542e07ade33.png)

> **图 S2：STATE 的完整模型架构。**（A）以嵌入空间表示作为输入的 ST 模型架构。当直接在基因表达空间中工作时，基因解码器由基因重建头取代；后者是一个简单的线性层，将 Transformer 输出投影回基因表达空间。
>



这使 ST 能在预测扰动后的下游转录组响应时，对输入细胞集合内部的异质性进行建模（图 1C）。

**ST 使用预测与观测到的受扰动细胞转录组之间的最大均值差异（MMD）损失进行训练。尽管 ST 学习的是细胞分布层面的扰动效应，它仍会为单个细胞预测受扰动细胞谱，这一特性对于学习受扰动群体的分布结构非常重要。**实证结果表明，在达到某一阈值之前，增大细胞集合规模所得到的验证损失远低于单细胞上的损失，无论这些单细胞是真实样本还是在相邻细胞间进行伪批量聚合得到的样本（图 1D）。此外，移除自注意力会导致性能下降（图 1D），这凸显了灵活的集合式自注意力在建模与扰动响应预测相关的细胞异质性方面的价值。

> 图 1：STATE：一种用于预测细胞集合层面扰动效应的基于 Transformer 的模型。**（D）增大细胞集合规模会改善验证损失，直至达到最优点；**在 Tahoe-100M 数据集（Zhang et al., 2025）上，将协变量匹配组切分为 256 个细胞的集合时获得最佳性能。完整 ST 模型显著优于伪批量模型（以平均池化替代自注意力的 STATE）和单细胞变体（集合大小 = 1 的 STATE）。移除自注意力机制的消融实验显著降低了性能，凸显了对集合内细胞间相互作用进行建模的重要性。

## STATE 在跨细胞情境预测扰动效应方面优于基线


我们在一项泛化任务上测试了 STATE 架构，评估其预测新细胞情境（例如未见过的细胞系或供体）中扰动效应的能力。具体而言，我们设计了一个代表不足情境泛化任务（第 4.2.1 节），其中每个模型在训练期间可以访问测试情境中 30% 的扰动（图 2A）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786088821536-3786dd9f-4189-457d-95c5-f2314a35b200.png)

> 图 2：STATE 在跨细胞情境预测扰动效应方面优于现有基线。**（A）代表不足情境泛化任务。**模型在来自一个或多个细胞情境的扰动数据上训练，并评估其预测相同扰动在一个基本留出、代表不足的目标情境中所产生效应的能力。“扰动均值”基线通过对训练细胞情境中观测到的受扰动状态与对照状态之差取平均来估计效应。“情境均值”基线使用目标细胞情境在所有训练扰动下的平均表达谱。
>



我们将性能与多个基线进行了比较（第 4.7.5 节），其中包括一个简单线性模型（Ahlmann-Eltze et al., 2024），以及针对该任务已发表的三个机器学习模型：CPA（Lotfollahi et al., 2023）、scVI（Lopez et al., 2018）和 scGPT（Cui et al., 2024）。我们还纳入了两个朴素的基于均值的基线，它们可以解释细胞类型泛化任务中相当一部分观测方差（图 2A）。“情境均值”基线预测训练数据中给定细胞情境在所有扰动下观测到的平均表达（Kernfeld et al., 2023）；“扰动均值”基线则预测训练细胞情境中的平均扰动效应，并将其施加于给定细胞情境的基础表达。在结果中，我们将预测平均表达或平均扰动效应的基线称为“均值基线”，将其他模型称为“基线模型”。所有模型（包括 STATE）均被训练用于预测前 2,000 个高变基因（HVG）的对数表达，这是基线比较中常用的特征空间。



我们在 Tahoe-100M 数据集的化学扰动数据（Zhang et al., 2025）、Parse Biosciences 的细胞因子信号扰动数据（Parse Biosciences, 2023，简称 Parse-PBMC），以及 Replogle et al.（2022）和 Nadig et al.（2025）的遗传扰动数据（简称 Replogle-Nadig）上评估了 STATE（图 2B）。Tahoe-100M 包含 50 种不同癌细胞系在 1,138 种处理条件下的扰动响应，涉及 380 种不同的药物扰动。Parse-PBMC 包含 12 名供体、18 种细胞类型对 90 种细胞因子扰动的响应。Replogle-Nadig 包含施加于四种不同细胞系的 2,024 种遗传扰动，其中已过滤靶向效力较低的扰动。对所有数据集，我们都直接使用由高变基因得到的细胞表征来训练 STATE（ST+HVG）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786088862307-d9d0ecc7-3cec-4961-9874-ba8f3533e6ac.png)

> 图 2：STATE 在跨细胞情境预测扰动效应方面优于现有基线。**（B）模型在化学、信号和遗传扰动数据集上训练和评估**（Zhang et al., 2025; Parse Biosciences, 2023; Replogle et al., 2022; Nadig et al., 2025）。比较对象包括（A）中的均值基线、一个简单线性模型（Ahlmann-Eltze et al., 2024）、基于自编码器的模型（scVI（Lopez et al., 2018）、CPA（Lotfollahi et al., 2023）），以及一个基础模型（scGPT（Cui et al., 2024））。
>



为检验泛化能力，我们实施了谨慎的数据划分策略：对 Tahoe-100M 数据集，我们使用 50 种可用细胞系的伪批量表达值绘制 PCA，以目视识别不同的表型簇。随后从中选择五种细胞系纳入最终模型评估的测试集（图 S3）。在整个模型开发过程中，模型均未见过这些细胞系的任何数据。在另一项评估中，我们迭代地将来自 11 个不同器官的全部细胞留出用于测试。对 Parse-PBMC 数据集，我们从 12 名供体中随机留出 4 名。对于每个这样的留出情境，我们从测试数据中随机移出其 $ 30\% $ 的扰动，并将其纳入相应的训练数据。对 Replogle-Nadig 数据集，我们通过迭代留出一种细胞系作为测试集进行评估。每次迭代中，模型使用其余三种细胞系，加上从测试细胞系中随机抽取的额外 $ 30\% $ 扰动进行训练。



![](https://cdn.nlark.com/yuque/0/2026/jpeg/1739170/1786085570247-8bbd45a1-9752-419c-9618-a3b466f8c9f0.jpeg)

> 图 S3：Tahoe-100M 伪批量样本的 PCA 可视化揭示了相似细胞类型的聚类。伪批量通过对细胞系、扰动和培养板均匹配的全部细胞计数取平均而计算，随后聚合为每个细胞系一个伪批量。泛化数据划分据此选取，既不过难（包含部分邻近聚类的细胞类型），也不过易（包含部分离群细胞类型）。本分析使用的五个留出细胞系为：C32、HOP62、HepG2/C3A、Hs 766T 和 PANC-1。
>



我们的评估框架涵盖单细胞扰动实验的关键输出，这些输出可由三类读出很好地表示：（1）基因表达计数；（2）差异表达（DE）统计量，包括差异表达基因（DEG）的识别及其对数倍数变化；（3）扰动效应的大小（例如 DEG 总数）（图 2B）。为了从这些维度全面评估模型性能，我们开发了一套评估指标 CELL-EVAL（第 4.7 节，图 2C）。这些指标兼具表达能力和生物学可解释性，可提供互补的洞见。例如，DEG 重叠可以将预测与特定通路联系起来，从而赋予其生物学意义；但与捕捉预测扰动效应和真实扰动效应相似性的扰动区分分数相比，它对细粒度变化的敏感性可能较低。此外，通过与朴素基线比较，这些指标能够更清楚地判断模型是在实现泛化，还是仅仅记忆训练集效应。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786088897931-582b0699-9dce-4978-b39a-33ac4d0acf18.png)

> 图 2：STATE 在跨细胞情境预测扰动效应方面优于现有基线。（C）使用 CELL-EVAL 指标（第 4.7 节）在标准 Perturb-Seq 输出——表达计数和差异表达（DE）基因——上评估性能。
>



扰动实验的一个核心目标，是识别最能驱动目标转录组状态的扰动。为此，模型必须能够有效区分不同的扰动效应。我们采用了由 Wu et al.（2024）方法改编的一种扰动区分分数变体，它根据预测的扰动后表达谱与真实扰动结果的相似性进行排序。STATE 在 Tahoe 和 PBMC 数据集上分别获得 54% 和 29% 的绝对提升（图 2D）。在遗传扰动数据集上，STATE 与扰动均值基线性能相当，并显著优于基线模型。

为直接评估预测基因表达计数的准确性，我们计算了观测与预测的扰动诱导表达变化之间的 Pearson 相关性。在该指标上，STATE 在 Tahoe 数据集和 PBMC 数据集上分别比基线高出 $ 63\% $ 和 $ 47\% $。在遗传扰动数据集上，由于扰动效应更细微，该任务更具挑战性。STATE 再次与性能最佳的基线相当；在这种情况下，最佳基线是情境均值而非扰动均值，这表明 STATE 的预测并非简单地类似于某一个朴素基线（图 2E）。

> 图 S4：用于评估显著基因识别能力的补充指标。模型在化学、信号和遗传扰动数据集上训练与评估（Zhang et al., 2025；Replogle et al., 2022；Nadig et al., 2025）。比较对象包括（A）中的均值基线、简单线性模型（Ahlmann-Eltze et al., 2024）、基于自编码器的模型（scVI（Lopez et al., 2018）、CPA（Lotfollahi et al., 2023））以及基础模型 scGPT（Cui et al., 2024）。性能依据标准 Perturb-Seq 输出——表达计数和差异表达（DE）基因——进行评估，考察指标包括：（A）精确率—召回率曲线下面积（AUPRC），用于概括模型识别真实差异表达基因的能力，尤其适用于类别不平衡情形；（B）热图比较以差异表达基因数量衡量的真实总体扰动效应与 STATE 预测的扰动效应大小。

为了在全局排序和相关性指标之外评估 STATE，我们开展了系统性的差异表达（DE）分析。使用 Wilcoxon 秩和检验，我们识别了扰动后的差异表达基因，并计算其对数倍数变化和校正后的 p 值（假发现率）。我们将 DE 分析分解为对各组成部分（p 值和对数倍数变化）的独立评估，以及二者组合后的评估（DE 基因重叠）。为评估模型所预测 DE 基因的 p 值，我们首先使用实验观测到的扰动数据计算真实显著 DE 基因，并将 FDR 阈值设为 0.05。随后使用精确率—召回率曲线，将模型预测所得 p 值与真实显著性水平进行比较。通过测量精确率—召回率曲线下面积，我们发现 STATE 在各数据集上始终优于所有基线（图 2F）。值得注意的是，在遗传扰动数据集上，STATE 的 AUPRC 比次优方法高出 184%（图 2G、图 S4）。

评估对数倍数变化时，我们将分析限制在真实显著的 DE 基因，以减少预测显著性水平所带来的混杂。对于每个此类基因，我们计算预测和真实对数倍数变化之间的 Spearman 相关性。scVI 等一些机器学习基线在该指标上表现强劲，但 STATE 在 Tahoe 和 PBMC 数据集上的性能仍比基线高出 10% 以上（图 2H）。为模拟实际的 DE 分析流程，我们对模型预测的 p 值施加 0.05 的 FDR 阈值以筛选 DE 基因，再按对数倍数变化对该集合排序，并与由真实 p 值和倍数变化得到的对应集合比较。在采用不同的重叠规模设置（k = 50、100、200）时，STATE 在三个数据集和三种 k 设置下都表现强劲（图 S5A）。为求完整，我们还评估了可变大小的重叠，将 k 设置为真实差异表达基因的数量。在 Tahoe 数据集上，STATE 的性能是次优基线 scGPT 的两倍；在 PBMC 数据集上，则比相应的最佳基线线性模型高 43%（图 2I）。为评估更具实际意义的最小化假阳性场景，我们还测量了预测的前 k 个 DE 基因中，在观测实验数据里确实显著的比例（precision@k）。在各数据集及不同 k 设置下，STATE 的表现均远强于基线（图 S5B）。

## STATE 嵌入增强了跨情境和扰动模态的零样本扰动预测


构建细胞状态与行为虚拟模型的目标之一，是开发可应用于新情境的通用预测模型，即使这些情境中没有任何可用的扰动数据也能使用（Bunne et al., 2024a）。这些模型还应能够从一个数据集中学习细胞调控信息，并将其有效迁移到其他数据集，而不受化学或遗传干预等扰动模态的限制。然而，基因表达计数会受到情境特异性变异的影响（例如测序深度和实验平台），因而并不总能很好地跨研究泛化。



为解决这一问题，我们开发了一种可在数据集和实验之间共享的统一细胞表征，以增强在此前未受扰动的细胞情境中的扰动预测能力。状态嵌入模型（SE）通过学习针对捕捉细胞类型特异性基因表达模式而优化的细胞嵌入，对 ST 形成补充（图 3A）。与 ST 结合使用时，该嵌入利用庞大的观察性单细胞数据资源库（Program et al., 2025; Zhang et al., 2025; Youngblut et al., 2025），在细胞状态上学习出更平滑的景观。SE 使我们能够间接利用观察性单细胞数据来改善扰动响应预测，特别是在特定情境的干预数据稀缺或噪声较大的情况下。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786090202246-771df1eb-1786-454a-b926-44d1055f613d.png)

> **图 3：状态嵌入增强了跨数据集、实验和模态的零样本扰动效应预测。（A）状态嵌入模型（SE）学习多样化数据集中丰富且可泛化的转录组信息表征。**给定一个对照（未受扰动）细胞群体，SE 计算细胞嵌入。随后 ST 预测这些嵌入将如何响应指定扰动而发生偏移，从而在潜在空间中有效建模扰动的分布效应。最后，一个学习得到的解码器将预测嵌入映射回基因表达空间。
>



从架构上看，SE 编码器是一种密集双向 Transformer，训练目标是预测对数归一化基因表达（第 4.4 节）。SE 解码器则是一个更小的专用 MLP，它根据学习到的细胞嵌入与目标基因嵌入的组合来预测基因表达（图 S2B）。这种架构上的非对称性促使模型将可泛化的细胞状态表征学习到单个向量嵌入中。SE 使用沿两个轴计算的损失进行训练：它既预测每个细胞内部跨基因的表达，也预测每个小批次内每个基因跨细胞的表达。这种双轴公式促使模型同时捕捉单个细胞内部及群体内跨细胞的基因表达相对变异（Lal et al., 2024; Ding et al., 2025; Fischer et al., 2024）。该损失通过保留准确进行差异表达建模所需的细胞间变异，增强了模型对扰动效应的敏感性。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786705038730-6045f5ef-8a58-4069-927a-271c9911cb45.png)

> **图 S2：STATE 的完整模型架构。（B）SE 的模型架构。输入模型的基因集合所对应的 Transformer 输出不用于下游扰动预测；**而是将 `[CLS]` 令牌转换为细胞状态的强表征 `[State]`，用于预测基因表达变异性。
>



通过学习能够捕捉细微细胞间变异的通用嵌入，SE 解决了扰动建模中的一项核心挑战：定义可在单细胞数据集之间迁移的特征空间（图 3B）。当 SE 与 ST 结合使用时，ST 学习预测受扰动细胞嵌入，同时学习将这些预测嵌入解码到对数表达空间（图 S2B）。为评估 SE 所生成嵌入的质量，我们考察了它们区分不同扰动的能力。我们通过检验观测细胞的嵌入能否按扰动标签形成簇来衡量内在质量，并通过考察 ST 预测的嵌入能否保持这种分离来衡量外在质量（图 3C）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786090239055-3322fe76-ffd7-4de2-bab6-e4d11435766d.png)

> 图 3：状态嵌入增强了跨数据集、实验和模态的零样本扰动效应预测。（B）理解共享潜在空间在跨多种细胞情境和扰动对扰动效应进行建模时所产生的影响。（C）使用内在和外在指标评估嵌入质量：内在性能反映使用观测数据生成的嵌入中受扰动细胞的分类准确率；外在性能衡量在细胞嵌入上训练的 ST 所预测的受扰动嵌入中的分类准确率。

我们将 SE 与直接使用基因表达计数的方法，以及由 scFoundation（Hao et al., 2024）、scGPT（Cui et al., 2024）、Universal Cell Embedding（UCE）（Rosen et al., 2023）和 Transcriptformer（TF）（Pearce et al., 2025）生成的细胞嵌入进行比较，所用数据为 SE 训练期间未见过的三个留出扰动数据集（Srivatsan et al., 2020; Jiang et al., 2025; Replogle et al., 2022）。为了测量可分性，我们在嵌入上训练一个简单线性探针，预测每个细胞对应的扰动标签。与所有其他基础模型和原始表达计数相比，状态嵌入能更有效地区分扰动表型，甚至超过了使用原始数据表征所达到的性能（图 3D）。这表明，在某些情况下，SE 能够对 Perturb-seq 数据进行去噪。在外在评估中，与所有基线相比，状态嵌入还使下游扰动分类准确率获得超过 $ 6\% $ 的绝对提升。

# 讨论
---

高通量细胞扰动实验与人工智能的最新进展相结合，为开发细胞状态和行为的计算模型开辟了令人振奋的新途径。通过计算预测细胞对外部扰动的转录响应，可以帮助揭示疾病进展的潜在机制，并支持发现更精准的治疗方法。我们及其他研究者此前在分子尺度基础模型方面的工作，已展现出预测分子结构和功能等核心生物学特征的卓越能力（Brixi et al., 2025; Nguyen et al., 2024; Hayes et al., 2025; Lin et al., 2023）。然而，将这些成功转化到细胞层面已被证明困难得多。单细胞基础模型尚未达到同等水平的预测准确性或泛化能力，这主要是由于细胞作为动态、情境依赖系统所固有的复杂性。与单个 DNA、RNA 或蛋白质分子相对静态且均一的性质不同，细胞系统表现出显著的异质性，并深受环境和时间因素影响。对细胞系统建模面临两项核心挑战：一是正在接受扰动的细胞群体具有内在异质性，无法使用已知协变量完全解析；二是不同实验和数据集之间会引入变异。



我们的模型 STATE 提供了一种可扩展方法，用于跨多种细胞情境和实验条件学习细胞状态与行为的基础模型。状态转移模型（ST）以独特方式学习细胞群体层面的扰动效应，同时仍在预测中保持单细胞分辨率，从而捕捉无法由已知实验或生物学协变量解释的残余异质性。既往研究曾通过将细胞建模为群组来处理单细胞数据中的异质性（Persad et al., 2023; Boyeau et al., 2022; Dann et al., 2022），而 STATE 独特地利用置换不变的 Transformer 架构（Lee et al., 2019; Zaheer et al., 2017），直接对未配对细胞分布间的扰动效应进行建模。与基于最优传输的方法不同（Bunne et al., 2023; Chen et al., 2024; Demir et al., 2024; Dong et al., 2023），这使 STATE 不受关于分布结构的预定义假设约束。此外，我们的理论发现确定：在渐近极限和温和的正则性条件下，连接未受扰动与受扰动细胞群体的唯一连续 OT 映射（由固定二次代价定义），可证明包含在我们模型的解空间中（定理 2）。这使 STATE 能够在必要时学习 OT 映射，而无需将自身显式约束于僵化、预定义的 OT 公式，也无需使用通常与显式 OT 求解器相关的专用架构组件。此外，通过引入显式的基于 Jacobian 的约束，我们表明 STATE 可以唯一识别并学习这一连续最优传输映射（定理 3），从而成为一个功能强大、具有理论基础的神经 OT 求解器。



STATE 的核心目标，是可靠地模拟多种细胞情境下的单细胞扰动实验。我们以该目标为指导，设计了一套综合模型评估体系 CELL-EVAL，重点考察三个关键维度的性能：基因表达计数、差异表达和扰动效应量。据我们所知，STATE 是首个在细胞情境泛化任务中，跨多个数据集、几乎所有指标上持续优于均值模型或线性模型等简单基线的机器学习模型。此外，纳入细胞嵌入模型 SE 的嵌入后，可以在新细胞情境中实现更有效的零样本扰动效应预测，这是开发真正可泛化虚拟细胞的一项核心目标。STATE 在预测扰动效应量时展现出强大的零样本性能；而反映更细微变化的指标，例如单个 DE 基因的准确性，则对数据集规模和质量更为敏感。随着大规模扰动图谱不断增长（Rood et al., 2024），我们预计这些更细微指标上的性能将会改善；鉴于 STATE 对细胞和数据变异的稳健性有所提高，它很适合利用这些数据集。此外，我们发现 ST 注意力图对细胞集合异质性具有敏感性，这表明可解释性是未来利用 STATE 进一步理解基因调控机制的一条有前景的路径（第 6 节）。



当应用于先前见过的情境时，我们发现 STATE 的预测具有生物学意义，能够准确捕捉情境特异性扰动效应，例如细胞类型特异性 DE 基因。研究还发现，预测的扰动后表达谱可以捕捉细胞存活等非转录性细胞表型。这些能力使 STATE 朝着实现更宏大的虚拟细胞愿景迈出了一步：一种能够探索可能细胞状态空间的模型（Bunne et al., 2024a; Noutahi et al., 2025），并可指导 AI 智能体等自主系统开展实验设计（Roohani et al., 2024b; Huang et al., 2025; Rizvi et al., 2025; Wu et al., 2025）。STATE 通过推进扰动—响应建模的最先进水平，并引入一种能够有意义地利用日益增长的单细胞扰动数据规模与多样性的架构，为这一愿景作出贡献。其灵活的 Transformer 架构可支持一系列涉及不同群体间转变建模的任务，例如分化、发育和重编程。STATE 也不依赖于特定细胞表征的选择，因此可以无缝扩展到更多数据模态，包括蛋白质组学、形态学测量以及基于文献的知识。通过在 STATE 中纳入扰动特征化机制，我们预计可以进一步降低药物与基因敲低等不同模态之间的障碍，同时为组合扰动预测打开大门。尽管 STATE 已在 70 多种细胞情境上训练和评估，我们尚未检验它在完全留出的数据集上的可用性，即训练期间未见过其中任何细胞情境的数据集。通过在 scBaseCount（Youngblut et al., 2025）等更大型数据集上训练来进一步改进 SE，将对跨如此多样化的设置泛化预测起到关键作用。

# 方法
---

## 数据生成过程


我们假设，每个细胞观测到的、经对数归一化的扰动后表达状态 $ X_{\mathrm{p}} $，是由一个不可观测的未扰动状态 $ X_0 $ 生成的随机变量；$ X_0 $ 本身也是一个随机变量，代表细胞的潜在表达状态。对于给定的一组协变量（例如细胞系、批次条件等），$ X_0 $ 从基础细胞分布 $ \mathcal{D}_{\mathrm{basal}} $ 中抽取，而扰动效应可建模如下：



$ X _ {p} = X _ {0} + T _ {p} (X _ {0}) + \varepsilon , \qquad X _ {0} \sim \mathcal {D} _ {\mathrm{basal}}\tag{2} $

其中：

+ $ T_{p}(X_{0}) $：扰动 $ p $ 所引起的真实效应。
+ $ \varepsilon $：实验特异性的技术噪声，假设其与 $ X_0 $ 相互独立。



由于单细胞转录组测量会破坏细胞，因此 $ X_{0} $ 不可观测，无法直接对式 2 建模。相反，我们的方法作用于可观测的 $ D_{basal} $，以预测记作 $ \hat{X}_{p} $ 的扰动后状态。这构成了我们模型的基础：



$ \begin{array}{r l} & {\hat {X} _ {p} \sim \hat {T} _ {p} (\mathcal {D} _ {\mathrm{basal}}) + H (\mathcal {D} _ {\mathrm{basal}}) + \varepsilon , \qquad \varepsilon \sim P _ {\varepsilon}} \\ & {X _ {\mathrm{p}} \stackrel {d} {\approx} \hat {X} _ {\mathrm{p}}} \end{array}\tag{3} $



在这一近似中，扰动的真实效应 $ T_{p}(X_{0}) $ 现在是在整个基础群体的情境下考虑的，记作 $ \hat{T}_{p}(\mathcal{D}_{\mathrm{basal}}) $。此外，我们显式引入 $ H(\mathcal{D}_{\mathrm{basal}}) $，以表示基线群体固有的生物学异质性。在第一个方程中，从 $ X_{0} \sim D_{basal} $ 采样时，这种异质性被隐式消除了；而在此处，为反映我们转向分布视角的变化，它被明确表示出来。$ \hat{X}_{p} $ 可视为 $ X_{p} $ 的分布层面对应物，使我们能够依据可观测的群体特征，而非不可观测的单个细胞状态，对扰动后状态建模。



图 1A 展示了这些假设。STATE 的设计旨在反映这一数据生成过程的假设：它使用状态转移模型（ST）直接建模 $ \hat{T}_{p}(\mathcal{D}_{\mathrm{basal}}) + H(\mathcal{D}_{\mathrm{basal}}) $，并使用状态嵌入模型（SE）处理 $ \varepsilon $。

## 任务描述


下面介绍用于评估的核心预测任务。

### 情境泛化任务


为评估扰动模型的泛化能力，我们首先测试扰动效应在 Perturb-Seq 数据集内部的泛化（图 2）。设生物学情境（某个数据集中的细胞类型或细胞系）的集合为 C，共用的扰动目录为 P。对于每个情境 $ c \in C $，以 $ P_{c} \subseteq P $ 表示在该情境中实际分析过的扰动子集，并以 $ X_{p,c} \in R^{d} $ 表示依据式 2 为二元组 $ (p,c) $ 生成的基因表达向量。形式化地，我们固定一个测试情境 $ c^{*} \in C $。随后选择比例 $ \alpha = 0.30 $，并均匀随机抽取一个支持集



$ \mathcal {P} _ {c ^ {*}} ^ {\sup} \subset \mathcal {P} _ {c ^ {*}}, \qquad | \mathcal {P} _ {c ^ {*}} ^ {\sup} | = \left\lfloor \alpha | \mathcal {P} _ {c ^ {*}} | \right\rfloor ,\tag{4} $



其余扰动构成查询集 $ P_{c^{*}}^{qry} = P_{c^{*}} \setminus P_{c^{*}}^{sup} $。一个折中的训练集和测试集划分如下：



$ \mathcal {D} _ {\text {train}} = \left\{\left(X _ {p, c}, p, c\right): c \in \mathcal {C} \setminus \left\{c ^ {*} \right\}, p \in \mathcal {P} _ {c} \right\} \cup \left\{\left(X _ {p, c ^ {*}}, p, c ^ {*}\right): p \in \mathcal {P} _ {c ^ {*}} ^ {\sup} \right\},\tag{5} $

$ \mathcal {D} _ {\text { test }} = \left\{\left(X _ {p, c ^ {*}}, p, c ^ {*}\right): p \in \mathcal {P} _ {c ^ {*}} ^ {\mathrm{qry}} \right\}.\tag{6} $



因此，模型能够看到 $ C \setminus \{c^{*}\} $ 中的所有扰动，但在测试情境 $ c^{*} $ 中仅能看到 30% 的扰动。若 $ |C| $ 较大，则从中指定一个多样且固定的子集 $ C_{test} \subset C $，包含 n 个情境，作为测试情境。我们使用 $ C \setminus C_{test} $ 中的情境，以及每个 $ c_{j} \in C_{test} $ 中 30% 的扰动来构建 $ D_{train} $。随后构建多个 $ D_{test} $，分别对应每个 $ c_{j} \in C_{test} $，每个测试集均包含来自 $ c_{j} $ 的其余未见扰动。若 $ |C| $ 较小，我们则迭代地留出单个情境 $ c^{*} = c_{j} $；使用其余 $ C \setminus \{c_{j}\} $ 情境以及 $ c_{j} $ 中 30% 的扰动构建 $ D_{train} $，并使用 $ c_{j} $ 中其余未见扰动构建 $ D_{test} $。这一迭代过程会生成多个训练集，从而能够报告各个独立训练模型之间的偏差。在两种情况下，我们均报告各 $ D_{test} $ 上的平均损失，由此稳健估计模型从稀疏观测的情境外推至同一情境内未见扰动的能力。

### 零样本适配任务


为评估扰动模型的跨数据集泛化能力，我们重点考察扰动效应跨生物学情境的零样本泛化（图 3G）。在此，模型先在较大的扰动数据集上训练，再通过完全微调适配至较小的数据集。我们重点研究跨数据集向新细胞系、细胞类型和供体的适配，因为这构成了一个定义明确且具有重要实践意义的情境迁移评估场景（Mirabelli et al., 2019）。



在零样本适配任务中，模型在一组细胞系的扰动数据上训练，并需预测相同扰动在完全未见细胞系中的效应。形式化地，细胞系集合被划分为 $ C_{train} \subset C $ 和 $ C_{test} \subset C $，且 $ C_{train} \cap C_{test} = \varnothing $。训练数据



$ \mathcal {D} _ {\mathrm{train}} = \left\{\left(X _ {p, c}, p, c\right) \Big | (p, c) \in \mathcal {P} \times \mathcal {C} _ {\mathrm{train}} \right\}\tag{7} $



包含训练细胞系中的全部扰动。在 $ D_{train} $ 上拟合 $ f_{\theta} $ 后，我们在相同扰动 $ p \in P $、但未见细胞系 $ c \in C_{test} $ 上对其进行评估。因此，测试集为



$ \mathcal {D} _ {\text { test }} = \Big \{\left(X _ {p, c}, p, c\right) \big | (p, c) \in \mathcal {P} \times \mathcal {C} _ {\text { test }} \Big \}.\tag{8} $



该任务直接评估模型是否学到了生物学情境与扰动响应之间可泛化的关系。

## 状态转移模型（ST）


ST 是一个深度学习模型，用于学习扰动在细胞群体中引发的转录组响应。该模型使用一种在细胞间执行自注意力的 Transformer 架构，以预测对照细胞分布与扰动细胞分布之间的扰动效应。设



$ \mathcal {D} = \left\{\left(\mathbf {x} ^ {(i)}, p _ {i}, \ell_ {i}, b _ {i}\right) \right\} _ {i = 1} ^ {N}, \qquad \mathbf {x} ^ {(i)} \in \mathbb {R} ^ {G}.\tag{9} $



表示在该基因集上获得的单细胞 RNA 测序数据集，其中 G 为基因数。这里，$ \mathbf{x}^{(i)} $ 表示细胞 i 的原始计数值经过处理后得到的归一化表达向量。具体而言，细胞 i 经扰动 $ p_{i} $（若有）后，在基因 j 上观测到的原始计数值起初为 $ \mathbf{x}_{j}^{(i),\mathrm{raw}} \in \mathbb{N}_{0} $。使用 Scanpy（normalize_total → log1p）对这些原始计数进行测序深度归一化和对数变换，得到非负实值表达向量 $ \mathbf{x}^{(i)} $。每个细胞都带有扰动标签 $ p_{i} \in \{1, \ldots, P\} \cup \{\mathtt{ctrl}\} $、生物学情境或细胞系标签 $ \ell_{i} \in \{1, \ldots, L\} $，以及可选的批次效应标签 $ b_{i} \in \{1, \ldots, B\} $。

### 细胞集合的构建


我们依据细胞的生物学情境、扰动和批次标签将其分组为集合：



$ \mathcal {C} _ {\ell , p, b} = \left\{\mathbf {x} ^ {(i)} \in \mathcal {D} \mid \ell_ {i} = \ell , p _ {i} = p, b _ {i} = b \right\}.\tag{10} $



令 $ N_{\ell,p,b} = \left|\mathcal{C}_{\ell,p,b}\right| $ 表示各组中的细胞数。给定目标集合大小 $ S $，我们将 $ \mathcal{C}_{\ell,p,b} $ 划分为大小为 $ S $ 的互不重叠子集，以构建一组张量 $ \mathcal{S}_{\ell,p,b}^{(k)} \in \mathbb{R}^{S \times G} $，其中 $ k \in \left\{1, \ldots, \left\lfloor \frac{N_{\ell,p,b}}{S} \right\rfloor \right\} $。若 $ N_{\ell,p,b} $ 不能被 $ S $ 整除，则剩余细胞组成最后一个较小的集合；通过从该集合自身进行有放回的额外细胞采样，将其填充至大小 $ S $。

### 在细胞集合上训练


训练期间，每个集合 $ \mathcal{S}_{\ell,p,b}^{(k)} $（其中 $ p \in \{1, \ldots, P\} \cup \{ctrl\} $）都与相应的对照集合配对。对照集合通过从相同细胞系 $ \ell $、以及可选的相同批次 b 中随机采样 S 个对照细胞构建。形式化地，对于每个训练样本 $ \mathcal{S}_{\ell,p,b}^{(k)} $，我们通过映射操作构建配对的对照集合：



$ \operatorname{map} \left(\mathcal {S} _ {\ell , p, b} ^ {(k)}\right) = \operatorname{stack} \left(\left[ \mathbf {x} ^ {(i)} \right] _ {\mathbf {x} ^ {(i)} \sim \mathcal {C} _ {\ell , \text { ctrl }, b}}\right) \in \mathbb {R} ^ {S \times G}\tag{11} $



无论 $ \mathcal{S}_{\ell,p,b}^{(k)} $ 包含扰动细胞还是对照细胞，这一映射都以相同方式应用。映射函数的选择实际上决定了哪些变异来源会被显式控制。通过以特定协变量（例如细胞系 $ \ell $、批次 b）为条件，映射函数可以减少已知的异质性来源；否则，这些来源可能混淆真实的扰动信号。不同的映射策略会对非扰动变异引入不同的先验。例如，从同一批次采样对照细胞可减少技术变异，但也会限制每个集合中的不同细胞数量，因而可能限制模型性能。



为构建小批次，我们收集 B 个这样的集合对：$ \{(\mathcal{S}_{\ell_{i},p_{i},b_{i}}^{(k_{i})},\mathsf{map}(\mathcal{S}_{\ell_{i},p_{i},b_{i}}^{(k_{i})}))\}_{i=1,\ldots,B} $，其中不同的集合对可能来自不同的细胞系、扰动以及（可选）批次组合。随后将其整理为以下张量：



$ \begin{array}{r l} & {\mathbf {X} _ {\mathrm{target}} = \mathsf {s t a c k} ([ \mathcal {S} _ {\ell_ {1}, p _ {1}, b _ {1}} ^ {(k _ {1})}, \ldots , \mathcal {S} _ {\ell_ {B}, p _ {B}, b _ {B}} ^ {(k _ {B})} ]) \in \mathbb {R} ^ {B \times S \times G}} \\ & {\quad \mathbf {X} _ {\mathrm{ctrl}} = \mathsf {s t a c k} ([ \mathsf {m a p} (\mathcal {S} _ {\ell_ {1}, p _ {1}, b _ {1}} ^ {(k _ {1})}), \ldots , \mathsf {m a p} (\mathcal {S} _ {\ell_ {B}, p _ {B}, b _ {B}} ^ {(k _ {B})}) ]) \in \mathbb {R} ^ {B \times S \times G}} \\ & {\quad \mathbf {Z} _ {\mathrm{pert}} \in \mathbb {R} ^ {B \times S \times D _ {\mathrm{pert}}} \quad (\mathrm{perturbationembeddings})} \\ & {\quad \mathbf {Z} _ {\mathrm{batch}} \in \mathbb {R} ^ {B \times S \times D _ {\mathrm{batch}}} \quad (\mathrm{optionalbatchcovariates})} \end{array}\tag{12} $



其中，$ D_{pert} $ 和 $ D_{batch} $ 分别表示扰动嵌入和批次嵌入的维度。对于 STATE，我们对扰动和批次使用独热编码，因此 $ D_{pert} $ 等于数据中不同扰动的数量，而 $ D_{batch} $ 等于不同批次标签的数量。ST 将 $ X_{ctrl} $ 与扰动嵌入 $ Z_{pert} $ 一同作为输入，并学习预测作为输出的 $ X_{target} $，从而学习将对照细胞群体转换为相应的扰动后状态。

### 神经网络模块


ST 使用专门的编码器，将细胞表达谱、扰动标签以及可选的批次标签映射至共享隐藏维度 $ d_{h} $，该表示将作为 Transformer 的输入。



**对照细胞编码器。** 每个经对数归一化的表达向量 $ \mathbf{x}^{(i)} \in \mathbb{R}^{G} $，均通过一个采用 GELU 激活函数的四层 MLP 映射为嵌入。MLP $ f_{cell} $ 在整个对照张量中独立应用于每个细胞：



$ \mathbf {H} _ {\mathrm{cell}} = f _ {\mathrm{cell}} (\mathbf {X} _ {\mathrm{ctrl}}) \in \mathbb {R} ^ {B \times S \times d _ {h}}\tag{13} $



这会将输入形状从 $ (B\times S\times G)\to (B\times S\times d_h) $ 变换。



**扰动编码器。** 扰动标签被编码到相同的嵌入维度 $ d_{h} $。对于独热编码的扰动，将输入向量传入一个采用 GELU 激活函数的四层 MLP：



$ \mathbf {H} _ {\mathrm{pert}} = f _ {\mathrm{pert}} (\mathbf {Z} _ {\mathrm{pert}}) \in \mathbb {R} ^ {B \times S \times d _ {h}}\tag{14} $



这会将输入形状从 $ (B \times S \times D_{\mathrm{pert}}) \rightarrow (B \times S \times d_{h}) $ 变换（注意：给定批次的同一集合内，所有细胞的扰动嵌入均相同）。作为另一种选择，当扰动由连续特征表示时（例如分子描述符或基因嵌入），这些嵌入将直接用于 $ H_{pert} $，并令 $ d_{h} = D_{pert} $。



**批次编码器。** 为处理技术性批次效应，批次标签 $ b_{i} \in \{1, \ldots, B\} $ 被编码为维度 $ d_{h} $ 的嵌入：



$ \mathbf {H} _ {\mathrm{batch}} = f _ {\mathrm{batch}} (\mathbf {Z} _ {\mathrm{batch}}) \in \mathbb {R} ^ {B \times S \times d _ {h}}\tag{15} $



其中 $ f_{batch} $ 为嵌入层。这会将输入形状从 $ (B \times S \times D_{\mathrm{batch}}) \to (B \times S \times d_{h}) $ 变换。



**Transformer 的输入与输出。** ST 的最终输入通过将对照细胞嵌入、扰动嵌入和批次嵌入相加而构成：



$ \mathbf {H} = \mathbf {H} _ {\mathrm{cell}} + \mathbf {H} _ {\mathrm{pert}} + \mathbf {H} _ {\mathrm{batch}}\tag{16} $



该复合表示被传入 Transformer 主干 $ f_{ST} $，以对整个细胞集合中的扰动效应进行建模。输出计算如下：



$ \mathbf {O} = \mathbf {H} + f _ {\mathrm{ST}} (\mathbf {H})\tag{17} $



其中，$ O \in R^{B \times S \times d_{h}} $ 表示最终输出。这一形式促使 Transformer $ f_{ST} $ 将扰动效应学习为相对于输入表示 H 的残差。



**基因重建头。** 当直接在表达空间中使用输入时，基因重建头会将 Transformer 的输出 O 映射回基因表达空间。这通过一个线性投影层实现，并独立应用于每个细胞集合中各 token 的 $ d_{h} $ 维隐藏表示。具体而言，对于批次中的每个细胞 b，$ \mathbf{O}^{(b)} \in \mathbb{R}^{S \times d_{h}} $ 是细胞 b 的 Transformer 输出，其重建基因表达 $ \hat{\mathbf{X}}_{\mathrm{target}}^{(b)} \in \mathbb{R}^{S \times G} $ 为：



$ \hat {\mathbf {X}} _ {\mathrm{target}} ^ {(b)} = f _ {\mathrm{recon}} (\mathbf {O} ^ {(b)}) = \mathbf {O} ^ {(b)} \mathbf {W} _ {\mathrm{recon}} + \mathbf {b} _ {\mathrm{recon}}\tag{18} $



其中，$ W_{recon} \in R^{d_{h} \times G} $ 和 $ b_{recon} \in R^{G} $ 是可学习参数。该操作对隐藏表示进行变换，得到批次中每个细胞重建的、经对数变换的基因表达值。

### 使用最大均值差异学习扰动效应


ST 通过最小化预测的转录组响应 $ (\hat{\mathbf{X}}_{\mathrm{target}}) $ 与观测到的转录组响应 $ (\mathbf{X}_{\mathrm{target}}) $ 之间的差异进行训练。该差异使用最大均值差异（MMD）（Gretton et al., 2012）来量化；MMD 是一种统计量，通过选定的核函数，依据两个概率分布在再生核希尔伯特空间（RKHS）中的嵌入来衡量二者之间的距离。MMD 先前已被用于单细胞扰动效应建模（Zhang et al., 2023）。



对于每个小批次元素 b，我们考虑该批次中 S 个细胞的预测细胞表达向量集合（因此，这些细胞具有式 12 所述的相同细胞系 $ \ell $ 与扰动 p 组合）。稍微滥用一下记号，我们将该集合表示为 $ \hat{\mathbf{X}}_{\mathrm{target}}^{(b)}=\{\hat{\mathbf{x}}^{(i)}\in\mathbb{R}^{G}\text{ such that }i\in b\}_{i=1}^{S} $，并将批次中相应的 S 个目标细胞表达向量集合表示为 $ \mathbf{X}_{\mathrm{target}}^{(b)}=\{\mathbf{x}^{(i)}\in\mathbb{R}^{G}\text{ such that }i\in b\}_{i=1}^{S} $。随后使用 MMD 最小化这两个有限向量集合所隐式定义的经验概率分布之间的距离。



预测细胞集合与观测细胞集合之间的平方 MMD 计算如下：



$ \mathrm{MMD} ^ {2} \big (\hat {\mathbf {X}} _ {\mathrm{target}} ^ {(b)}, \mathbf {X} _ {\mathrm{target}} ^ {(b)} \big) = \frac {1}{S ^ {2}} \sum_ {i = 1} ^ {S} \sum_ {j = 1} ^ {S} \left[ k (\hat {\mathbf {x}} ^ {(i)}, \hat {\mathbf {x}} ^ {(j)}) + k (\mathbf {x} ^ {(i)}, \mathbf {x} ^ {(j)}) - 2 k (\hat {\mathbf {x}} ^ {(i)}, \mathbf {x} ^ {(j)}) \right]\tag{19} $



其中，$ k(\cdot,\cdot) $ 表示核函数。三项依次对应：（1）预测集合内部的相似性；（2）观测集合内部的相似性；（3）预测集合与观测集合之间的交叉相似性。



我们使用能量距离核：

$ k (\mathbf {u}, \mathbf {v}) = - \| \mathbf {u} - \mathbf {v} \| _ {2}, $



并通过 geomloss 库（Feydy et al., 2019）实现。



为便于表述，对于包含 B 个细胞集合的训练小批次，我们将批次平均 MMD 损失定义为这些 $ MMD^{2} $ 值的平均值：



$ \mathcal {L} _ {\mathrm{MMD}} (\hat {\mathbf {X}} _ {\mathrm{target}}, \mathbf {X} _ {\mathrm{target}}) = \frac {1}{B} \sum_ {b = 1} ^ {B} \mathrm{MMD} ^ {2} \Bigl (\hat {\mathbf {X}} _ {\mathrm{target}} ^ {(b)}, \mathbf {X} _ {\mathrm{target}} ^ {(b)} \Bigr).\tag{20} $



最小化该损失会促使模型生成扰动细胞表达向量集合，使其由 MMD 捕捉的整体统计属性与扰动标签一致，并与观测细胞集合的统计属性匹配。总损失为：



$ \mathcal {L} _ {\mathrm{total}} = \mathcal {L} _ {\mathrm{MMD}} (\hat {\mathbf {X}} _ {\mathrm{target}}, \mathbf {X} _ {\mathrm{target}}).\tag{21} $

### 在嵌入空间中训练 ST


ST 既可以直接在基因表达空间中训练，也可以在指定的嵌入空间中训练。为支持在嵌入空间中训练，我们对架构进行修改，加入一个额外的表达解码器。形式化地，令 E 表示嵌入空间的维度，通常 $ E \ll G $。张量 $ X_{target} $ 和 $ X_{ctrl} $ 现在分别记作 $ X_{target}^{emb} $ 和 $ X_{ctrl}^{emb} $，其维度为 $ B \times S \times E $。相应地，$ f_{cell} $ 被修改为将输入形状从 $ (B \times S \times E) \to (B \times S \times d_h) $ 变换，而 $ f_{recon} $ 被修改为将输出形状从 $ (B \times S \times d_h) \to (B \times S \times E) $ 变换。该输出记作 $ \hat{X}_{target}^{emb} $。其他编码器以及 Transformer 本身保持不变。



为恢复目标细胞的原始基因表达 $ X_{target} $，我们训练一个额外的解码器头 $ f_{decode} $。这是一个带有 dropout 的多层 MLP，用于从嵌入空间映射回完整基因表达空间：



$ \hat {\mathbf {X}} _ {\mathrm{target}} = f _ {\mathrm{decode}} (\hat {\mathbf {X}} _ {\mathrm{target}} ^ {\mathrm{emb}})\tag{22} $



这会将预测嵌入从 $ (B \times S \times E) \to (B \times S \times G) $ 变换，以恢复基因表达谱。



因此，ST 的损失被修改为使用两个目标集合：$ X_{target}^{emb} \in R^{B \times S \times E} $ 包含目标嵌入，而 $ X_{target} \in R^{B \times S \times G} $ 包含目标基因表达谱。具体而言，模型使用嵌入空间和基因表达空间中的 MMD 损失加权组合进行训练：



$ \mathcal {L} _ {\mathrm{total}} = \mathcal {L} _ {\mathrm{MMD}} (\hat {\mathbf {X}} _ {\mathrm{target}} ^ {\mathrm{emb}}, \mathbf {X} _ {\mathrm{target}} ^ {\mathrm{emb}}) + 0. 1 \cdot \mathcal {L} _ {\mathrm{MMD}} (\hat {\mathbf {X}} _ {\mathrm{target}}, \mathbf {X} _ {\mathrm{target}}) $



表达损失的权重乘以 0.1，以平衡两项并避免其压倒嵌入空间中的主要目标。这会促使模型主要在嵌入空间中学习扰动效应，同时将其解码至表达空间。我们的实验表明，嵌入空间提升了跨数据集扰动效应的学习效果，这说明嵌入空间更平滑的结构有利于更好地建模扰动生物学。

## 状态嵌入模型（SE）


ST 的设计推动了高质量细胞嵌入的发展：这类嵌入需要捕捉相关生物学信号，同时减少技术伪影。为此，我们开发了状态嵌入模型（SE），这是一个采用基因表达预测目标进行训练的自监督模型，用于从单细胞 RNA 测序数据中学习细胞表示。SE 生成的嵌入作为 ST 的输入，从而实现跨数据集与生物学情境更稳健的迁移。

### 通过蛋白质语言模型表示基因


我们的数据集（式 9）由细胞表达测量值 $ \mathbf{x}^{(i)} $ 构成，其中每个元素 $ \mathbf{x}_{j}^{(i)} $ 表示细胞 i 中基因 j 的归一化表达水平。除这些表达值外，SE 模型还通过预训练蛋白质语言模型嵌入 $ g_{j} $ 纳入了基因本身的丰富信息。



遵循近期工作（Rosen et al., 2023; Pearce et al., 2025），我们利用预训练蛋白质语言模型来编码基因特征。基因嵌入使用 ESM-2（3B）（esm2_t48_15B_UR50D（Lin et al., 2023））计算：首先，对基因中每条蛋白质编码转录本的逐氨基酸嵌入取平均，以计算转录本嵌入；随后，再对该基因的所有转录本取平均。此特征化过程捕捉基因之间的进化与功能关系。没有 Ensembl ID 的基因使用 MyGene API（Wu et al., 2013）和 Ensembl REST API（Yates et al., 2015）进行映射，并对有歧义的情况进行人工校订。SE 不纳入非蛋白质编码基因。



每个基因嵌入 $ \mathbf{g}_j\in \mathbb{R}^{5120} $ 均通过一个可学习的编码器投影到模型嵌入维度 $ h $：



$ \tilde {\mathbf {g}} _ {j} = \mathrm{SiLU} (\mathrm{LayerNorm} (\mathbf {g} _ {j} \mathbf {W} _ {g} + \mathbf {b} _ {g}))\tag{23} $



其中，$ W_{g} \in R^{5120 \times h} $ 和 $ b_{g} \in R^{h} $ 是可学习参数，SiLU 表示 Sigmoid 线性单元激活函数（Elfwing et al., 2018）。

### 细胞表示


我们将每个细胞 i 表示为其 $ \mathbf{x}^{(i)} $ 中表达量最高的基因序列。对于每个细胞，我们依据对数倍数表达水平排名，选择前 L = 2048 个基因来构建一个“表达集合”。经验上，将 L 增大至 2048 以上时，模型性能的边际收益逐渐减小。随后，在该序列中加入两个特殊 token：



$ \tilde {\mathbf {c}} ^ {(i)} = [ \mathbf {z} _ {\mathrm{cls}}, \tilde {\mathbf {g}} _ {1} ^ {(i)}, \tilde {\mathbf {g}} _ {2} ^ {(i)}, \ldots , \tilde {\mathbf {g}} _ {L} ^ {(i)}, \mathbf {z} _ {\mathrm{ds}} ] \in \mathbb {R} ^ {(L + 2) \times h}\tag{24} $



其中，$ z_{cls} \in R^{h} $ 是用于聚合细胞层面信息的可学习分类 token，而 $ z_{ds} \in R^{h} $ 是有助于解耦数据集特异性效应的可学习数据集 token。这里，$ \tilde{\mathbf{g}}_{\ell}^{(i)} $ 表示细胞 i 中表达量排名第 $ \ell $ 位的基因经过投影后的嵌入，其中 $ \ell \in \{1 \ldots, L\} $。基因选择具有细胞特异性：不同细胞可能具有不同的高表达基因集合，因而其各自表达集合中的基因嵌入也不同。若某个细胞表达的基因少于 L 个，则从未表达基因池中随机采样，将序列填充至长度 L。这样可为 Transformer 处理维持固定长度的输入。

### 表达感知嵌入


尽管细胞序列中的基因按表达水平排序，但模型并不会显式编码或使用其位置。相反，SE 使用一种受软分箱启发的表达嵌入方案（Hao et al., 2024），直接纳入表达值。对于细胞 $ i $ 的表达集合中表达量排名第 $ \ell $ 位的基因（对应基因 ID $ j_{\ell}^{(i)} $），其在细胞 $ i $ 中经对数归一化的表达值为 $ \mathbf{x}_{j_{\ell}^{(i)}}^{(i)} $，我们计算如下软分箱分配：



$ \boldsymbol {\alpha} _ {\ell} ^ {(i)} = \text { Softmax } (\text { MLP } _ {\text { count }} (\mathbf {x} _ {j _ {\ell} ^ {(i)}} ^ {(i)})) \in \mathbb {R} ^ {1 0}\tag{25} $

$ \mathbf {e} _ {\ell} ^ {(i)} = \sum_ {k = 1} ^ {1 0} \pmb {\alpha} _ {\ell , k} ^ {(i)} \mathbf {b} _ {k}\tag{26} $



其中，$ MLP_{count} : R \to R^{10} $ 由两个采用 LeakyReLU 激活函数的线性层（维度为 $ 1 \to 512 \to 10 $）构成，$ \{b_{k}\}_{k=1}^{10} $ 是维度为 h 的可学习分箱嵌入。得到的表达编码 $ \mathbf{e}_{\ell}^{(i)} $ 被加到相应的基因身份嵌入 $ \tilde{\mathbf{g}}_{\ell}^{(i)} $ 上：



$ \mathbf {g} _ {\ell} ^ {(i)} = \tilde {\mathbf {g}} _ {\ell} ^ {(i)} + \mathbf {e} _ {\ell} ^ {(i)}\tag{27} $



这些表达嵌入类似于语言模型中的位置编码；在这里，我们将表达量级直接嵌入基因身份表示之中。

### Transformer 编码


由表达感知的基因嵌入和特殊 token 构成的输入序列，被传入 Transformer 编码器 $ f_{SE} $：



$ \mathbf {E} ^ {(i)} = f _ {\mathrm{SE}} \big ([ \mathbf {z} _ {\mathrm{cls}}, \mathbf {g} _ {1} ^ {(i)}, \mathbf {g} _ {2} ^ {(i)}, \ldots , \mathbf {g} _ {L} ^ {(i)}, \mathbf {z} _ {\mathrm{ds}} ] \big) \in \mathbb {R} ^ {(L + 2) \times h}\tag{28} $



其中，对于 $ \ell\in\{1,\ldots,L\} $，每个 $ \mathbf{g}_{\ell}^{(i)} $ 均如式 27 所定义。需要注意的是，特殊 token [CLS] 和 [DS] 的表达编码被设为零。



输出是一个情境化嵌入序列。随后，从位置 0 的 [CLS] token 中提取细胞嵌入并进行归一化：



$ \mathbf {e} _ {\mathrm{cls}} ^ {(i)} = \mathrm{LayerNorm} (\mathbf {E} _ {0} ^ {(i)}) \in \mathbb {R} ^ {h}\tag{29} $



该嵌入作为细胞转录组状态的汇总表示。类似地，我们从位置 $ L + 1 $ 的 [DS] token 中提取数据集表示：



$ \mathbf {e} _ {\mathrm{ds}} ^ {(i)} = \mathrm{LayerNorm} (\mathbf {E} _ {L + 1} ^ {(i)}) \in \mathbb {R} ^ {h}\tag{30} $



该嵌入用于在训练期间捕捉并处理数据集特异性效应。



最终嵌入是这两个量的拼接：



$ \mathbf {z} _ {\mathrm{cell}} ^ {(i)} = [ \mathbf {e} _ {\mathrm{cls}} ^ {(i)}, f _ {\mathrm{proj}} (\mathbf {e} _ {\mathrm{ds}} ^ {(i)}) ] \in \mathbb {R} ^ {h + 1 0}\tag{31} $



其中，$ f_{\mathrm{proj}}(\mathbf{e}_{\mathrm{ds}}^{(i)}) \in \mathbb{R}^{10} $ 是一个可学习的线性投影，将数据集嵌入从 $ h \to 10 $ 投影。该细胞嵌入 $ \mathbf{z}_{\mathrm{cell}}^{(i)} $ 作为 ST 中单个细胞的输入表示，使多尺度 State 架构能够利用丰富的细胞表示，对群体层面的扰动进行建模。

### 预训练目标


SE 使用包含两个互补目标的自监督学习框架进行训练：（1）基因表达预测任务；（2）辅助数据集分类任务，后者有助于将技术性批次效应与生物学信号解耦。



**基因表达预测。** 训练期间，模型接收完整的细胞输入序列（如式 24 所述），并需要为每个细胞预测一组选定的 1,280 个基因的表达值。为确保覆盖整个表达动态范围，预测目标基因从以下三类中抽取：

+ $ \mathcal{P}^{(i)} $：一组 $ |\mathcal{P}^{(i)}| = 512 $ 个高表达基因（来自细胞序列 $ i $ 的前 $ L $ 个基因）；
+ $ \mathcal{N}^{(i)} $：一组 $ |\mathcal{N}^{(i)}| = 512 $ 个未表达基因（从不属于细胞 $ i $ 前 $ L $ 个基因的基因中随机采样）；
+ $ \mathcal{R} $：一组从完整基因集中随机采样的 $ |\mathcal{N}^{(i)}| = 256 $ 个基因，由批次中的所有细胞共享。



由此，每个细胞共有 1,280 个基因需要预测其表达值。该策略促使模型在广泛的表达动态范围内重建表达值，并在预测时能够访问完整转录组情境的同时，学习已表达基因与沉默基因的有意义表示。



**表达预测解码器。** 为了从测序深度不同的各类数据集的基因表达预测中学习，我们使用一个结合多种信息来源的 MLP 解码器：



$ \hat {\mathbf {x}} _ {j} ^ {(i)} = \mathrm{MLP} _ {\mathrm{dec}} ([ \mathbf {z} _ {\mathrm{cell}} ^ {(i)}; \tilde {\mathbf {g}} _ {j}; r ])\tag{32} $



其中，$ \mathbf{z}_{\mathrm{cell}}^{(i)} \in \mathbb{R}^{h+10} $ 是学到的细胞嵌入（式 31），$ \tilde{g}_{j} \in R^{h} $ 是目标基因的嵌入（式 23），$ r \in R $ 是一个标量测序深度指标，其计算方式为输入序列中已表达基因的平均对数表达量。这些量被拼接后传入 $ MLP_{dec} $；后者由两个带跳跃连接的模块和随后的线性输出层构成，用于预测细胞 i 中目标基因 j 的对数表达量。



对于训练批次中的每个细胞 $ i $，令 $ \hat{\mathbf{Y}}^{(i)} = [\hat{\mathbf{x}}_j^{(i)}]_{j\in \mathcal{P}^{(i)}\cup \mathcal{N}^{(i)}\cup \mathcal{R}}\in \mathbb{R}^{1\times 1280} $ 表示一个行向量，其中包含集合 $ \mathcal{P}^{(i)}\cup \mathcal{N}^{(i)}\cup \mathcal{R} $ 内基因的预测表达值；令 $ \mathbf{Y}^{(i)} = [\mathbf{x}_j^{(i)}]_{j\in \mathcal{P}^{(i)}\cup \mathcal{N}^{(i)}\cup \mathcal{R}}\in \mathbb{R}^{1\times 1280} $ 表示包含相应真实表达值的行向量。这些张量在批次中的细胞维度上堆叠：$ \mathbf{Y} = \mathsf{stack}([ \mathbf{Y}^{(i)} ]_{i = 1}^B) $，且 $ \hat{\mathbf{Y}} = \mathsf{stack}([ \hat{\mathbf{Y}}^{(i)} ]_{i = 1}^B) $，最终形状为（$ B\times 1\times 1280 $）。基因层面损失为：



$ \mathcal {L} _ {\mathrm{gene}} = \frac {1}{B} \sum_ {b = 1} ^ {B} \| \hat {\mathbf {Y}} ^ {(b)} - \mathbf {Y} ^ {(b)} \| _ {2}\tag{33} $



因此，它实际上衡量每个细胞 b 内预测基因表达模式与真实基因表达模式之间的相似性（随后在 $ L_{gene} $ 中对细胞取平均）。



为了捕捉小批次内不同细胞之间的基因表达变异，我们还使用共享基因子集 R 计算细胞层面损失。令 $ \hat{\mathbf{S}}^{(i)} = \mathsf{stack}([\hat{\mathbf{x}}_{j}^{(i)}]_{j \in \mathcal{R}}) \in \mathbb{R}^{256} $ 和 $ \mathbf{S}^{(i)} = \mathsf{stack}([\mathbf{x}_{j}^{(i)}]_{j \in \mathcal{R}}) \in \mathbb{R}^{256} $，分别表示细胞 i 中共享基因 R 的预测表达值和真实表达值。这些张量在批次中的细胞维度上堆叠后转置：$ S' = \text{transpose}(\text{stack}([\mathbf{S}^{(i)}]_{i=1}^{B})) $，且 $ \hat{S}' = \text{transpose}(\text{stack}([\hat{\mathbf{S}}^{(i)})]_{i=1}^{B}) $，得到形状 $ (|\mathcal{R}| \times 1 \times B) $，其中 $ |\mathcal{R}| = 256 $。随后，对于每个基因，我们计算批次中所有细胞的拼接预测值与目标值之间的距离。具体而言，我们考虑转置张量的第 r 个基因（行），记作 $ \hat{\mathbf{S}}'(r) $ 和 $ \mathbf{S}'(r) $（二者均为 $ 1 \times B $ 向量）：



$ \mathcal {L} _ {\mathrm{cell}} = \frac {1}{| \mathcal {R} |} \sum_ {r = 1} ^ {| \mathcal {R} |} \| \hat {\mathbf {S}} ^ {\prime (r)} - \mathbf {S} ^ {\prime (r)} \| _ {2}\tag{34} $



因此，它实际上衡量 R 中每个基因在批次内不同细胞之间的预测表达与真实表达之间的相似性（随后在 $ L_{cell} $ 中对基因取平均）。



表达预测的最终训练损失结合了两个轴向：



$ \mathcal {L} _ {\mathrm{expression}} = \lambda_ {1} \mathcal {L} _ {\mathrm{gene}} + \lambda_ {2} \mathcal {L} _ {\mathrm{cell}}\tag{35} $



这种双轴重建损失既捕捉每个细胞内按基因计算的重建保真度，也捕捉共享基因在不同细胞之间表达模式的一致性。



**数据集分类建模。** 为将数据集特异性的技术效应与生物学变异解耦，我们引入了一个辅助数据集预测任务。模型使用 [DS] token 嵌入预测数据来源：



$ \hat {d} ^ {(i)} = \mathrm{MLP} _ {\mathrm{dataset}} (\mathbf {e} _ {\mathrm{ds}} ^ {(i)})\tag{36} $



其中，$ \mathbf{e}_{\mathrm{ds}}^{(i)} $ 如式 30 所定义。我们采用交叉熵损失：



$ \mathcal {L} _ {\mathrm{dataset}} = \frac {1}{B} \sum_ {b} ^ {B} \mathrm{CrossEntropy} (\hat {d} ^ {(b)}, d ^ {(b)})\tag{37} $



其中，$ d^{(b)} $ 表示批次中细胞 b 的真实数据集标签，$ \hat{d}^{(b)} $ 为预测标签。



在我们的实现中，对于该分类任务，同一 AnnData 文件中的细胞被视为来自同一个数据集。对于在 Arc scBaseCount、CZ CELLxGENE 和 Tahoe 上训练的 SE 模型，该任务成为一个覆盖约 14,000 个数据集的多类别分类问题。该辅助目标促使模型将相关信息汇聚到这一 token 位置，并使其与真实生物学信号解耦。从经验上看，由于 scBaseCount 中的数据集按 Sequence Read Archive 实验标识符（SRX）组织，而这些标识符通常对应单独的细胞类型或实验条件，因此数据集 token 在捕捉技术性批次效应的同时，也会捕捉细胞类型与细胞系信息。由于该 token 嵌入完全源自细胞序列表示，未纳入元数据，因此训练后的模型可在推理时使用，而无需显式指定技术参数。



**总损失。** SE 模型使用两种损失的组合进行训练：



$ \mathcal {L} = \mathcal {L} _ {\mathrm{expression}} + \mathcal {L} _ {\mathrm{dataset}}.\tag{38} $

### ST 训练细节


所有组件均使用前述目标进行端到端训练。这些组件包括对照细胞编码器 $ f_{cell} $、扰动编码器 $ f_{pert} $、可选的批次编码器 $ f_{batch} $、Transformer 主干 $ f_{ST} $，以及重建头 $ f_{recon} $ 和解码头 $ f_{decode} $。



对于适配任务（图 3G），我们使用预训练权重初始化一个新的 ST 模型，同时选择性地重新初始化数据集特异性的组件。具体而言，我们重新初始化扰动编码器 $ f_{\mathrm{pert}} $，以支持跨扰动模态迁移。如果 ST 使用细胞嵌入进行训练，还会重新初始化基因解码器 $ f_{\mathrm{decode}} $，以适应数据集之间基因覆盖范围的差异。由于不同实验平台和数据集通常测量不同的基因子集，因此必须重新训练解码器，将共享嵌入空间映射到目标数据集特有的基因表达空间。所有其他组件——$ f_{\mathrm{cell}} $、$ f_{\mathrm{batch}} $ 和 $ f_{\mathrm{ST}} $——均保留其预训练权重，并在目标数据集上进行微调。

### SE 超参数


SE 是一个具有 6 亿参数的编码器—解码器模型，旨在通过预测基因表达变异来学习细胞表示。编码器由 16 个 Transformer 层组成，每层包含 16 个注意力头，隐藏维度 h = 2048。每层均采用预归一化，前馈网络扩展至维度 $ 3 \times h $，并使用 GELU 激活。我们在注意力层和前馈层中均使用概率为 0.1 的 dropout。解码器是一个多层感知机（MLP），通过学到的细胞嵌入和目标基因嵌入来恢复基因表达。我们使用 AdamW 优化器（Loshchilov and Hutter, 2017），最大学习率为 $ 10^{-5} $，权重衰减为 0.01，并使用 zclip（Kumar et al., 2025）进行梯度裁剪。学习率调度在总训练步数的前 3% 采用线性预热，随后通过余弦退火降至最大学习率的 30%。训练前，所有 SE 权重均通过从 Kaiming 均匀分布采样进行初始化。

### SE 训练细节


SE 在一个由 14,420 个 AnnData 文件组成的大规模语料库上训练了 4 个 epoch；该语料库覆盖 Arc scBaseCount（Youngblut et al., 2025）、CZ CELL×GENE（Program et al., 2025）和 Tahoe-100M（Zhang et al., 2025）数据集中的 1.67 亿个人类细胞。为避免数据泄漏，我们在数据集层面将数据划分为独立的训练集与验证集。为实现高效的大规模训练，我们使用 Flash Attention 2（Dao, 2024），并采用混合精度（bf16）训练（Kalamkar et al., 2019）。训练分布在 4 个计算节点上，每个节点配备 8 块 NVIDIA H100 GPU。模型训练时的有效批次大小为 3,072，每设备批次大小为 24，并在 4 个步骤上进行梯度累积。

## 评估


为了全面评估 STATE 对扰动效应进行建模的能力，我们设计了评估框架 CELL-EVAL，它既衡量表达水平的准确性，也捕捉具有生物学意义的差异表达模式。CELL-EVAL 不仅衡量统计性能，还衡量模型在模拟真实 Perturb-Seq 实验方面的实用性。

### 扰动评估指标


扰动模型的一个关键目标是区分不同的扰动效应。CELL-EVAL 使用若干互补指标对此进行评估：



**扰动判别分数。** 该指标改编自 Wu et al. (2024)，依据预测的扰动后表达谱与真实值的相似度对其进行排序。该分数定义为：对于某一预测扰动，在所有真实扰动中，其对应真实值的归一化排名。它直接评估模型能否恢复不同扰动之间的相对差异。在 Wu et al. (2024) 中，排序使用余弦相似度计算；我们则使用转录组之间的曼哈顿距离，原因有二：它对幅度更敏感（图 S10），并且我们的损失未进行归一化（Steck et al., 2024）。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786091437248-7fd5bcb2-4371-4bb0-a63f-a1d0b8db8dca.png)

> 图 S10：对真实基因表达数据采用不同判别运算所得的分布表明，余弦相似度会使排序指标产生偏斜。我们发现，余弦相似度不考虑表达数据中基因的幅值，因此会夸大真实基因表达值与预测值之间的相似性，进而导致下游基于排序的指标发生分布偏移。相比之下，欧氏距离（L2）和曼哈顿距离（L1）能够更好地区分细胞群体内不同的基因表达。
>



具体而言，令 $ T $ 为不同扰动的数量，$ y_{t} $ 为扰动 $ t $ 的真实表达谱，$ \hat{y}_{t} $ 为其预测表达谱。使用距离

$ d(\cdot,\cdot) $（此处为曼哈顿距离或欧氏距离），定义



$ r _ {t} = \sum_ {p \neq t} \mathbf {1} \Bigl \{d (\hat {y} _ {t}, y _ {p}) <   d (\hat {y} _ {t}, y _ {t}) \Bigr \},\tag{rank} $



即真实表达谱比正确表达谱更接近 $ \hat{y}_{t} $ 的其他扰动数量。每个扰动的分数为



$ \mathrm{PDisc} _ {t} = \frac {r _ {t}}{T}, $

（归一化排名）

其取值范围为 $ [0,1) $；$ PDisc_{t}=0 $ 表示完美匹配（不存在更接近的表达谱），接近 1 的值则表示判别能力较差。总体分数为其均值

$ \mathrm{PDisc} = \frac {1}{T} \sum_ {t = 1} ^ {T} \mathrm{PDisc} _ {t}.\tag{overall} $

我们报告归一化逆扰动判别分数：

$ \mathrm{PDiscNorm} = 1 - 2 \mathrm{PDisc}. $

（归一化总体分数）



因此，随机预测器得分为 0.0，完美预测器得分为 1.0。



**Pearson 差值相关性。** 该指标计算预测表达差值与观测表达差值之间的 Pearson 相关系数。表达差值是扰动伪批量与未扰动伪批量之间的转录组差异。具体而言，对于每个扰动 $ t $，我们构造伪批量 $ \bar{p}_{t} $ 和对照 $ \bar{c} $，并计算表达差值：$ \Delta_{t} = |\bar{p}_{t} - \bar{c}| $，即扰动细胞平均表达（$ \bar{p}_{t} $）与对照细胞平均表达（$ \bar{c} $）之间逐元素绝对差。评估分数为 Pearson 相关性



$ \mathrm{P} \Delta \text { Corr } = \operatorname{corr} \left(\Delta^ {\text { pred }}, \Delta^ {\text { real }}\right), $



使用 `scipy.stats.pearsonr` 在所有扰动上计算。



**校正互信息（AMI）。** AMI 用于评估模型在学习到的嵌入空间中保留扰动聚类结构的程度。我们首先按扰动聚合细胞，然后分别在真实数据集和预测数据集中，对每个扰动的所有相关细胞嵌入取平均，以计算该扰动的质心。随后，我们对这些质心执行 Leiden 聚类，并使用 AMI 比较预测聚类标签与真实聚类标签。所有分辨率下的最大 AMI 分数作为最终指标，用以反映模型预测的扰动空间捕获生物学扰动全局结构的程度。令 $ \mathcal{R} $ 为 Leiden 聚类分辨率的集合，$ \mathcal{C}_{r}^{true} $ 和 $ \mathcal{C}_{r}^{pred} $ 分别为分辨率 $ r $ 下真实质心和预测质心的聚类，则



$ \mathrm{AMI} ^ {*} = \max _ {r \in \mathcal {R}} \mathrm{AMI} \left(\mathcal {C} _ {r} ^ {\text {true}}, \mathcal {C} _ {r} ^ {\text {pred}}\right)\tag{39} $

****

**平均绝对误差（MAE）与均方误差（MSE）。** 为评估表达偏移的保留程度，我们计算每个扰动在预测数据集与真实数据集之间的 MAE 和 MSE。MAE/MSE 指标在预测伪批量和观测伪批量上进行评估。形式化地，对于扰动 $ t $，令 $ \bar{p}_{t} $ 和 $ p_{t} $ 分别表示预测和观测的伪批量表达，则



$ \mathrm{MAE} = \frac {1}{T} \sum_ {t = 1} ^ {T} \| \overline {{\bar {p}}} _ {t} - p _ {t} \| _ {1}, \quad \mathrm{MSE} = \frac {1}{T} \sum_ {t = 1} ^ {T} \| \overline {{\hat {p}}} _ {t} - p _ {t} \| _ {2} ^ {2}.\tag{40} $

### 差异表达


为评估生物学相关性，CELL-EVAL 使用 Wilcoxon 秩和检验进行差异表达分析，并采用 Benjamini–Hochberg 程序进行多重假设校正；该分析同时应用于测试细胞系中的观测值和模型预测值。



**符号。** 固定一个扰动 $ t \in [T] = \{1, \ldots, T\} $，令 $ G $ 为所有基因的集合。将 $ G_{t,\text{true}}^{(k)} $ 和 $ G_{t,\text{pred}}^{(k)} $ 定义为真实值和预测值中按对数倍数变化 $ |\Delta_{tg}| $ 排序的前 $ k $ 个显著差异表达基因（$ p_{adj} < 0.05 $）；将 $ G_{t,\text{true}}^{(\text{DE})} $ 和 $ G_{t,\text{pred}}^{(\text{DE})} $ 定义为完整的显著基因集合。所有秩相关均为 Spearman 相关，以 $ \rho_{rank} $ 表示。



CELL-EVAL 还使用许多互补指标评估模型性能：  


**DE 重叠准确率。** 对于每个扰动，我们识别前 $ k $ 个差异表达基因（$ k = 50, 100, 200, N $）；这些基因按校正后的 p 值筛选，并按绝对对数倍数变化排序。我们计算预测 DEG 集合与真实 DEG 集合的交集，并将重叠数量占 $ k $ 的比例作为结果。当 $ k = N $ 时，$ k $ 值随扰动而变化，其中 $ N $ 是真实 DEG 集合中差异表达基因的总数。未指定 $ k $ 时，DE 重叠指 $ N $ 处的 DE 重叠。即



$ \mathrm{Overlap} _ {t, k} = \frac {\left| G _ {t , \mathrm{true}} ^ {(k)} \cap G _ {t , \mathrm{pred}} ^ {(k)} \right|}{k}.\tag{41} $

****

**Top-k 精确率。** 对于每个扰动，我们计算真实值中前 $ k $ 个 DEG 有多少出现在模型预测的前 $ k $ 个 DEG 中，从而衡量不同阈值下的精确率。即



$ \mathrm{Precision} _ {t, k} = \frac {\left| G _ {t , \mathrm{true}} ^ {(k)} \cap G _ {t , \mathrm{pred}} ^ {(k)} \right|}{\left| G _ {t , \mathrm{pred}} ^ {(k)} \right|}.\tag{42} $

****

**方向一致性。** 对于每个扰动，我们使用校正 p 值阈值（例如 $ p < 0.05 $）在真实值中识别显著差异表达（DE）基因集合。然后求预测 DE 基因集合与观测 DE 基因集合的交集。对于每个重叠基因，我们检查预测倍数变化与真实倍数变化的方向是否相同。方向一致性定义为预测方向与观测方向相符的重叠基因比例。形式化地，令 $ G_{t}^{\cap} = G_{t,\mathrm{true}}^{(\mathrm{DE})} \cap G_{t,\mathrm{pred}}^{(\mathrm{DE})} $，对数倍数变化分别为 $ \Delta_{tg} $（真实）和 $ \hat{\Delta}_{tg} $（预测），则



$ \mathrm{DirAgree} _ {t} = \frac {| \{g \in G _ {t} ^ {\cap} \colon \mathrm{sgn} (\hat {\Delta} _ {t g}) = \mathrm{sgn} (\Delta_ {t g}) \} |}{| G _ {t} ^ {\cap} |}.\tag{43} $

****

**Spearman 相关性。** 我们将范围限定为真实值中显著差异表达的基因，并计算预测倍数变化与观测倍数变化之间的 Spearman 秩相关。对于每个扰动，我们依据校正 p 值阈值提取显著基因列表，然后计算预测值与真实值对数倍数变化之间的 Spearman 相关系数。即



$ \mathrm{Spearman} _ {t} = \rho_ {\mathrm{rank}} \big (\hat {\Delta} _ {t, G _ {t} ^ {*}}, \Delta_ {t, G _ {t} ^ {*}} \big).\tag{44} $

****

**ROC-AUC。** 为评估模型区分显著与非显著 DE 基因的能力，我们为观测数据中的每个基因赋予二元标签（若 $ p < 0.05 $ 则为 1，否则为 0），并将预测的 $ -\log_{10} $（校正 p 值）用作置信分数。我们在多个阈值下计算真阳性率（TPR）和假阳性率（FPR），并使用 `auc` 计算 ROC 曲线下面积。该指标评估模型在不受分类阈值影响的情况下区分显著与非显著基因的能力。即



$ \mathrm{ROC-AUC} _ {t} = \int_ {0} ^ {1} \mathrm{TPR} _ {t} (\mathrm{FPR}) d \mathrm{FPR}.\tag{45} $

****

**PR-AUC。** 为衡量模型识别显著 DE 基因时精确率与召回率之间的权衡，与 ROC-AUC 类似，我们使用观测数据的二元标签，并以预测的 $ -\log_{10}(\mathrm{p}\text{-values}) $ 作为分数。当显著 DE 基因较为稀疏时，该指标反映模型以高精确率恢复真阳性的能力。即



$ \mathrm{PR-AUC} _ {t} = \int_ {0} ^ {1} \mathrm{Precision} _ {t} (r) d \mathrm{Recall}.\tag{46} $

****

### 其他评估


**药物相似性分析。** 为评估不同模型保留药物扰动之间关系结构的程度，我们首先将每种药物表示为一个向量，其中包含跨细胞系的基因表达 $ \log_{2} $ 倍数变化。这些向量被对齐至共享的基因 × 细胞系空间。随后使用余弦相似度计算药物两两之间的相似性。为评估扰动结构的保留程度，我们分别对真实距离矩阵和预测距离矩阵应用平均链接的层次聚类，并计算所得聚类分配之间的校正 Rand 指数（ARI；使用 $ k = 5 $ 个簇）。



**细胞集合缩放。** 为评估 STATE 中细胞集合大小的影响，我们对每个集合的细胞数和批大小进行了消融，使批大小与细胞集合大小的乘积始终为 16,384，并测量验证损失随浮点运算次数（FLOPs）的变化（图 1C）。我们还将这些模型与两种模型进行了比较：一种是用均值池化替代 STATE 中自注意力的伪批量模型；另一种是 STATE 的掩码注意力版本，其中每个细胞只能关注自身。随着细胞集合增大，在留出细胞系上的验证损失显著改善，直至达到最优值 256。



**生存预测分析。** 为评估模型能否预测每个药物孔中各细胞系的生存情况——这是先前使用过的一种适应度指标（Yu et al., 2024）——我们构建了一个模型，依据每种细胞类型相对于 DMSO 的 2K HVG 集合平均表达来预测生存。具体而言，对于留出的细胞系和扰动集合，我们计算了 DMSO 与扰动之间真实基因表达差异的向量。随后，我们基于这些向量训练支持向量机模型来预测生存值，同时留出随机选取的 35 种药物的全部 3 个剂量。最后，我们使用同一 SVM 模型预测这些留出处理的生存情况：先基于真实基因表达计数进行预测，再分别基于预测值、细胞类型均值和扰动均值（pert-mean）进行预测。为计算置信区间，该过程重复 10 次，每次留出不同的药物集合。



SVM 模型采用 scikit-learn 默认的支持向量回归模型，并使用“rbf”核。每种条件的相对适应度计算为 



$ \log_{2}\left(\frac{\text{cell\_line\_counts}_{\text{treatment}}}{\text{cell\_line\_counts}_{\text{DMSO}}}\right) $，其中 DMSO 与处理条件来自同一培养板。

### 基线模型


下面描述并形式化定义用于与 STATE 比较的各种基线模型。



**扰动均值基线。** 该基线将扰动表达谱预测为：相应细胞情境的对照均值，加上从训练数据中学习的全局扰动偏移。对于每种细胞类型 $ c $ 和扰动 $ p $，首先计算细胞类型特异性的均值



$ \boldsymbol {\mu} _ {c} ^ {\mathrm{ctrl}} = \frac {1}{| \mathcal {C} _ {c} |} \sum_ {i \in \mathcal {C} _ {c}} \mathbf {x} ^ {(i)}, \qquad \boldsymbol {\mu} _ {c, p} ^ {\mathrm{pert}} = \frac {1}{| \mathcal {P} _ {c , p} |} \sum_ {i \in \mathcal {P} _ {c, p}} \mathbf {x} ^ {(i)}, $



其中，$ C_{c} $ 是类型为 $ c $ 的对照细胞集合，$ P_{c,p} $ 是类型为 $ c $ 且接受扰动 $ p $ 的细胞集合。二者之差为细胞类型偏移 $ \delta_{c,p} = \mu_{c,p}^{pert} - \mu_{c}^{ctrl} $。对所有包含扰动 $ p $ 的细胞类型取平均，得到全局偏移



$ \boldsymbol {\delta} _ {p} = \frac {1}{| \mathcal {C} _ {p} |} \sum_ {c \in \mathcal {C} _ {p}} \boldsymbol {\delta} _ {c, p}, \quad \mathcal {C} _ {p} = \{c \mid | \mathcal {P} _ {c, p} | > 0 \}, $



给定测试细胞类型 $ t $ 和扰动标签 $ p $，模型输出



$ \hat {\mathbf {x}} = \pmb {\mu} _ {t} ^ {\mathrm{ctrl}} + \pmb {\delta} _ {p}, \qquad \pmb {\delta} _ {\mathrm{ctrl}} \equiv \mathbf {0}. $



因此，对照被精确复现，而每种非对照扰动均获得相同的全局偏移。



**情境均值基线。** 该基线通过返回训练集中观测到的同一细胞类型细胞的平均扰动表达，来预测某个细胞的扰动后表达谱。对于每种细胞类型 $ c $，我们收集训练集中扰动不为对照的所有细胞，并构成伪批量均值



$ \boldsymbol {\mu} _ {c} = \frac {1}{| \mathcal {T} _ {c} |} \sum_ {i \in \mathcal {T} _ {c}} \mathbf {x} ^ {(i)}, \qquad \mathcal {T} _ {c} = \Big \{i \big | \mathrm {cell\_type} (i) = c, p ^ {(i)} \neq \mathrm{ctrl} \Big \}. $



在推理时，对于细胞类型为 $ c^{(i)} $、扰动标签为 $ p^{(i)} $ 的测试细胞 $ i $，我们预测



$ \hat {\mathbf {x}} ^ {(i)} = \left\{ \begin{array}{l l} \mathbf {x} ^ {(i)} & p ^ {(i)} = \text {ctrl}, \\ \boldsymbol {\mu} _ {c ^ {(i)}} & p ^ {(i)} \neq \text {ctrl}. \end{array} \right. $



即对照细胞保持不变，而扰动细胞继承其细胞类型均值。



**线性基线。** 该基线将扰动视为一种低秩、覆盖全基因的线性位移，并将其加到每个细胞自身的对照表达上（Ahlmann-Eltze et al., 2024）。令 $ G \in \mathbb{R}^{G \times d_g} $ 为固定的基因嵌入矩阵（例如预训练的蛋白质特征向量，每个基因对应一行），$ P \in \mathbb{R}^{P \times d_p} $ 为固定的扰动嵌入矩阵（每个扰动对应一个独热编码行）。首先从训练集构建一个“表达变化”伪批量



$ Y _ {g, p} = \frac {1}{| \mathcal {P} _ {p} |} \sum_ {i \in \mathcal {P} _ {p}} \left(x _ {g} ^ {\mathrm{pert}, (i)} - x _ {g} ^ {\mathrm{ctrl}, (i)}\right), \qquad \mathcal {P} _ {p} = \Big \{i \mid p ^ {(i)} = p \Big \},\tag{48} $



因此，$ Y \in \mathbb{R}^{G \times P} $ 存储每个基因 $ g $ 和扰动 $ p $ 相对于该细胞匹配对照的平均变化。模型寻求一个低秩映射 $ K \in \mathbb{R}^{d_g \times d_p} $ 和逐基因偏置 $ \mathbf{b} \in \mathbb{R}^G $，使得



$ Y \approx G K P ^ {\top} + \mathbf {b 1} ^ {\top}.\tag{49} $



我们通过求解岭正则化最小二乘问题，一次性得到 $ K $



$ \min _ {K} \left\| Y - G K P ^ {\top} - \mathbf {b} \mathbf {1} ^ {\top} \right\| _ {F} ^ {2} + \lambda \| K \| _ {F} ^ {2}, \quad \mathbf {b} = \frac {1}{P} Y \mathbf {1},\tag{50} $



其闭式解为



$ K = \left(G ^ {\top} G + \lambda I\right) ^ {- 1} G ^ {\top} Y P \left(P ^ {\top} P + \lambda I\right) ^ {- 1}.\tag{51} $



这里不需要基于梯度的优化，因为一旦计算出 $ K $，模型便固定下来。对于具有自身对照表达谱 $ \mathbf{x}^{\mathrm{ctrl},(i)} $ 和扰动标签 $ p^{(i)} $ 的测试细胞 $ i $，预测为



$ \hat {\mathbf {x}} ^ {(i)} = \left\{ \begin{array}{l l} \mathbf {x} ^ {\mathrm{ctrl}, (i)} & p ^ {(i)} = \mathrm{ctrl}, \\ \mathbf {x} ^ {\mathrm{ctrl}, (i)} + G K P _ {p ^ {(i)}} + \mathbf {b} & p ^ {(i)} \neq \mathrm{ctrl}, \end{array} \right.\tag{52} $



其中，$ P_{p^{(i)}} $ 表示 $ P $ 中与扰动 $ p^{(i)} $ 对应的行。因此，每项预测都精确保留细胞的基础状态，并加入从训练队列学习到的扰动特异性低秩偏移；模型容量仅由嵌入维度和岭参数 $ \lambda $ 控制。



**深度学习基线。** 我们将 STATE 与若干利用相关深度学习架构、用于预测不同细胞情境下扰动效应的基线进行了基准比较。其中包括两个基于自动编码器的模型 scVI（Lopez et al., 2018）和 CPA（Lotfollahi et al., 2023），以及基于 Transformer 的 scGPT 模型（Cui et al., 2024）。scVI 在考虑技术噪声和批次效应的同时对基因表达分布进行建模。CPA 学习组合式潜在空间，以捕获扰动、剂量和细胞类型的加性效应。scGPT 利用超过 3,300 万个细胞上的生成式预训练，支持在包括扰动预测在内的不同任务间进行零样本泛化。所有模型均使用图 2B 所述的相应数据集和设置进行评估。

# 分析：作为最优传输的状态转移
---

本节分析状态转移（State Transition，ST）学习跨细胞分布最优传输映射的理论能力。首先，我们证明 ST 的解族涵盖对照细胞分布与扰动细胞分布之间的最优传输映射。其次，我们推导出使 ST 学习唯一连续最优传输映射的显式约束。最后，我们讨论该理论分析的意义和未来可能的研究方向。

## ST 的渐近行为与解族


最优传输（Optimal Transport，OT）通过寻找使某个固定成本最小化的映射或耦合，为概率分布的比较和对齐提供了一种框架。传统 OT 方法显式定义成本函数，并求解线性规划或使用迭代算法来寻找最优耦合或映射（Cuturi, 2013; Peyré et al., 2019）。深度学习的兴起催生了神经最优传输（Neural Optimal Transport，Neural OT），它利用神经网络对 OT 问题进行参数化和求解（Bunne et al., 2024b, 2023）。



神经 OT 方法（Bunne et al., 2024b）通常通过以下任一方式运行：（1）使用为满足 OT 性质而设计的神经网络，直接参数化 OT 映射 $ T $；（2）用神经网络参数化 OT 耦合矩阵（$ P $）或其对偶势（例如 $ \alpha $、$ \beta $）；（3）将显式最小化 OT 成本函数（或其对偶目标）作为主要损失。例如，CellOT（Bunne et al., 2023）使用输入凸神经网络（Input Convex Neural Networks，ICNNs）显式参数化对偶最优传输问题的凸势，从而为每个扰动 $ k $ 学习最优传输映射 $ T_{k} = \nabla g_{k} $，其中 $ g_{k} $ 是对偶势之一。



尽管 ST 并不以传统方式显式求解 OT 问题，但它执行的是一项与神经 OT 相关的任务：学习一种使未扰动细胞分布与扰动细胞分布对齐的变换。该变换是学习得到的，并非针对某个固定成本显式设计。然而，已有严格的理论工作证明，固定参数的 Transformer 可通过工程化提示实现梯度下降，从而以可证明的方式求解最优传输（Daneshmand, 2024）。受此启发，我们证明：在渐近设定下，当分布满足正则性假设时，经过训练和优化的 ST 的解族包含细胞分布之间唯一的连续最优传输映射。



在本分析中，我们关注单个训练小批次，记为第 $ b $ 个批次。首先描述 ST 的数学形式：它旨在学习某个单一扰动对细胞群体的效应，即从 $ \mathbf{X}_{\mathrm{ctrl}}^{(b)} \in \mathbb{R}^{S \times G} $ 到 $ \mathbf{X}_{\mathrm{pert}}^{(b)} \in \mathbb{R}^{S \times G} $ 的变换。回顾一下，该批次的 Transformer 输入由对照细胞嵌入与广播后的扰动嵌入、批次嵌入相加构成：$ \mathbf{H}^{(b)} = \mathbf{H}_{\mathrm{cell}}^{(b)} + \mathbf{H}_{\mathrm{pert}}^{(b)} + \mathbf{H}_{\mathrm{batch}}^{(b)} \in \mathbb{R}^{S \times d} $（Eq. 16）。Transformer 的输出计算为 $ \mathbf{O}^{(b)} = \mathbf{H}^{(b)} + f_{\mathrm{ST}}(\mathbf{H}^{(b)}) \in \mathbb{R}^{S \times d} $，其中 $ f_{\mathrm{ST}} $ 为 Transformer 编码器（Eq. 17）。考虑具有 $ L $ 层的 $ f_{\mathrm{ST}} $，第一层的输入为 $ \mathbf{H}^0 = \mathbf{H}^{(b)} $：



$ f _ {\mathrm{ST}} = F _ {L} \circ \dots \circ F _ {1}, \quad \mathbf {H} ^ {i} = F _ {i} (\mathbf {H} ^ {i - 1}) = (G + \operatorname{Id}) \left(\mathbf {H} ^ {i - 1} + A ^ {i} (\mathbf {H} ^ {i - 1}, \mathbf {H} ^ {i - 1}) V ^ {i} (\mathbf {H} ^ {i - 1})\right)\tag{53} $



这里，$ A^{i} $ 表示多头注意力，$ V^{i} $ 表示注意力值编码器，$ G + Id $ 表示与残差连接组合的前馈层。层归一化函数被吸收到各个构造的函数中。最后，对于第 $ b $ 个批次，逐细胞线性变换为 $ S $ 个细胞定义最终输出 $ \hat{\mathbf{X}}_{\mathrm{target}}^{(b)} $（Eq. 18）。对每个细胞 $ s $，可以等价地改写为：



$ \hat {\mathbf {X}} _ {\mathrm{pert,s}} ^ {(b)} = f _ {\mathrm{recon}} (\mathbf {O} ^ {(b)}) = \mathbf {O} _ {s} ^ {(b)} \mathbf {W} _ {\mathrm{recon}} + \mathbf {b} _ {\mathrm{recon}} \in \mathbb {R} ^ {G},\tag{54} $



其中，$ \hat{\mathbf{X}}_{\mathrm{pert},\mathrm{s}}^{(b)} $ 表示 $ \hat{\mathbf{X}}_{\mathrm{pert}}^{(b)} $ 的第 $ s $ 行，其中包含细胞 $ s $ 的预测状态；该状态由其嵌入 $ \mathbf{O}_{s}^{(b)} $ 得到，后者表示 $ \mathbf{O}^{(b)} $ 的第 $ s $ 行。



常量 $ \mathbf{H}_{\mathrm{ST}}^{(b)} + \mathbf{H}_{\mathrm{batch}}^{(b)} $ 以及变换 $ f_{cell}, f_{recon} $ 可以被吸收到 $ f_{ST} $ 的第一层和最后一层中，因此我们将其定义为 $ f_{ST}^{pert,batch} $。于是，细胞 $ s $ 的预测状态可以等价地改写为：



$ \hat {\mathbf {X}} _ {\mathrm{pert}, s} ^ {(b)} = \left[ \left(f _ {\mathrm{recon}} \circ f _ {\mathrm{cell}} + f _ {\mathrm{sets}} ^ {\mathrm{pert,batch}}\right) (\mathbf {X} _ {\mathrm{ctrl}} ^ {(b)}) \right] _ {s},\tag{55} $



其中，$ [\cdot]_{s} $ 表示取所得输出的第 $ s $ 行。为简化分析，我们关注细胞集合大小 $ S $ 趋于无穷的渐近情形。回顾一下，每个细胞均从分布 $ D_{ctrl} $ 中采样。于是，在一定正则性条件下，当细胞数 $ S \to \infty $ 时，单个细胞的输出 $ \hat{\mathbf{X}}_{\mathrm{pert},s}^{(b)} $ 仅依赖于 $ \mathbf{X}_{\mathrm{ctrl},s}^{(b)} $ 本身以及总体分布 $ D_{ctrl} $，因为注意力机制实际上处理了来自整个分布的信息。因此，可按细胞定义极限算子：



$ \hat {\mathbf {X}} _ {\mathrm{pert,s}} ^ {(b)} = \left[ \left(f _ {\mathrm{recon}} \circ f _ {\mathrm{cell}} + f _ {\mathrm{ST}, \mathcal {D} _ {\mathrm{ctrl}}} ^ {\mathrm{pert,batch}}\right) (\mathbf {X} _ {\mathrm{ctrl}} ^ {(b)}) \right] _ {s} := F _ {\mathrm{pert,batch}} (\mathbf {X} _ {\mathrm{ctrl,s}} ^ {(b)}).\tag{56} $



近期关于 Transformer 极限平均场动力学的工作给出了更详细的论述（Furuya et al., 2024; Biswal et al., 2024）。值得注意的是，Eq. 56 对从分布 $ D_{ctrl} $ 中采样的任意细胞 $ s $ 均成立。算子 $ F_{pert,batch} $ 定义了从 $ D_{ctrl} $ 到 $ \hat{D}_{pert} $ 的映射。我们进一步假设 Transformer 模型具有足够的表达能力，因而可以将经验核 MMD 目标最小化至 $ \widehat{\mathrm{MMD}}(\hat{\mathbf{X}}_{\mathrm{pert}}, \mathbf{X}_{\mathrm{pert}}) = 0 $，其中能量核为 $ k(u, v) = -\|u - v\|_{2} $。下面的引理表明，经验 MMD 为零意味着以概率 1 实现分布匹配。



**引理 1（通过经验 MMD 实现分布匹配）。** 假设 $ \hat{D}_{pert}, D_{pert} $ 的支撑集有界。当细胞数 $ S \to \infty $ 时，若经验 MMD 达到零，即 $ \widehat{MMD}(\hat{\mathbf{X}}_{pert}^{(b)}, \mathbf{X}_{pert}^{(b)}) = 0 $，则以概率 1 有



$ \hat {\mathcal {D}} _ {p e r t} = \mathcal {D} _ {p e r t}.\tag{57} $



反之，若 $ \hat{\mathcal{D}}_{pert} = \mathcal{D}_{pert} $，则以概率 1 有 $ MMD(\hat{\mathbf{X}}_{pert}^{(b)},\mathbf{X}_{pert}^{(b)}) = 0 $。



**证明。** 用作 ST 目标的经验 MMD 定义为



$ \widehat {\mathrm{MMD}} ^ {2} (\hat {\mathbf {X}} _ {\mathrm{pert}} ^ {(b)}, \mathbf {X} _ {\mathrm{pert}} ^ {(b)}) = \frac {1}{S ^ {2}} \sum_ {i = 1} ^ {S} \sum_ {j = 1} ^ {S} k (\hat {\mathbf {x}} ^ {(i)}, \hat {\mathbf {x}} ^ {(j)}) + k (\mathbf {x} ^ {(i)}, \mathbf {x} ^ {(i)}) - 2 k (\hat {\mathbf {x}} ^ {(i)}, \mathbf {x} ^ {(j)}).\tag{58} $



这里，我们分别使用 $ \hat{\mathbf{x}}^{(i)},\hat{\mathbf{x}}^{(j)},\mathbf{x}^{(i)},\mathbf{x}^{(j)} $ 表示 $ \hat{\mathbf{X}}_{\mathrm{pert}}^{(b)},\mathbf{X}_{\mathrm{pert}}^{(b)} $ 中的细胞。分布 $ \hat{\mathcal{D}}_{\mathrm{pert}},\mathcal{D}_{\mathrm{pert}} $ 上相应的理论 MMD 定义为



$ \mathrm{MMD} ^ {2} (\hat {\mathcal {D}} _ {\mathrm{pert}}, \mathcal {D} _ {\mathrm{pert}}) = \mathbb {E} _ {x, x ^ {\prime} \sim \hat {\mathcal {D}} _ {\mathrm{pert}}} [ k (x, x ^ {\prime}) ] + \mathbb {E} _ {y, y ^ {\prime} \sim \mathcal {D} _ {\mathrm{pert}}} [ k (y, y ^ {\prime}) ] - 2 \mathbb {E} _ {x \sim \hat {\mathcal {D}} _ {\mathrm{pert}}, y \sim \mathcal {D} _ {\mathrm{pert}}} [ k (x, y) ].\tag{59} $



经验 MMD 是一个 V-统计量（Gretton et al., 2012）。因此，当支撑集有界（从而核值 $ k $ 也有界）时，根据 V-统计量的强大数定律（SLLN）（Hoeffding, 1961; De la Pena and Giné, 2012），有



$ \widehat {\mathrm{MMD}} ^ {2} (\hat {\mathbf {X}} _ {\mathrm{pert}} ^ {(b)}, \mathbf {X} _ {\mathrm{pert}} ^ {(b)}) \stackrel {a. s.} {\rightarrow} \mathrm{MMD} ^ {2} (\hat {\mathcal {D}} _ {\mathrm{pert}}, \mathcal {D} _ {\mathrm{pert}}).\tag{60} $



使用能量核 $ k(x,y) = -\|x - y\|_{2} $ 时，理论 MMD 与分布之间的能量距离 $ D^{2} $ 一致：



$ \mathrm{MMD} ^ {2} (\hat {\mathcal {D}} _ {\mathrm{pert}}, \mathcal {D} _ {\mathrm{pert}}) \equiv D ^ {2} (\hat {\mathcal {D}} _ {\mathrm{pert}}, \mathcal {D} _ {\mathrm{pert}}).\tag{61} $



最后，能量距离为零意味着分布相等，反之亦然（Rizzo and Székely, 2016）。



我们将使经验 MMD 为零并实现分布匹配的连续解族定义为



$ \begin{array}{r l} & {\hat {\mathcal {F}} = \{F \in \mathbb {C} | \widehat {\mathrm{MMD}} (\hat {\mathbf {X}} _ {\mathrm{pert}} ^ {(b)}, \mathbf {X} _ {\mathrm{pert}} ^ {(b)}) = 0 \mathrm{and} \hat {\mathbf {X}} _ {\mathrm{pert}, s} ^ {(b)} = F (\hat {\mathbf {X}} _ {\mathrm{ctrl}, s} ^ {(b)}) \},} \\ & {\mathcal {F} = \{F \in \mathbb {C} | F (\mathcal {D} _ {\mathrm{ctrl}}) = \mathcal {D} _ {\mathrm{pert}} \}.} \end{array}\tag{62} $



于是，由引理 1 可得

$ \hat {\mathcal {F}} = \mathcal {F} \text {   with   probability   1.   }\tag{63} $



为简化分析，我们假设模型具有足够的表达能力，可以学习 $ \hat{F} $ 中的任意元素；而 $ \hat{F} $ 以概率 1 与 $ F $ 相同。接下来我们证明，在温和的正则性条件下，从 $ D_{ctrl} $ 到 $ D_{pert} $ 的唯一最优传输映射属于解族 $ F, \hat{F} $。



**定理 2（STATE 解族中的最优传输映射）。** 假设 $ D_{ctrl}, D_{pert} $ 的密度绝对连续且有界，并且其支撑集严格凸、紧致，且边界为 $ C^{2} $。那么，与平方距离成本 $ c(x,y)=\|x-y\|^{2} $ 相关联的、从 $ D_{ctrl} $ 到 $ D_{pert} $ 的连续最优传输映射 $ T $，以概率 1 满足 $ T\in F,\hat{F} $。



**证明。** 在为分布 $ D_{ctrl}, D_{pert} $ 提出的正则性条件下，应用 Caffarelli 定理（Caffarelli, 1992）可知，$ D_{ctrl}, D_{pert} $ 之间存在连续且可微的最优传输映射 $ T \in C^{1} $。因此根据定义，$ T \in F $。此外，由引理 1，$ F = \hat{F} $ 以概率 1 成立，此时同样有 $ T \in \hat{F} $。



该定理虽然表明连续最优传输映射 $ T $ 存在且被解族 $ \hat{F} $ 所涵盖，但 $ \hat{F} $ 除了 $ T $ 之外还包含无限多个其他元素，因此并不能保证模型一定学习到最优传输解。这种内在灵活性对 STATE 而言是有利的，因为生物学变换通常包含复杂性和未建模变异，它们可能无法与单一、固定的最优传输解完全一致。不过，在下一个定理中，我们证明：如果在 ST 模型目标中对 Jacobian 矩阵施加约束，就可以保证学习到最优传输映射。



**定理 3（获得唯一 OT 映射的约束 ST 模型）。** 在与定理 2 相同的假设下，考虑受约束的解族：



$ \begin{array}{r} \hat {\mathcal {F}} ^ {*} = \{F \in \mathbb {C} ^ {1} | \widehat {M M D} (\hat {\mathbf {X}} _ {p e r t} ^ {(b)}, \mathbf {X} _ {p e r t} ^ {(b)}) = 0 a n d \hat {\mathbf {X}} _ {p e r t, s} ^ {(b)} = F (\hat {\mathbf {X}} _ {c t r l, s} ^ {(b)}); \\ J _ {\mathbf {F}} = \left\{\frac {\partial \mathbf {F} _ {i}}{x _ {j}} \right\} _ {i j} i s s y m m e t r i c a n d s e m i - p o s i t i v e d e f i n i t e \}. \end{array}\tag{64} $



则以概率 1，$ \hat{\mathcal{F}}^{*} $ 唯一包含连续 OT 映射 $ T $：$ \hat{\mathcal{F}}^{*} = \{T\} $。



**证明。** 根据 Brenier 定理（Brenier, 1991），$ T $ 是关于二次成本的唯一连续最优传输映射，当且仅当它是某个凸函数 $ \psi $ 的梯度，即 $ T = \nabla \psi $。由 Caffarelli 定理，我们已经有 $ T \in \mathbb{C}^1 $，因此该条件等价于 $ T $ 的 Jacobian 矩阵对称且半正定。进一步由引理 1，以概率 1 有 $ T \in \hat{\mathcal{F}}^* $；而 $ T $ 的唯一性意味着 $ \hat{\mathcal{F}}^* = \{T\} $。



我们的理论分析可视为 Caffarelli 定理和 Brenier 定理关于二次成本下连续最优传输映射的一个推论。特别是，最后一个定理提示：通过对映射的 Jacobian 矩阵施加适当的正则化，我们可以迫使模型学习从 $ D_{ctrl} $ 到 $ D_{pert} $ 的最优传输映射。对 Jacobian 矩阵施加更精确的约束，可能需要额外的架构设计来显式满足 Jacobian 约束，或直接获取凸神经网络的梯度（Makkuva et al., 2020; Bunne et al., 2023）。



尽管可行解集合很大，其中包含大量过拟合解，神经网络模型仍展现出卓越的泛化能力。神经网络泛化能力的一个重要方面是隐式偏置（Soudry et al., 2018; Gunasekar et al., 2018; Vardi, 2023），即梯度下降会偏好某些解，例如与初始权重相比变化最小的解（Gunasekar et al., 2018）。因此，我们假设 ST 的优化可能会得到使 $ D_{ctrl} $ 到 $ D_{pert} $ 的“总体偏移”最小的解，从而类似于采用某个未知成本函数的最优传输映射。对状态转移模型中隐式偏置的理论刻画超出了本文范围，但仍是一个很有前景的未来研究方向。

# 探索 STATE 的潜在空间
---

初步的可解释性分析表明，可以通过 STATE 的内部计算模式更好地理解其预测；这些模式尤其提示，状态转移模型架构利用异质性增强了扰动预测。



**State 嵌入展现出通过自监督学习获得的生物学知识标志。** 我们首先评估 SE 生成的细胞嵌入。鉴于该嵌入模型在跨数据集零样本设定下表现出色，对 STATE 的嵌入结构进行考察具有启发意义。如图 S9A 所示，State 嵌入的主成分能够捕获不同细胞类型之间及其内部的细微差异，表明其具备丰富的迁移表征。值得注意的是，K-562 和 Jurkat（两种白血病细胞系）的嵌入在该空间中彼此接近，说明在 STATE 学习到的表征下二者具有相似性，这与 Nadig et al. (2025) 的结果一致。重要的是，SE 在训练时并未被直接告知 K-562 与 Jurkat 具有这些相似性，而是纯粹通过对基因表达数据进行自监督学习，识别并利用了此类生物学概念。



![](https://cdn.nlark.com/yuque/0/2026/png/1739170/1786091421067-4c549abc-54af-4155-b3bf-107f8ceffe49.png)

> 图 S9：初步可解释性分析揭示了 State 如何利用所学的生物学信息进行预测。（A）SE 在没有生物学标签的情况下，仅凭基因表达数据便学得 K-562 与 Jurkat 具有相似性（两者均来源于白血病细胞系）。（B）在所有注意力头中，ST 的最后一层对隐藏状态变化贡献最大。（C）对最后一层的注意力头（Query × Key）进行可视化，可见不同注意力头之间存在显著差异。（D）在推理时构造一个由 K-562 和 Jurkat 混合组成的细胞集合，可直观显示自注意力如何对输入集合中细胞间的异质性建模。
>



**状态转移模型通过自注意力利用细胞异质性。** 早期对深度机器学习模型进行逆向工程的工作通常侧重于可视化激活，以揭示神经网络如何编码概念（Zeiler and Fergus, 2014; Olah et al., 2017; Bau et al., 2017; Clark et al., 2019）。与这些工作类似，由于 ST 的所有输入均来自同一细胞系，我们试图从细胞异质性的角度拆解模型的内部工作机制。为此，针对定义明确的细胞集合分析基于范数的贡献幅度和自注意力图，可以发现模型预测方法中的一般行为。使用 Replogle-Nadig 数据集进行推理时，我们首先发现，在所有注意力头中，隐藏状态的最大变化均发生在状态转移模型的最后一层（图 S9B）。深入考察这些注意力头可以发现耐人寻味的结构行为。我们发现，最后一层的注意力头承担着截然不同的角色。具体而言，我们识别出两大类注意力头：

1. **异质性敏感注意力头**：在许多细胞之间表现出分散且幅度较高的 Query-Key 交互，或仅关注与 Query 对应的 Key 矩阵（图 S9C&D）。
2. **异质性不敏感注意力头**：聚焦于较窄范围的 Key 矩阵——通常仅来自少数几个细胞——并广泛应用于所有 Query（图 S9C&D）。这些行为类似于伪批量化操作（即对单细胞表达谱取平均以模拟批量测量）或 PerturbMean 风格的计算；这两种基线都很稳健，但表达能力弱于 STATE。



为进一步剖析异质性敏感的注意力行为，我们构造了一个推理时示例，其中混合细胞集合由 50% 的 K-562 细胞和 50% 的 Jurkat 细胞组成（图 S9D）。输入这一混合集合后，我们观察到某些注意力头会自适应地改变行为：异质性感知注意力头变得更加极化，同时出现了一个新的不敏感注意力头；它在同时对两种细胞类型的 Query 进行计算时，仅选择性使用来自一种细胞类型的 Key 矩阵。这种非对称注意力模式表明，STATE 并非只是在细胞集合上求平均，而是会以情境敏感的方式主动区分它们。这类计算提示，状态转移模型内化了异质性的表征，并在推理过程中动态利用这些表征来提高预测性能。



这些初步结果凸显了利用 Transformer 可解释性来更好理解细胞扰动效应的潜力。未来工作可以应用更复杂的可解释性方法——超越注意力图，因为注意力图在精确定位方面作用有限（Hase et al., 2023; Chefer et al., 2021）——以更好地理解 STATE 的预测机制，并在旨在提取稀疏、更细粒度模型特征的方法基础上进一步发展（Bricken et al., 2023; Bhaskar et al., 2024; Dunefsky et al., 2024; Ameisen et al., 2025）。
