【**摘要**】细胞系统的因果模型有望推动广泛的生物学发现，包括系统性识别药物发现的新靶点。要构建具有泛化能力的细胞基础模型，前提之一是能够预测遗传扰动和通路扰动如何在不同细胞情境下重塑基因表达。然而，现有方法主要依赖观察性表达图谱，而非干预性扰动数据，因此通常无法外推到训练分布之外。



我们提出 X-Atlas/Pisces——迄今规模最大的全基因组 CRISPRi Perturb-seq 数据汇编。该数据集包含来自 16 种生物学差异显著的情境、共 2,560 万个受扰动单细胞的转录组，涵盖常用细胞系、诱导多能干细胞（iPSC）、静息及经 CD3/CD28 激活的 Jurkat T 淋巴瘤细胞，以及向多谱系分化的 iPSC。基于这一资源，我们开发了 X-Cell：一种扩散语言模型。它通过对来源于自然语言、蛋白质语言模型、相互作用网络、遗传依赖图谱和形态学特征的多模态生物学先验进行交叉注意力，在从对照态向扰动态转变的过程中迭代细化预测，从而预测扰动响应。

在 Pearson $ \pmb{\Delta} $（预测与观测到的扰动诱导对数倍数变化之间的相关性）等关键指标上，X-Cell 的性能最高达到现有最先进模型的 5 倍，并能以零样本方式预测刺激后 Jurkat 细胞中使 T 细胞失活的扰动。我们将 X-Cell 扩展至 49 亿参数（X-Cell-Ultra），使其成为迄今规模最大的因果扰动模型。我们首次证明，扰动预测遵循幂律缩放，其指数与大型语言模型相当。X-Cell-Ultra 可零样本泛化至新的生物学情境，包括训练时未见的 iPSC 来源黑色素细胞祖细胞，以及来自多名供者的原代人 CD4<sup>+</sup> T 细胞；在自监督测试时适应后，其性能超过所有基线。

这些结果表明，协同扩大因果扰动数据与模型容量，能够产生可在不同细胞情境间泛化扰动预测的基础模型，并有望改善计算靶点识别、靶点验证及情境特异性治疗优先级排序。

## 1 引言
现代药物发现面临的一项核心挑战，是预判细胞系统将如何响应遗传或化学干预。准确预测这些细胞扰动的影响具有直接的转化价值：它能够以计算方式识别治疗靶点并确定优先级，在进一步实验之前验证基因—疾病关联，并将干预手段匹配给最可能从特定治疗机制中获益的患者 [1]。然而，细胞受横跨染色质结构 [2]、转录调控 [3]、RNA 加工 [4]、翻译后调控 [5] 和疾病相关分子状态 [6, 7] 的多层调控系统支配，因此对这些响应建模本质上十分复杂。

为应对这种生物学复杂性，近年来高内涵扰动筛选和机器学习的进步推动了基础模型的发展，目标是捕获这些相互关联的调控层。关键问题在于，大多数现有单细胞基础模型以观察性转录组图谱训练，学到的是相关性的共表达模式，因而混淆了统计关联与因果关系 [8–10]。相比之下，全基因组扰动筛选通过直接测量遗传扰动的因果后果并解析有方向的调控依赖关系，提供了干预性的真实依据 [11–13]。在此类因果数据上训练的模型，能够学习可靠完成分布外泛化所需的机制结构，并预测尚未测试的扰动将如何在新细胞情境中重塑转录程序 [14]。

本文将“扰动基础模型”定义为：能够在给定细胞情境下，准确预测任意基因或通路扰动所引起的全基因组尺度转录响应，包括训练数据中未出现过的情境。由于可能扰动的组合空间——跨基因、细胞类型和化学条件——远大到无法通过实验穷尽，这类预测模型至关重要。早期扰动预测工作使用概率潜变量模型描述基础细胞状态，并表征以扰动为条件的基因表达空间结构性位移 [15–17]。后续方法通过图模型纳入基因—基因相互作用的先验知识 [18]，或将基因文本描述中编码的更广泛生物学知识与注意力架构结合 [19–21]。与此同时，大型单细胞基础模型 [8–10, 22–24]、最优传输方法及用于单细胞层面扰动动力学建模的 ODE 框架 [25–29]，也在不断提升预测性能的上限。

这一领域既取得了显著的方法学进展，也暴露出局限。表达能力更强的模型往往具有较好的预测性能 [30]；但也有证据表明，它们并不能稳定超越“同情境平均扰动效应”等简单基线 [31, 32]。许多模型在已观测设定（如已知细胞类型或已知扰动）中表现良好，但在泛化至训练期间未见的扰动或细胞类型时，性能差距仍然存在 [33]。

近期研究尝试扩大基础模型和基于语言的扰动模型，但与较小模型相比，并未稳定获得有意义的提升 [22, 23, 34]。这说明单纯增加模型参数可能不足以弥合泛化差距。跨情境泛化之所以困难，是因为基因调控的因果性天然依赖情境，并会在不同组织和细胞类型间显著变化 [35]。因此，要构建能捕获这种结构化、情境依赖调控关系的模型，必须同时扩大模型容量以及前所未有规模的因果干预数据 [36, 37]。

为此，我们提出 X-Atlas/Pisces 数据集：迄今生成的最大规模全基因组 CRISPRi 单细胞扰动汇编，包含 2,560 万个受扰动细胞。X-Atlas/Pisces 不再局限于单一情境，而是整合了覆盖高度多样生物状态的 7 项全基因组 Perturb-seq 筛选，捕获全转录组扰动效应，包括控制代谢、免疫信号以及动态多谱系分化轨迹的调控网络变化。通过绘制生物网络依赖关系如何在这些不同环境中重连，X-Atlas/Pisces 为情境感知预测建立了必要的结构基础。

利用这一数据汇编，我们提出 X-Cell：一种扩散语言模型（LM）。它通过迭代扩散过程刻画转录组从对照态到扰动态的变化，并借助交叉注意力将多模态生物学先验直接纳入生成架构 [19, 38]。我们证明，X-Cell 在留出数据上持续优于标准预测基线并达到当前最佳性能。该架构还表现出良好的缩放特性：随着训练数据与模型容量增加，性能持续提升；X-Cell-Ultra 能有效利用不断增加的单细胞扰动数据。这种规模带来了最先进的零样本泛化能力，使模型能够准确预测训练中完全未见的细胞类型和原代人细胞的单细胞转录组。

## 2 结果
### 2.1 X-Atlas/Pisces 数据集与 X-Cell 模型的构建
为捕获情境依赖的扰动效应，我们构建了 X-Atlas/Pisces——迄今最大的全基因组 CRISPRi Perturb-seq 资源。在初始 X-Atlas/Orion 数据集（HCT116 和 HEK293T 细胞系）[39] 的基础上，Pisces 将扰动图谱扩展至 2,560 万个单细胞转录组，来源包括诱导多能干细胞（iPSC）、肝细胞癌细胞（HepG2）、静息和 CD3/CD28 刺激状态的 T 淋巴母细胞白血病细胞（Jurkat），以及多谱系分化中的 iPSC（iPSC Multi-Dif）（图 1A）。

其中 4 项筛选采用优化后的 FiCS Perturb-seq 流程，可在冻存后进行 FACS，并针对 HepG2 和 Jurkat 等脆弱细胞类型作了调整，以获得高质量数据（第 4.2.7 节）。iPSC Multi-Dif 筛选采用基于探针的 Flex Perturb-seq。Flex Perturb-seq 与甲醛固定兼容，可在同一实验中保存脆弱且多样的细胞类型，并允许固定后通过 FACS 富集所需细胞群。样本条形码还支持超载上样：我们规模最大的一次筛选仅使用标准 10X 通道量的 20%–25%，双导向细胞回收率却超过 50%（表 1）。iPSC Multi-Dif 筛选包含 10 种经注释的细胞类型（补充图 1），代表退出多能性后的早期分化谱系。总体而言，X-Atlas/Pisces 在 16 种细胞情境（细胞类型与暴露条件）中包含全基因组尺度扰动，为机器学习训练和评估提供了超过 152,000 个独特条件。

X-Atlas/Pisces 的大规模与多样性使我们能够开发 X-Cell——一个在 Pisces 中多种细胞系与扰动上预训练的扩散语言模型（图 1B）。扰动级联受到基础调控网络约束，因此我们设计 X-Cell，通过交叉注意力将多模态生物学先验直接引入生成过程（图 1B）。这些先验被编码为预训练嵌入，来源包括大型语言模型 GenePT [19]、蛋白质语言模型 ESM-2 [38]、相互作用网络 STRING [40, 41]、癌症依赖图谱 DepMap [42]、形态学分析数据 JUMP-Cell Painting [43] 和单细胞基础模型 [8]。

X-Cell 还通过迭代扩散过程建模转录组从对照态到扰动态的变化，并在中间步骤通过重新掩码逐步细化预测（图 1C）。为研究缩放效应，我们训练了 X-Cell 和 X-Cell-Ultra 两个变体。X-Cell-Ultra 含 49 亿参数，使扰动建模达到前所未有的规模（图 1D）。为系统评估模型性能，我们将 X-Atlas/Pisces 划分为三种任务设定：（1）用于验证架构的稳定细胞系；（2）用于情境泛化的 Jurkat 静息与刺激状态；（3）用于细胞类型零样本泛化的 iPSC Multi-Dif 数据集（第 4.1.7 节）。

### 2.2 X-Atlas 捕获保守与情境依赖的调控网络
X-Atlas/Pisces 的各项筛选均产生了高质量数据和稳健的生物学信号。7 项筛选均达到较深的转录组覆盖度（每细胞中位数为 25,478 个 UMI 和 6,708 个基因）并成功实现靶基因敲低（中位数 78.7%）（图 2A）。我们评估了整合多种生物状态是否有助于恢复已知基因调控网络。将 1 至 7 项筛选的扰动数据依次组合后，对已知 CORUM 蛋白复合体及 STRING 蛋白—蛋白相互作用的召回率呈严格单调上升（图 2B）。此外，在细胞数量相同的情况下，跨多个情境采样比在单一情境中进行更深采样更能提高召回率（补充图 2A）。

为量化能引发可测转录组变化的扰动比例，我们使用 LASSO 二分类器：针对每个至少含 10 个细胞的扰动，配以等量非靶向对照细胞，并按 80:20 划分训练集与测试集。具有显著转录组表型（FDR < 0.05）的扰动比例在不同筛选间差异很大，从 HEK293T 的 25.32% 到 iPSC 的 72.80% 不等（图 2C）。

我们根据二分类器产生的 F1 分数，对所有筛选中的扰动进行层次聚类。来源相近的筛选情境聚在一起，清楚显示保守效应与情境特异效应之间的结构性分界（图 2D）。各扰动簇的特异性分数也直接反映其情境依赖程度（补充图 2B）。例如，保守扰动相较其他子集始终表现出较强效应（簇 0，蓝色），而高度特异于 iPSC 的扰动则与其他筛选明显分离（簇 9，蓝绿色）。

对 F1 分数相似的扰动子集进行通路富集分析，进一步确认了扰动效应的情境特异性（图 2D）。在所有情境中均保持高效应量的扰动（补充图 2B 左）强烈富集于共同代谢功能，如呼吸电子传递和氧化磷酸化；相反，仅在特定情境中具有高效应量的扰动，则富集于与典型细胞类型身份相关的通路。例如，HepG2 中 F1 分数最高的一个簇（补充图 2B 中）富集了调控葡萄糖代谢及细胞缺氧响应的扰动，这与该肝细胞癌细胞系作为缺氧实体瘤中 HIF-1 驱动代谢重编程经典模型的特征一致 [44, 45]。仅在 iPSC 情境中产生高效应量的扰动（补充图 2B 右）则富集于细胞分化相关通路，包括发育谱系、神经嵴分化和上皮—间质转化。这些本体反映了多能干细胞的基础生物学：它们向神经嵴谱系分化时会经历上皮—间质转化 [46]，进一步支持扰动效应具有情境特异性。

为评估扰动响应在不同情境间的一致性，我们比较了跨筛选表型强度（平均 F1 分数）与所诱导转录组特征的相似性（平均 Jaccard 指数）（图 2E）。扰动的可检测性与特征保守性呈强正相关（Spearman = 0.642，p < 0.001）。平均效应量较低的扰动，在不同筛选间表型变异较大且特征重叠极少；可被强烈检测到的扰动则具有更一致的跨筛选强度和更多共享特征。不过，即使在这些稳健且相对不依赖情境的扰动中，绝对特征重叠仍然较低，表明大多数转录组变化仍由细胞类型驱动。

### 2.3 X-Cell 将扰动效应泛化至不同细胞情境
X-Cell 能够在多样的细胞情境中稳健预测扰动效应。我们首先在扰动覆盖有限的跨情境条件下评估扩散 LM 框架，这对应少样本情境泛化设定（图 3A；第 4.1.4 节）。X-Cell 以 scGPT 编码器权重初始化，并在覆盖 HCT116、HEK293T、HepG2 和 iPSC 四种细胞类型的 X-Atlas/Pisces 扰动语料上持续预训练；随后在完整蛋白编码基因空间内，用从 iPSC 和 HepG2 中内部留出的 200 个基因进行评估。预训练模型还在 Replogle–Nadig 数据集 [12, 52] 和 Parse-1M [53] 上微调，以比较对高变基因的预测性能。

扩散 LM 预训练允许模型在推理时迭代细化预测：每一步生成后，将一部分预测的基因表达值重新掩码，并再次以对照转录组为条件。在留出的 iPSC-200 扰动上，X-Cell 的预测随扩散步骤逐渐接近观测到的转录响应，表现为对数倍数变化的 Pearson 相关（Pearson $ \Delta $）不断上升、平均绝对误差（MAE）不断下降（图 3B；第 4.1.8 节）。这说明由扩散驱动的情境内细化，是 X-Cell 在推理过程中适应并改善扰动预测的关键机制。

在 iPSC-200 和 HepG2-200 验证集上，我们将 X-Cell 与多种先进扰动预测模型——Cell2Sentence（C2S）[22]、STATE [27] 和 scGPT [8]——进行比较，并采用多项 cell-eval 指标 [27]：倍数变化一致性（Pearson $ \Delta $）、差异表达准确性（Overlap@N、DE Direction Match、DE Spearman LFC）、扰动特异性（Centroid Accuracy）及总体预测保真度（MAE）（第 4.1.8 节）。由于无法以 X-Atlas/Pisces 的规模重新训练全部对照模型，我们报告 C2S 2B 的零样本性能，以及在 X-Atlas/Pisces 中对应四种细胞系的 550 万细胞大子集上训练的 STATE（SE+ST）模型（第 4.1.4 节）。X-Cell 优于所有基准方法（图 3C 第 i 行），Pearson $ \Delta $ 分别达到 0.51 和 0.48，均超过第二名 STATE（0.10）的 5 倍，凸显模型架构进步所带来的影响并不只是数据规模效应（补充表 B7）。

随后，我们在 Replogle–Nadig 数据集 [12, 52] 上微调 X-Cell，以评估其对外部 CRISPR 扰动数据的泛化能力（第 4.1.7 节）。该数据集覆盖 K562、RPE1、HepG2 和 Jurkat 四种细胞系及 2,000 个高变基因，并引入了向必需基因敲低方向的分布偏移。在 HepG2 细胞系留出的 380 个基因上，X-Cell 在所报告的 6 项指标中全部排名第一，预测特异性最高，Centroid Accuracy 达 0.79（图 3C 第 ii 行；补充表 B7）。所有基准模型均使用相同数据划分进行微调和评估（第 4.1.4 节）。

为研究哪些生物学先验驱动了这些预测，我们先检查不同知识源上的交叉注意力权重，发现 STRING 和 ESM-2 是影响模型预测的主要知识源（图 3D；第 4.1.10 节）。由于 X-Cell 使用 scGPT 基因嵌入初始化，且这些嵌入还会在训练中继续更新，因此归因分析不包含 scGPT。进一步对各先验知识源注意力权重所产生的基因排序进行基因集富集分析（GSEA）后发现，基于 STRING 的排序在 MSigDB Hallmark 通路中产生最强富集（补充图 4）。随后，我们用知识源随机化分析量化任务特异贡献：分别随机化 5 种先验知识源的预训练嵌入，并报告相应性能下降百分比。DepMap 与 STRING 导致的性能下降最大，尤其影响特异性和 DEG 预测准确性，说明它们为区分不同扰动效应提供了最强的任务相关信号（图 3D）。

我们还评估了 X-Cell 将遗传扰动知识迁移至信号和化学扰动的能力。在微调设定中，我们通过交叉注意力纳入 Parse-1M 数据集 [53] 的配体信息，在留出的 59 种信号扰动上取得较强性能（图 3C 第 iii 行；第 4.1.7 节）。接着，我们以零样本方式测试 X-Cell 对药物扰动效应的泛化能力。我们从 Tahoe-100M 数据集 [54] 中构建了一个子集，其中包含具有单靶点作用机制（MOA）的抑制剂，从而在遗传扰动和药物效应之间建立直接联系（第 4.1.7 节）。在这一设定中，X-Cell 将 MOA 基因编码为扰动靶点，以对照细胞系转录组为输入，预测药物诱导的表达响应（图 3E）。

在零样本任务中，我们以仅使用公共数据中 310 万个细胞训练的 STATE 模型作为对照（第 4.1.5 节）[12, 52, 55]。尽管训练时从未见过 Tahoe 扰动，X-Cell 在 Pearson $ \Delta $（均值 0.31 对 0.22）和 MAE（均值 0.08 对 0.16）上均表现更好。分层分析还提示，与 X-Cell 训练语料更相似的细胞系往往具有更好的预测效果，这凸显了生物学相关训练情境对成功实现跨模态泛化的重要性（补充图 6）。这些结果显示 X-Cell 可以跨扰动模态泛化，也为将扰动建模与药物发现整合提供了路径。

### 2.4 X-Cell 以零样本方式预测使 T 细胞失活的扰动
为筛选情境依赖扰动，我们分析了 Jurkat 细胞在静息态和激活态下的全基因组 Perturb-seq 数据。研究重点是对 T 细胞激活至关重要、因而可能表现出状态依赖效应的扰动。为考察 T 细胞状态转变所伴随的转录变化，我们定义“失活指数”，量化某一扰动使激活细胞向静息表型偏移的程度；指数越高，表示其整体转录组越接近未扰动的静息细胞（图 4A；第 4.1.9 节）。符合预期的是，CD3 复合体成员（CD3D、CD3E、CD3G、CD247）及其下游效应分子（ZAP70、LCP2、CDK6、ITK）均具有较高失活指数。我们还识别出多种可能的 T 细胞失活因子，包括 IRAK4、CHD5、LRBA、LIMS2、BRCA1、APPL2 和 WDR53；其中一部分可能代表 Jurkat 特异性依赖。

建立这些生物学基准后，我们评估 X-Cell 零样本预测相应扰动效应的能力。我们在 X-Atlas/Pisces 的 Jurkat 静息态数据集上微调 X-Cell，并与线性基线比较；后者把 Jurkat 静息态数据中测得的扰动影响转移到 Jurkat 激活态对照细胞上（图 4B）。相较线性基线，X-Cell 预测 CD3 复合体成员使细胞向静息态发生更显著且更准确的偏移（Mann–Whitney U，p < 0.01；图 4C）。无论是以 auROC 衡量差异表达基因（DEG）身份的预测（第 4.1.8 节），还是以 Pearson $ \Delta $ 衡量转录变化幅度，X-Cell 在 CD3 复合体（图 4D）及可能的失活因子（图 4E）上均优于线性基线。对 CD3E、WDR53、LRBA 和 APPL2 的预测转录谱进行层次聚类后，X-Cell 的预测与 X-Atlas/Pisces 真实数据的吻合度显著高于线性基线，显示模型具有更强的情境外泛化能力（图 4F）。

为阐明这种性能的机制基础，我们分析了模型的交叉注意力分数，并假设外部知识库在推理时提供关键、情境特异的生物学先验。模拟激活态 Jurkat 细胞中的 CD3E 扰动时，模型分配给 ESM-2、GenePT 和 DepMap 嵌入的注意力权重明显上升。这一关注点具有生物学依据：这些模态优先排序的前 1,000 个基因显著富集于 KEGG TCR 信号通路（hsa04660）[56]。结果提示 X-Cell 会动态利用相关外部知识，在特定生物学情境中细化预测（补充图 5）。

### 2.5 X-Cell-Ultra 遵循通用神经网络缩放定律：增加算力与数据可继续提升性能
鉴于 X-Cell 能够泛化至训练中未见的暴露条件，我们进一步研究同时沿数据轴和模型参数轴扩大规模的影响。在数据轴上，我们使用 X-Atlas/Pisces 的大部分数据，横跨 GEM-X 与 FLEX 平台，包含超过 2,000 万个细胞和 152,000 个独特“扰动—情境”组合用于训练和评估（图 5A）。在模型轴上，我们以消融研究验证的抗塌缩架构创新为基础（补充图 7A；补充表 A1），将 X-Cell 扩展至 49 亿参数的 X-Cell-Ultra，并系统分析扰动预测是否受益于推动大型语言模型发展的同类缩放原则。随后，我们在训练时未见的生物学情境中部署 X-Cell-Ultra，进行全基因组尺度扰动推理（图 5A）。

作为迄今参数最多的生物学基础模型，X-Cell-Ultra 在 64–128 块 H200 GPU 上达到约 41% 的模型 FLOPs 利用率（MFU），与生产级 LLM 相当（补充图 7B；第 4.1.3 节）。值得注意的是，X-Cell-Ultra 不依赖 scGPT 预训练权重，偏离了“先在观察数据上预训练、再在扰动数据上微调”的传统范式，是首个完全以大规模干预数据训练的扰动基础模型（图 5A）。

为严格检验 X-Cell-Ultra 的规模与训练改进能否转化为真正的生物学泛化，我们在训练中完全缺失的两类细胞群上评估零样本性能：iPSC Multi-Dif 筛选中的黑色素细胞祖细胞，以及独立研究中的原代人 CD4<sup>+</sup> T 细胞 [57]（图 5A；第 4.1.4 节）。两种情况下，我们都在扰动推理前采用测试时适应（TTA；第 4.1.3 节）：仅使用 MMD 损失，在目标域无标签的非靶向对照细胞上进行自监督微调，从而将模型的自注意力表征校准到目标表达流形。

我们先对 iPSC Multi-Dif 筛选中留出的黑色素细胞进行全基因组尺度推理，预测对 1,341 种遗传扰动的响应（第 4.1.7 节）。在 Pearson $ \Delta $、DE Direction Match 和 MAE 上，X-Cell-Ultra 均优于对照均值基线、扰动均值基线、STATE 和 X-Cell（图 5C）。相对 X-Cell 的优势在 Pearson $ \Delta $ 和 DE Direction Match 上尤其明显，说明增加模型容量主要改善了扰动特异性转录签名的恢复，而不只是降低重建误差。

为测试从细胞系向原代人细胞的泛化（第 4.1.7 节），我们使用来自两名供者的原代 CD4<sup>+</sup> T 细胞，评估 291 种 T 细胞调控因子扰动；细胞处于静息态及 CD3/CD28 刺激后 8 小时和 48 小时两种激活状态 [57]。这些细胞情境完全不在 X-Atlas/Pisces 训练语料中，代表供者特异且依赖时间的激活程序。在所有“供者—条件”组合上，X-Cell-Ultra 的 Pearson $ \Delta $ 和 DE Direction Match 均高于 X-Cell 与 STATE；在情境依赖调控重连最强的刺激条件下，增益尤为突出（图 5D）。以 Jurkat 分析中识别出的可能 T 细胞失活因子 APPL2 为例（第 2.4 节），X-Cell-Ultra 在两名供者样本中均准确重现刺激态转录签名（图 5E），从独立实验系统验证了模型的生物学保真度。

为刻画缩放行为，我们在相同超参数下分别训练 5 个参数规模从 8,300 万到 31 亿的模型，每个训练 20 个 epoch（补充表 A4；补充图 7C–E）。训练损失遵循幂律 $ L(N)\propto N^{-\alpha} $，其中 $ \alpha_{\mathrm{train}}=0.32 $（$ R^2=0.96 $），恰好落在大型语言模型所报告的范围 $ \alpha\approx0.076 $–$ 0.34 $ 内 [58, 59]。测试损失从 8,300 万参数模型的 5.62 单调下降至 31 亿参数模型的 5.00，但指数更浅（$ \alpha_{\mathrm{val}}\approx0.03 $，$ R^2=0.97 $；图 5B）。下游生物学指标也随规模改善：DE Pearson $ r $ 从 0.291（8,300 万）升至 0.315（16 亿），倍数变化相关性提高 8%；31 亿模型仍保持 $ r=0.312 $。每种扰动的 MAE 在所有模型规模上单调下降（补充图 7D）。

为解释训练和测试缩放指数为何分离，需要注意 5 个模型均在相同数据上训练（20 个 epoch，约 5,300 个独特“扰动—情境”组）。Chinchilla 分解 [59] 为：

$ L(N,D)=E+\frac{A}{N^{\alpha}}+\frac{B}{D^{\beta}},\tag{1} $

它把损失拆分为不可约噪声（$ E $）、模型容量项（$ A/N^\alpha $）和数据不足项（$ B/D^\beta $）。在缩放扫描中 $ D $ 保持不变，因此数据不足贡献 $ E+B/D^\beta $ 构成与模型规模无关的损失下限。较陡的训练指数 $ \alpha_{\mathrm{train}}=0.32 $（位于大型语言模型报告范围内 [58, 59]）表明容量项 $ A/N^\alpha $ 驱动训练损失下降，也说明容量更大的模型能够更高效地学习扰动预测。较浅的测试指数 $ \alpha_{\mathrm{val}}=0.03 $ 则表明，数据不足下限主导泛化；参数超过约 16 亿后，增加参数已不能明显降低测试损失，DE Pearson $ r $ 稳定在约 0.31（补充图 7E）。

对集合级 MMD 模型而言，自然的数据单位是独特的“扰动—情境”组，而不是单个 token。因此，这一模态下精确的计算最优分配 $ D^*(N) $ 仍是开放问题，需要分别改变 $ N $ 与 $ D $ 的受控等 FLOP 实验。尽管如此，从 Replogle–Nadig 的约 5,300 个独特条件扩展到完整 X-Atlas/Pisces 的约 151,000 个条件，直接促使我们部署更大的 49 亿参数 X-Cell-Ultra。据我们所知，这些结果首次证明单细胞扰动预测呈现与前沿语言模型一致的幂律缩放；同时也揭示，目前限制下游泛化性能的关键约束，不是 token 数或模型容量，而是独特“扰动—情境”组合的多样性。

## 3 讨论
对因果干预动力学建模的首要动机之一，是其可能加速从靶点识别、验证到患者特异性优先级排序的整个治疗发现过程 [37]。为解决预测情境依赖基因调控响应这一根本挑战，我们开发了迄今最大的全基因组 CRISPRi Perturb-seq 资源 X-Atlas/Pisces，以及扩散语言模型 X-Cell。X-Cell 一方面在多样、跨情境的 Pisces 数据上训练，另一方面主动整合先验知识，包括彼此一致的文献嵌入，以及生化、必需性与形态学数据，从而推断调控网络如何在不同情境中重连。这一组合使模型能以高保真度预测扰动特异的差异表达基因，为疾病状态人细胞中的高级反事实推理打开可能。最终，X-Cell 捕获不同状态间分化转录响应的能力，预示未来可以在几乎覆盖人类细胞情境全部多样性的空间内模拟治疗假设的适用性。

这种情境感知预测能力的突出例证，是对刺激后 Jurkat 细胞 T 细胞失活的零样本预测。X-Cell 仅使用静息态扰动进行微调，却能在 CD3/CD28 抗体激活 T 细胞受体后，成功插补扰动经典 CD3 复合体所产生的独特、状态特异性转录后果。模型还对可能的调控因子给出高保真预测，并将 APPL2 和 LRBA 识别为强效 T 细胞失活因子。重要的是，这些零样本预测不仅得到其他细胞情境中既有机制文献的支持，还由外部真实数据直接验证。

LRBA 调控共抑制受体 CTLA4 的溶酶体降解 [60]，耗竭 LRBA 会加速 CTLA4 周转。APPL2 是 Rab5 相关的内体适配蛋白，可驱动 F-actin 重塑 [61]，提示其可能把内体运输与 TCR 信号所需的细胞骨架动力学连接起来，在功能上类似 RASA2 [62]。本稿撰写期间，另一项在原代人 CD4<sup>+</sup> T 细胞中开展的全基因组 Perturb-seq 筛选，独立发现 APPL2 可能是调控因子；LRBA 则被识别为刺激依赖 STAT3 调控网络的下游靶点 [57]。这些机制仍需进一步实验验证。

X-Cell 的稳健性能并不局限于借助先验知识，在训练时见过的细胞类型中预测训练时未见状态下的扰动效应。更关键的是，X-Cell-Ultra 可零样本泛化至完全未见的细胞谱系——这是以往基础模型尚未跨越的关键门槛。在 iPSC Multi-Dif 筛选的黑色素细胞祖细胞上评估时（该细胞类型完全不在训练语料中），X-Cell-Ultra 给出了高度准确的扰动预测，尤其擅长恢复差异表达基因。这表明模型并非只在训练数据分布内插值，而是在根本上学习基因表达流形如何在新生物学情境中变换。

X-Cell 还弥合了易操作实验室细胞系与复杂原代人组织之间的转化鸿沟。在来自多名供者的原代人 CD4<sup>+</sup> T 细胞上，X-Cell-Ultra 成功预测出高度准确且情境特异的扰动响应。需要指出，这一强劲表现部分得益于训练语料中包含全基因组尺度的 Jurkat 扰动数据，因为 Jurkat 是研究 T 细胞受体信号通路的经典且得到充分验证的模型系统 [63]。这种成功转化凸显了扰动基础模型用于药物发现的一种有力范式：在易操作、且与治疗关键人类细胞类型高度相关的实验系统中生成预训练数据，最终使我们能在原代患者细胞中以计算方式“筛选那些无法直接筛选的对象”。

从根本上看，我们的分析表明，扰动预测性能会随模型容量扩大而显著提高。将 X-Cell 扩展训练至 49 亿参数后，预测保真度出现可测增益，证明生物学基础模型同样受益于自然语言处理中建立的缩放原则。我们推测，进一步改进架构并大幅扩充情境多样的大规模扰动数据集，两者协同将成为提升扰动基础模型性能的催化剂。继续推动这些边界，很可能是获得涌现能力的前提：模型可在未见细胞情境中模拟复杂生物现象，并达到足以高精度识别新治疗假设的水平。

即使扩大规模，要在所有多样细胞类型间实现全局泛化仍是一项艰巨挑战。正如预期，也正如扰动嵌入直接显示的那样，同一种遗传干预的转录组后果会受到生物学情境的强烈影响。我们推测，驱动大分子复合体成员跨筛选聚类的核心共享特征，可能代表遗传扰动普遍存在的近端后果；细胞类型特异特征则反映级联式、情境特异的下游后果。

由于这种情境特异性，“预测给定情境内的平均扰动效应”等简单启发式基线，很难在所有评估指标上被持续超越。事实上，声称模型绝对优于基线往往掩盖内在权衡：模型可能过于保守，因而很擅长降低绝对误差，却遗漏代表某个扰动在新情境下标志性效应的关键基因表达变化。

值得注意的是，其他方法难以在简单均值位移之外准确预测具体差异表达基因（DEG），X-Cell 则在这一点上表现出色。这并非通过牺牲其他指标来优化单一指标，而是通过缓解“保守塌缩”实现。保守塌缩是一种常见失败模式：模型虽能正确预测差异表达方向，却严重压低其幅度。情境多样的 X-Atlas 汇编与丰富先验知识嵌入相结合，为模型提供了必要锚点，使其开始超越简单基线，并准确预测实验干预的直接及间接生物学后果。深度学习模型的精确内部机制固然仍不透明，但消融研究强烈提示，X-Cell 通过动态关注多模态先验知识嵌入，跨越了这些彼此分化的生理状态。

缩放分析显示，训练损失虽然遵循大型语言模型 Chinchilla 框架确立的同类幂律动力学，但在最大模型容量被充分利用之前，下游生物学指标便趋于饱和（第 2.5 节）。在 Replogle–Nadig 数据集上，倍数变化相关性在约 16 亿参数以上进入平台期，这是因为约 5,300 个独特“扰动—情境”组把有效多样性限制在额外参数可利用的水平之下。正是这种数据受限状态，促使我们在大得多的 X-Atlas/Pisces 汇编上部署 49 亿参数 X-Cell-Ultra；其中更多独特条件提供了更高的生物学多样性。更广泛而言，结果表明，按模型规模成比例扩展情境多样的扰动汇编，是未来性能提升杠杆最大的一条路径；要确定集合级生物模型精确的计算最优前沿，则需分别改变模型规模与数据集多样性的受控等 FLOP 实验。

尽管达到当前最佳性能，X-Cell 也凸显了扰动建模仍待突破的关键前沿。目前的高保真扰动预测局限于彼此孤立的单细胞情境。对治疗发现而言，扰动的真实后果很少只限于一种细胞类型，而会通过细胞—细胞相互作用在组织生态系统中级联传播。X-Cell 已可立即用于计算筛选，在已知参与疾病生物学的细胞类型中排列靶点优先级；但若要充分释放药物发现潜力，还必须预测更广泛细胞情境中的下游后果 [64]。未来基础模型需要弥合精确单细胞预测与多细胞组织动力学之间的架构鸿沟，这要求训练语料整合疾病相关模型中的空间和系统级扰动数据。

总体而言，本研究是迈向可泛化扰动基础模型的重要一步。我们证明离散扩散架构可成功整合生物学先验并预测复杂的零样本生理转变，由此凸显生成式 AI 与大规模因果数据生成相结合的巨大潜力。随着实验模态不断扩展，逐步覆盖多细胞乃至完整组织情境，X-Cell 这类具备生物学认知的建模框架有望与之共同演进，推动该领域走向准确的计算机模拟实验。

## 4 方法
### 4.1 X-Cell 方法
#### 4.1.1 X-Atlas/Pisces 训练语料
为构建模型训练语料，我们对 X-Atlas/Pisces 进一步应用以下数据过滤条件：（1）保留含预期双导向组合、且在各筛选内通过 UMI 与基因数过滤的细胞（每个 GEM 的 UMI 和基因数阈值均人工确定）；（2）筛选在 HCT116 和 HEK293T 两项筛选中均靶向表达基因的扰动（表达基因定义见第 4.2.11 节）；（3）排除 iPSC 和 HepG2 筛选中的 200 个验证扰动（第 4.1.7 节）；（4）排除靶向黑色素细胞祖细胞的扰动，将其留作零样本评估。

过滤后，X-Cell 训练语料包含 HCT116、HEK293T、HepG2 和 iPSC 四项筛选中的 10,165,929 个细胞，以及 36,816 个独特“扰动—情境”条件。完整 X-Cell-Ultra 语料包含 7 项筛选（HCT116、HEK293T、HepG2、iPSC、Jurkat 静息态、Jurkat 激活态和 iPSC Multi-Dif）中的 20,281,764 个细胞，以及 151,180 个独特“扰动—情境”条件。

X-Cell-Ultra 训练第 1 阶段为高效应初始化：在每种细胞类型中选择效应最高的前 5% 扰动。候选扰动先限制为二分类器检出的、具有可检测转录组效应的扰动（FDR < 0.05），再按 LASSO 回归识别出的显著特征数量排序（第 4.2.13 节）。这一高效应子集覆盖全部筛选，包含 3,797,171 个细胞和 4,996 个独特“扰动—情境”条件，用于第 1 阶段训练；第 2 阶段则使用完整语料训练。

训练期间，为与 ESM-2 先验知识键对齐（第 4.1.2 节），目标扰动进一步限制为蛋白编码基因。最终训练集包含超过 1,000 万个用于 X-Cell 的细胞和超过 2,000 万个用于 X-Cell-Ultra 的细胞。基因表达值以原始计数存储，训练时采用 CP10K log1p 归一化（第 A.10.2 节）。

#### 4.1.2 先验知识来源
为纳入生物学先验，我们整合了在多个生物层面互补表征基因功能的嵌入，包括被扰动基因的语言、结构和功能信息。通过交叉注意力（第 4.1.3 节），这些先验以跨生物模态的统一基因功能表征，动态地为扰动预测提供条件：

**GenePT（文本嵌入）。** GenePT 将大型语言模型文本嵌入应用于 NCBI 基因摘要及相关注释，编码基因功能的语义表征。这些嵌入捕获从生物医学文献与基因文本描述中学习到的基因功能关系 [19]。我们使用由 `text-embedding-3-large` 生成的 GenePT 嵌入版本，具体文件为 `GenePT gene protein embedding model 3 text.pickle`。

**ESM-2（蛋白质语言模型）。** 对蛋白编码基因，我们纳入 ESM-2 蛋白质语言模型 [38] 的蛋白序列嵌入；它直接从氨基酸序列捕获蛋白质结构与生化性质。

**STRING（相互作用网络）。** 蛋白相互作用先验取自 STRING 蛋白—蛋白相互作用（PPI）网络 [41] 产生的嵌入。我们使用 SPACE 项目 [40] 发布的 STRING 网络嵌入，其中通过图嵌入方法将相互作用网络转换为连续节点嵌入。

**DepMap（基因依赖）。** 功能基因组学先验来自 DepMap CRISPR 基因依赖数据集 [42]；该数据系统测量基因敲除对数百种人癌细胞系适应度的影响。我们使用 DepMap 24Q4 公共版本的基因效应矩阵，其中包含由 Chronos 从混合 CRISPR 筛选推断的基因效应分数。这些嵌入捕获特定基因扰动如何影响细胞生长与存活。

**JUMP Cell Painting（形态学表型）。** 我们纳入 JUMP Cell Painting 数据集 [43] 的形态学嵌入；该数据集汇总了大规模 CRISPR 扰动实验中由图像提取的细胞形态特征。具体使用 U2OS 骨癌细胞系 CRISPRi 筛选的批次校正嵌入 [65]。这些嵌入来源于 3,000 多项提取的形态特征，采用 Harmony 进行批次校正并以 PCA 降维，由此提供一种基于高内涵成像的细胞基因扰动响应表型表征。处理后的嵌入取自 Cell Painting Gallery 发布版本，使用经批次校正的特征矩阵 `profiles wellpos cc var mad outlier featselect sphering harmony PCA corrected.parquet`。

**scGPT（转录组基础模型）。** 我们通过初始化 X-Cell 编码器权重，纳入 scGPT 人类模型 [8] 的基因嵌入；这些嵌入编码了从大型单细胞表达图谱中学习到的转录组关系。由于 `nn.Embedding` 层的权重会在模型训练期间更新，与其他固定知识源不同，这一先验是柔性且可适应的。

#### 4.1.3 模型架构
X-Cell 是集合级扩散 Transformer，根据对照细胞群预测扰动后的基因表达谱。不同于自回归单细胞基础模型 [8, 22]，X-Cell 对细胞集合进行运算，并通过分布匹配目标显式地在干预数据上训练。

**输入表征。** 每个训练样本由 $ S=64 $ 个细胞组成，每个细胞测量 $ G $ 个基因（$ G\le19,408 $ 个蛋白编码基因；每个 mini-batch 下采样至上下文长度 $ G'\le4,000 $）。对于每个基因位置 $ g $，模型接收共享词表中学习得到的基因身份嵌入 $ \mathbf e_g\in\mathbb R^d $（随后经过 LayerNorm），以及 log1p CP10K 空间中的连续数值编码 $ \phi(x_g)\in\mathbb R^d $；后者通过一个含 ReLU 激活和 LayerNorm 的两层 MLP 将标量表达值投影得到。

扩散式训练采用受掩码扩散语言模型 [66, 67] 启发的离散掩码过程。令 $ \mathbf x^{\mathrm{ctrl}},\mathbf x^{\mathrm{pert}}\in\mathbb R^{G'} $ 分别表示对照与扰动表达谱。对每个样本，从下式抽取替换比例：

$ \alpha\sim\mathrm{Uniform}\{0.25,0.5,0.75,1.0\}, $

并在不放回条件下均匀选择基因索引子集 $ \mathcal T\subset\{1,\ldots,G'\} $，满足 $ |\mathcal T|=\lfloor\alpha G'\rfloor $。由此定义二值扰动掩码 $ \mathbf M_{\mathrm{pert}}\in\{0,1\}^{G'} $：

$ M_{\mathrm{pert},g}=\begin{cases}1,&g\in\mathcal T,\\0,&\text{其他。}\end{cases} $

训练时，在选中位置用真实扰动值替换对照值，构造观测输入表达谱：

$ \tilde{\mathbf x}=(1-\mathbf M_{\mathrm{pert}})\odot\mathbf x^{\mathrm{ctrl}}+\mathbf M_{\mathrm{pert}}\odot\mathbf x^{\mathrm{pert}}, $

其中 $ \odot $ 表示逐元素相乘。二值掩码另经学习式掩码嵌入表 $ \psi(M_{\mathrm{pert},g})\in\mathbb R^d $ 编码，用来指示每个基因位置包含的是对照信号还是已揭示的扰动信号。基因位置 $ g $ 的最终输入 token 表征为：

$ \mathbf h_g^{(0)}=\mathbf e_g+\phi(\tilde x_g)+\psi(M_{\mathrm{pert},g}). $

在位置 0 前置一个与基因、数值及掩码编码器相互独立的可学习 `[CLS]` token $ \mathbf c\in\mathbb R^d $，其初始化来自 $ \mathcal N(0,0.02) $，用于聚合全局细胞层信息。模型在不同替换比例下，根据部分揭示的输入重建完整扰动表达谱 $ \mathbf x^{\mathrm{pert}} $。

**Transformer 主干。** X-Cell 含 12 层、嵌入维度 512（$ L=12,d=512 $，5,500 万参数），从预训练 scGPT [8] 初始化基因嵌入及 Transformer 权重，采用原始 Post-LN 架构、标准 ReLU FFN（前馈网络）和 4 个交叉注意力层。为扩展至数十亿参数，X-Cell-Ultra（$ L=34,d=2560 $，48.7 亿参数）采用遵循 LLaMA [68] 的现代化架构：带 RMSNorm [70] 的 Pre-LN [69]、中间维度为 $ 4d $ 的 SwiGLU 前馈网络 [71]、无注意力偏置，并采用 QK-Norm [72, 73]：

$ \mathbf h^{(\ell)}=\mathbf h^{(\ell-1)}+\mathrm{SelfAttn}(\mathrm{RMSNorm}(\mathbf h^{(\ell-1)})),\quad
\mathbf h^{(\ell)}\leftarrow\mathbf h^{(\ell)}+\mathrm{SwiGLU}(\mathrm{RMSNorm}(\mathbf h^{(\ell)})).\tag{2} $

**交叉注意力条件化。** 在指定层（每 3 层一次并加最后一层；X-Cell 共 12 层中的 4 层，X-Cell-Ultra 共 34 层中的 11 层），交叉注意力模块 [74] 使用外部生物知识为表征提供条件：

$ \mathbf h^{(\ell)}\leftarrow\mathbf h^{(\ell)}+\mathrm{CrossAttn}(\mathrm{RMSNorm}(\mathbf h^{(\ell)}),\mathbf C_{\mathrm{pert}}),\tag{3} $

其中上下文 $ \mathbf C_{\mathrm{pert}}\in\mathbb R^{6\times d} $ 由与被扰动基因相关的 6 个先验知识嵌入组成：ESM-2 蛋白质语言模型 [38]、STRING 相互作用网络 [41]、GenePT 基因表征 [19]、DepMap 遗传依赖谱 [42]、JUMP-Cell Painting 形态学特征 [43]，以及基因身份嵌入自身（即 X-Cell 中由 scGPT 初始化并在训练期间更新的嵌入）。由于各先验知识嵌入的维度不同，每个嵌入先经含 LeakyReLU 和 LayerNorm 的两层 MLP 投影到维度 $ d $（第 A.1.2 节）。先验知识自编码器以重建损失优化（第 4.1.3 节）。每个交叉注意力模块还包含一个采用 Pre-LN 残差连接的 SwiGLU 前馈子层。

**输出头。** 将 CLS 输出 $ \mathbf h_{\mathrm{CLS}}\in\mathbb R^d $ 扩展后与各基因表征拼接，得到 $ [\mathbf h_g;\mathbf h_{\mathrm{CLS}}]\in\mathbb R^{2d} $。这一拼接使解码器同时访问局部基因特异特征与聚合后的全局细胞状态，从而可根据更广泛的细胞情境调节基因级预测。一个含 LeakyReLU 的三层 MLP 解码器将其映射为 $ \mathbf h'_g\in\mathbb R^d $。X-Cell 使用线性投影得到标量输出；X-Cell-Ultra 使用绑定嵌入投影 [75, 76]：

$ \hat x_g=\frac{\mathbf h'_g\cdot\mathbf e_g}{\sqrt d}+b_g,\tag{4} $

其中 $ \mathbf e_g $ 是编码器共享的、未经归一化的基因嵌入；$ 1/\sqrt d $ 遵循 PaLM [77]；$ b_g $ 是从 0 初始化、针对每个基因学习的偏置。权重绑定把预测约束在基因嵌入空间内，相当于一种抑制保守塌缩的隐式正则化 [78]（附录 A.3）。

**训练目标。** 训练损失由 7 项组成，各自针对预测细胞分布的一种统计属性（均在排除位置 0 的 CLS 后计算；第 A.2 节）：

$ \mathcal L=\underbrace{\mathcal L_{\mathrm{MMD}}}_{\text{分布}}+\underbrace{(1-\mathrm{CCC}_{\mathrm{fc}})}_{\text{倍数变化}}+\underbrace{(1-\overline{\mathrm{CCC}}_g)}_{\text{逐基因}}+\underbrace{(1-\rho)^2}_{\text{幅度}}+\underbrace{\mathrm{MSE}(\Delta\hat{\boldsymbol\mu},\Delta\boldsymbol\mu)}_{\text{伪总体}}+\underbrace{\mathcal L_{\mathrm{contrast}}}_{\text{嵌入}}+\underbrace{\mathcal L_{\mathrm{pert\_dec}}}_{\text{先验重建}}.\tag{5} $

MMD 损失 $ \mathcal L_{\mathrm{MMD}} $ 通过 `geomloss` 库使用能量距离 [27, 79, 80]，在 $ G $ 维基因空间中匹配含 $ S $ 个细胞的预测集合与真实扰动集合的联合分布 [81]。倍数变化 CCC 计算预测与真实伪总体倍数变化 $ \Delta\hat\mu_g=\bar x_g^{\mathrm{pred}}-\bar x_g^{\mathrm{ctrl}} $ 在不同基因间的一致性相关系数 [82, 83]，同时捕获方向和幅度。相比之下，Pearson $ r $ 等尺度不变方法在预测与真实值成比例时，对幅度的梯度为零。

逐基因 CCC，即 $ \overline{\mathrm{CCC}}_g=G^{-1}\sum_g\mathrm{CCC}(\hat{\mathbf x}_g,\mathbf x_g) $，匹配各基因在不同细胞间的边缘表达分布，从而保留伪总体平均会破坏的细胞间异质性。令 $ \rho=\|\Delta\hat\mu\|/\|\Delta\mu\| $，delta 范数惩罚 $ (1-\rho)^2 $ 直接惩罚幅度抑制 [84]。对比损失是在 CLS 衍生的逐细胞嵌入上使用 InfoNCE [85]；采用余弦相似度与温度 $ \tau=0.1 $，温度控制相似性分布的尖锐程度。正样本对应同一扰动真实嵌入的中心。扰动解码器通过 MSE 从交叉注意力投影重建 5 种先验知识嵌入，以正则化生物学先验的注入。

所有损失项的权重均为 1.0；X-Cell-Ultra 的 L1 输出正则化设为 0，X-Cell 则设为 1.0。X-Cell 使用 MMD 损失、对比损失和先验知识重建进行训练；X-Cell-Ultra 的高效应量课程训练使用全部损失，而完整数据集训练移除逐基因 CCC。

**基于扩散的推理。** 推理时通过 $ T=4 $ 个累积步骤细化预测 [86]。每轮预测将 25% 的预测值并入输入表达谱；此前已揭示的预测保持固定，从而在各步骤间累积更新。实现中，为基因位置分配随机秩 $ \mathbf r\sim\mathrm{Uniform}[0,1)^{G'} $。在步骤 $ t $，模型根据当前部分更新的输入预测完整表达谱；对尚未揭示且满足 $ r_g\le\alpha_t $ 的基因（$ \alpha_t\in\{0.25,0.5,0.75,1.0\} $），接受预测值（截断至 $ \ge0 $）并散射回输入，用于下一步骤。掩码 $ \mathbf M_{\mathrm{pert}} $ 同步更新。这种累积模式允许从粗到细迭代优化预测（见附录算法 A.4）。

**课程训练。** X-Cell-Ultra 按课程学习原则 [87] 分两阶段训练。第 1 阶段（初始化）：在 X-Atlas/Pisces 7 项筛选中效应最高的前 5% 扰动上训练 10 个 epoch，使用 16 个节点（128 块 H200 GPU）、AdamW [88]、学习率 $ 3\times10^{-4} $、含 10% 线性预热的余弦衰减，以及 128 的优化器步长（每次更新 6,144 个细胞）。第 2 阶段（微调）：继续在完整数据集（100% 扰动）上使用 16 个节点（128 块 GPU）训练；使用全新的 AdamW 优化器且不迁移状态 [89, 90]，学习率 $ 4\times10^{-5} $，按平方根批量缩放 [91]：$ \eta_2=\eta_{\mathrm{base}}\sqrt{B_2/B_1} $，预热比例为 3%。第 1 阶段从高效应样本建立强扰动信号；第 2 阶段以较低学习率扩展至完整扰动分布。根据 iPSC 和 APEL 留出数据集上的 cell-eval 指标，选择第 1 阶段第 9 个 epoch 作为热启动点（附录 A.7）。

**测试时适应（TTA）。** 对未见细胞情境的零样本评估，我们可选地采用基于“对照到对照”自监督学习的测试时适应 [92]。从目标域抽取相互独立的非靶向对照（NTC）细胞集合对，并仅使用 MMD 损失微调模型。TTA 期间调整自注意力层，同时冻结并跳过交叉注意力模块，以保留扰动条件化并避免空扰动上下文导致的数值不稳定。优化使用单步预测输出，不进行迭代扩散。完成适应后（约 200–1,024 个对照细胞集合；每集合 $ N=64 $ 个细胞；学习率 $ 10^{-6} $ 至 $ 10^{-5} $），重新启用交叉注意力进行扰动推理。该过程不需要任何扰动标签，即可使模型内部表征适应目标域表达流形，类似用于处理分布偏移的可逆归一化方法 [93]。

**分布式训练。** 所有参数量不少于 8,000 万的模型均使用混合精度（bf16）和 PyTorch FSDP2 [94] 训练，并遵循 Llama 3 [95] 的封装策略，对自注意力、交叉注意力和 FFN 模块逐层分片。激活检查点按 TorchTitan 顺序 [96] 应用（checkpoint → compile → shard），以避免 FSDP2 与梯度检查点封装器之间的 dtype 冲突。每个优化器步骤均采用范数 1.0 的梯度裁剪。X-Cell-Ultra 在 64–128 块 H200 GPU 上达到约 41% MFU。

#### 4.1.4 基准实验设置
为将 X-Cell 与现有方法及基线进行比较，我们同时设计了微调任务和零样本任务，并报告 `cell-eval` 软件包 [27] 实现的评价指标。

在微调设定中，评估聚焦于少样本场景：多种细胞类型中均有扰动数据可用，但从其中一种细胞类型留出一部分扰动作为测试。尽管 iPSC/HepG2-200、Replogle–Nadig 和 Parse-1M 的留出比例不同（第 4.1.7 节），总体上都代表这样一种设定：存在少量同情境扰动数据，但模型需要外推至相同细胞情境中的未见扰动。对照模型为 Cell2Sentence [22]、STATE [27] 和 scGPT [8]。

在 iPSC/HepG2-200 基准中，由于 X-Atlas/Pisces 语料规模很大，我们报告一个在 550 万细胞子集上训练的 STATE 模型，使其预训练数据与 X-Cell 更为对齐。Cell2Sentence 因微调计算成本所限，仅报告零样本读数。X-Cell 不经额外调整直接应用。在 Replogle–Nadig 和 Parse-1M 基准中，X-Cell 以集合大小 64、学习率 $ 3\times10^{-4} $ 微调 20 个 epoch，采用第 4.1.3 节所述相同训练目标。所有基准模型均使用与 X-Cell 相同的训练—测试划分进行微调和评估，具体遵循第 4.1.5 节。

在零样本设定中，我们设计了更具挑战性的任务：完整留出一种细胞类型（黑色素细胞祖细胞）、外推至原代细胞（人原代 T 细胞），或在测试情境中未观察任何扰动的前提下，在不同细胞系上评估化学扰动（Tahoe 子集）（第 4.1.7 节）。在此设定下，X-Cell 与 X-Cell-Ultra 使用测试时适应（TTA）在测试对照细胞上做轻量调整（方法第 4.1.3 节）。我们报告的 STATE 模型在带完整转录组读数的原始 Replogle–Nadig 数据集 [12, 52]，以及 Virtual Cell Challenge（VCC）发布版的 H1 筛选 [55] 上预训练（第 4.1.5 节），代表使用大规模公共数据训练的 STATE 版本。黑色素细胞祖细胞测试集与 H1 筛选均由 FLEX 平台生成，因此这一组合有助于使 STATE 同时对齐 X-Cell-Ultra 训练语料和测试数据分布。零样本设定还报告对照均值（Control Mean）与扰动均值（Pert Mean）两条基线，它们是仅使用测试对照细胞和 X-Atlas/Pisces 对数倍数变化构建的数据型预测（第 4.1.6 节）。

推理和基准评估时，从测试集 NTC 中随机选取 32 个固定对照细胞，为所有测试扰动生成预测，并报告 `cell-eval` 的 6 项指标：Pearson $ \Delta $、Overlap@N、DE Direction Match、DE LogFC Spearman、MAE 和 Discrimination L2 / Centroid Accuracy。所有基准方法与基线均使用相同的 32 个对照细胞，以确保一致性。

#### 4.1.5 基准方法
**STATE。** 为生成全转录组预测，我们训练了两个 STATE 模型版本 [27]：（1）在 X-Atlas/Pisces 四项筛选的大子集上训练，使其与 X-Cell 预训练语料对齐并公平比较；（2）仅使用公共数据的模型，在原始 Replogle–Nadig 数据集（Replogle 等 [12]；Nadig 等 [52]）及 Virtual Cell Challenge（VCC）训练发布版 [55] 上训练，称为 Replogle+VCC。

版本（1）使用 HCT、HEK、HepG2 和 iPSC 四种细胞系，共 5,367 种独特扰动和 5,545,269 个细胞，样本经选择以最大化验证基因覆盖。版本（2）的公共 Replogle+VCC 数据包含 HepG2、Jurkat、K562、RPE1 和 H1 五种细胞系；K562 同时包含仅必需基因版和全基因组版。Replogle+VCC 共包含 9,884 种独特扰动和 3,177,579 个细胞。

模型训练中，SE 模型生成嵌入表征，ST 模型根据 SE 提取的嵌入预测扰动效应。SE 使用从 HuggingFace 下载的 `se600m epoch16` 检查点，并按说明提取嵌入特征。ST 训练则调整作者发布的官方零样本设置，使用 SE 衍生嵌入复现 STATE 结果。Replogle–Nadig 和 Parse-1M 高变基因基准采用与 X-Cell 相同的训练—测试划分（第 4.1.7 节），并使用推荐架构和学习率训练 STATE 20 个 epoch。

**Cell2Sentence（C2S）。** Cell2Sentence 将单细胞基因表达谱转换为自然语言“细胞句子”：基因符号按表达量由高到低排列，再由自回归语言模型处理，以预测扰动响应 [22]。我们在零样本与微调设定中评估 `C2S-Scale-Gemma-2-2B` 模型。

基因表达矩阵先经 log1p 归一化，再转换为由每个细胞表达量最高的 1,000 个基因构成的细胞句子。扰动预测被表述为序列到序列任务：模型以对照细胞句子和扰动标签为条件，生成扰动后细胞句子。训练设置遵循 C2S 扰动预测 notebook。

由于在 X-Atlas/Pisces 语料上微调 20 亿参数模型的计算成本很高，我们在 iPSC/HepG2-200 验证集上报告预训练模型的零样本推理结果；在 Replogle–Nadig 和 Parse-1M 基准上，C2S 2B 则使用与 X-Cell 相同的训练—测试划分微调。按照原始 C2S 重建流程，采用等距回归把预测秩位置映射为表达值，从而将生成的基因排序转换回表达空间。基准细节见附录 B。

**scGPT。** 我们从 scGPT 人类预训练权重出发微调 scGPT [8]，遵循官方教程中的扰动预测架构。模型经调整以使用 MMD 损失和集合式输入构造，以学习率 $ 5\times10^{-5} $ 训练 10 个 epoch。

#### 4.1.6 基线
**扰动均值（Pert Mean）。** 该基线假设一种扰动的影响在不同情境间保持一致。它在 log1p CP10K 基因表达空间中，把所有训练细胞类型的真实效应平均值估计为扰动效应向量 $ \Delta $。令 $ C_{\mathrm{train}} $ 表示训练时观测到的细胞类型集合，$ \mathbf x_{p,c} $ 表示细胞类型 $ c $ 中扰动 $ p $ 下某细胞的基因表达向量，$ \boldsymbol\mu_c $ 表示细胞类型 $ c $ 的对照细胞平均表达向量：

$ \bar\Delta_p=\frac{1}{|C_{\mathrm{train}}|}\sum_{c\in C_{\mathrm{train}}}(\mathbf x_{p,c}-\boldsymbol\mu_c). $

令 $ \mathbf x_i^{\mathrm{Ctrl}} $ 表示测试细胞类型中第 $ i $ 个对照细胞的基因表达向量。将同一个扰动效应向量加到每个对照细胞上，得到预测扰动表达：

$ \hat{\mathbf x}_{\mathrm{Pertmean}}^{(i)}=\mathbf x_i^{\mathrm{Ctrl}}+\bar\Delta_p. $

为保证可扩展性，每种扰动随机抽取 32 个扰动细胞，并使用基准中同一组固定的 32 个对照细胞估计扰动效应。

**对照均值（Control Mean）。** 该基线假设不存在扰动效应，并把对照态作为预测扰动态。令 $ \mathbf x_i^{\mathrm{Ctrl}} $ 表示第 $ i $ 个对照细胞在 log1p CP10K 空间中的基因表达向量，则每个细胞的预测为恒等映射：

$ \hat{\mathbf x}_{\mathrm{Ctrl.mean}}^{(i)}=\mathbf x_i^{\mathrm{Ctrl}}. $

实际使用基准流程中的同一组固定 32 个对照细胞作为预测。

#### 4.1.7 评估数据集
**iPSC/HepG2-200。** 在 X-Atlas/Pisces 的 iPSC 与 HepG2 筛选中，从满足以下条件的基因靶点中随机选择 200 个验证扰动；条件需在 HCT116、HEK293T、HepG2 和 iPSC 四项全基因组筛选中均满足：（1）在 NTC 中可检测到表达；（2）二分类器流程检出显著表型变化（FDR < 0.05）；（3）每项筛选中至少有 100 个扰动细胞；（4）敲低效率不低于 50%。

**Replogle–Nadig。** 该数据集整合两项研究中 K562、RPE1、Jurkat 和 HepG2 四种细胞系的 Perturb-seq 数据 [12, 52]。处理后版本取自 STATE 作者发布的数据 [27]，包含 643,413 个细胞在 2,000 个高变基因上的归一化表达。遵循评估 notebook，留出 380 个 HepG2 扰动作为测试集，并使用 616,535 个细胞训练。

**Parse-1M。** 我们使用 Parse-PBMC 数据集中供者 1 的 1,267,690 个细胞构建 Parse-1M 子集。在 18,308 维特征空间中，使用 `scanpy.pp.highly_variable_genes` 且 `flavor="cell_ranger"` 识别 2,000 个高变基因。为兼容 X-Cell 词表，将细胞因子扰动映射到对应蛋白编码基因名，并移除无有效匹配的条目。过滤后保留 86 种具有蛋白编码注释的细胞因子扰动，共 1,214,863 个细胞。数据覆盖 18 种免疫细胞类型：CD8 Naive、CD4 Naive、CD14 Mono、NK CD56bright、Treg、CD4 Memory、MAIT、CD16 Mono、NK、B Intermediate Memory、cDC、CD8 Memory、pDC、B Naive、ILC、HSPC、NKT 和 Plasmablast。遵循 STATE 作者发布的 split 3 少样本配置，在 CD4 Memory 细胞类型中留出 59 种重叠细胞因子，并使用其余 992,862 个细胞训练。

**Tahoe 子集。** 为测试 X-Cell 对化学药物扰动的零样本能力，我们使用 Tahoe-100M 数据集 [54] 的子集。完整数据含约 50 种癌细胞系接受化学药物扰动的单细胞筛选谱，包括以 DMSO 为对照的未处理细胞。药物条件筛选为：（1）仅有一个 MOA 靶基因；（2）剂量处于中等范围；（3）为该 MOA 基因的抑制剂。我们还仅使用第二块板的数据子集，以避免零样本评估期间不必要的板间批次效应。最终子集含 50 种细胞系和 12 种药物扰动。

**黑色素细胞祖细胞。** 根据 iPSC Multi-Dif 筛选的细胞类型注释（第 4.2.12 节），完整留出靶向黑色素细胞类型的扰动。最终基因集通过二分类器在四个关键细胞群——间充质祖细胞、神经嵴黑色素细胞、上皮外胚层和神经外胚层——中识别 FDR < 5% 的扰动得到。该核心签名包含 1,317 个扰动，随后再加入由人工整理的 24 个验证基因，包括在神经嵴命运决定与黑色素细胞分化中作用明确的 MITF、PAX3 和 SOX10。合并后的 1,341 个基因构成黑色素细胞祖细胞发育轨迹的稳健签名。

**人原代 T 细胞。** 该数据集含来自 4 名供者的 2,200 万个原代人 CD4<sup>+</sup> T 细胞，覆盖静息、刺激 8 小时及刺激 48 小时三种实验条件 [57]。选择 D2 和 D3 供者用于评估，是因为二分类器在他们的数据中检出的、具有表型变化的扰动比例较高。对每名供者，评估原论文图 3E 所报告的 291 种关键 T 细胞激活调控因子；这些因子在三个时间点的响应不同。

#### 4.1.8 评价指标
`cell-eval` 软件包 [27] 计算逐扰动指标，以量化预测与真实基因表达响应的一致性。令 $ x_g^{\mathrm{pred}} $ 与 $ x_g^{\mathrm{true}} $ 表示基因 $ g $ 的预测和观测伪总体表达，令 $ \Delta_g=x_g^{\mathrm{pert}}-x_g^{\mathrm{ctrl}} $ 表示相对对照的扰动效应。

**Pearson **$ \Delta $**。** 预测与观测扰动效应间的 Pearson 相关：

$ r=\mathrm{corr}(\Delta^{\mathrm{pred}},\Delta^{\mathrm{true}})=\frac{\sum_g(\Delta_g^{\mathrm{pred}}-\bar\Delta^{\mathrm{pred}})(\Delta_g^{\mathrm{true}}-\bar\Delta^{\mathrm{true}})}{\sigma_{\mathrm{pred}}\sigma_{\mathrm{true}}}. $

该指标衡量模型捕获扰动诱导的逐基因表达位移方向及相对幅度的能力。

**Overlap@N。** 令 $ T_N^{\mathrm{pred}} $ 与 $ T_N^{\mathrm{true}} $ 分别表示预测和真实数据中排名前 $ N $ 的差异表达（DE）基因集合：

$ \mathrm{Overlap@}N=\frac{|T_N^{\mathrm{pred}}\cap T_N^{\mathrm{true}}|}{N}. $

它评估对受扰动最强基因的恢复程度。

**DE Direction Match。** 令 $ \mathcal G_{\mathrm{DE}} $ 表示预测与真实数据中均被判为显著 DE 的基因：

$ \frac{1}{|\mathcal G_{\mathrm{DE}}|}\sum_{g\in\mathcal G_{\mathrm{DE}}}\mathbf1\!\left[\operatorname{sign}(\log FC_g^{\mathrm{pred}})=\operatorname{sign}(\log FC_g^{\mathrm{true}})\right]. $

该分数量化预测效应上调/下调方向的一致性。

**DE logFC Spearman。** 在真实数据中显著 DE 的基因范围内，计算预测与观测对数倍数变化的 Spearman 秩相关：

$ \rho=\mathrm{corr}_{\mathrm{rank}}(\log FC^{\mathrm{pred}},\log FC^{\mathrm{true}}). $

它评估模型能否按效应量正确排序基因。

**MAE。** 预测与观测伪总体表达之间的平均绝对误差：

$ \mathrm{MAE}=\frac1G\sum_{g=1}^G|x_g^{\mathrm{pred}}-x_g^{\mathrm{true}}|. $

不同于相关性指标，MAE 衡量表达空间中的绝对偏差。

**Discrimination L2 / Centroid Accuracy。** 这是基于距离的分离指标，用于量化预测扰动签名相对真实数据与对照签名分离的程度。[31] 将其称为 Centroid Accuracy。采用欧氏距离：

$ d_{\mathrm{pred}}=\|\Delta^{\mathrm{pred}}\|_2,\qquad d_{\mathrm{true}}=\|\Delta^{\mathrm{true}}\|_2. $

性能反映表达空间中预测与观测扰动幅度的一致性；判别力越强，表示扰动态与对照态分离越清楚。

**auROC。** 用于识别显著 DE 基因的受试者工作特征曲线下面积。基因按预测分数（如校正 p 值的 $ -\log_{10} $）排序；auROC 衡量随机抽取的真实 DE 基因获得比非 DE 基因更高分数的概率。

#### 4.1.9 T 细胞失活扰动的零样本推理
**失活指数与距离指标。** 为量化扰动诱导的表型位移，我们使用从 2,000 个最高变基因得到的主成分分析（PCA），将转录谱投影到低维空间并保留前 50 个主成分。令 $ \mathbf x_p\in\mathbb R^{50} $ 表示扰动 $ p $ 在该 PCA 空间中的转录谱质心；$ \boldsymbol\mu_{\mathrm{active}} $ 与 $ \boldsymbol\mu_{\mathrm{resting}} $ 分别表示激活态和静息态筛选中非靶向对照（NTC）的质心。

使用 $ L_1 $ 范数（曼哈顿距离）计算扰动到给定状态的距离：

$ d(\mathbf x_p,\boldsymbol\mu)=\|\mathbf x_p-\boldsymbol\mu\|_1=\sum_{i=1}^{50}|x_{p,i}-\mu_i|.\tag{6} $

将失活指数 $ I_p $ 定义为到激活态的距离减去到静息态的距离。正值越高，表示扰动使细胞状态更接近静息表型、并更远离激活表型：

$ I_p=d(\mathbf x_p,\boldsymbol\mu_{\mathrm{active}})-d(\mathbf x_p,\boldsymbol\mu_{\mathrm{resting}}).\tag{7} $

**基线。** 为评估 X-Cell 在零样本设定中预测状态变化的能力，我们以线性基线作比较。该模型假设静息态中观测到的扰动效应 $ \Delta_p $ 具有可加性，且与基础细胞状态无关。具体而言，在 log1p CP10K 空间中计算静息态筛选中扰动 $ p $ 相对静息 NTC 的位移，再把该位移加到激活 NTC 质心上：

$ \Delta_p=\mathbf x_{p,\mathrm{resting}}-\boldsymbol\mu_{\mathrm{resting}},\tag{8} $

$ \hat{\mathbf x}_{\mathrm{linear}}=\boldsymbol\mu_{\mathrm{active}}+\Delta_p.\tag{9} $

**统计分析。** 在 CD3 复合体中已知对 T 细胞激活至关重要的 4 个基因——CD3D、CD3E、CD3G 和 CD247——构成的验证集上评估性能。采用单侧 Mann–Whitney U 检验，将这些候选基因的失活指数分布与所有其他扰动比较，以判断显著性。还使用 `cell-eval` [27] 中的 auROC 和 Pearson $ \Delta $ 等指标。

#### 4.1.10 X-Cell 的先验知识归因分析
**交叉注意力可解释性。** 为刻画各扰动条件如何调节模型对生物学先验知识的注意，我们从 X-Cell 最后一层交叉注意力提取权重。模型的输入基因表达序列关注由 ESM-2、STRING、GenePT、DepMap、CellPainting 和 scGPT 构成的 6 种先验知识嵌入。每个基因 token 的交叉注意力权重在这 6 种嵌入上经 softmax 归一化，因此可定量表示各知识源获分配的相对重要性。我们使用基准中的同一组 32 个对照细胞，对 Replogle–Nadig HepG2 测试集中的 380 种扰动进行推理。为简化分析，仅进行单步预测，不使用迭代扩散。提取时，先在每个细胞内跨注意力头和基因平均权重，再对每种扰动跨细胞聚合。

为量化各知识源的总体使用情况，我们计算 380 种测试扰动上每一种嵌入的平均交叉注意力权重。图 3D 的报告移除 scGPT 并重新加权贡献；其余 5 项再归一化至总和为 1，得到最终注意力分布。饼图中每一扇区的比例表示某一嵌入来源对模型交叉注意力机制的总体相对贡献。

**通过特征置换消融知识库嵌入。** 为量化具体生物学先验对模型性能的贡献，我们对 5 种知识库嵌入执行全局置换重要性分析。每个来源提供高维表征 $ \mathbf E_s\in\mathbb R^{G\times128} $，其中 $ G=19,408 $ 表示蛋白编码基因集合。这些嵌入通过交叉注意力整合进模型，使模型可跨不同生物学情境加权信息。

**置换流程。** 在 Replogle–Nadig HepG2 测试集上，通过系统破坏每个嵌入来源 $ s\in\{1,\ldots,5\} $ 的信息内容评估模型稳健性。对给定来源，把随机置换函数 $ \mathcal P(\cdot) $ 应用于展平后的嵌入张量：

$ (\mathbf E'_s)_{i,j}=\mathcal P\big((\mathbf E_s)_{g,k}\mid\forall g,k\big).\tag{10} $

该流程保留嵌入数值的全局分布（均值、方差和数据类型），同时彻底破坏基因特异语义映射及潜空间内部的结构关系。模型每次仅使用一种经置换的嵌入 $ \mathbf E'_s $ 推理，其他知识源和模型权重保持不变。

**量化性能退化。** 使用 `cell-eval` 的一组指标评估各知识源影响，包括 MAE、L2 Discrimination Score、Pearson $ \Delta $、Overlap@N、DE Direction Match 和 DE LogFC Spearman。为在异质指标之间标准化重要性，计算相对性能下降 $ \Delta M_s $。对数值越高性能越好的指标（如 Pearson $ \Delta $、Overlap@N）：

$ \Delta M_s=\frac{M_{\mathrm{baseline}}-M_{\mathrm{permuted},s}}{M_{\mathrm{baseline}}}\times100.\tag{11} $

对数值越低越好的误差指标（如 MAE），计算误差百分比增幅：

$ \Delta M_s=\frac{M_{\mathrm{permuted},s}-M_{\mathrm{baseline}}}{M_{\mathrm{baseline}}}\times100.\tag{12} $

$ \Delta M_s $ 越高，表示模型越依赖该知识库来源中包含的具体生物信息来准确预测扰动。这种方法允许按功能上与 HepG2 调控图景的相关程度排列 5 种知识源，并验证交叉注意力机制确实利用了所提供的生物学先验，而非只依赖训练分布。

#### 4.1.11 相关工作与扩展讨论
早期扰动预测计算方法主要基于概率潜变量模型。Conditional Perturbation Autoencoder（CPA）及其扩展 chemCPA，把扰动效应建模为学习式基因表达潜空间中的结构位移，并将扰动与协变量及基础细胞状态解耦 [15–17]。这些框架证明，扰动响应可近似为潜空间中的加法或组合变换，从而能在不同剂量和组合之间插值。

后续研究引入生物学先验，以改善对未见扰动的外推。GEARS 等图模型显式整合基因—基因相互作用网络，提升对未见扰动及组合扰动的泛化 [18]。PRESAGE、TxPert、GenePT 等方法则利用从大型生物语料得到的预训练基因嵌入或结构化先验，为扰动建模提供信息 [19–21]。这些知识驱动策略证明，纳入基因调控或相互作用结构可改善未见扰动上的表现。然而，它们的预测形式主要捕获相对对照表达谱的条件均值响应，通常在伪总体摘要或确定性重建上评估，而没有显式建模扰动态的完整单细胞分布。

为更直接地建模分布转变，多项研究把扰动响应表述为概率分布之间的映射。最优传输（OT）被用于对齐对照群体与扰动群体，并推断跨条件的细胞轨迹 [97]；相关神经 ODE 方法则建模细胞状态间的连续时间转变 [98]。cinemaOT 及相关 OT 方法进一步把扰动形式化为条件分布传输问题 [25, 26]。这些方法强调学习分布间变换，而非预测点估计，为捕获细胞响应异质性提供了原则性框架。近期，scLDM 和 CellFlow 等基于扩散的生成模型被用于建模基因表达动力学与随机状态转变，为单细胞情境中的分布级建模提供了可扩展方案 [28, 29]。

大规模预训练模型也被改造用于扰动预测。scGPT、scTransformer 等 Transformer 架构在大量公共 RNA-seq 或单细胞语料上预训练，学习情境化基因表征，再针对扰动建模等下游任务微调 [8, 10]。C2S 等受语言模型启发的方法同样利用大规模生物文本或表达语料，得到可迁移至扰动任务的基因嵌入 [22]。STATE 把预训练表征与分布目标结合，以更好地捕获单细胞分辨率下扰动诱导的变异 [27]。这些工作显示大规模预训练可改善表征质量，但预训练语料与扰动专用数据集在规模和多样性上仍存在部分失配，因而限制了对扰动预测缩放行为的系统评估。

### 4.2 X-Atlas/Pisces 方法
#### 4.2.1 sgRNA 文库构建、慢病毒制备及单细胞测序
文库构建（sgRNA 设计、克隆和慢病毒包装）及测序（文库制备和测序）的核心方法按先前报道执行 [39]。sgRNA 文库组成有一处调整：HCT116 与 HEK293T 筛选靶向全部蛋白编码基因；后续筛选则只为 bulk RNA 测序判定在相应细胞系中表达的基因纳入扰动（第 4.2.2 节）。表达基因定义为累计占比对计数 99% 的转录本（第 4.2.11 节）。

#### 4.2.2 bulk RNA 测序
每个样本使用 100 ng 总 RNA 构建 mRNA 测序文库。按厂商方案使用 Watchmaker mRNA Library Prep Kit（Watchmaker Genomics，货号 7K0105-096）制备文库，并使用 IDT 的 xGen UDI-UMI Full-length adapters（货号 10005903）建立索引。最终文库以 Qubit dsDNA High Sensitivity Assay（Thermo Fisher）定量，使用 TapeStation 系统的 D1000 ScreenTape Analysis 检查片段长度分布与质量。文库按等摩尔量混池，并以 qPCR 定量最终混池浓度以保证准确上样。混池文库在 Illumina NovaSeq 6000 系统上测序。

#### 4.2.3 iPSC 筛选
按既往方法 [99]，通过 Cas9 介导的 GAPDH 位点插入，使 ASE-9211-iPSC（Applied Stem Cell）表达 dCas9-KRAB-ZIM3；区别在于，转基因被靶向插入 GAPDH 终止密码子下游的 3′ UTR（ASE-9211-GZ3-iPSC），并移除终止密码子。Sanger 测序验证预期插入，编辑后确认核型正常。ASE-9211-GZ3-iPSC 在 Geltrex（货号 A1413202）包被板上用 mTeSR Plus（货号 100-0276）维持培养，支原体检测阴性。

在全基因组 Perturb-seq 实验中，将 8,745 万个细胞以 MOI 0.2 悬液转导，再分装至 33 个 T-150 培养瓶；培养基为含 10 μM Y-27632（货号 72304）的 mTeSR Plus。转导后 24 小时移除慢病毒，随后以含 2 μg/mL 嘌呤霉素（货号 A1113803）的培养基培养 5 天，富集转导细胞。转导后第 7 天使用 Accutase 收获细胞，以 Zombie NIR Fixable Viability Kit 染色，再按上文进行整体固定和冻存。之后解冻固定细胞等分样本并经 FACS（Sony SH800 或 BD CytoFLEX）分选，分离存活（Zombie NIR 阴性）且表达扰动系统（dCas9-mScarlet 阳性、sgRNA-mNeonGreen 阳性）的细胞。

#### 4.2.4 HepG2 筛选
HepG2（ATCC）在添加 10% FBS、100 U/mL 青霉素和 100 μg/mL 链霉素的 EMEM 中培养。按照厂商说明（SBI），使用 PiggyBac 转座子稳定整合由 dCas9-mScarlet-ZIM3 构建体与博来霉素抗性基因组成的 CRISPRi 效应器。细胞按 mScarlet 荧光分选至至少 95% 纯度，扩增并冻存。

解冻扩增后，将 4.5 亿个细胞按每瓶 500 万个接种于 90 个 T150 培养瓶，并以 sgRNA 文库转导（MOI = 0.25）。次日换液移除慢病毒。转导后第 3 天用 Accutase 解离细胞，再按每瓶 1,500 万个接种于 100 个 T150 培养瓶，培养基含 2 μg/mL 嘌呤霉素；次日更换含相同浓度嘌呤霉素的新培养基，再下一日换新培养基移除嘌呤霉素。sgRNA 转导后第 7 天用 Accutase 收获，以 Zombie NIR 固定型活性染料染色，再按上文固定和冻存。之后解冻固定细胞等分样本并经 FACS 分选，分离存活且表达扰动系统的细胞。

#### 4.2.5 Jurkat 静息态与激活态筛选
Jurkat（E6-1 克隆）在添加 10% FBS 的 RPMI 1640 中培养。按厂商说明，通过 PiggyBac 转座稳定表达带博来霉素抗性标记的 dCas9–mScarlet–ZIM3 CRISPRi 效应器，建立 Jurkat CRISPRi 细胞系。使用 Lonza CK-116 程序，以转座酶（SBI）与转座子 1:2.5 的比例电转，再用 Sony SH800 分选仪将 mScarlet 阳性纯度提高到 95% 以上。分选后细胞先在含 10 μg/mL 博来霉素的培养基中维持至少 5 天，再以全基因组 sgRNA 文库转导。

刺激条件下，在收获和固定前 24 小时，以 25 μL/mL 的 ImmunoCult Human CD3/CD28 T Cell Activator 诱导 T 细胞激活。为减少固定淋巴细胞所受剪切应力，使用磁激活细胞分选（MACS）替代 FACS 富集。解冻细胞用 Dead Cell Removal Kit（Miltenyi Biotec，货号 130-090-101）处理以去除裂解细胞；整个解冻和富集流程均使用宽口移液枪头，进一步减少物理应力。

#### 4.2.6 iPSC Multi-Dif 筛选
约 $ 1.27\times10^9 $ 个 ASE-9211-GZ3-iPSC（第 4.2.3 节）以 MOI 0.2 悬液转导，再分装至 41 个 T-150 培养瓶；培养基为含 10 μM Y-27632 的 mTeSR Plus。转导后 24 小时移除慢病毒。转导后第 2 天用 Accutase 将 iPSC 收获为单细胞悬液，以流式细胞术测定 MOI；随后按每孔 $ 10.9\times10^6 $ 个细胞接种于 38 块 6 孔板，培养基含 2 μg/mL 嘌呤霉素。

接种后 24 小时（分化 D0），将培养基更换为 STEMdiff APEL2 Medium（STEMCELL Technologies，货号 05275）。D1–3、D5–8 和 D9–12 换液，D4 不换液。D13 用 Accutase 收获细胞，以 Zombie NIR Fixable Viability Kit 染色，随后使用 10X Genomics Fixed RNA Flex assay 试剂进行整体固定并在 −80°C 长期保存。之后解冻固定细胞等分样本，经 FACS 分离存活且表达扰动系统的细胞，再于 −80°C 长期保存。所有细胞分选均在固定后 3 周内完成。

#### 4.2.7 优化的 FiCS-Perturb 流程调整
为实现全基因组通量，同时降低批次效应与细胞裂解导致的测序噪声，我们实施了在原 FiCS-Perturb 流程上改造的“固定—冻存—富集”（Fix-Freeze-Enrich）优化流程。与固定后立即分选的原方法不同，该流程将固定与文库制备解耦，允许批量建库储存。

细胞收获后，在室温下用 1 mg/mL 二硫代双（琥珀酰亚胺丙酸酯）（DSP）固定 30 分钟。淬灭并洗涤后，立即将细胞重悬于添加 0.2 U/μL RNasin Plus RNase Inhibitor 的 Bambanker 冻存液中，以每份 1,000 万至 5,000 万个细胞在 −80°C 批量冻存。文库制备当天，在 37°C 快速解冻至仅剩少量冰晶。为防止渗透压冲击与细胞裂解，用冷 10X Cell Buffer（DPBS + BSA）缓慢稀释解冻细胞：每次加入 1 mL 后轻柔颠倒混匀，最终定容至 15–50 mL。定量及“超载”至 10x Genomics Chromium GEM-X 5′ 芯片前，立即富集解冻细胞，去除冻融期间积累的非存活细胞和碎片；目标密度为每通道 100,000 个细胞。

#### 4.2.8 基于 10X Flex 的单细胞转录组分析与 sgRNA 检测（Flex Perturb-seq）
iPSC Multi-Dif 筛选中，解冻已固定和分选的细胞等分样本，作为 Flex Fixed RNA Assay（v1）的输入，并掺入定制探针以检测 CRISPRi 和 sgRNA 构建体、恢复 sgRNA 扰动身份。共进行 6 组、每组 16 个杂交反应。随后合并并洗涤各杂交产物，生成 GEM（共 34 个），目标为每个 GEM 通道回收 320,000 个细胞。

按厂商说明生成测序文库，并根据技术指南“CRISPR Screening with GEM-X Flex Gene Expression”（CG000814 Rev A）调整杂交、预扩增 PCR 和 Feature PCR 步骤。使用 Illumina 25B NovaSeq X 试剂盒测序，每次运行混合 3 个基因表达文库和 3 个配对 CRISPR 文库。每个混池测序两次，目标每通道回收 320,000 个细胞。基因表达文库测序深度为每细胞 50,000 reads，CRISPR 文库为每样本每细胞 5,000 reads。

最终分别将基因表达与 CRISPR 文库混至 10 nM；浓度根据高灵敏度 DNA Qubit 定量与 TapeStation D1000 ScreenTape 试剂测得，并使用 200–1,000 bp 的平均片段长度范围。测序前以 CFX Opus 384 Real-Time PCR System（货号 12011452）和 Kapa Library Quantification Kit Universal qPCR Master Mix（货号 KK4824）对最终 10 nM 文库进行 qPCR 验证。之后用 Qiagen EB Buffer 将 10 nM 混池稀释至 2 nM，并加入 10% PhiX。最终 2 nM 混池按 Illumina NovaSeq X 流程变性和测序，目标最终上样浓度为 170 pM，测序参数为 28/10/10/90。

#### 4.2.9 碱基识别、比对与 sgRNA 判定
使用 bcl2fastq2（v2.2）进行碱基识别与 FASTQ 拆分。用于比对、细胞条形码判定和 UMI 计数的 Cell Ranger 版本为：v8.0.0（HCT116）、v8.0.1（HCT116、HEK293T、iPSC、HepG2）、v9.0.1（Jurkat 静息态与激活态）、v10.0.0（iPSC Multi-Dif）。HCT116、HEK293T、HepG2、iPSC、Jurkat 静息态和激活态筛选以 10x Genomics 预构建基因组 GRCh38 2024-A 为参考转录组。iPSC Multi-Dif 筛选使用定制参考基因组（GRCh38 2024-A）及探针集（Human Transcriptome v1.1.0），并加入 BFP、mScarlet 和 dCas9。比对后，检查各 GEM 组的每细胞平均 reads、每细胞基因数中位数及每细胞 CRISPR UMI 中位数等 QC 指标，以确保测序深度和覆盖充分。

sgRNA 判定遵循先前方法 [39]，并增加确定最低 UMI 阈值的优化步骤。评估 3–50 的不同阈值，选择使有效双导向细胞（恰好被分配一个匹配导向对的细胞）数量最大的阈值。移除 UMI 计数低于该阈值的导向，再根据剩余导向判定为每个细胞分配 0、1 或多个 sgRNA 身份。后续分析只使用含预期双 sgRNA、且两条 sgRNA 靶向同一基因的细胞。

#### 4.2.10 X-Atlas/Pisces 的 QC 指标
+ **每细胞平均 reads**：基因表达 reads 总数除以细胞相关条形码数。
+ **每细胞 UMI 中位数**：各细胞相关条形码 UMI 计数的中位数。
+ **每细胞基因数中位数**：每个细胞相关条形码中检出的基因数（至少 1 个 UMI）中位数。
+ **每细胞平均 CRISPR reads**：CRISPR reads 总数除以细胞相关条形码数。
+ **每细胞 CRISPR UMI 中位数**：每个细胞相关条形码的 CRISPR UMI 数中位数（对所有识别出的导向序列求和）。
+ **筛选中的扰动数**：至少识别到一个有效双导向细胞的独特扰动总数。
+ **每种扰动的细胞数中位数**：在被分配有效双导向对的细胞群中计算。
+ **每种扰动的靶向敲低率中位数**：逐扰动比较扰动群体中靶基因的平均归一化表达 $ \bar E_{\mathrm{target}} $ 与 NTC 群体表达 $ \bar E_{\mathrm{NTC}} $：$ \mathrm{KD}\%=\left(1-\bar E_{\mathrm{target}}/\bar E_{\mathrm{NTC}}\right)\times100 $。
+ **具有显著表型的扰动比例**：二分类器判定 FDR < 0.05 的扰动比例（第 4.2.13 节）。

#### 4.2.11 界定 X-Atlas/Pisces 全基因组文库
使用 bulk RNA-seq（第 4.2.2 节）确定 HCT116、HEK293T、HepG2、iPSC、Jurkat 静息态及激活态筛选中的表达基因。采用 Nextflow `nf-core` 流程（v3.16.0）实现的 STAR（v2.7.10a）—Salmon（v1.10.1）拆分 reads，计算基因计数和 TPM，并按 ENSEMBL gene ID 聚合。基因表达量以每百万转录本数（TPM）计算；累计占总 TPM 计数 99% 的基因定义为表达基因。

Jurkat 静息态和激活态筛选包含 5 种条件的 20 个样本：静息、ImmunoCult、TransAct、CD3/CD28 Dynabeads 和 PMA/Ionomycin，每种条件 4 个重复；按上述相同参数拆分并比对。以 TPM 评估表达量，以 $ \log_{10}(\mathrm{TPM}+1) $ 的标准差评价表达变异性，前 500 个视为高变基因。为系统选择各样本活跃基因，先按 TPM 从高到低排序，再计算总 TPM 的累积比例；在给定阈值（如 99%）下，构成该累积比例的基因定义为活跃基因。在同一刺激条件至少 2 个样本中活跃的基因，标为该条件的活跃基因。

使用 PyDESeq2（v0.5.3）识别静息和激活 Jurkat 细胞间差异表达基因。检验前过滤低表达基因，只保留在至少 5 个样本中计数大于 10 的基因。对 4 种刺激条件分别通过 Wald 检验与静息基线比较；各比较内以 Benjamini–Hochberg 法进行多重检验校正，FDR < 0.05 视为显著。任一刺激条件下显著的基因均纳入最终文库。

iPSC Multi-Dif 的全基因组文库由 bulk 与单细胞 RNA-seq 共同确定。开展多时间点 iPSC Multi-Dif 筛选，于第 2、6、9、13 天采样。细胞注释到相应类型，并为每种细胞类型生成伪总体表达谱。分别从 bulk 和逐细胞类型伪总体中保留构成表达转录本前 99% 的全部基因，生成表达基因列表；最终文库定义为 bulk RNA-seq 表达基因与各细胞类型伪总体表达基因的并集。

#### 4.2.12 iPSC Multi-Dif 细胞类型注释
使用 Scanpy（v1.10.1）处理细胞×基因计数矩阵。细胞过滤条件为：总计数 $ 5,000<n_{\mathrm{counts}}<130,000 $；总基因数 $ 1,000<n_{\mathrm{genes}}<11,000 $；线粒体 reads 百分比 $ \mathrm{pct.mt}\le10 $；含有效双导向对。使用 `scanpy.pp.filter_genes(min_cells=3)` 保留至少在 3 个细胞中检出的基因。计数归一化至每万个并进行 log2 转换。

用 `scanpy.pp.highly_variable_genes(n_top_genes=3000,n_bins=20,flavor="seurat")` 检测高变基因；用 `scanpy.pp.pca(n_comps=50,svd_solver="arpack")` 进行 PCA 降维；用 `scanpy.pp.neighbors()` 默认参数计算近邻；用 Leiden 算法聚类（resolution=0.50，n_iterations=5）。每个簇的标志基因通过 `scanpy.tl.rank_genes_groups(n_genes=50,method="wilcoxon")` 识别。

按照上述流程创建参考数据集，并结合逐簇从头获得的标志基因与人工整理的胚层标志基因集进行人工注释。后续各测序批次的计数矩阵均使用 `scanpy.tl.ingest()` 默认参数映射并注释到参考对象。

#### 4.2.13 二分类
X-Atlas/Pisces 全部筛选均按既往方法 [39] 使用二分类器评估，并有两项调整：（1）处理至少含 10 个细胞的扰动；（2）使用 Benjamini–Hochberg 法进行多重检验校正。由于 iPSC Multi-Dif 筛选中各注释细胞类型回收数量差异较大，本文报告使用数据集中全部细胞、不按细胞类型再分组得到的二分类结果。

#### 4.2.14 已知生物网络的召回
使用 EFAAR 框架 [100] 评估 X-Atlas/Pisces 的生物学覆盖度。排除少于 10 个细胞的扰动；其余扰动与非靶向对照分别下采样至每项筛选最多 100 个细胞和每个 GEM 最多 100 个细胞。转录谱经 PCA 嵌入、离群值过滤，并使用 Typical Variation Normalization（TVN）进行跨批次对齐。对齐后的表达谱按扰动求均值，再用余弦相似度推断成对基因关系，并在每项实验内转换为相对秩。

将基因相似性秩与 CORUM [101] 和 STRING [102]（v12.0，score ≥ 950）的参考相互作用比较。使用相似性秩最高和最低的 5% 基因对计算召回率，仅纳入数据集和参考数据库中均存在的基因对。为评估组合情境中扰动对的影响，在各筛选所有可能组合上计算累积召回指标并报告均值和标准差。对最高与最低 5% 基因对取并集；若同一基因对在多项筛选中检出，保留最极端的秩。为评估 1–7 项筛选的累积表现，对每个可能子集计算召回率；对每种子集大小（如双筛选子集共 21 种组合），报告召回率均值和标准差。

#### 4.2.15 识别情境无关与情境依赖扰动
在 HCT116、HEK293T、HepG2、iPSC、Jurkat 静息态、Jurkat 激活态和 iPSC Multi-Dif 7 项筛选间汇总二分类器 F1 分数，纳入最大 F1 ≥ 0.75 且至少出现在 3 项筛选中的扰动。所得 F1 矩阵用 k-means 聚为 10 组（随机种子 42），计算距离时以 0 填补缺失值。簇按大小降序排列，簇内基因按跨筛选平均 F1 排序。列（筛选）则在列均值填补的数据上，使用欧氏距离与平均连接法进行层次聚类。热图使用 `seaborn.clustermap()`（seaborn v0.13.2）绘制，并以行颜色注释簇分配。

为识别情境无关与情境依赖扰动，对每个簇计算特异性分数：目标筛选中的平均 F1 减去其他所有筛选的平均 F1。对情境无关簇（所有筛选中平均 F1 最高）以及筛选特异性最强的簇执行 GSEA。使用 `gseapy.enrich()`（gseapy v1.1.4），以 MSigDB v2025.1 基因集（WikiPathways、Reactome、GO Biological Process、GO Cellular Component、GO Molecular Function 和 Hallmark）为参照，以热图全部基因为背景，阈值 FDR < 0.05。

#### 4.2.16 按筛选在 UMAP 上可视化扰动
将 7 项筛选中二分类器得到的特征（基因；$ n=39,447 $ 个扰动）聚合为一个联合数据矩阵。若某扰动的二分类器 p 值不小于 0.05，或唯一检出的特征是被扰动基因本身，则从嵌入中排除。特征基因列表进一步限制为 19,082 个蛋白编码基因——即 GENCODE 注释与 ESM-2 词表的交集。过滤后最终分析集含 35,016 个扰动。

对每种扰动，使用 `sklearn.preprocessing.MultiLabelBinarizer`（scikit-learn v1.7.2）把检出的特征基因编码为稀疏二值向量。所得稀疏矩阵（35,016 个扰动 × 11,351 个基因）通过 `sklearn.feature_extraction.text.TfidfTransformer(norm="l2",sublinear_tf=False)` 应用 L2 归一化词频—逆文档频率（TF-IDF）权重。随后使用 `sklearn.decomposition.TruncatedSVD(n_components=100)` 保留前 100 个奇异向量，得到稠密嵌入；再以 `umap.UMAP(n_neighbors=30,min_dist=0.005,metric="cosine",n_components=2)`（umap-learn v0.5.9）可视化。

在 UMAP 嵌入上使用 `sklearn.cluster.HDBSCAN(min_cluster_size=20,min_samples=5,cluster_selection_method="eom",metric="euclidean")` 进行密度聚类。88.1% 的扰动被分配到 253 个不同簇，其余 11.9% 作为未分配噪声。

为评估功能一致性，使用 `gseapy.enrich()`（gseapy v1.1.11）检验每个簇内独特受扰动基因在 CORUM 人蛋白复合体数据库中的富集。Benjamini–Hochberg 校正后，253 个簇中有 223 个至少显著富集一个 CORUM 复合体（FDR < 0.05）。使用 STRING 数据库（network v11.5）评估蛋白—蛋白相互作用（PPI）富集。对每个簇，将所有簇内基因对的 STRING combined score 均值作为观测分数。使用 `numpy.random.default_rng(42).permutation`（numpy v1.26.4）随机置换簇标签 200 次并保留原始簇大小，生成匹配背景的零分布。观测簇分数显著高于对应零分数（`scipy.stats.ttest_rel` 配对 t 检验；$ n=253 $ 个簇，$ t=8.60 $，$ p=8.44\times10^{-16} $）。

为可视化特定大分子复合体，人工筛选空间上连贯且 CORUM 富集强的簇。将选中簇的基因并集映射至相应结构模型（线粒体核糖体 PDB: 3J9M [47]；复合体 I PDB: 5XTD [48]），使用 `pymol2` API 渲染。与检出基因对应的链通过 `cmd.fetch()` 与 `cmd.show("cartoon")` 可视化，并映射至打乱后的青色到黄绿色渐变；未检出的链标为中灰色以形成视觉对比。

## 附录 A：X-Cell 模型规格
### A.1 架构细节
#### A.1.1 输入编码
每个训练样本为元组 $ (\mathbf X_{\mathrm{ctrl}},\mathbf X_{\mathrm{target}},\mathbf T,\mathbf M_{\mathrm{pert}},p) $。其中，$ \mathbf X_{\mathrm{ctrl}},\mathbf X_{\mathrm{target}}\in\mathbb R^{S\times G'} $ 是 $ S $ 个细胞、$ G' $ 个下采样基因上的对照与扰动表达矩阵；$ \mathbf T\in\mathbb Z^{S\times G'} $ 包含基因词表索引；$ \mathbf M_{\mathrm{pert}}\in\{0,1\}^{S\times G'} $ 是二值扰动掩码，用来指示哪些基因位置含已揭示扰动信号；$ p $ 标识扰动。为进行 token 级处理，批次从 $ (B,S,G') $ 重塑为 $ (B\cdot S,G') $。

训练期间，按扰动掩码混合对照值与扰动值，构造观测表达输入 $ \tilde{\mathbf X} $：

$ \tilde{\mathbf X}=(1-\mathbf M_{\mathrm{pert}})\odot\mathbf X_{\mathrm{ctrl}}+\mathbf M_{\mathrm{pert}}\odot\mathbf X_{\mathrm{target}},\tag{A1} $

其中 $ \odot $ 表示逐元素相乘。三个编码器分别产生 $ d $ 维表征。

**基因身份编码器：**

$ \mathbf e_g=\operatorname{LayerNorm}(\operatorname{Embedding}(t_g))\in\mathbb R^d,\quad t_g\in\{0,\ldots,|\mathcal V|-1\}.\tag{A2} $

词表 $ \mathcal V $ 包含约 19,400 个蛋白编码基因、特殊 token（`<cls>`、`<mask>`）以及扰动基因别名。

**连续数值编码器：**

$ \phi(x)=\mathrm{LayerNorm}\!\left(\mathrm{Dropout}\!\left(W_2\mathrm{ReLU}(W_1\mathrm{clip}(x,-\infty,512))+\mathbf b_2\right)\right)\in\mathbb R^d,\tag{A3} $

其中 $ W_1\in\mathbb R^{d\times1},W_2\in\mathbb R^{d\times d} $。

**扰动掩码编码器：** 二值扰动掩码经可学习嵌入表与 LayerNorm 编码：

$ \psi(M_{\mathrm{pert},g})=\mathrm{LayerNorm}(\mathrm{Embedding}_{\mathrm{mask}}(M_{\mathrm{pert},g}))\in\mathbb R^d,\tag{A4} $

用于指示位置 $ g $ 的输入值是对照信号还是已揭示扰动信号。

**可学习 CLS token：** 位置 0 的 CLS token 是独立于基因、数值及掩码编码器的学习式嵌入 $ \mathbf c=\mathrm{Embedding}_{\mathrm{CLS}}(0)\in\mathbb R^d $。位置 1 至 $ G' $ 的基因正常编码，并前置 CLS 嵌入：

$ \mathbf H^{(0)}=[\mathbf c;\mathbf e_1+\phi(\tilde x_1)+\psi(M_{\mathrm{pert},1});\ldots;\mathbf e_{G'}+\phi(\tilde x_{G'})+\psi(M_{\mathrm{pert},G'})]\in\mathbb R^{(G'+1)\times d}.\tag{A5} $

#### A.1.2 扰动上下文编码
对每个扰动 $ p $，将 6 种先验知识嵌入投影到维度 $ d $：

$ \mathbf c_{\mathrm{ESM}}=\mathrm{MLP}_{\mathrm{ESM}}(\mathbf z_{\mathrm{ESM}}^{(p)})\in\mathbb R^d,\quad\mathbf z_{\mathrm{ESM}}\in\mathbb R^{5120},\tag{A6} $

$ \mathbf c_{\mathrm{STRING}}=\mathrm{MLP}_{\mathrm{STRING}}(\mathbf z_{\mathrm{STRING}}^{(p)})\in\mathbb R^d,\quad\mathbf z_{\mathrm{STRING}}\in\mathbb R^{512},\tag{A7} $

$ \mathbf c_{\mathrm{GenePT}}=\mathrm{MLP}_{\mathrm{GenePT}}(\mathbf z_{\mathrm{GenePT}}^{(p)})\in\mathbb R^d,\quad\mathbf z_{\mathrm{GenePT}}\in\mathbb R^{3072},\tag{A8} $

$ \mathbf c_{\mathrm{DepMap}}=\mathrm{MLP}_{\mathrm{DepMap}}(\mathbf z_{\mathrm{DepMap}}^{(p)})\in\mathbb R^d,\quad\mathbf z_{\mathrm{DepMap}}\in\mathbb R^{1150},\tag{A9} $

$ \mathbf c_{\mathrm{CP}}=\mathrm{MLP}_{\mathrm{CP}}(\mathbf z_{\mathrm{CP}}^{(p)})\in\mathbb R^d,\quad\mathbf z_{\mathrm{CP}}\in\mathbb R^{259},\tag{A10} $

$ \mathbf c_{\mathrm{gene}}=\operatorname{sg}(\mathbf e_p)\in\mathbb R^d\quad\text{（停止梯度的基因嵌入）}.\tag{A11} $

每个 $ \mathrm{MLP}_s:\mathbb R^{d_s}\to\mathbb R^d $ 均为含 LeakyReLU 激活和 LayerNorm 输出的两层网络。6 个 token 组成交叉注意力上下文：$ \mathbf C_{\mathrm{pert}}=[\mathbf c_{\mathrm{ESM}};\mathbf c_{\mathrm{STRING}};\mathbf c_{\mathrm{GenePT}};\mathbf c_{\mathrm{DepMap}};\mathbf c_{\mathrm{CP}};\mathbf c_{\mathrm{gene}}]\in\mathbb R^{6\times d} $，并在每个集合的 $ S $ 个细胞上复制。缺失嵌入（如某基因无 STRING 条目）以 0 填补，并通过布尔掩码 $ \mathbf m_{\mathrm{ext}}\in\{0,1\}^6 $ 标记，作为 key padding mask 传入交叉注意力。

#### A.1.3 Transformer 编码器
编码器由 $ L $ 个自注意力层组成，并在指定索引 $ \mathcal T_{\mathrm{cross}}\subset\{0,\ldots,L-1\} $ 处交错插入交叉注意力。

**带 QK-Norm 的自注意力。** 对第 $ \ell $ 层：

$ \mathbf Q=\mathrm{RMSNorm}_q(W_Q\mathrm{RMSNorm}(\mathbf H^{(\ell-1)})),\tag{A12} $

$ \mathbf K=\mathrm{RMSNorm}_k(W_K\mathrm{RMSNorm}(\mathbf H^{(\ell-1)})),\tag{A13} $

$ \mathbf V=W_V\mathrm{RMSNorm}(\mathbf H^{(\ell-1)}),\tag{A14} $

$ \mathrm{Attn}(\mathbf Q,\mathbf K,\mathbf V)=\mathrm{softmax}\!\left(\frac{\mathbf Q\mathbf K^\top}{\sqrt{d_k}}\right)\mathbf V,\tag{A15} $

$ d_k=d/n_{\mathrm{heads}}.\tag{A16} $

$ \mathrm{RMSNorm}_q $ 与 $ \mathrm{RMSNorm}_k $ 是分别作用于每个注意力头的 RMSNorm（可学习缩放，无偏置）[72]。所有投影矩阵 $ W_Q,W_K,W_V,W_O\in\mathbb R^{d\times d} $ 均省略偏置项，遵循 LLaMA 约定。

**RMSNorm：**

$ \operatorname{RMSNorm}(\mathbf x)=\frac{\mathbf x}{\sqrt{\frac1d\sum_{i=1}^d x_i^2+\epsilon}}\odot\boldsymbol\gamma,\quad\boldsymbol\gamma\in\mathbb R^d.\tag{A17} $

**SwiGLU 前馈网络：**

$ \mathrm{SwiGLU}(\mathbf x)=W_{\mathrm{down}}(\mathrm{SiLU}(W_{\mathrm{gate}}\mathbf x)\odot W_{\mathrm{up}}\mathbf x),\tag{A18} $

其中 $ W_{\mathrm{gate}},W_{\mathrm{up}}\in\mathbb R^{d_{\mathrm{ff}}\times d} $，$ W_{\mathrm{down}}\in\mathbb R^{d\times d_{\mathrm{ff}}} $，$ d_{\mathrm{ff}}=4d $，均无偏置。

**Pre-LN 残差模块：**

$ \mathbf H^{(\ell)}=\mathbf H^{(\ell-1)}+\mathrm{SelfAttn}(\mathrm{RMSNorm}(\mathbf H^{(\ell-1)})),\quad
\mathbf H^{(\ell)}\leftarrow\mathbf H^{(\ell)}+\mathrm{SwiGLU}(\mathrm{RMSNorm}(\mathbf H^{(\ell)})).\tag{A19} $

**交叉注意力模块。** 在 $ \ell\in\mathcal T_{\mathrm{cross}} $ 的层，自注意力残差后应用：

$ \tilde{\mathbf H}=\mathrm{RMSNorm}(\mathbf H^{(\ell)}),\tag{A20} $

$ \mathbf H^{(\ell)}\leftarrow\mathbf H^{(\ell)}+\mathrm{CrossAttn}(\tilde{\mathbf H},\mathbf C_{\mathrm{pert}},\mathbf C_{\mathrm{pert}}),\tag{A21} $

$ \mathbf H^{(\ell)}\leftarrow\mathbf H^{(\ell)}+\mathrm{SwiGLU}(\mathrm{RMSNorm}(\mathbf H^{(\ell)})).\tag{A22} $

查询来自 $ \tilde{\mathbf H} $（基因表征），键和值来自 $ \mathbf C_{\mathrm{pert}} $（扰动上下文）。这使每个基因表征均以关于该扰动的生物学先验知识为条件。全部 $ L $ 层后应用最终 RMSNorm。

为促进梯度流并保留基因信号的初始身份，可选用全局残差连接：

$ \mathbf H'=\mathbf H^{(L)}+\mathbf H^{(0)},\tag{A23} $

其中 $ \mathbf H^{(0)} $ 是 Transformer 模块前的初始输入表征。

#### A.1.4 细胞嵌入与解码器
CLS token 输出 $ \mathbf h_{\mathrm{CLS}}=\mathbf H_0^{(L)}\in\mathbb R^d $ 作为细胞级嵌入。扩展后与基因级输出拼接：

$ \mathbf D_g=[\mathbf H_g^{(L)};\mathbf h_{\mathrm{CLS}}]\in\mathbb R^{2d},\quad g=1,\ldots,G'.\tag{A24} $

表达解码器是含 LeakyReLU（$ \alpha=0.01 $）的三层 MLP：

$ \mathbf h_g=W_3\operatorname{LReLU}(W_2\operatorname{LReLU}(W_1\mathbf D_g))\in\mathbb R^d.\tag{A25} $

**绑定嵌入输出。** 基因 $ g $ 的预测表达按式（4）计算：

$ \hat x_g=\frac{\mathbf h_g\cdot\mathbf e_g}{\sqrt d}+b_g.\tag{A26} $

$ \mathbf e_g $ 是与编码器共享的原始、未经归一化的基因嵌入；$ b_g\in\mathbb R $ 是通过 `nn.Embedding` 学习的逐基因偏置。$ 1/\sqrt d $ 缩放可防止大隐藏维度下 logit 爆炸 [77]。

#### A.1.5 扰动解码器（辅助）
为正则化交叉注意力，模型通过各知识源专属 MLP，从交叉注意力输出重建每种先验知识嵌入：

$ \hat{\mathbf z}_s=\mathrm{MLP}^{\mathrm{dec}}_s(\mathbf c_s),\quad
\mathcal L_{\mathrm{pert\_dec}}=\sum_{s\in\mathcal S}\|\hat{\mathbf z}_s-\mathbf z_s\|_2^2,\tag{A27} $

其中 $ \mathcal S=\{\mathrm{ESM,STRING,GenePT,DepMap,CP}\} $。

### A.2 训练目标
所有损失项均在排除 CLS 后运算，即 $ \hat{\mathbf X}=\hat{\mathbf X}_{\mathrm{raw}}[:,:,1:] $，移除位置 0。

#### A.2.1 MMD 损失（能量距离）
$ \mathcal L_{\mathrm{MMD}}=\frac1B\sum_{b=1}^B\mathrm{ED}(\hat{\mathbf X}_b,\mathbf X_b^{\mathrm{target}}).\tag{A28} $

ED 为能量距离 [27, 79]，通过 `geomloss` 库计算，参数为 `kernel="energy"`、`blur=0.05`、`scaling=0.5` [81]。每个 $ \hat{\mathbf X}_b\in\mathbb R^{S\times G'} $ 是 $ S $ 个预测细胞组成的集合，与 $ S $ 个真实扰动细胞比较。能量距离可捕获 MSE 无法提供的分布性质，如方差与多模态性。

#### A.2.2 倍数变化 CCC 损失
一致性相关系数（CCC）[82] 衡量预测与真实伪总体倍数变化的一致程度：

$ \Delta\hat\mu_g=\frac1S\sum_{s=1}^S\hat x_{s,g}-\frac1S\sum_{s=1}^Sx_{s,g}^{\mathrm{ctrl}}\quad\text{（逐基因预测倍数变化）},\tag{A29} $

$ \Delta\mu_g=\frac1S\sum_{s=1}^Sx_{s,g}^{\mathrm{target}}-\frac1S\sum_{s=1}^Sx_{s,g}^{\mathrm{ctrl}}\quad\text{（逐基因真实倍数变化）},\tag{A30} $

$ \mathrm{CCC}_{\mathrm{fc}}=\frac{2\operatorname{Cov}(\Delta\hat{\boldsymbol\mu},\Delta\boldsymbol\mu)}{\operatorname{Var}(\Delta\hat{\boldsymbol\mu})+\operatorname{Var}(\Delta\boldsymbol\mu)+(\overline{\Delta\hat{\boldsymbol\mu}}-\overline{\Delta\boldsymbol\mu})^2},\tag{A31} $

$ \mathcal L_{\mathrm{fc\_ccc}}=\frac1B\sum_{b=1}^B(1-\mathrm{CCC}_{\mathrm{fc}}^{(b)}).\tag{A32} $

统计量在每个批样本内部跨基因计算。不同于 Pearson、cosine 等尺度不变损失，CCC 同时惩罚方向和幅度不匹配；消融研究显示，这对抵抗保守塌缩至关重要（表 A1）。

#### A.2.3 逐基因 CCC 损失
$ \overline{\mathrm{CCC}}_g=\frac1{G'}\sum_{g=1}^{G'}\mathrm{CCC}(\hat{\mathbf x}_{:,g},\mathbf x_{:,g}^{\mathrm{target}}),\quad
\mathcal L_{\mathrm{per\_gene\_ccc}}=\frac1B\sum_{b=1}^B(1-\overline{\mathrm{CCC}}_g^{(b)}).\tag{A33} $

对每个基因独立跨细胞维度 $ S $ 计算 CCC，以匹配逐基因边缘分布，补充 MMD 的联合分布匹配。

#### A.2.4 Delta 范数惩罚
$ \rho=\frac{\|\Delta\hat{\boldsymbol\mu}\|_2}{\|\Delta\boldsymbol\mu\|_2+\epsilon},\quad
\mathcal L_\rho=\frac1B\sum_{b=1}^B(1-\rho_b)^2.\tag{A34} $

这是直接的抗塌缩正则项：$ \rho\ll1 $ 表示模型抑制扰动幅度，即预测表达接近对照。平方惩罚以 $ \rho=1 $ 为中心对称。

#### A.2.5 Delta 伪总体 MSE
$ \mathcal L_{\Delta\mathrm{MSE}}=\frac1B\sum_{b=1}^B\frac1{G'}\sum_{g=1}^{G'}(\Delta\hat\mu_g^{(b)}-\Delta\mu_g^{(b)})^2.\tag{A35} $

这是倍数变化的逐基因 L2 误差，提供绝对幅度信号，以补充基于相关性的 CCC。

#### A.2.6 对比嵌入损失
对 CLS 衍生细胞嵌入应用 InfoNCE [85]：

$ \mathcal L_{\mathrm{contrast}}=-\frac1B\sum_{b=1}^B\log\frac{\exp(\mathrm{sim}(\mathbf z_b,\mathbf z_b^+)/\tau)}{\sum_j\exp(\mathrm{sim}(\mathbf z_b,\mathbf z_j^+)/\tau)}.\tag{A36} $

$ \mathbf z_b $ 是预测细胞嵌入，$ \mathbf z_b^+ $ 是同一扰动真实嵌入的中心，负样本为其他扰动的中心；$ \mathrm{sim} $ 是余弦相似度，$ \tau=0.1 $。

#### A.2.7 完整目标
7 项损失以相同权重 $ w=1.0 $ 求和（L1 正则化权重设为 0）：

$ \mathcal L_{\mathrm{total}}=\mathcal L_{\mathrm{MMD}}+\mathcal L_{\mathrm{fc\_ccc}}+\mathcal L_{\mathrm{per\_gene\_ccc}}+\mathcal L_\rho+\mathcal L_{\Delta\mathrm{MSE}}+\mathcal L_{\mathrm{contrast}}+\mathcal L_{\mathrm{pert\_dec}}.\tag{A37} $

**梯度 RMS 监控。** 为诊断梯度平衡，在训练前 100 步记录逐损失梯度 RMS：$ \sqrt{\frac1n\sum_j(\partial\mathcal L_i/\partial\hat x_j)^2} $。结果显示，尺度不变损失（Pearson、cosine）会稀释 MMD 梯度却不能修复塌缩，因此改用 CCC。

### A.3 架构与损失消融
大型模型（不小于 17.5 亿参数）出现保守塌缩 [84]：扰动方向正确（DE Pearson $ r>0 $），但幅度受抑制（$ \rho=\|\Delta\hat{\boldsymbol\mu}\|/\|\Delta\boldsymbol\mu\|\ll1 $；早期 35 亿参数实验约为 0.17–0.22）。在 17.5 亿参数模型上进行的系统消融（Replogle–Nadig，6 个 epoch）识别出 5 个根因（表 A1；补充图 7A）：

1. **Post-LN → Pre-LN。** Post-LN 在 $ L>12 $ 时塌缩（$ \rho<0.1 $）；Pre-LN [69] 在注意力前归一化，使深层训练更稳定。
2. **Pearson/cosine → CCC。** 当 $ \hat{\mathbf x}\propto\mathbf x $ 时，尺度不变损失满足 $ \partial\mathcal L/\partial\|\hat{\mathbf x}\|=0 $。CCC 分母中的 $ (\mu_x-\mu_y)^2 $ 项提供非零幅度梯度 [82]。梯度 RMS 中，Pearson 占总量不足 5%，CCC 占 20%–40%。
3. **移除残差。** 跳连 $ \mathbf H^{(L)}+=\mathbf H^{(0)} $ 会产生惰性捷径 [103–105]。移除后 MAE 从 0.178 降至 0.163。
4. **L1 正则化。** $ \lambda\|\hat{\mathbf X}\| $ 直接惩罚幅度，因此设 $ \lambda=0 $。
5. **绑定嵌入。** 采用带 $ 1/\sqrt d $ 缩放 [77] 的权重绑定 [75]，将输出约束在基因嵌入空间，防止神经回归塌缩 [78]；$ \rho $ 从 0.43 升至 0.51，DE $ r $ 从 0.150 升至 0.327。

**训练效率。** 逐层 FSDP2 封装 [94] 将每步耗时从约 17 秒降至约 12.3 秒（降低 28%）。X-Cell-Ultra 在 64 块 H200 GPU 上达到 41% MFU，与 Llama 3 的 38%–43% [95] 相当，并比既往单细胞模型（约 1%–16%；补充图 7B）高 20 倍以上。

**QK-Norm。** 对 Q、K 逐头使用 RMSNorm [72]，防止 34 层网络在 bf16 下注意力 logit 爆炸。它对指标只有温和改善，主要是生产级训练中的稳定性措施。

### A.4 扩散掩码机制
**训练。** 对每个训练样本，从 $ \{0.25,0.5,0.75,1.0\} $ 中均匀抽取对照掩码策略 $ \alpha $。在固定随机排列中，最后 $ \lfloor\alpha G'\rfloor $ 个基因位置的对照表达被目标表达替换：

$ x_g^{\mathrm{input}}=\begin{cases}x_g^{\mathrm{target}},&g\in\mathcal R_\alpha,\\x_g^{\mathrm{ctrl}},&\text{其他，}\end{cases}\quad
M_g=\begin{cases}1,&g\in\mathcal R_\alpha,\\0,&\text{其他，}\end{cases}\tag{A38} $

其中 $ \mathcal R_\alpha $ 是已揭示位置集合。模型从这一部分揭示的输入预测完整 $ \mathbf X_{\mathrm{target}} $。

**推理（累积模式）。** 推理时通过 $ T=4 $ 个步骤迭代细化预测：

1. 初始化：$ \mathbf X^{(0)}=\mathbf X_{\mathrm{ctrl}} $，$ \mathbf M^{(0)}=\mathbf0 $，为基因分配随机秩 $ \mathbf r\in[0,1)^{G'} $。
2. 对 $ t=1,\ldots,T $，揭示比例 $ \alpha_t\in\{0.25,0.5,0.75,1.0\} $：
    - 前向传播：$ \hat{\mathbf X}^{(t)}=f_\theta(\mathbf X^{(t-1)},\mathbf M^{(t-1)},\mathbf C_{\mathrm{pert}}) $。
    - 选择新揭示基因：$ \mathcal N_t=\{g:r_g\le\alpha_t\}\setminus\{g:r_g\le\alpha_{t-1}\} $。
    - 更新：若 $ g\in\mathcal N_t $，则 $ X_g^{(t)}=\hat X_g^{(t)} $ 且 $ M_g^{(t)}=1 $。
3. 返回 $ \hat{\mathbf X}^{(T)} $ 作为最终预测。

### A.5 测试时适应细节
测试时适应（TTA）通过调整模型自注意力表征以适应目标域表达流形，使模型无需扰动标签即可零样本泛化至未见细胞情境 [92]。

**数据构造。** 在“对照到对照”（ctrl2ctrl）模式下，数据加载器从目标域抽取彼此独立的 NTC 细胞集合对。每个训练对由两个独立抽取、各含 $ S $ 个细胞的 NTC 集合组成，提供自监督分布匹配信号。模型在没有扰动信息的情况下学习目标域表达统计，包括基因—基因相关、方差结构和细胞类型特异模式。实现中设置 `ctrl_to_ctrl=True`，并用 `ctrl_mask_strategy="none"` 保证 $ \mathbf M_{\mathrm{pert}}=\mathbf0 $。

**模型配置。** 两个标志共同控制适应：

+ `skip_cross_attn=True`：向 Transformer 传入 `label_ctx=None`，绕过全部 11 个交叉注意力模块。NTC 对没有有意义的扰动上下文，所有外部嵌入掩码均会激活；该设置可避免全掩码注意力键导致数值不稳定。
+ `freeze_cross_attn=True`：令交叉注意力模块参数（X-Cell-Ultra 中约 11.5 亿）`requires_grad=False`。TTA 后设 `skip_cross_attn=False`，使用冻结的预训练权重重新启用交叉注意力；此时它作用于已适应目标域的自注意力特征。

**超参数。** 学习率 $ 10^{-6} $ 至 $ 10^{-5} $，权重衰减 0，仅使用 MMD 损失（$ \mathcal L=\mathcal L_{\mathrm{MMD}} $），200–1,024 个 NTC 集合，余弦预热 10%。训练按步数进行，以 `max_steps` 为停止标准。针对每个目标域扫描学习率和 NTC 集合总数（200、500 或 1,024），共 56 种配置，以验证损失为选择标准。

**TTA 后推理。** 加载适应后的检查点，并用模型覆盖项 `{skip_cross_attn: false}` 重新启用扰动条件化。DDP 检查点（单个 `.pt` 文件）和 FSDP 检查点（分片目录）均可透明支持。

### A.6 训练验证指标
以下指标在训练期间于留出验证划分上计算，用于监控优化和检测塌缩，并非正文报告的最终留出测试指标。训练验证指标作用于每个含 $ S=64 $ 个细胞的预测集合所聚合的伪总体质心，上下文长度经下采样为 $ G'\le4,000 $，并相对匹配对照集合计算倍数变化。相比之下，`cell-eval` 测试指标（第 4.1.8 节）作用于未见数据集或情境的完整上下文预测（$ G\approx19,000 $）。

训练 DE Pearson $ r $ 会先把全部扰动与基因的倍数变化展平为一个向量，再计算单个全局 $ r $；`cell-eval` Pearson $ \Delta $ 则逐扰动计算相关后取平均。类似地，$ \hat\rho $（delta 范数比）是诊断幅度塌缩（$ \hat\rho\ll1 $）的训练指标，在 `cell-eval` 中没有直接对应项。

**逐扰动 MAE。** 对每个独特扰动 $ p $，在该扰动全部细胞上平均预测得到质心，并与真实质心比较：

$ \mathrm{MAE}_p=\frac1{G'}\sum_{g=1}^{G'}|\bar{\hat x}_{p,g}-\bar x_{p,g}|,\quad
\mathrm{per\_pert\_MAE}=\frac1{|\mathcal P|}\sum_{p\in\mathcal P}\mathrm{MAE}_p.\tag{A39} $

**质心准确率。** 对每个预测质心 $ \hat{\boldsymbol\mu}_p $，计算它到真实质心 $ \boldsymbol\mu_p $ 以及同情境下其他全部真实质心的 L2 距离。最近真实质心恰为正确扰动的比例，即质心准确率（top-1 检索准确率）。

**DE Pearson **$ r $**。** 将倍数变化向量 $ \Delta\hat\mu=\hat\mu_p-\mu_{\mathrm{ctrl}} $ 与 $ \Delta\mu=\mu_p-\mu_{\mathrm{ctrl}} $ 在全部扰动和基因上展平后计算 Pearson 相关，用于衡量模型能否捕获差异表达的全局模式。

**Delta 范数比 **$ \rho $**。** $ \rho=\mathrm{mean}_p(\|\Delta\hat{\boldsymbol\mu}_p\|_2/\|\Delta\boldsymbol\mu_p\|_2) $。远小于 1 的值表示保守塌缩。

### A.8 分布式训练细节
**FSDP2 配置。** Fully Sharded Data Parallel（FSDP2）[94] 对 `ModernTransformerEncoderLayer`、`TransformerEncoderLayer` 和 `CrossAttnBlock` 三种模块进行逐层封装。74% 的参数位于逐层分片单元中，26% 位于根模块（嵌入、解码器）。检查点使用 `FULL_STATE_DICT`。

**激活检查点。** 按 TorchTitan 模式 [96] 在 FSDP 准备前应用：activation checkpoint → `torch.compile` → FSDP 分片，从而避免 FSDP2 与激活检查点封装器之间的 dtype 不匹配。

**模型 FLOPs 利用率：**

$ \mathrm{MFU}=\frac{4\times\mathrm{FLOP}_{\mathrm{fwd}}}{t_{\mathrm{step}}\times N_{\mathrm{GPU}}\times F_{\mathrm{peak}}}.\tag{A41} $

系数 4 来自 1 倍前向 + 1 倍激活检查点重计算 + 2 倍反向；H200 bf16 的 $ F_{\mathrm{peak}}=989 $ TFLOP/s。X-Cell-Ultra 在 64 块 H200 上每步 12.3 秒，达到约 41% MFU。

**训练时间估计：**

$ t_{\mathrm{epoch}}=\frac{|\mathcal D|}{\mathrm{oss}}\times t_{\mathrm{step}},\quad
t_{\mathrm{run}}=n_{\mathrm{epochs}}\times t_{\mathrm{epoch}},\tag{A42} $

其中 $ |\mathcal D| $ 为数据集中的细胞集合数，oss 为优化器步长（每次梯度更新的集合数）。逐层 FSDP 封装将每步耗时从约 17 秒降至约 12.3 秒，改善 28%。

### A.9 热启动词表重映射
用数据集 $ \mathcal D_A $ 训练的模型热启动，并在 $ \mathcal D_B $ 上微调时，基因词表可能不同。X-Cell 通过多分辨率查找构建重映射 $ \pi:\mathcal V_B\to\mathcal V_A $：

1. 在特征集间直接匹配 ENSEMBL ID。
2. 通过 GTF 参考匹配基因符号（符号 → ENSEMBL → 特征索引）。
3. 未映射基因获得 `<mask>` token 索引（共享嵌入）。

强制要求 95% 的重叠阈值；若成功映射的基因不足 95%，热启动失败。重映射张量注入 collator，使 $ \mathbf T $ 中的基因索引始终引用预训练词表。

### A.10 数据管线
#### A.10.1 集合构造
MMD 数据加载器为分布级训练构建分层的 $ S $ 细胞集合。对每个“情境—扰动—批次”组，打乱细胞索引并切分为大小 $ S $ 的集合；不完整集合通过有放回采样补齐。对每个扰动集合，从相同情境与批次抽取匹配的对照（NTC）集合；若批次特异 NTC 细胞不足，则回退至情境级 NTC 池。

#### A.10.2 预处理
基因表达预处理为：原始计数 → CP10K 归一化（$ x_g\leftarrow10^4x_g/\sum_gx_g $）→ $ \log(1+x) $ → 通过 GRCh38-2024-A GTF 参考过滤蛋白编码基因。对已预归一化的数据集（Replogle–Nadig），跳过 CP10K 和 log1p。下采样至上下文长度 $ G'\le4,000 $ 时随机选择基因，并强制把被扰动基因放在位置 1（CLS 位于位置 0）。

#### A.10.3 外部扰动嵌入
对每个扰动基因 $ p $，从参考文件加载 5 种预计算嵌入：

+ ESM-2 [38]：$ \mathbf z_{\mathrm{ESM}}\in\mathbb R^{5120} $，蛋白质语言模型表征；
+ STRING [40, 41]：$ \mathbf z_{\mathrm{STRING}}\in\mathbb R^{512} $，蛋白—蛋白相互作用网络嵌入；
+ GenePT [19]：$ \mathbf z_{\mathrm{GenePT}}\in\mathbb R^{3072} $，LLM 产生的多模态基因表征；
+ DepMap [42]：$ \mathbf z_{\mathrm{DepMap}}\in\mathbb R^{1150} $，跨癌细胞系的遗传依赖谱；
+ JUMP-Cell Painting [43]：$ \mathbf z_{\mathrm{CP}}\in\mathbb R^{259} $，U2OS 细胞形态学表型特征的 PCA。

每种嵌入可在 collate 前选择性地进行 LayerNorm 归一化。缺失嵌入（基因不在来源数据库中）以 0 填补，并通过传给交叉注意力作为 key padding mask 的布尔掩码标记，使模型学会忽略缺失来源。

## 附录 B：基准实现细节
### B.1 Cell2Sentence-Scale 扰动预测基准
#### B.1.1 Cell2Sentence-Scale 模型
Cell2Sentence（C2S）把单细胞基因表达谱转换为自然语言“细胞句子”。句子由按表达量降序排列、以空格分隔的基因名组成，使自回归语言模型可以预测细胞对扰动的响应（Levine 等，2023；Rizvi 等，2025）。我们评估该模型的大规模版本 Cell2Sentence-Scale，并将 C2S-Scale-Gemma-2-2B 与 C2S-Scale-Gemma-2-27B 同 X-Cell 比较。这两个 Gemma-2 语言模型在 CellxGene 和 Human Cell Atlas 的 5,700 多万个人及小鼠细胞上预训练。扰动预测被表述为序列到序列翻译任务：给定对照细胞句子和扰动标签，模型生成预测的扰动后细胞句子。

#### B.1.2 细胞句子数据准备
对每个基准数据集（Replogle–Nadig 及 Parse PBMC 零样本/少样本数据集），按扰动级留出把细胞划分为互不重叠的训练集与测试集，以支持零样本评估。使用 GRCh38-2024-A 参考 GTF 将 Ensembl ID 映射为 HGNC 基因符号。表达矩阵经 log1p 归一化（与 C2S 预训练约定一致），再用公开 GitHub `cell2sentence` 库转换为 Arrow 支持的细胞句子数据集。

**提示格式与对照—扰动细胞配对。** 每个训练样本把一个对照细胞与一个扰动细胞配对。对照细胞（Replogle–Nadig 中标为 `non-targeting`，Parse 中标为 `PBS`）全局汇总，再按 C2S 扰动预测教程（Tutorial 10）的方法，以均匀随机有放回采样与扰动细胞配对。遵循标准 C2S 实现，不按批次、细胞类型或其他 `.obs` 元数据匹配协变量。提示模板为：

> 给定以下由 {num genes} 个表达基因组成、代表某细胞基础状态的细胞句子，请预测施加扰动 {perturbation name} 后的细胞句子。对照细胞句子：{control cell sentence}。扰动后细胞句子：
>

期望响应为扰动细胞 top-K 基因句子，末尾加句号。每细胞使用表达量最高的 1,000 个基因（`top_k_genes=1000`），覆盖度显著高于 C2S 教程默认的 200 个基因。

#### B.1.3 在新数据集上训练 C2S-Scale
使用 HuggingFace Trainer、Accelerate 和 FSDP 进行多节点分布式全参数微调，不采用 LoRA 或 adapter 层；训练运行于 Oracle OCI 的 H200 集群。按照 C2S 的 `loss_on_response_only=True` 约定，仅在响应 token 上计算训练损失，提示 token 的标签掩为 −100。关键超参数如下：

+ **上下文长度**：总计 4,096 token，提示与响应各占一半（`response_ratio=0.5`）。按每个基因名约 4 token 估算，截断后可容纳每个细胞句子所指定 1,000 个基因中的 500 个。提示与响应分别截断，确保模型始终有响应 token 可学习，防止训练塌缩。
+ **批量大小**：每设备 4，梯度累积 4 步，使用 16 块 GPU（2 个节点，每节点 8 块 H200），有效批量为 256。
+ **学习率**：2B 与 27B 均为 $ 10^{-6} $，采用余弦衰减及 3% 线性预热。
+ **Epoch**：1，即单次遍历训练集。
+ **FSDP 策略**：`FULL_SHARD`，对 `Gemma2DecoderLayer` 使用 `TRANSFORMER_BASED_WRAP`。多节点通信经 RDMA 使用 NCCL，并以 Gloo rendezvous。

token 化数据集缓存到共享网络文件系统存储，并以 `keep_in_memory=True` 加载，从而在多节点 NFS 上由内存映射 Arrow 文件训练。HuggingFace 模型缓存设为共享 NFS 目录，保证全部节点访问相同下载权重。

#### B.1.4 C2S-Scale 分布式推理
使用 Accelerate 的 `split_between_processes`，跨 GPU 进行数据并行分布式推理。每块 GPU 以 bfloat16 加载完整模型副本并启用 Flash Attention 2；按 rank 显式设置 device map，不使用 FSDP。预测使用贪心解码（`do_sample=False`），`max_new_tokens` 设为总上下文长度的一半。

零样本评估使用未经微调的基础预训练 C2S；微调评估的推理上下文设置与训练一致（总计 4,096，响应比例 0.5）。各 rank 的预测保存为独立 JSON，主进程使用基于轮询的超时机制聚合，以妥善处理潜在 rank 失败，并通过可用 GPU 数量实现近似成倍加速的分布式推理。

#### B.1.5 通过等距回归重建表达值
C2S 生成的是排序基因列表而非表达值。为把预测排序转换回表达空间用于定量比较，我们拟合等距回归模型，将秩位置映射为表达值，并用训练集对照细胞校准：

1. 对每个对照细胞按表达值降序排序，保留前 K 个值。
2. 汇总所有对照细胞的“秩—表达”对，使用 scikit-learn 的 `IsotonicRegression(increasing=True,out_of_bounds="clip")`，在“秩、负表达”上拟合，学习单调递减的秩—丰度关系。
3. 对每个预测细胞句子，按顺序解析基因名并与参考基因词表匹配，再根据预测秩位置从等距模型分配表达值。不在参考词表中的基因被忽略，未匹配位置取 NaN。

该方法比原始 C2S 重建代码使用的线性秩—表达模型（`slope × log(rank + 1) + intercept`）更灵活；等距回归无需预设参数形式，即可捕获经验秩—丰度曲线的非线性形状。

#### B.1.6 评估
使用逐细胞 MAE 比较预测与真实表达矩阵，仅在预测和参考中都存在的基因上计算。MAE 逐扰动和全局聚合。零匹配基因的细胞（模型只生成词表外 token）会被标记，但仍纳入报告。全部指标记录至 Weights & Biases。
