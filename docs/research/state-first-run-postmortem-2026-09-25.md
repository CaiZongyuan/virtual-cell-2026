## 1. 分数究竟说明什么

| 评价 | NTC 对照基线 | 冻结主干 | 解冻主干 |
|---|---:|---:|---:|
| H1 综合分数 | −0.045231 | −0.857072 | −0.855783 |
| H1 原始归一化 MSE ↓ | 1.002242 | 382.131478 | 325.187313 |
| H1 原始 NMAE ↓ | 1.005045 | 25.152131 | 20.701355 |

NTC（non-targeting control，非靶向对照）是携带不靶向任何基因的向导的细胞。NTC 基线把这些细胞重采样后直接当作预测，相当于保守地预测“没有额外扰动效应”。模型应在保留目标细胞背景的基础上预测变化；如果把背景本身预测错，变化信号会被淹没。

H1 对照分数复现 benchmark 参考值，误差小于 `1e-12`。这支持评分链路一致，削弱了“只是评测安装错误”的解释。解冻组的归一化 MSE 约为对照的 324 倍，NMAE 约为对照的 20.6 倍；冻结与解冻只差 `+0.001288` 综合分，不构成成功。

官方 A/B/C 综合分为 **−0.992407**，NMAE 缩放分触及 **−6**，其在六项均值中的贡献就是 −1；其他五项合计只补回约 0.00759。MSE 的缩放分 0 **不表示误差为 0**。分数不是百分比，H1 与 A/B/C 使用不同参考点，不能直接比较绝对数值。

来源：[首轮记录](state-first-run-2026-09-25.md)、[机器可读评分](../../experiments/state_finetune/results/2026-09-25/summary.json)、[官方 FAQs](../Official-website/FAQs.md)。

## 2. 本次补做的诊断

用 [诊断脚本](../../experiments/state_finetune/diagnose_first_run.py) 检查已保存预测：H1 冻结/解冻及 A/B/C 解冻，每组按符号排序取前 3 个靶点、每靶点 400 个细胞，共 15 个条件。按照原导出 seed 和抽样方法重建对照模板，所有预测行的总计数均与对应模板逐行一致。

另在解冻 checkpoint step 1250 上，对 H1/A/B/C 各 64 个对照细胞输入 `non-targeting` 条件，执行 CPU FP32 前向和计数适配的期望值计算，不加入多项式采样噪声。这是校准探针，不是原 GPU bf16 导出的逐位复现。

### 2.1 连无扰动条件也会大幅改写表达组成

先把每个细胞的各基因计数除以该细胞总计数，再对细胞取平均，得到表达比例向量。比较预测与模板的总变差距离（total variation）：

`TV = 0.5 × Σg |平均预测比例[g] − 平均对照比例[g]|`

它的范围是 0–1；0.54 表示两个平均分布之间约有 54% 的表达质量需要重新分配，**不是 54% 的基因预测错误**，也不是比赛六指标中的某一项。

| 无扰动探针 | H1 | A | B | C |
|---|---:|---:|---:|---:|
| 预测与原对照的 TV | 0.5382 | 0.5659 | 0.5913 | 0.5852 |
| 对照拆半的 TV（各 32 个细胞） | 0.0540 | 0.0766 | 0.0959 | 0.0835 |
| 未监督基因总表达比例：预测 / 对照 | 0.9062 | 0.6618 | 0.8149 | 0.6526 |

这直接显示当前模型与计数适配组合没有通过无扰动校准。分布模型不要求每个输出细胞逐行复制输入，但在无扰动时应保持对照群体分布；本诊断比较的是群体平均组成。JSON 另记录把 64 个对照拆成两组各 32 个时的 TV，作为这个小样本的抽样波动参照，不当作精确置信区间。

### 2.2 不同扰动叠加了高度相似的整体偏移

在保存的预测上，计算每个靶点的“预测平均比例 − 匹配模板平均比例”，再比较不同靶点变化向量的余弦相似度：

| 预测组 | 抽查靶点 | 变化方向的两两余弦相似度 |
|---|---|---:|
| H1 冻结 | ACAT2 / ACVR1B / AKT2 | 0.9840–0.9896 |
| H1 解冻 | 同上 | 0.9872–0.9938 |
| A 解冻 | ABCD1 / ACLY / ADNP | 0.9857–0.9905 |
| B 解冻 | 同上 | 0.9608–0.9825 |
| C 解冻 | 同上 | 0.9671–0.9794 |

这些靶点的预测共同偏向几乎同一个方向。真实扰动也可能共享生物效应，因此单凭高相似度不能证明模型完全忽略靶点；结合无扰动探针也发生大偏移，证据更支持“共有的背景/输出校准错误占据了很大部分变化”。尚不能给每个原因分摊官方失分。

### 2.3 “未监督基因回退到 NTC”没有保持其表达比例

当前 [integer_counts](../../experiments/state_finetune/model.py) 的操作是：有监督基因使用模型输出的 `expm1` 权重，无监督基因使用对照 CP10000 权重，最后把所有权重归一化。

设有监督基因权重和为 `S`，无监督基因的对照权重和为 `U`。对一个无监督基因，原对照权重为 `b_g`，最后预测比例是 `b_g/(S+U)`，原对照比例则是 `b_g/10000`。因此它们会被统一乘以：

`预测比例 / 对照比例 = 10000 / (S + U)`

只有 `S+U=10000` 时，回退才能保留原比例。保留每细胞总计数不能修复这件事；多项式采样也只会围绕已经偏移的比例产生计数。

保存的解冻预测中，抽查无监督基因的总表达比例降为对照的 **0.824–0.842（H1）**、**0.615–0.664（A）**、**0.686–0.788（B）**、**0.641–0.759（C）**。这是实测偏移，不只是代码上的可能性。它能解释回退部分被共同压低；不能单独解释所有受监督基因或整份成绩的错误。

小型结果和限制保存在 [postmortem-diagnostics.json](../../experiments/state_finetune/results/2026-09-25/postmortem-diagnostics.json)。早期 H1 文件未写入后加的 `vc2026_export_contract` 属性，JSON 对此保留 `null`；不补写或伪造原文件元数据。模板总计数对应关系已核实，NTC 探针单独记录 checkpoint SHA-256。

## 3. 我在哪些判断上做错了

| 已确认的决策或实现 | 为什么不够可靠 | 当时应该采用的验收点 |
|---|---|---|
| 父模型 2,024 个旧靶点与比赛 300 靶点没有精确符号交集 | 不能把它当成直接兼容比赛的现成模型 | 先声明迁移跨度，在可兼容的小面板验证原模型行为和改造代价 |
| 同时扩大基因轴、替换靶点表示、扩展输出层、移除 batch encoder/辅助 decoder、加入缺测编码 | 多处接口变化混在一起，失败时无法识别是哪一处破坏校准 | 每次改一个主要接口，用相同小验证集测迁移前后误差 |
| 18,536 维输出只继承 1,877 个旧输出行，其余新初始化 | 输出轴齐全不等于已有全基因表达能力；大部分输出需要重新学习 | 先测基线表达重建、输出组成和新旧基因分组误差 |
| 保留 `output_space=gene` 的隐空间残差分支 | 该分支是 `project_out(transformer_output + control_embedding)` 再 ReLU，**并不直接在表达空间把原始对照加回去** | 不能从“有 residual”推断对照基线会被保留；必须实测无扰动分布 |
| 父模型的精确归一化尺度未核验就使用新的 `log1p(CP10000)` | 预训练参数依赖输入含义和尺度；“两组都用同一预处理”只能控制组间比较，不能证明迁移有效 | 把预处理一致性设为迁移前提，无法确认时明确降格为新模型适配实验 |
| 训练按各来源测量基因面板归一化，推理按完整目标轴归一化 | 相同基因的数值会受所用分母影响；缺测 mask 本身不保证消除此偏差 | 同一批细胞在两种面板上做尺度一致性检查 |
| NTC 只作为输入匹配对照，没有作为输出条件参与本次微调 | 缺少约束无扰动输出保持背景的直接校准信号 | 把 NTC 分布校准纳入验证；是否增加训练约束再做受控比较 |
| 优先完成冻结 vs 解冻比较，没有先建立有效的适配基线 | 只回答“一个很差的适配器上更新主干是否略好” | 对照基线和表达校准先验收，失败时切换为诊断 |
| 源内开发损失用于选模，而目标是未见背景泛化 | 相同背景的留出细胞不能检验迁移到新细胞背景 | 保留独立背景的验证，并监测与任务相关的原始误差 |

上述接口改动都可在 [model.py](../../experiments/state_finetune/model.py)、[data.py](../../experiments/state_finetune/data.py)、[train.py](../../experiments/state_finetune/train.py) 核对；父模型分支见 [固定上游源码](https://github.com/ArcInstitute/state/blob/9bbfe78a434a55205e4de834e1ea99f85f7a3add/src/state/tx/models/state_transition.py)。

这些是确定发生的设计与流程问题。**尚未证明哪一项对总误差贡献最大。** 特别是：扩大绝对输出头、预处理变化、源内表达先验和靶点泛化不足，需要逐项消融才能比较。小探针显示目标对照在各训练源测量面板内的表达质量占比约 0.795–0.903，证实面板分母存在差异；这个幅度本身不能解释全部 TV≈0.6 的偏差。

训练仅覆盖三个细胞背景、254/300 个比赛靶点和 10,480/18,533 个比赛基因，也是限制。但资源少或覆盖有限不构成跳过基础校准的理由；应当先用更保守的预测和更小的实验控制失效范围。

## 5. 下一轮分阶段门槛

以下是复盘后的建议，不代表本次已经启动新训练或获得新的成绩。

1. **冻结失败证据，复现最小基线。** 保留本轮权重、环境、预测和分数；NTC 重采样及同一计数适配器的恒等输入作为对照。确认 H1 面板、预处理和原始误差口径，再做新模型。若计数适配器就引入系统性比例漂移，先修正并单独验证。
2. **验证无扰动与表达尺度。** 核实父权重预处理，在固定的小面板做 NTC→NTC 群体分布检验，比较模型偏移与对照随机拆分的波动。检查新旧输出基因、受监督/未监督基因和各背景。只有校准回到对照波动附近，才进入扰动学习；数值阈值依据多次对照拆分预先确定，不事后为模型放宽。
3. **一次验证一个建模变化。** 优先试保留目标对照基线、学习受限扰动变化的方案；残差的空间、尺度和全局归一化都需要显式定义。输出头、靶点编码和主干解冻分开比较，加入从零初始化或简单效应迁移对照，识别预训练本身是否有用。此路线是待验证工程假设，不宣称优于 State 原方法。
4. **用固定的未见背景验证收益。** 先跑便宜的均值/组成诊断，再跑完整六指标；与 NTC 及简单模型比，而不只在两个差模型之间选较好者。H1 已经用于诊断，之后若据此反复调参，它就是开发验证集；需另留整背景确认，不能继续称其为完全未触碰测试集。对通过门槛的候选再做种子重复。
5. **完整导出与下一次提交。** 只有前述科学验收通过，才花资源生成 A/B/C 大文件、打包并提交提分候选；若目标仅是验证提交合同，单独命名和记录工程测试，不把它描述为模型改进。首次负结果提交原本已有授权，后续关键是改进决策质量。
