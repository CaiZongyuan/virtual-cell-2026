## 固定 H1 比较

沿用 benchmark v0.2.0、126 targets × 400 cells、18,080 genes，cell-eval2 0.16.0 / pdex 0.3.0，六项 `from_replicate` 分数取均值。H1 是开发背景，标签只交给评分器；Jurkat 本轮未再次用于调参或确认。

| 方案 | H1 综合分 ↑ | 原始归一化 MSE ↓ | 原始 NMAE ↓ |
|---|---:|---:|---:|
| 非靶向对照重采样 | −0.045231 | 1.002242 | 1.005045 |
| 经验迁移，强度 0.5 | **0.163874** | 1.303612 | **0.986160** |
| 保守经验迁移，强度 0.2 | 0.080502 | **1.018687** | 0.987548 |
| 加法均值迁移，强度 0.5 | 0.057952 | 3.575863 | 1.353180 |
| 预训练 State 残差 | 0.081697 | 1.024098 | 0.989496 |

保守缩放降低了均值误差，却降低了综合分。加法方案允许在原为零的位置增加分子，其强度由来源背景排除校准选定：600 个条件、201 个靶点，来源均值误差代理比为 0.727812；但在 H1 上误差明显变差。这表明该来源代理不足以保证 H1 上的迁移收益，不能把“能填零”本身视为改进。

State 复用公开权重的既有后代，采用零初始化有符号输出头、固定训练锚点、成对靶点差异损失及固定 0.1 残差权重，训练 6,000 步。来源开发细胞损失为 0.152172，零修正为 0.171487；H1 仅比同强度的保守经验方案高 0.001194，没有达到预定接受门槛。这是当前适配方案的负结果，不是所有 State 方法无效的证据。父权重原始归一化和历史暴露仍未完全核验。

候选接受规则提前固定为：综合分至少超过 incumbent 0.01，原始 MSE 不超过 incumbent，NMAE 不超过其 1.1 倍。三组新候选均未通过，继续保留 incumbent。[实验协议与源码](../../experiments/effect_calibration/README.md)、[冻结选择](../../experiments/effect_calibration/results/2026-09-26/selection.json)。
