# 可靠性加权迁移实验（2026-09-26）

状态：数据汇总、三个候选导出及 State 微调已完成；完整 H1 评分进行中。
此时尚无本轮新官方分数，不能把来源诊断或训练损失当作比赛提升。

## 已验证的问题与边界

旧方案的 254 个有监督官方靶点全部来自 GWPS/K562。只使用既有 GWPS 训练
细胞，将每个靶点随机分成两半，排除直接靶基因并保留对照均值 >0.1 CP10K
的基因，两个效应向量的余弦相似度中位数为 **0.0396**。共用对照可能抬高
该数值，因此只能作为效应不稳定的诊断，不能视作独立生物重复或官方失分的
因果证明。[逐靶点诊断](../../experiments/reliability_transfer/results/2026-09-26/audit/gwps-reliability-diagnostic.json)。

本轮保留固定 H1 benchmark 与评价器、模型选择规则、生成种子和三个候选上限，
详见[协议](../../experiments/reliability_transfer/README.md)。未将 H1 或 Jurkat
扰动表达加入训练，未从零预训练基础模型。使用公开 State 权重的既有后代，
其原生尺度和预训练历史的已知缺口不因本轮微调而消失。

## 来源数据扩充和效应不确定性

| 来源 | 新训练扰动细胞 | 来源×靶点条件 |
|---|---:|---:|
| GWPS | 101,701 | 638 |
| K562 essential | 30,215 | 242 |
| RPE1 | 31,366 | 271 |
| HepG2 | 15,307 | 227 |
| 合计 | **178,589** | **1,378** |

逐项排除旧开发细胞的原始行号，训练不再限于每条件 256 个细胞；保留符合
对照要求的全部训练细胞。每个来源保留原技术批次，以该靶点的批次比例匹配
NTC 均值。计算细胞归一化计数均值、方差和 log effect 的近似抽样方差。
CP10K 指把每细胞的基因计数按总量缩放到一万，仅用于效应估计；提交和评分
预测仍是非负整数原始计数。

全量条件覆盖 643 个不同靶点。官方靶点覆盖 **254 → 267 / 300**，但仍只
来自 GWPS；H1 canonical 面板 **110 → 112 / 126**。当前输出基因测量范围
没有因此扩大。[汇总与实际来源](../../experiments/reliability_transfer/results/2026-09-26/sources/)。

经验 Bayes 收缩把效应大小与不确定性一起考虑：同样的变化，如果抽样误差很
大，预测会更接近零；强且可靠的效应保留更多。本实现用固定尺度的正态混合
先验、100 次 EM、每来源最多 200,000 个训练观测拟合权重，不根据 H1 分数
调参。GWPS 的效应 RMS 从 0.1675 降为 0.0551；这只说明收缩发生，尚不证明
它保留了正确的生物信号。[文献依据与实现区别](reliability-transfer-literature-2026-09-26.md)。

## State 微调与验证代表性

有符号、零初始化输出头沿用上一轮固定训练配方：6,000 步、相同公开权重
后代初始化、固定四锚点、成对差异损失、最后两层有限解冻；监督换为去噪后的
来源效应，经验先验强度固定 0.5，残差强度固定 0.1。训练循环 902.49 秒，
来源开发细胞诊断损失 0.150228，零修正为 0.169989。它不是整背景未见验证，
也不是独立的官方成绩。[训练记录](../../experiments/reliability_transfer/results/2026-09-26/state/complete.json)。

这条残差支路要求同一个靶点在另一生物背景有监督，因此仍只训练 **201 个
跨背景靶点，官方靶点交集为 0**；全模型对官方靶点的直接监督来自经验先验。
不能把“完成 State 微调”表述为残差已学过 267 个官方靶点。
[结构覆盖核验](../../experiments/reliability_transfer/results/2026-09-26/neural-target-coverage.json)。

在候选完整分数产生前，按外部训练来源预先固定 H1 诊断分组：76 个仅 GWPS
支持的靶点、36 个多生物背景靶点、14 个未支持靶点。完成后分别报告逐靶点
原始指标，检查总体提升是否掩盖官方更常见的单来源条件。分组不改变已经冻结
的选模/发布门槛，不将 H1 子组等同于官方背景。
[预先固定的分组](../../experiments/reliability_transfer/results/2026-09-26/diagnostic-target-groups.json)。
