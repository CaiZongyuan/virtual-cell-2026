## 2. 改变旧方案的新事实

这不是只有输出维度不匹配的问题。State Transition（ST，状态转移模型）还需要知道要敲低哪个靶基因。候选权重使用 one-hot 靶点编码，即每个已知靶点有独立编号；词表之外的靶点没有已经学好的输入表示。

| 核查对象 | 实际结果 | 对方案的影响 |
|---|---|---|
| `ST-HVG-Replogle/zeroshot/jurkat` 的靶点词表 | 2,024 个名称；与 A/B/C 的 300 个靶点精确符号交集为 **0** | 不能直接作为全部比赛目标上的未微调预测基线 |
| 同一词表与 H1 training 的 150 个靶点 | 覆盖 **48**，缺 **102** | 不能直接运行完整 H1 benchmark 后声称它是原模型的完整基线 |
| 父权重的 2,000 个高变基因与 A/B/C 测量轴 | 交集 **1,877**，缺 **123** | 缺测不能当作真实零表达；输入也要适配 |
| `st-x-replogle-full/k562_0.99` 的 6,546 个基因 | 与 A/B/C 交集 **6,197**，缺 **349** | `full` 不等于比赛全基因；原生重建层也增加迁移复杂度 |
| 官方 SE 变体 | 所检查配置仍用 2,024 维 one-hot 靶点 | 换用 SE 表达嵌入不会自动解决新靶点问题 |
| H1 training 与 A/B/C 靶点 | 150 与 300 中仅 **13** 个交集 | 只加 H1 训练，不能据此认定已取得全部比赛靶点监督 |
| scPerturb K562 GWPS 的扰动类别 | 9,867 个标签，覆盖 A/B/C **272/300**；缺的 28 个也均不在 H1 training 中 | 仅扩 one-hot 并加入 GWPS/H1，仍不能给所有比赛靶点提供监督 |

以上是名称精确匹配结果，不能推断官方刻意排除了某类基因，也没有证明别名映射全部完成。符号映射如需修订，必须采用可核验映射并保存前后清单，不能靠字符串相似度合并。

可复核来源：

- [H1 靶点清单](https://storage.googleapis.com/arc-institute-virtual-cell-atlas/virtual-cell-challenge/2025/train/pert_counts_Training.csv)：2,824 bytes；SHA-256 `633d202be221418bdbac16efd8cb169666de0ef6469a4e9bfdfb64666ea81a89`。

## 3. 推荐实验：共同适配后，比较冻结与解冻

原权重对比赛靶点没有定义完整的预测。先建立共同的输入/输出适配，再比较是否微调 State 主干，才有可解释的对照。

1. 选择一个固定的父 checkpoint，审计实际配置、预处理尺度、基因/靶点字典与预训练来源。优先检查上述 HVG 权重，不仅凭模型文件名宣称某背景从未出现。
2. 建立统一的新靶点接口。已核数据不能提供全部比赛靶点监督，因此推荐接入连续靶点特征，优先核验官方 ESM2 资产。ESM2 是从蛋白质序列产生特征向量的模型；这里复用向量并训练它到 State 条件空间的映射，不以训练 ESM2 本体为首投要求。它允许为未监督靶点构造输入，不保证响应预测正确。K562 GWPS 是新增扰动监督的首要候选，正式下载后仍须核对细胞数、质量和目标字段。
3. 固定相同的基因轴适配、未知批次处理、计数生成器、训练与评价划分。两组从同一初始化或共同适配 checkpoint 分支。
4. **冻结组**：保持预训练 Transformer 主干冻结，训练预先声明的靶点适配和外围参数。
5. **解冻组**：相同外围参数可训练，同时解冻主干；采用相同训练数据、采样顺序、有效批量、更新步数和评价流程。分别记录参数数目、计算量和峰值，不能把相同步数称为相同计算量。

这个实验回答的是：**在获得同样的新靶点接口与监督后，解冻 State 主干是否改善未见背景预测。** 它不单独证明预训练优于从零训练；后者需要额外的随机初始化对照，不纳入首次提交的默认范围。

连续特征必须覆盖全部预测目标，保存蛋白/基因映射与来源；任何缺向量都显式失败并补齐可核验资产，不能静默给零向量、随机向量或 NTC 结果。分别记录“有输入向量”和“有实际扰动训练标签”，不能把两者称为同一种覆盖。该接口属于比赛适配，不把官方 starter 已有的 ESM2 能力列为模型创新。

## 4. 分阶段推进

实现与复现说明见 [experiments/state_finetune](../../experiments/state_finetune/README.md)。正式协议固定为 500-step 共同预热，以及各 1,500-step 的冻结/解冻分支；4×64 个细胞/step。先运行的 100-step pilot 仅验证完整流程，不作为两组的共同初始化。

| 阶段 | 工作与验收产物 |
|---|---|
| 1. 数据与权重合同 | 固定版本和校验和；输出每个比赛/验证靶点的监督来源、细胞数、对照、基因测量轴和已知训练暴露；明确缺口 |
| 2. 可运行与可导出 | 独立环境、参数迁移清单、少量前向/反向检查；测 GPU 与主机峰值；生成小型整数计数文件并检验导出合同 |
| 3. 冻结实验协议 | 固定训练/开发/最终留出背景、评价面板、种子、计数生成和选模规则；参考扰动标签仅对相应训练或评价用途开放 |
| 4. 两组受控训练 | 冻结/解冻两组 checkpoint、训练曲线、参数与资源记录；首轮仅改变主干是否可训练 |
| 5. 离线比较 | 相同数据上报告官方指标实现可支持的完整结果、逐靶点诊断与采样波动；固定计数转换后比较，正负结果都保留 |
| 6. 首次官方评分 | 分块生成 A/B/C；完整预检与 `.vcc` 打包；使用参赛账户提交；保留文件校验和、提交 ID、状态和真实得分 |

推荐首轮用 K562 GWPS 做新增监督、H1 做固定开发留出背景，复用已有六指标 benchmark；首轮不把 H1 扰动加入微调训练。必要的旧任务混合数据只在数据审计后明确清单，禁止加入 H1 扰动。连续特征必须支持 H1 的完整评价面板；如果只评子面板，需要明确称为子面板诊断，不能复用完整面板的总分含义或伪装成 canonical H1 评分。H1 一旦进入微调训练，就不能继续充当该实验的未见背景。

H1 是否未被父 checkpoint 见过，仍须结合发布配置、来源说明与训练清单核验；只有名称或数据来源线索时如实标为暴露证据不完整。Jurkat 发布留出协议可作为补充验证候选，首投不默认要求额外完成四背景留出。对 H1 的有限选模使它成为开发集，不能再称为独立最终测试。

主机 RAM 只有约 31 GiB，原生推理存在整体加载/稠密化路径，因此采用按背景、靶点分块读写。官方打包与评分的实际峰值也须实测，不凭显卡容量承诺全流程可运行。

## 5. 已选定的研究范围

**D1：实验主张。** 采用第 3 节“共同适配后的冻结组 vs 解冻组”作为本轮微调收益的定义，替代对 300 个目标不存在的原始模型预测作直接比较。

**D2：第一轮输出范围。** 采用 H1/比赛基因轴并集的全基因适配，按名字迁移父模型输入列和输出行，两组共享新增层。保留父权重在 `output_space=gene` 下的计算分支，并扩展其输入/输出维度；完整基因轴不要求额外切换到 `output_space=all` 的大型重建层。使用测量 mask 区分真实零计数与未测量，损失只计算该来源有测量的基因。

全基因输出合同不等于所有基因都有扰动监督。元数据实测：GWPS/K562-essential/RPE1/HepG2 的并集覆盖 A/B/C 10,480 个基因；加入 Jurkat 也仅为 10,964。对于最终训练清单中完全未测量的基因，不使用随机输出层冒充学到的效应，统一回退对应目标背景 NTC 的表达权重，记录覆盖 mask。两组保持相同回退；后续提分可另扩有用数据，首轮不因此隐瞒覆盖限制。

原始计数是测序后去重得到的非负整数分子数；模型的归一化浮点输出不是原始计数。两组必须使用同一个计数生成器和同一批对照模板。当前尚未证实发布权重的预处理一定是 CP10K，不能从通用 CLI 推定尺度；转换方式要在尺度核验后固定。
