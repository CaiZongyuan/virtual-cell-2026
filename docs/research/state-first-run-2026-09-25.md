## 2. H1 对照实验

H1 是人胚胎干细胞背景。本轮微调没有使用其扰动细胞；评价采用固定的 **126 targets ×400 cells、18,080 genes** 社区 benchmark，复用官方 `cell-eval2==0.16.0` 和 `pdex==0.3.0`。下表均取 `scores.csv` 的 `from_replicate` 列。

| 方法 | H1 综合分数 | 原始归一化 MSE ↓ | 原始 NMAE ↓ |
|---|---:|---:|---:|
| NTC 对照基线 | **−0.0452306877** | 1.002242 | 1.005045 |
| 冻结 State 主干，训练适配层 | −0.8570715546 | 382.131478 | 25.152131 |
| 适配层与 State 主干一起训练 | −0.8557832998 | 325.187313 | 20.701355 |

NTC（non-targeting control，非靶向对照）基线通过重采样未靶向任何基因的对照细胞生成预测。实测分数与 benchmark 作者给出的 `−0.045230687652238` 相差小于 `1e-12`，支持本次评价链路的数值一致性。

## 3. 实际训练了什么

父模型为 Arc 发布的 `ST-HVG-Replogle/zeroshot/jurkat`，revision 为 `bb6a9562cbbf1fd152df14cc53b4cc7517c77175`。State 源码固定在 `9bbfe78a434a55205e4de834e1ea99f85f7a3add`，保留 328 维、8 层、64-cell 集合的主干。

原权重的 2,024 个靶点与比赛 300 个靶点没有精确符号交集。本轮接入官方 ESM2 蛋白序列特征，训练连续靶点接口；其初始化拟合父模型已有靶点表示。原 one-hot 字典的全部 2,024 个坐标顺序已经逐项核验，不按未经核实的数组位置迁移。

内部输入/输出轴扩展为 H1 与比赛基因并集的 18,536 维，按基因名称继承 1,877 个旧输入列/输出行，并加入测量缺失标记。使用父模型的 `output_space=gene` 计算分支扩展维度，没有额外引入 `output_space=all` 的大型重建层。

| 阶段 | 更新步数 | 选用的 checkpoint 步数 | 可训练参数 |
|---|---:|---:|---:|
| GWPS pilot，只验证流程 | 100 | 不用于正式比较 | 52,187,264 |
| 共同接口预热 | 500 | 400 | 19,937,976 |
| 冻结组 | 1,500 | 1,500 | 19,937,976 |
| 解冻组 | 1,500 | 1,250 | 52,187,264 |

模型总参数为 62,683,264。两组从同一个预热 checkpoint 出发，采用相同来源、采样顺序、种子 42、4×64-cell 有效批量、计数生成器和源内开发集选模规则。接口学习率 `1e-4`，解冻主干学习率 `1e-5`；使用 AdamW、零 weight decay、梯度范数截断 10、bf16 前向与 FP32 Energy 分布损失。相同更新步数不等于相同计算量。

该对照回答的是：**在同一任务接口适配之上，进一步更新主干是否改善预测。** 它没有比较预训练与从零训练的优劣，也没有把接口尚未适配的原权重当作可预测全部比赛靶点的基线。

## 4. 训练数据与覆盖边界

| 来源 | 实际准备的细胞记录数（含对照） | 源/靶点条件数 |
|---|---:|---:|
| K562 GWPS | 184,222 | 603 |
| K562 essential | 42,558 | 209 |
| RPE1 | 35,598 | 189 |
| HepG2 | 14,069 | 82 |
| 合计 | **276,447** | **1,083** |

四个文件代表三个细胞背景，两个 K562 screen 不作为两个背景计数。训练面板包含比赛/H1 靶点以及 256 个旧任务靶点；每个源/靶点至少有 64 个可用细胞，最多保留 256 个扰动细胞，另保存匹配批次的 NTC。集合按源/靶点组成，每个抽样扰动细胞匹配同技术批次的对照。源内开发集采用不重叠的扰动细胞，不称为未见背景验证。

最终训练记录对比赛 **254/300** 个靶点具有直接监督；其余 46 个仅有可用的蛋白特征和模型迁移先验。四个来源的测量并集覆盖比赛 **10,480/18,533** 个基因，另外 **8,053** 个基因使用固定的目标 NTC 权重回退。因此，完整输出轴不代表所有基因的扰动响应都已学到。

H1 旧符号 `TAZ` 的官方 Ensembl ID 为 `ENSG00000102125`，对应 HGNC 的 `TAFAZZIN`。特征查找使用显式映射，输出标签保留 `TAZ`；没有将其误映射到另一个也使用 TAZ 别名的 `WWTR1`。

## 5. 计数生成与结论边界

模型在显式定义的 `log1p(CP10000)` 空间训练。输出转为非负线性权重，在完全没有测量监督的基因上采用目标 NTC 权重，随后归一化，并用对应 NTC 模板的每细胞总计数进行多项式采样，得到非负整数计数。两组使用相同流程与生成种子。

这里保留的是归一化前的 NTC **权重**，不是最后的比例或期望计数：全局权重和若偏离 10,000，所有回退基因仍会被一起缩放。不能把该策略解释为“这些基因保持原对照表达”。

这包含需要后续检验的**工程假设**：采用固定对照计数深度、如何补全未监督基因、以及新预处理尺度对迁移的影响。父权重的原始归一化尺度尚未完整核验。本轮只在一个留出背景和一个生成种子上比较，没有量化多种子波动；父模型的训练暴露依据发布资料，缺少逐细胞训练清单。

**下一轮优先诊断的方向：**先检查未扰动输入的基线重建、跨背景表达尺度以及计数适配，再考虑扩大主干训练。当前误差不能单凭综合分数归因于其中某一项；这些是待验证方向，不是已定位的模型机制。

## 6. 工程验证与交付

- 使用 uv、独立 Python 3.12 环境和用户指定的清华 PyPI 镜像；CUDA PyTorch 来自官方 cu126 索引。
- RTX 3090 24 GB、31 GiB 主机内存完成全部工作。PyTorch 记录的训练显存峰值约为冻结组 0.65 GiB、解冻组 1.03 GiB；训练进程主机峰值约 8.9 GiB。
- 8 项数据/计数/恢复合同测试、1 项 SwanLab 启动回归测试、实际 GPU 前向/反向检查均通过。
- 首次打包因 SciPy 整数求和的整体 int64 转换触发内存终止；采用分块数值检查、分块 FP64 行求和和稀疏索引复用后，全部验证保留，真实打包峰值降到约 17.5 GiB，退出码为 0。原版与优化版的打包解压结果通过 counts/obs/var 一致性及无效输入边界测试。
- H1 评分保留相同统计实现和面板；增加计算线程，并在对照基线中缓存已核验的固定 NTC 矩阵，复用完成的基因块。最终对照分数复现了作者参考值。
- SwanLab 的错误 3500 来自首份日志产生前启动看板，数据库 Proxy 随后未重新初始化。启动包装等待已记录的实验并固定端口，回归测试覆盖该真实流程。
