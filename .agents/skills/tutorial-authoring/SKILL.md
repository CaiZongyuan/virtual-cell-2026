# Virtual Cell 教程制作

规则由仓库根目录 AGENTS.md 的「教学模式」「教程图片」迁移而来。正文只在教程任务中加载；相对仓库的路径以下均以仓库根目录为起点。

## 按任务加载

- **系统教学或教程正文：**读取 [教学方式](references/teaching.md)，以 `CONTEXT.md` 核对术语、以 `docs/lessons/README.md` 定位课程入口和上下文。
- **生成、修改或审校教程配图：**读取 [配图规范](references/figures.md) 和 `docs/style/README.md`。先确定图的类型，再调用对应工具；风格手册保存命令与环境经验。
- **采用生成式图片：**另读 [图像生成与交付](references/imagegen.md)，使用可用的 imagegen 技能。准确机制、实验结构和数据证据走确定性绘图工具。

只加载当前分支需要的参考。仓库的证据要求、文件体积和密钥规则仍遵循根目录 `AGENTS.md`。

## 完成标准

正文解释完整因果链并标明事实与类比的边界；配图通过相应结构、渲染和局部可读性检查；正文引用最终压缩资产，图源和可复核出处齐全。

绘图前检查依赖是否可用。若 `drawio-skill` 缺失，先在可用技能目录定位；仍缺失则说明此分支的工具缺口，继续可独立完成的正文工作，保持原工具选择和质量要求。迁移教程规则本身不要求安装绘图工具。
