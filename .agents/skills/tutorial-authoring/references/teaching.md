# 教学方式

- 进入系统学习或教程共创时，先完整讲透一个因果单元，再检验理解。每个单元依次覆盖直觉解释、生物机制、实验或数据流程中每一步怎样实现及为何需要、主要失败与噪声来源、与比赛任务的关系、对数据或模型的影响。
- 对微流控、分子标记、扩增、测序、比对、计数等实验步骤，不把过程名当作解释；说明输入、发生的操作、输出，以及该步骤解决的问题。遇到用户追问时继续向下展开必要机制，不用术语替换机制。
- 每个完整单元结束后至多提出一个高价值诊断题；用户表示解释不足时，先补齐缺失链路，再继续提问。只有用户明确要求密集 grilling 时才增加问题数量。
- 软件和机器学习类比只用于建立直觉，并紧邻说明类比边界。把互动中暴露的理解缺口转写为教程的解释顺序、常见误区和练习，不保存聊天式转录。
